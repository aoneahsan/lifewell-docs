Формат экспортируемого файла

Здесь описан файл, который создаёт страница «Экспортировать копию». Другое приложение сможет прочитать его без догадок о содержимом.

Это не особый формат LifeWell. JSON остаётся обычным JSON, а архив — обычным ZIP с файлами CSV.

Три файла​

ФорматИмя файлаТип содержимогоОбъём
JSONlifewell-export-<YYYY-MM-DD>.jsonapplication/jsonВыбранный период; до 5 000 строк на таблицу
CSVlifewell-export-<YYYY-MM-DD>.zipapplication/zipВыбранный период; до 5 000 строк на таблицу
PDFlifewell-export-<YYYY-MM-DD>.pdfapplication/pdfСводка, описанная ниже

Дата в имени файла — ваш местный день, а не день сервера. Имя записывается символами ASCII и выглядит одинаково на всех языках: так его легче найти в папке загрузок.

Документ JSON​

Один объект с коротким заголовком и отдельным ключом для каждой таблицы. Под ключом находится массив строк.

{
  "exportedAt": "2026-09-08T11:04:22.417Z",
  "schema": 1,
  "range": { "from": "2026-01-01", "to": "2026-09-08" },
  "rowCap": 5000,
  "truncated": ["metric_entries"],
  "profile": { "id": "…", "display_name": "…" },
  "conditions": [],
  "medications": [ { "…": "…" } ]
}
Поле заголовкаТипЗначение
exportedAtстрока ISO 8601, UTCКогда создан файл
schemaчислоВерсия формата. Сейчас 1
range.from / range.toдата ISO или nullВыбранный период. null означает отсутствие границы
rowCapчислоПредел строк для каждой таблицы — 5000
truncatedмассив названий таблицТаблицы, достигшие предела. Пустой массив означает, что ничего не обрезано
profileобъект или nullСтрока вашего профиля целиком, а не массив из одной строки

Прежде чем писать программу для чтения файла, учтите три особенности:

  • Таблица без строк представлена пустым массивом, а не отсутствующим ключом. "meals": [] точно говорит, что записей нет; отсутствие ключа оставило бы вопрос.
  • truncated — признак неполного файла. Проверьте его, прежде чем заключить, что у человека нет старых записей.
  • JSON записан с отступом в два пробела. Файл предназначен и для чтения человеком. Одна строка размером восемь мегабайт плохо открывается в текстовом редакторе.

Архив CSV​

ZIP содержит по одному .csv на таблицу с именем <table>.csv. Столбцы соответствуют столбцам таблицы.

ДетальЗначение
Окончания строкCRLF по RFC 4180
КодировкаUTF-8 с меткой порядка байтов
КавычкиПо RFC 4180: кавычки удваиваются, поля с ", ,, CR или LF заключаются в кавычки
Пустая ячейкаnull и undefined оба превращаются в пустую ячейку
Вложенные значенияСохраняются целиком как JSON в ячейке, а не раскладываются по строкам

Два решения могут показаться ошибкой, но они приняты намеренно:

  • Даже пустая таблица получает файл с одной строкой заголовков. Отсутствующий файл нельзя отличить от неудачного экспорта; заголовок подтверждает, что таблицу обработали.
  • Перед текстом ячейки, начинающимся с =, +, -, @, табуляции или возврата каретки, добавляется апостроф. Электронные таблицы могут принять такой текст за формулу. Это защищает того, кому вы передадите файл, например врача. Если вы разбираете CSV программой, а не открываете в таблице, уберите добавленный апостроф.

Метка порядка байтов нужна потому, что Excel на Windows может принять UTF-8 без метки за местную кодовую страницу и испортить имена с диакритикой именно в том инструменте, для которого готовится файл.

Все таблицы в файле​

Шестьдесят пять таблиц, сгруппированных по разделам.

  • Период — строки с датой ограничиваются выбранным периодом. Постоянные строки включаются всегда: список доз без лекарств выглядел бы как потеря данных.
  • В PDF — полностью означает печать строк; только количество означает число и период без строк; не входит означает полное отсутствие таблицы.

Что исключено из каждого формата​

JSON и CSV содержат поддерживаемые таблицы за выбранный период. Строки с датой вне периода не включаются; таблица с более чем 5 000 строками обрезается и называется в заголовке. Форматы позволяют читать или переносить включённые сведения. Восстановить учётную запись из этих файлов через LifeWell сейчас нельзя.

PDF устроен иначе — в этом его смысл. Его могут распечатать, передать сотруднику приёмной и оставить на столе. Поэтому в него попадает то, что полезно прочитать врачу, без остального:

  • Полностью — постоянные записи: состояния здоровья, лекарства, виды показателей и цели, дети, рост, этапы развития, люди, связи, общие ссылки, календарь, напоминания, профиль.
  • Только количество — многочисленные датированные записи: показания, дозы лекарств, приёмы пищи, тренировки, дни цикла, записи о ребёнке, занятия с подсказками, медиафайлы, сохранённые места. Сорок строк из четырёх тысяч были бы выборкой; в документе под названием «ваши записи» она могла бы ввести читателя в заблуждение. Если таблица печатается строками, их будет не больше 60.
  • Не входит в PDF — личный журнал, воспоминания, заметки, страницы альбома, сообщения, ответы сообщества и остальное, что человек написал для себя.
Личный журнал никогда не входит в PDF

Для других разделов это вопрос полезности. Личный журнал — та часть LifeWell, которая не должна оказаться на листе бумаги, забытом на столе. Он входит в JSON и CSV: эти файлы вы открываете сами.

Чего нет ни в одном формате​

Семь видов сведений отсутствуют в любом экспорте. Выбранный период и предел таблицы могут исключить дополнительные строки.

Что отсутствуетПочему
Сами медиафайлыИзображения хранятся в вашем Google Drive. Экспорт содержит ссылку, подпись и дату; байты файлов никогда не хранились у нас
То, чем поделились с вамиЭто чужой журнал, временно открытый вам. Владелец может отозвать доступ, а копия в вашем файле осталась бы
Удалённые строкиУдалённое не возвращается из корзины экспорта: такой корзины нет
Операционные журналыСчётчики пределов запросов, закрытые уведомления и подобное состояние интерфейса, а не ваш журнал
Ваш парольЕго нет. Вход через Google; мы не видим и не храним пароль
Ваш ключ провайдера ИИОн хранится зашифрованным и остаётся действующим секретом. Записать его в обычный файл, который вы можете переслать по почте, значило бы создать утечку
Учёт использования ИИПо нему считают предел, но это не написанные вами сведения

Ещё пять таблиц исключены по той же причине: они содержат секрет или чужие данные.

Что исключеноПочему
Ваши жалобы на публикацииТаблицу нельзя прочитать обычным запросом, в том числе вам. Выгрузка очереди модерации нарушила бы то же правило через другой путь
Контакты донора крови, открытые вамОни выдаются один раз одному человеку и могут быть отозваны. Строка в постоянном файле не соответствует этим условиям
Подключение Google DriveСодержит действующий токен обновления
Запись о покупке PlayСодержит токен покупки, который принимает Google. Право доступа уже есть в файле, в профиле
Закрытые объявленияСведения о том, какие уведомления вы закрыли, относятся к интерфейсу

Ещё четыре таблицы содержат общие справочные данные, а не ваши: список планов, каталог сообщества, базу продуктов питания и одну внутреннюю таблицу проверки доступности сервиса.

Как прочитать файл позже​

Импорта нет. LifeWell не умеет загружать эти файлы обратно в учётную запись.

Формат описан, чтобы файл могла прочитать другая программа: скрипт, электронная таблица, другое приложение или вы сами через пять лет в текстовом редакторе. Это возможно благодаря двум намеренным свойствам:

  1. Каждый идентификатор — настоящее имя столбца базы данных, одинаковое в JSON, CSV и на этой странице.
  2. Заголовок сам называет пределы файла. Неполный файл говорит об этом в первых десяти строках.

Когда меняется эта страница​

При добавлении таблицы в список выше добавляется и её строка. Проверка сравнивает список со схемой в обе стороны: отсутствующая таблица останавливает сборку, а не создаёт незаметный пробел.

Если вы пишете программу чтения, ориентируйтесь на schema. Сейчас значение 1; оно увеличится до того, как изменится смысл описанной выше структуры.
