アクセストークンと認証

LifeWellのアクセストークンは、設定 → ほかのアプリで作成する長い秘密情報です。APIリクエストごとにAuthorization: Bearer <token>として送ります。選んだ権限範囲と有効期限が適用され、1回の操作で取り消せます。利用者に代わって接続するアプリはOAuthを使うため、トークンを渡す必要はありません。

トークンの作り方は？​

  1. 設定 → ほかのアプリ → アクセストークンを開き、新しいトークンを選びます。
  2. あとで分かる名前を付けます。キッチンのカレンダースクリプトなら、トークン1より用途が伝わります。
  3. 権限範囲と有効期限を選びます。
  4. LifeWellはトークンを一度だけ表示します。画面を閉じる前にコピーして安全な場所に保管してください。

以後の一覧には、名前、権限範囲、冒頭の数文字、作成日時、最終利用日時が表示されます。トークン全体は表示されません。トークンを作成するとLifeWellからメールが届くので、心当たりのない作成にも気付けます。

トークンを再表示できますか？​

はい。サインインから10分以内なら再表示できます。トークンの行で表示を選びます。

  • サインインから10分未満：トークンが表示されます。
  • 10分以上経過：LifeWellが理由を示し、再度サインインを案内します。サインイン後は同じ行に戻ります。
  • 二段階認証が有効：10分以内でも、認証アプリのコードが必要です。

何日もサインインしたまま使えるのは便利ですが、盗まれたノートパソコンも同じ状態です。新しいサインインで、操作しているのが本人だと確かめます。再表示は1時間に10回までで、毎回アカウントに記録されます。トークンがメールで送られることはありません。

権限範囲とは？​

記録の各部分には、最大3つの権限範囲があります。

権限範囲許可される操作
<resource>:readその部分を読み取る
<resource>:write追加・変更する
<resource>:delete削除する

account:readは自分のアカウント情報を読み取ります。対象リソースと正確な権限範囲名はOpenAPIファイルに記載されています。

削除の権限は自動的には付きません。 書き込みに削除は含まれず、削除権限は画面でも別に表示され、選ぶまで無効です。作成後にトークンの権限を増やすことはできません。追加が必要なら新しいトークンを作り、古いものを取り消してください。管理者権限を持つトークンは作れません。

トークンの有効期間は？​

30日、90日、365日から選べます。期限の7日前にLifeWellからメールが届きます。期限後はトークンが使えず、リクエストには401が返ります。

トークンの交換・取り消しは？​

  • ローテーションで新しいトークンを作ります。古いものは、スクリプトに差し替えるため24時間使え、その後取り消されます。それまでは両方が一覧に表示されます。
  • 取り消すとすぐに使えなくなり、次のリクエストには401が返ります。確認のため2回押します。ダイアログはありません。

LifeWellアカウントを削除すると、すべてのトークン、接続済みアプリ、Webhook、フィードも取り消されます。

アプリはトークンなしでどう接続しますか？​

AIアシスタントと同じくOAuth 2.1を使います。アプリはLifeWellの同意ページhttps://lifewell.aoneahsan.com/oauth/consentを開き、次の内容を表示します。

  • アプリ名と、承認後に戻るURL。
  • 接続するLifeWellアカウント。
  • 求める権限。読み取り・書き込み・削除に分けた平易な説明と、個別のチェック欄。削除は最初は選択されません。
  • 横並びの承認と拒否。

二段階認証が有効なら、承認時にコードが必要です。接続後、アプリは設定 → ほかのアプリ → 接続済みアプリに表示され、名前の変更や取り消しができます。取り消すと次のリクエストからアクセスできません。現在のサインイン期限までは待ちません。同意ページについてはAIアシスタント（MCP）もご覧ください。

利用制限は？​

各トークンと接続済みアプリは、1分間に120リクエストを送れます。さらに、アカウント全体の1日上限はプランによって決まり、Freeは5,000件、ProとFamilyは50,000件です。すべてのトークンとアプリで共有するため、トークンを増やしても上限は増えません。設定 → ほかのアプリには、上限と当日の件数が表示されます。すべてのレスポンスに次のヘッダーが含まれます。

ヘッダー意味
RateLimit-Limit現在の期間に許可されたリクエスト数
RateLimit-Remaining残りのリクエスト数
RateLimit-Reset次の期間が始まるまでの秒数

上限を超えると、APIはRetry-Afterヘッダー付きの429を返します。指定された秒数を待って再試行してください。

同時に大量のリクエストを送ると、LifeWellが受け取る前にホスティング基盤から546が返ることもあります。順番に、または少数ずつ送り、546の場合は1秒後に再試行してください。

エラーの形式は？​

どのルートのエラーも同じ形式です。

{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}

プログラムではcodeを判定してください。messageは人が読むための文で、表現が変わることがあります。失敗したリクエストについて問い合わせる場合は、correlation_idを伝えてください。そのリクエストを特定するために使います。

ステータス主な意味
401トークンがない、誤っている、取り消された、期限切れ
403必要な権限範囲がない（detailsに表示）、または再サインインが必要
404そのIDの記録がない。他人の記録も含む
429利用制限に達した。Retry-Afterを確認

コードの全一覧はOpenAPIファイルに記載されています。
