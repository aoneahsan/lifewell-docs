# 人生阶段

生活中有些阶段，不会年年相同。这个领域就是为它们留的位置。

## 由您的身份决定是否显示的六个页面

个人资料中的一个回答，会决定菜单是否列出以下页面：

| 页面 | 保存什么 |
|---|---|
| 生理周期 | 根据您的情况调整预测，而不是套用其他人的平均值 |
| 备孕 | 时间窗口、检查和笔记，放在一处，不必分散到三个应用和一本笔记本 |
| 排卵 | 周期中可能受孕的日子，并明确提醒周期会变化 |
| 多囊卵巢综合征 | 与其他健康状况一样保存症状、预约，以及诊所告知您的内容 |
| 更年期 | 症状及其在数月中的变化，日后仍能回看 |
| 母乳喂养 | 在孩子自己的记录中保存哺喂及时间 |

选择**男性**会将这些页面从菜单中移开。选择其他任何回答，都会保留全部页面；无论怎样选，都不会删除记录。

从菜单中移开，并不等于消失。已记录的内容会保留；直接前往页面仍可打开。

## 生理周期

`/period` 会记录周期日期，并依据**您自己的**历史预测下一次，而非假设每个人都是 28 天。页面会说明预测的局限：周期有变化，预测也会变化；应用不会把推测的日期说成确定事实。

## 婴儿

`/baby` 保存孩子的早年记录。每个孩子有自己的记录，不会合成一张清单：

- **哺喂**——`/baby/feeding`
- **睡眠**——`/baby/sleep`
- **尿布**——`/baby/diapers`
- **生长**——`/baby/growth`，以图形而非表格呈现
- **成长节点**——`/baby/milestones`

保存的生长图在 LifeWell 内使用 WHO 参考表。原公开地址 `/tools/child-growth` 现在重定向到 [ZTools 儿童生长计算器](https://ztools.zaions.com/child-growth-percentile-calculator)。

## 婴儿名字

[`/baby-names`](https://lifewell.aoneahsan.com/baby-names) 是公开页面，无需账号，也不会保存您的任何信息。

## 与他人分享人生阶段

您可以让伴侣或家人只读取此领域的一部分，而不是全部。这属于分享决定，并非人生阶段本身的设置——参阅[分享](./sharing.md)。
