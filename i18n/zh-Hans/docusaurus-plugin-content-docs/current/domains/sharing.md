# 分享

默认不会分享任何内容。

“分享”是唯一没有关闭开关的领域，它本身并不保存另一份生活记录。它保存的是关于其他六个领域的决定：谁能查看什么、可以查看到何时。每项决定都能单独撤销。

| 菜单项 | 地址 | 用途 |
|---|---|---|
| 概览 | `/sharing` | 当前分享了什么、仍有效的链接、等您处理的回复 |
| 伴侣分享 | `/people/connections` | 已与您建立连接、拥有自己 LifeWell 账号的人 |
| 链接 | `/people/share-links` | 您创建的每条链接，以及通过链接收到的回复 |
| 分享控制 | `/people/data-sharing` | 在一份清单中查看每个人和每个分享项目，旁边都有撤销操作 |

所有方案都可使用链接，包括 Free。

## 为什么没有关闭开关 \{#why-it-has-no-switch}

其他六个领域可以关闭，“分享”不能：您允许别人查看了什么，必须始终对您可见。`/settings?tab=domains` 会把它列成没有开关的一行。您完全可以不分享任何内容，那时它只是一个空页面。

[删除“分享”领域](../your-data/delete.md#people-and-sharing-are-deleted-separately)是另一项操作：它会一次结束所有链接和连接，同时保留您的人物记录。

## 三种链接

| 类型 | 作用 |
|---|---|
| **只读链接** | 对方打开您选择的内容，只能读取 |
| **收集链接** | 您向对方询问资料。对方提交姓名；如果愿意，也可以提供与您的关系、出生日期和邮箱地址，方便您日后联系；一份回复还可附上最多二十位其他人物 |
| **只读链接上的补充** | 如果只读链接包含关系树，可以允许补充。勾选*他们可以添加遗漏的人*后，打开链接的人便可提议添加人物，但只能关联到链接已向其展示的人 |

任何人提交的内容都不会自动进入您的记录。它会作为回复等您查看和决定。

可从 `/people/share-links` 创建链接，也可从内容本身发起：每个记录图表页面和用药页面都有**分享此项**，两种关系树页面都有**分享这棵树**。它们打开的是同一个对话框，相关内容已预先勾选。

## 链接给谁看

**任何拿到地址的人。** 链接地址很长，难以猜中，但保护它的确实只有这个地址。因此，链接会过期：默认七天，也可以选三十天或*直到我撤销*。发送它时，应像发送密码一样谨慎。三年都没人撤销的链接，三年后仍可能有效。

**一位已连接的人。** 选择已与您建立连接的人时，不会生成地址。对方登录自己的账号后，会在分享页面的*别人分享给您*中找到内容。结束连接也会结束分享。您随时可以改变分享内容或撤销分享；无论哪种情况，对方都不会收到通知。

## 链接能包含什么 \{#what-a-link-can-carry}

只有三类：一项记录图表、您的用药信息，或一棵关系树。完整清单就是这三类。一条链接可以包含多项；每项各占一个标签页。只包含一项时不会显示标签栏。

### 一项记录图表

只能分享您实际使用的记录工具。标签页的结构与记录工具页面相似：最近 7、14 或 90 天的图表、旁边的数字，以及按最新在前排列的读数表——**时间 · 数值 · 单位 · 备注**。每条读数都照您输入的样子显示，包括备注。

血压会显示两张图，分别是高压和低压，没有目标线。若用一条线判断读数是否“达标”，便是在别人面前对您的身体作出评价；LifeWell 不会这样做。

### 用药信息

只读显示当前用药安排，包括每种药物的名称、规格、剂量、服药时间和备注。

只有您为该链接勾选*同时显示过去 14 天是否服药*，才会分享服药标记。勾选后，读者还能看到您标记为已服药的比例，以及每天、每种药分别有多少剂已服用、已跳过或漏服。对方看不到每个标记的具体时间、您对某次服药写下的内容，也看不到 14 天前的信息。未勾选时，链接会明确说明不包含这些内容。

这里的比例统计的是标记，不是药片。服用了但没有标记的一剂，不会计入。

### 家谱或工作关系树

关系树记录的是其他活着的人，而他们并未选择出现在您的链接里。因此，每条关系树链接都会询问要分享多少内容：

| 级别 | 包含的内容 |
|---|---|
| **仅显示结构** | 您对每个人的称呼，以及人物之间的连线 |
| **按您保存的关系树显示**——默认勾选 | 上述两项，再加上每个人与您的关系，以及谁已经去世 |
| **可供处理的家庭记录** | 全部六个字段：上述四项，加上出生日期和档案上的姓名 |
| **自行选择字段** | 同样六个字段，由您逐项勾选 |

- **档案上的姓名**——诊所或银行会使用的姓名——只有最广的级别或您主动勾选时才会分享。完整姓名加上完整出生日期，足以被人用来冒名开户。
- **出生日期**要么完整分享，要么完全不分享。只给年份、却同时给出完整姓名，看似准确，实际并不准确。
- **您对某个人写下的其他内容绝不会分享**，无论链接或级别如何设置。

创建链接之前，对话框会显示读者将看到的说明。之后可以扩大或缩小级别；但已经被别人读过的内容，缩小权限也无法收回。

## 对方会看到什么

页面会显示您的姓名、分享项目数、链接失效时间，以及您可以提前结束分享。关系树链接还会说明**这条链接不包含什么**，让树中的人知道，自己出现在链接中不会让哪些资料暴露。

访问者无需登录。除了链接被打开这一事实，不会记录关于他们的其他内容；您的清单只显示打开次数和最近一次打开时间。页面不会被搜索引擎收录。

在清单的每条链接上选择**查看对方所见**，可以看到根据您自己的记录生成的同一页面：

> **这就是链接显示的内容。** 您正在查看自己的记录，不是别人的。预览不会计入链接打开次数，也不能从这里提交内容。

## 回复与“保留此项”

收集链接或补充功能带回的内容，会等在**待您处理的回复**中。在您决定前，它们都还不属于您的记录。

- **保留此项**会把回复中的人物加入记录。按下前不会写入。
- **拒绝**会让您的记录保持原样。发送者不会收到结果通知，因为链接从未承诺一定回复。

补充功能不要求填写姓名，所以相应回复会写着*未署名的回复*，并显示它来自哪条链接。

## 结束链接

| 操作 | 结果 |
|---|---|
| **撤销** | 地址立即失效。持有链接的人会看到链接已结束 |
| **编辑** | 修改名称、包含的内容、级别、到期时间，以及是否允许补充人物。新的到期时间从今天算起 |
| **再次分享** | 对已结束的链接，创建一条包含相同内容、但地址不同的新链接，需要您重新发送。已撤销的地址不会恢复 |
| **删除** | 移除已结束链接的记录。如果链接曾用于收集内容，经过它收到的所有回复也会删除，无论您读过没有 |

撤销无法收回别人已经读过的内容，任何操作都做不到。对方打开的页面可能仍在屏幕上，截图也已经留下。

## 复制和发送地址

地址本身不透露内容。它由 64 个随机字符组成，不含姓名、关系树或链接所分享内容的说明。有人在消息中看到地址，打开前也无法从中读出内容。地址使用 LifeWell 自己的网页域名生成，而不是复制时设备的地址，因此每条链接只有一个地址，不会分成网页和 Android 两种：在应用或浏览器中复制，得到的都是同一串字符，发到哪里都能在浏览器中打开分享页。

LifeWell 只保存地址不可逆的哈希值和前八个字符，方便您区分链接。完整地址在您的设备上生成，从未发送给我们，因此只有创建它的设备能再次复制或发送。

在那台设备上，列表项提供**复制链接**和**分享**：

> 地址以 `8f3c…` 开头 · 这台设备创建并保留了完整地址，所以您可以再次从这里复制或发送。完整地址从未传给我们。

在其他设备上：

> 地址以 `5d0e…` 开头 · 这台设备没有保存完整地址。只有创建链接的设备会保留它；在那台设备退出登录后，地址也会被移除。请撤销这条链接并创建新链接，才能从当前设备发送。

撤销或结束链接时，设备上的完整地址也会移除，以免失效地址再次被发送。分享给单个已连接人的内容没有地址，也就没有可复制的链接。**分享**在网页上打开 LifeWell 自己的分享窗口，在 Android 应用中打开手机系统分享面板。

## 绝不会离开您的内容

- **链接未指明的任何内容。** 链接只包含记录图表、您的用药信息或关系树。日记、回忆、照片、笔记、日历和位置都不能附在地址后面，数据库根本没有记录这些内容分享权限的位置。
- **记录的其他部分。** 从分享页没有入口访问您保存的其他内容。
- **关系树中的某人是否使用 LifeWell。** 任何分享级别都不会显示这一点。

各级关系树和用药选项会省略什么，详见[链接能包含什么](#what-a-link-can-carry)。
