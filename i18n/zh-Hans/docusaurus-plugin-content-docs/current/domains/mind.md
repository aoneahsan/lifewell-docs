# 心灵

按页面数量看，这是最小的领域；但关于哪些内容可以离开这里，它的规则最严格。

## 日记

入口是 `/health/mood-journal`。日记可以写下任何您注意到的事。这是写给自己的笔记，不是一套理论；本页不会将它变成理论。

日记包含几类记录：心情、感恩、梦境和自由写作。它们共用一份存储，每条记录都有类别，因此回看一个月时，仍能看到同一个月，而不是四份分开的月份。

:::note[日记绝不会进入 PDF 导出文件]
PDF 常被打印、交给前台，然后放在桌面上。LifeWell 的日记不该以这种方式离开。它会进入由您自行打开的 JSON 和 CSV 导出文件。参阅[导出格式](../reference/export-format.md#what-each-format-leaves-out)。
:::

## 引导练习 \{#guided-sessions}

`/health/breathing`、`/health/meditation`、`/health/sleep-sounds`、`/health/affirmations`、`/health/panic-attack` 和 `/health/stress-assessment`。

只有您要求时，练习才会被记下。这里的清单若是空的，说明页面安静地完成了自己的工作。

## 工作间歇提醒

`/wellness` 提供工作日的三种短暂停顿：眼部休息、活动和姿势提示。每一种都有自己的时间安排，默认关闭。饮水记录在饮水追踪器中；打开药物清单时，未标记的到期剂次会在 LifeWell 收件箱提示。

## 有意不提供的内容

没有心情评分、健康指数，也没有评价您这一周表现如何的报告。LifeWell 保存您写下的内容，并以便于回看的方式展示；它不会替您作出评价。

如果某个数字对您有用，[健康](./health.md)中的记录工具可以保存它。是否使用，由您决定，而不是应用决定。
