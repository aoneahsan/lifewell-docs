# 七个领域

六款应用，各自了解您的一部分。没有一款了解完整的您。

LifeWell 保存七个领域，**您自己**在中间。“您自己”指账号——个人资料、方案和设置——不属于七个领域，因为它不是可以关闭的内容。

先从人开始：加入重要的人，记下您对他们的了解和共度的时刻。回忆、日常和分享与他们相连；健康、心灵和人生阶段围绕在旁，帮助生活过得更好。健康只是其中之一，不是应用的中心。

| 领域 | 菜单分组 | 保存的内容 |
|---|---|---|
| [人物](./people.md) | 家人与工作 | 人物、关系树、地点、消息、社区、专业人员、献血者 |
| [回忆](./memories.md) | 回忆 | 照片、回忆、笔记 |
| [日常](./everyday.md) | 日常 | 日历 |
| [分享](./sharing.md) | 分享 | 您允许别人查看的内容——链接、伴侣分享、收到的回复 |
| [健康](./health.md) | 健康 | 各类记录工具、用药、饮食、运动、健康状况 |
| [心灵](./mind.md) | 心灵 | 日记、呼吸练习、睡眠、工作间歇提醒 |
| [人生阶段](./stages.md) | 人生阶段 | 生理周期、婴儿、生长 |

## 为什么地址与领域名称不一致 \{#why-the-addresses-do-not-match-the-areas}

`/health/mood-journal` 属于**心灵**；`/health/menopause` 属于**人生阶段**；`/people/share-links` 属于**分享**。地址前缀没有反映当前领域，但这是有意保留的。

这些地址曾在 2.x 应用中被搜索引擎收录。已经收录的地址，也是对所有链接到它的人的承诺。重建会修改代码，但不会随意更改地址。完整清单见[保持有效的地址](../reference/addresses.md)。

领域是产品的组织方式，地址前缀则记录了历史。不要把两者当成一回事。

## 关闭一个领域 \{#switching-an-area-off}

`/settings?tab=domains` 提供六个开关，每个可关闭领域一个。“分享”也列在这里，但没有开关：您允许别人查看了什么，必须始终对您可见。参阅[分享](./sharing.md#why-it-has-no-switch)。

**关闭意味着让它安静下来，具体有三层含义：**

- 菜单不再列出该领域；
- 已经记下的内容会保留，现在和以后都不会因为关闭而删除；
- 直接打开领域中的页面仍可访问，页面顶部会用一句话说明为何它不在菜单里。

这个面板没有保存按钮。需要另按保存的开关，会让人误以为切换时已经生效。因此，每次切换都会立即写入，开关本身就是操作反馈。写入失败时，它会回到原位并说明原因。

## 隐藏领域不等于删除

这是两项不同操作，故意分开放置：

| 操作 | 位置 | 结果 |
|---|---|---|
| 关闭领域 | `/settings` → 领域 | 菜单不再列出，所有记录仍在 |
| [删除领域](../your-data/delete.md#delete-one-area) | `/settings` → 您的记录 | 一个事务中删除其中所有记录，并报告删除数量 |

如果只想隐藏，结果却删除了内容，就无法挽回。这也是删除操作要求您亲手输入确认文字的原因。

## 哪些因素决定页面是否显示

只有两个回答：

1. **您开启了哪些领域**——上述六个开关。
2. **您的身份**——个人资料中的一个字段，决定是否在菜单中列出六个人生阶段页面。参阅[首次使用](../getting-started/first-run.md#the-one-answer-that-changes-what-you-see)。

如果一个人同时符合这两个条件，会在两个位置看到相同的说明。这也是有意设计。
