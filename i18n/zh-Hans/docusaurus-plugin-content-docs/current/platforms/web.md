# 网页版

[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) 可在浏览器中打开 LifeWell。Android 应用使用同一账号和记录；设备通知及分享方式则取决于使用的平台。

## 浏览器

支持当前版本的 Chrome、Edge、Firefox 和 Safari。浏览器过旧、无法运行应用时，启动页面会明确说明，不会显示一个损坏的界面。

## 网页版缺少什么

部分操作取决于浏览器和操作系统：

- **应用关闭后送达的本地提醒。** 获支持的日程和健康提醒会在允许通知时由 Android 安排。浏览器标签页关闭后无法送达这类设备提醒；打开用药清单时，到期剂量的提示会出现在 LifeWell 收件箱中。
- **系统分享面板。** 在网页上分享[购物清单](../features/shopping-list.md)时，应用内分享视图会提供明确的复制操作，而不会打开系统面板。

两个平台可以访问同一账号和已保存的记录。各项功能的送达方式与权限要求请查阅对应指南。

## 添加到主屏幕

多数浏览器会提供安装选项，让应用以图标和无地址栏窗口的形式打开。它不会额外下载内容，也不会改变应用本身；这是浏览器提供的功能。

## 离线使用

连接中断时，网页版会遮挡当前页面。如果开启了**保持离线记录**，您可以选择将受支持的快捷记录暂存在这台设备上；其他记录仍需连接服务器。应用不会缓存页面供离线打开。参阅[离线与同步](../concepts/offline-and-sync.md)。

## 公开页面

有些地址无需账号即可访问：[工具](../features/tools.md)、婴儿名字浏览器、献血者名录、博客、功能介绍页，以及四个法律页面。它们是普通网页，直接渲染为真实 HTML，而不是加载后才由 JavaScript 拼出内容。因此，搜索引擎和 AI 抓取程序读到的文字与您看到的一样。
