# 浏览器扩展程序

**已为 Chrome 和 Firefox 建成，尚未在任何一家扩展商店发布。**

## 目前的情况

3.0.0 重建时留下了旧的扩展程序文件夹。现在的配套扩展程序是独立的 WXT 项目，已经有 Chrome 和 Firefox 构建版本。它尚未提交到两家商店，因此目前没有可从商店安装的版本。

## 扩展程序能让您随手查看什么

浏览网页时，弹出面板提供喝水和休息提醒、附有来源的一般食物处理信息以及预约信息。本地记录的身心健康条目和预约详情保存在浏览器存储中。即使连接 LifeWell 账号，这些内容也**不会上传到您的 LifeWell 记录**。

## 如何连接账号

从扩展程序发起连接后，LifeWell 网站会打开。批准这台浏览器前，请核对两处显示的短代码是否一致。随后，扩展程序会获得独立的账号会话，并读取您个人资料中的语言设置。您可以在扩展程序中断开连接。

弹出面板还可能展示 Zaions 的其他产品。这些自家产品推荐在商店信息中计为广告。

我们保留此页面的地址，让旧版扩展程序说明链接能指向当前事实。扩展程序上架后，此页会加入商店链接。
