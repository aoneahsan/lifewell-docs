# 从 MyChart 转到 LifeWell

如果您的医院或诊所使用 Epic，MyChart 就是它提供的患者门户。诊所发来的检查结果、药物信息、账单和消息都在那里。

LifeWell 是您自己维护的记录，可以跨诊所保存内容，旁边还有您生活中的人和回忆。

最后核查：2026-11-26。对比见 [LifeWell 与 MyChart](https://lifewell.aoneahsan.com/compare/mychart)。

## 在 MyChart 旁保留自己的副本

1. 保留 MyChart。诊所发送的内容来自诊所，LifeWell 不连接这个系统。
2. [登录 LifeWell](/getting-started/first-run)。
3. 把想保留的检查结果填入[健康](/domains/health)中的化验结果，把当前药物填入用药记录。
4. 每次就诊都可建立一条[预约](/features/calendar-and-appointments)，在清单中写下要问的问题。
5. 如果照顾孩子，儿童用药有独立清单，与成人剂量分开。LifeWell 不提供医疗建议。

## MyChart 与 LifeWell

| 功能 | LifeWell | MyChart |
|---|---|---|
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带提醒的预约 | 有 | 部分支持（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 保存用药、疾病和检查结果 | 有 | 有（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 部分支持（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

MyChart 页面没有显示价格，也没有说明是否支持每人一份记录、家族树、回忆、语音写入、笔记、下载数据、Android 应用或免费方案。

MyChart 网站：<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">MyChart</a>。
