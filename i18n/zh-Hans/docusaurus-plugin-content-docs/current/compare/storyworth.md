# 从 Storyworth 转到 LifeWell

Storyworth 每周通过邮件或电话向父母、祖父母问一个问题，一年后把回答装订成精装书。这是一份有结束日期、最终留下一本书的礼物。

LifeWell 免费保存您听到的故事，将它们放在讲述者名下，只要您保留记录，它们就一直留在那里。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Storyworth](https://lifewell.aoneahsan.com/compare/storyworth)。

## 在书完成后保存故事

1. 下载至今的故事电子书，免费留存副本。之后无论怎么选择，这份副本都属于您。
2. [登录 LifeWell](/getting-started/first-run)，在[人物](/domains/people)中加入讲故事的人及其与您的关系。
3. 把重要的故事整理成[回忆](/domains/memories)，每条附上日期、地点和其中的人。
4. 下次在餐桌上听到故事时，可以用“说出来”。它会转写口述内容，直到您确认前都不会保存。
5. 订阅期间的每周问题和印刷书继续由 Storyworth 提供。

## Storyworth 与 LifeWell

| 功能 | LifeWell | Storyworth |
|---|---|---|
| 带照片、日期和地点的回忆 | 有 | 部分支持（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 说出内容并转写成文字 | 有 | 有（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 部分支持（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 部分支持（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

我们阅读的 Storyworth 页面没有说明是否支持每人一份记录、家族树、分享链接、预约、健康记录、笔记、Android 应用或免费方案。

LifeWell 会私下保存每段“说出来”录音，直到您删除；它不会印制书籍，也不能打印家族树。
