# 从 Bearable 转到 LifeWell

Bearable 面向长期患病的人，展示症状、情绪、睡眠与用药在数月间如何相互变化。大部分功能免费，也能在应用内导出和删除所有内容。

LifeWell 则把健康记录放在生活其他部分旁边：人物、回忆和预约。

最后核查：2026-11-26。两款产品的对比见 [LifeWell 与 Bearable](https://lifewell.aoneahsan.com/compare/bearable)。

## 带着历史记录离开 Bearable

1. 先在 Bearable 中导出数据。
2. [登录](/getting-started/first-run) LifeWell。
3. 情绪和睡眠可记在[健康](/domains/health)领域的记录工具中，同一天以最新条目为准。药物则填入用药页面。
4. 为每种疾病建立长期记录，再在其下记录每次发作。
5. 把预约本身放进[日历](/features/calendar-and-appointments)，附上需要提出的问题清单。
6. 如果就诊时需要 Bearable 的报告，请继续使用它。LifeWell 不提供医疗建议。

## Bearable 与 LifeWell

| 功能 | LifeWell | Bearable |
|---|---|---|
| 保存用药、疾病和检查结果 | 有 | 部分支持（<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://bearable.app/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Bearable 的页面没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、预约、笔记、Android 应用或家庭方案。
