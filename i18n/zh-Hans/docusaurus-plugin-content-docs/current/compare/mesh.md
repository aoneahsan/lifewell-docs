# 从 Mesh 转到 LifeWell

Mesh 用来维系庞大的职业人脉。它从邮件、LinkedIn 和日历导入联系人，关注他们的生活动态，并提醒您何时重新联系；另有 macOS、Windows 和 iOS 应用。

LifeWell 记录的是家人与朋友，而不是职业人脉。回忆和健康记录放在每个人名下，免费方案无需信用卡。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Mesh](https://lifewell.aoneahsan.com/compare/mesh)。

## 从 Mesh 中挑出家人与朋友

1. [登录](/getting-started/first-run)。
2. 从 Mesh 的联系人中挑出家人和亲近朋友，加入[人物](/domains/people)。
3. 把他们重要的日期放进[日历](/features/calendar-and-appointments)，并设置[提醒](/features/reminders)。
4. 职业人脉继续留在 Mesh。LifeWell 不读取您的邮件或 LinkedIn，也不连接外部日历。

## Mesh 与 LifeWell

| 功能 | LifeWell | Mesh |
|---|---|---|
| 为生活中的每个人保存记录 | 有 | 有（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带提醒的预约 | 有 | 部分支持（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Mesh 定价页没有说明是否支持家族树、回忆、语音写入、分享链接、健康记录、笔记、下载数据、Android 应用或家庭方案。

Mesh 有 iOS 应用。LifeWell 没有 iOS 应用，但可在 iPhone 的 Safari 中使用。
