# 从 Withings+ 转到 LifeWell

Withings+ 配合 Withings 的体重秤和手表使用，把测量结果变成每日分数，提供健康助手，还能生成视频问诊所需的 PDF。

LifeWell 适合没有这些硬件、亲手记录数据的人，把健康内容放在生活中的人和回忆旁边。

最后核查：2026-11-26。对比见 [LifeWell 与 Withings+](https://lifewell.aoneahsan.com/compare/withings-plus)。

## 不再使用设备时

1. 先从 Withings 下载健康报告 PDF，保留测量记录。
2. [登录](/getting-started/first-run)。
3. 手动输入您在意的数值。[健康](/domains/health)领域分别有体重、血压和心率记录工具；LifeWell 不读取体重秤或手表。
4. 视频问诊和其他预约一样，可放进[日历](/features/calendar-and-appointments)。
5. 如果仍在使用设备，可以保留免费的 Withings 应用。LifeWell 不提供医疗建议。

## Withings+ 与 LifeWell

| 功能 | LifeWell | Withings+ |
|---|---|---|
| 保存用药、疾病和检查结果 | 有 | 部分支持（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 部分支持（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 部分支持（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Withings+ 页面没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、预约、笔记或 Android 应用。
