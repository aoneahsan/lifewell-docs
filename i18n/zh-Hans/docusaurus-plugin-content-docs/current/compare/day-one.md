# 从 Day One 转到 LifeWell

Day One 是每日写作的日记应用，提供端到端加密、写作提示、音频、位置记录，还能把条目印成书。如果您天天写日记，它就是为此设计的。

LifeWell 会把一段回忆放在与之有关的人物名下；免费方案也不限于每条记录只放一张照片。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Day One](https://lifewell.aoneahsan.com/compare/day-one)。

## 把日记条目整理成回忆

1. 先从 Day One 导出日记。CSV 和 JSON 导出可以在迁移期间保全全文；LifeWell 不支持直接导入。
2. [登录 LifeWell](/getting-started/first-run)。
3. 在[人物](/domains/people)中加入您在日记里反复提到的人。
4. 把值得保留的条目逐条整理成[回忆](/domains/memories)，附上照片、日期、地点和在场的人。
5. 不想打字的日子，可以用“说出来”口述。它会转成文字，保存前请您确认。
6. 日常写作和纸质日记书，仍可留在 Day One。

| 功能 | LifeWell | Day One |
|---|---|---|

| 说出内容并转写成文字 | 有 | 有（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 有（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Day One 定价页没有说明是否支持每人一份记录、家族树、预约、健康记录、笔记或家庭方案。

您交给“说出来”的录音只对您可见，删除后就会移除。LifeWell 没有 iPhone 应用，在 iPhone 上可通过 Safari 使用。参阅 [iOS](/platforms/ios)。
