# 从 Journey 转到 LifeWell

Journey 是日记应用：免费版可一直使用，会员方案增加端到端加密、共用日记，以及 ePub 和 DOCX 导出。

LifeWell 同样看重日子里的人。一段回忆会放在其中人物的记录下，旁边是家族树、健康记录和预约。

最后核查：2026-11-26。应用内的两款产品对比见 [LifeWell 与 Journey](https://lifewell.aoneahsan.com/compare/journey)。

## 从日记条目转到人物

1. 通过 Journey 会员功能把日记导出为 DOCX 或 ePub，把全文保存在您自己的文件中。
2. [登录 LifeWell](/getting-started/first-run)。
3. 在[人物](/domains/people)中加入日记提到的人。
4. 将想保留的条目连同照片、日期和地点复制到[回忆](/domains/memories)。
5. 私人的每日写作仍可继续留在 Journey。

## Journey 与 LifeWell

| 功能 | LifeWell | Journey |
|---|---|---|
| 带照片、日期和地点的回忆 | 有 | 有（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 向没有账号的人分享页面 | 有 | 有（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Journey 会员页没有说明是否支持每人一份记录、家族树、语音写入、预约、健康记录、笔记、Android 应用或家庭方案。

Journey 的网页链接展示一条日记；LifeWell 链接则可展示关系树、记录工具或用药信息。参阅[分享](/domains/sharing)。
