# 从 Tinybeans 转到 LifeWell

Tinybeans 是记录孩子日常的私人照片日记。祖父母通过邮件追看；这条简单的动态就是它的核心。

LifeWell 希望陪伴孩子长大。同一批人以后还可以拥有家族树、回忆和健康记录；免费方案的内容也完整写明。

最后核查：2026-11-26。应用内对比见 [LifeWell 与 Tinybeans](https://lifewell.aoneahsan.com/compare/tinybeans)。

## 当宝宝照片变成家庭记录

1. [登录](/getting-started/first-run)，在[人物](/domains/people)中加入孩子和关注日记的亲人。
2. 把不想遗失的照片加入[回忆](/domains/memories)，每张附上日期和地点。
3. 将人物连起来，[家族树](/domains/people)就会出现。
4. 祖父母阅读的照片动态仍可留在 Tinybeans。

## Tinybeans 与 LifeWell

| 功能 | LifeWell | Tinybeans |
|---|---|---|
| 带照片、日期和地点的回忆 | 有 | 有（<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

核查时无法读到 Tinybeans 的价格：定价、Premium、方案和应用页面均返回未找到。首页没有说明是否支持每人一份记录、家族树、语音写入、预约、健康记录、笔记、下载数据、Android 应用、免费方案或家庭方案。

LifeWell 没有 iPhone 应用，在 iPhone 上可通过 Safari 使用。参阅 [iOS](/platforms/ios)。

Tinybeans 网站：<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">Tinybeans</a>。
