# 从 Obsidian 转到 LifeWell

Obsidian 将笔记作为普通文件保存在您自己的设备上，免费使用且没有数量限制；同步和发布功能需付费。

LifeWell 提供不必自己设计的结构。人物、家族树、回忆、健康记录和预约已经彼此相连。

最后核查：2026-11-26。对比见 [LifeWell 与 Obsidian](https://lifewell.aoneahsan.com/compare/obsidian)。

## 从知识库转到人物记录

1. [登录](/getting-started/first-run)。
2. 如果您的知识库中每人有一条笔记，可以在[人物](/domains/people)导入页逐行粘贴姓名；保存前会显示识别出的人。
3. 把各人的笔记正文复制到人物记录，或复制到支持富文本的[笔记](/domains/everyday)。
4. 带日期的笔记，例如复诊和纪念日，可加入[日历](/features/calendar-and-appointments)并设[提醒](/features/reminders)。
5. 请保留原知识库。无论您在 LifeWell 做什么，Markdown 文件仍留在您的设备上。

## Obsidian 与 LifeWell

| 功能 | LifeWell | Obsidian |
|---|---|---|
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 有（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 部分支持（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Obsidian 定价页没有说明是否支持每人一份记录、家族树、回忆、语音写入、预约、健康记录、下载数据或家庭方案。

LifeWell 记录保存在数据库中，不是设备上的普通文件。您可以选择日期范围[导出](/your-data/export) JSON 或 CSV，每张表最多 5,000 行；也可以下载 PDF 摘要。如需更多记录，请继续选择其他日期范围。
