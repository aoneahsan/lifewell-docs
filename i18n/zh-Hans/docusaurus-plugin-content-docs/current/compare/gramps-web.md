# 从 Gramps Web 转到 LifeWell

Gramps Web 是免费、开源的家谱软件，由您在自己的服务器上运行。它可读写 GEDCOM、绘制交互式图表，还能制作家族树 PDF 书籍报告。

LifeWell 适合不想自己维护服务器的人。它由服务方托管，有 Android 应用，同一批人物名下也能保存回忆、预约和健康记录。

最后核查：2026-11-26。附来源的对比见 [LifeWell 与 Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web)。

## 离开自己维护的服务器

1. 完整下载 Gramps Web 数据并保留。LifeWell 不读取 GEDCOM，这份文件仍是您完整的研究副本。
2. [登录 LifeWell](/getting-started/first-run)。
3. 如果已备好姓名，可在[人物](/domains/people)导入页逐行粘贴。保存前页面会展示识别出的人；只导入姓名，日期和关系需由您补上。
4. 连起人物关系，[家族树](/domains/people)便会根据这些连接绘制。
5. 把在意的照片加入[回忆](/domains/memories)，标记照片中的人，与 Gramps Web 的人物标签类似。
6. 如果还需要 PDF 书籍报告或完整研究数据库，可以继续保留 Gramps 服务器。

| 功能 | LifeWell | Gramps Web |
|---|---|---|
| 为生活中的每个人保存记录 | 有 | 有（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 绘制家族树 | 有 | 有（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带照片、日期和地点的回忆 | 有 | 部分支持（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.grampsweb.org/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Gramps Web 的页面没有说明是否支持语音写入、预约、健康记录、笔记、Android 应用或家庭方案。

LifeWell 无法打印家族树，也不会生成书籍报告。
