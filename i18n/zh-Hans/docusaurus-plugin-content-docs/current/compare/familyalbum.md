# 从 FamilyAlbum 转到 LifeWell

FamilyAlbum 是按月份整理、可与亲友分享的儿童照片和视频相册，免费且存储不限量；相片冲印和相册书另行购买。

LifeWell 则把相册放进整个家庭的记录里，照片旁边还有家族树、健康笔记和预约。

最后核查：2026-11-26。完整对比见 [LifeWell 与 FamilyAlbum](https://lifewell.aoneahsan.com/compare/familyalbum)。

## 整理孩子的相册

1. [登录](/getting-started/first-run)，在[人物](/domains/people)中加入孩子、自己和关注相册的亲友。
2. 挑出能讲述故事的照片，例如第一天、第一次旅行，将它们连同日期和地点加入[回忆](/domains/memories)。每个文件都保存在您自己的 Google Drive。
3. 标记每张照片中的人，让回忆也出现在他们的记录中。
4. 加入相册不会保存的内容：在[健康](/domains/health)中记录孩子的疫苗和药物，把预约放进[日历](/features/calendar-and-appointments)。
5. 要继续向亲友分享照片，可以保留 FamilyAlbum。LifeWell 链接可分享关系树、记录工具或用药信息，不能分享相册。参阅[分享](/domains/sharing)。

## FamilyAlbum 与 LifeWell

| 功能 | LifeWell | FamilyAlbum |
|---|---|---|
| 带照片、日期和地点的回忆 | 有 | 有（<a href="https://family-album.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 部分支持（<a href="https://family-album.com/premium" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://family-album.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 有（<a href="https://family-album.com/premium" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

FamilyAlbum 的页面没有说明是否支持每人一份记录、家族树、语音写入、分享链接、预约、健康记录、下载数据或 Android 应用。
