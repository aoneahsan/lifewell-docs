# 从 TickTick 转到 LifeWell

TickTick 在各个平台上把任务、习惯和日历放进同一款应用，有免费方案和按年付费的 Premium。LifeWell 没有待办事项清单。

LifeWell 的日历围绕其中的人展开，而这些人物名下还有回忆、家族树和健康记录。

最后核查：2026-11-26。逐项对比见 [LifeWell 与 TickTick](https://lifewell.aoneahsan.com/compare/ticktick)。

## 一起使用 TickTick 和 LifeWell

1. [登录](/getting-started/first-run)。
2. 找出 TickTick 中真正与家人有关的清单，例如父母的用药、孩子的预约，把他们加入[人物](/domains/people)。
3. 将家庭清单中带日期的事项移到 LifeWell 的[日历](/features/calendar-and-appointments)。月视图会把它们与记录中其他带日期的内容放在一起。
4. 如果清单记录的是某人的药物，应改放进[健康](/domains/health)，补上剂量、时间和[提醒](/features/reminders)。
5. 习惯和普通任务继续留在 TickTick。

## TickTick 与 LifeWell

| 功能 | LifeWell | TickTick |
|---|---|---|
| 说出内容并转写成文字 | 有 | 部分支持（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带提醒的预约 | 有 | 部分支持（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 部分支持（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 部分支持（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

TickTick 升级页没有说明是否支持每人一份记录、家族树、回忆、分享链接、健康记录、下载数据或家庭方案。

“说出来”的录音只对您可见，直到您删除。
