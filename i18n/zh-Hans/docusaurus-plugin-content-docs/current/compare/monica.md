# 从 Monica 转到 LifeWell

Monica 是开源的个人联系人管理工具，可以免费放在自己的服务器上运行，也有托管版。它朴素地记录人物、关系、谈话和“给母亲打电话”之类的提醒。

LifeWell 是现在就能在 Android 或网页上使用的托管应用，可在这些人物名下加入回忆、家族树和健康记录。

最后核查：2026-11-26。附来源的对比见 [LifeWell 与 Monica](https://lifewell.aoneahsan.com/compare/monica)。

## 从 Monica 移出人物

1. [登录 LifeWell](/getting-started/first-run)。
2. 如果您有姓名清单或 .vcf 联系人文件，可在[人物](/domains/people)导入页粘贴或选择文件。应用只读取姓名，保存前会展示找到的所有人。
3. 手动补全每个人与您的关系，以及您曾在 Monica 记录的细节。
4. 将 Monica 的提醒改为[预约](/features/calendar-and-appointments)，为每项设置[提醒](/features/reminders)。
5. 关于某个人的文字可整理进[笔记](/domains/everyday)文件夹。
6. 在需要的内容都转移完成前，请继续运行 Monica 服务器。

| 带提醒的预约 | 有 | 部分支持（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 有（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Monica 的页面没有说明是否支持回忆、语音写入、分享链接、健康记录、Android 应用或家庭方案。

LifeWell 没有 iPhone 应用。
