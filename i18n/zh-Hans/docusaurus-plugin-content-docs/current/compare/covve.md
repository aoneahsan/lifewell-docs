# 从 Covve 转到 LifeWell

Covve 适合参加活动后带回一叠名片的人。它可以扫描名片、加标签和导出联系人，按席位提供月付和年付价格。

LifeWell 保存的则是那些不属于销售线索的人：家人与朋友，连同他们的回忆、关系树和健康内容，放在一份免费记录里。

最后核查：2026-11-26。完整对比见 [LifeWell 与 Covve](https://lifewell.aoneahsan.com/compare/covve)。

## 从 Covve 移出私人联系人

1. 从 Covve 导出到手机联系人或 Excel；定价页列出了两种方式。然后[登录 LifeWell](/getting-started/first-run)。
2. 将电子表格另存为 CSV，在[人物](/domains/people)的导入页面选择文件。LifeWell 只读取姓名，保存前会展示清单；销售线索不必导入。
3. 在 Android 上，电话号码旁的“联系人”按钮可从手机填入号码。LifeWell 只读取您选中的联系人。
4. 将 Covve 中的笔记写入各人物记录或[笔记](/domains/everyday)。
5. 与朋友的计划可放进[日历](/features/calendar-and-appointments)，需要时再设[提醒](/features/reminders)。
6. 扫描名片仍可继续使用 Covve。

## Covve 与 LifeWell

| 功能 | LifeWell | Covve |
|---|---|---|
| 为生活中的每个人保存记录 | 有 | 有（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 有（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Covve 定价页没有说明是否支持家族树、回忆、语音写入、分享链接、预约、健康记录、Android 应用、免费方案或家庭方案。
