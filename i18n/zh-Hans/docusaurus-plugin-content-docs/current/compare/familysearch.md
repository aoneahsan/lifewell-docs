# 从 FamilySearch 转到 LifeWell

FamilySearch 是非营利机构运营的免费家族史网站，拥有一棵全球共用的家族树和数十亿份历史记录。想在教区登记册里寻找曾祖母，可以从这里查起；当地中心还提供面对面帮助。

LifeWell 保存的是您现在还能打电话联系的家人。家族树由您私下保管，同一批人物名下还有回忆、预约和健康记录。

最后核查：2026-11-26。逐项附来源的对比见 [LifeWell 与 FamilySearch](https://lifewell.aoneahsan.com/compare/familysearch)。

## 把自己的家族分支带过来

1. [登录 LifeWell](/getting-started/first-run)，先加入自己。其他关系都从您开始。
2. 同时打开 FamilySearch，复制您家族分支中仍在世的人：父母、祖父母、兄弟姐妹和子女。LifeWell 不会读取 FamilySearch 家族树，每个人都需手动加入[人物](/domains/people)。
3. 填写他们与您的关系。[家族树](/domains/people)便会根据这些关系绘制，一代占一层。
4. 把您已经知道的故事放进[回忆](/domains/memories)：照片、日期、地点和在场的人。
5. 祖先、历史档案和全球共用家族树继续留在 FamilySearch，那里仍可免费研究。

## FamilySearch 与 LifeWell，逐项对比

| 功能 | LifeWell | FamilySearch |
|---|---|---|
| 绘制家族树 | 有 | 有（<a href="https://www.familysearch.org/en/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带照片、日期和地点的回忆 | 有 | 有（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 部分支持（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

我们查看的 FamilySearch 页面没有说明是否支持每人一份记录、语音写入、分享链接、预约、健康记录、笔记、下载数据或家庭方案，因此未列出这些行。

LifeWell 只能在屏幕上绘制家族树，不能打印成挂在墙上的版本。
