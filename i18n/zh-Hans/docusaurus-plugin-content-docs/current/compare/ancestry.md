# 从 Ancestry 转到 LifeWell

Ancestry 是付费的家族史研究服务。它的长处是档案：记录线索、DNA 匹配，以及来自 80 多个国家的资料，按月订阅。如果您想追溯家族过去，Ancestry 适合做这件事。

LifeWell 完全不做历史研究。它免费保存您真正认识的人，以及与他们有关的回忆和预约。

最后核查：2026-11-26。下表每行都链接到来源；完整对比见 [LifeWell 与 Ancestry](https://lifewell.aoneahsan.com/compare/ancestry)。

## 从 Ancestry 家族树转到 LifeWell 记录

1. [登录](/getting-started/first-run)，先从自己开始。
2. 先从 Ancestry 家族树里挑出还在世、您记得生日的人，把他们逐一加入[人物](/domains/people)。LifeWell 无法直接导入 Ancestry 数据。
3. 把人物一一连起来。LifeWell 的[家族树](/domains/people)只显示您输入的人，因此规模取决于您认识的家人。把他们的照片连同日期、地点放进[回忆](/domains/memories)。
4. 如果您曾在 Ancestry 应用中录语音备忘，LifeWell 的“说出来”可以用声音记录故事：您说出内容，应用转成文字，保存前由您确认。
5. 还在研究家族史时，继续保留 Ancestry 订阅。记录线索、档案集合和 DNA 匹配都留在 Ancestry；LifeWell 不替代这些功能。
