# 从 Cloze 转到 LifeWell

Cloze 读取您的邮件和日历，自动补全联系历史，还会提醒回复邮件并支持邮件合并。对收件箱繁忙的人，这正是它的用途。

LifeWell 的做法相反。记录由您亲手写下，可免费使用；家人朋友的回忆和健康记录都放在同一个人物名下。

最后核查：2026-11-26。附来源的对比见 [LifeWell 与 Cloze](https://lifewell.aoneahsan.com/compare/cloze)。

## 离开 Cloze 后亲手整理记录

1. [登录](/getting-started/first-run)。
2. 在[人物](/domains/people)中加入家人与朋友。工作联系人可以留在 Cloze。
3. Cloze 关联到联系人的笔记，需要手动写入此人的记录或[笔记](/domains/everyday)。
4. 私人会面和后续事项可放进[日历](/features/calendar-and-appointments)，并设置[提醒](/features/reminders)。LifeWell 不读取您的收件箱，也不连接外部日历。
5. 邮件合并和收件箱历史继续交给 Cloze。

| 功能 | LifeWell | Cloze |

| 带提醒的预约 | 有 | 部分支持（<a href="https://www.cloze.com/app/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Cloze 定价页没有说明是否支持家族树、回忆、语音写入、分享链接、健康记录、下载数据、Android 应用、免费方案或家庭方案。
