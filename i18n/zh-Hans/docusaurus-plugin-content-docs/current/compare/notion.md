# 从 Notion 转到 LifeWell

Notion 是由您自己搭建的工作空间：页面、数据库和日历，也是许多人工作时使用的工具。有人喜欢用它亲手搭建生活管理系统。

LifeWell 已经搭好。人物、回忆、家族树、健康记录和预约都有现成的结构，并且彼此相连，无须自行设计。

最后核查：2026-11-26。应用内对比见 [LifeWell 与 Notion](https://lifewell.aoneahsan.com/compare/notion)。

## 从 Notion 数据库移出

1. 从 Notion 将工作空间导出为 CSV；它也提供 HTML、Markdown 和 PDF 导出。
2. [登录 LifeWell](/getting-started/first-run)，打开[人物](/domains/people)导入页，选择人物数据库的 CSV。应用把第一列当作姓名，因此姓名应放在第一列。
3. 补全每个人的资料，连起家庭关系，[家族树](/domains/people)便会绘制。
4. 带日期的行可改为[预约](/features/calendar-and-appointments)，需要时设[提醒](/features/reminders)；自由文字可放进[笔记](/domains/everyday)，按文件夹整理富文本。
5. 工作内容可以继续放在 Notion。LifeWell 没有让您自行设计的页面或数据库。
