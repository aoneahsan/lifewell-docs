# 从 CareClinic 转到 LifeWell

CareClinic 用于管理慢性病：把症状、药物、化验、疫苗和影像资料放在可搜索的一处，还提供经过验证的评估、护理计划和供医疗人员查看的 30 天报告。

LifeWell 的 Free 方案提供较简洁的用药、检查结果和预约记录，并把它们放在您生活中的人旁边。

最后核查：2026-11-26。并列对比见 [LifeWell 与 CareClinic](https://lifewell.aoneahsan.com/compare/careclinic)。

## 从 CareClinic 转出记录

1. 先在 CareClinic 生成一份 30 天报告，作为复制内容的依据。
2. [登录 LifeWell](/getting-started/first-run)。
3. 在[健康](/domains/health)领域各自的页面输入化验结果和疫苗信息。疾病是一份长期记录，每次病情发作记录在它下面。
4. 把就诊摘要整理成带清单的[预约](/features/calendar-and-appointments)，让每个问题与答案留在一起。
5. 医疗人员需要查看时，可以生成 LifeWell 的 PDF [导出文件](/your-data/export)。PDF 会有意省略一些内容。
6. 如果护理计划仍放在 CareClinic，请继续使用它。LifeWell 不提供医疗建议。

## CareClinic 与 LifeWell

| 功能 | LifeWell | CareClinic |
|---|---|---|
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带提醒的预约 | 有 | 部分支持（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 保存用药、疾病和检查结果 | 有 | 有（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 部分支持（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 有（<a href="https://careclinic.io/pricing/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://careclinic.io/getting-started/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

CareClinic 的入门页面称大部分功能免费，但核查的页面没有列出高级版价格。页面也没有说明是否支持每人一份记录、家族树、回忆、语音写入、笔记或家庭方案。
