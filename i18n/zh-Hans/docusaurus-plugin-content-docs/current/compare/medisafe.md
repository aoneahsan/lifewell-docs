# 从 Medisafe 转到 LifeWell

Medisafe 围绕按时服药设计，也能通知照护者。其应用下载页称应用免费，但没有列出面向个人用户的付费方案价格。

LifeWell 把用药信息作为生活记录中的一个页面，旁边还有人物、回忆和预约，并公开列出自己的价格。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Medisafe](https://lifewell.aoneahsan.com/compare/medisafe)。

## 转移药物清单

1. 写下 Medisafe 中保存的每种药物、剂量和服用时间。
2. [登录 LifeWell](/getting-started/first-run)，在[健康](/domains/health)领域的用药页面逐一输入剂量和时间安排。
3. 用药[提醒](/features/reminders)默认开启；只有不想收到某种药物的提示时才关闭它。
4. 如果照顾孩子，请把孩子的药物加入独立的儿童用药清单，避免儿童剂量混入成人清单。
5. 与药物有关的就诊可放进[日历](/features/calendar-and-appointments)，在清单中写下打算提出的问题。
6. 如果照护者依赖 Medisafe 的通知，请继续保留它。LifeWell 不提供医疗建议，也不连接医生的系统。
