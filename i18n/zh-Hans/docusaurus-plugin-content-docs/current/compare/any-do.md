# 从 Any.do 转到 LifeWell

Any.do 为家庭提供共用的家务、购物和提醒空间，可免费使用，也有供四人使用的 Family 方案。LifeWell 没有待办事项清单。

LifeWell 的不同之处，在于家庭记录包含什么：关系树、回忆，以及每个人的健康笔记和预约。

最后核查：2026-11-26。两款产品的完整对比见 [LifeWell 与 Any.do](https://lifewell.aoneahsan.com/compare/any-do)。

## 把家庭内容分开整理

1. [登录 LifeWell](/getting-started/first-run)，在[人物](/domains/people)中加入家人。
2. 把看医生、看牙医和家长会移到[预约](/features/calendar-and-appointments)，并为每项设置[提醒](/features/reminders)。
3. 购物内容可以留在 Any.do，也可以移到 LifeWell 的[购物清单](/features/shopping-list)。它能根据餐食计划填入商品，并以纯文本分享，负责采购的人不需要账号。
4. 家务任务继续留在 Any.do。

## Any.do 与 LifeWell

| 功能 | LifeWell | Any.do |
|---|---|---|
| 带提醒的预约 | 有 | 有（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 有（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Any.do 的定价页没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、健康记录、笔记、下载数据或 Android 应用。
