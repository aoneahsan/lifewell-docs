# 从 MyHeritage 转到 LifeWell

MyHeritage 用于建立延伸到祖先的庞大家族树，250 人以内免费；按年收费的方案提供档案匹配、照片修复与上色、DNA 匹配。它适合向前追溯许多代。

LifeWell 关注现在还在世的几代人，把他们的回忆、健康记录和预约放在家族树旁。

最后核查：2026-11-26。应用内的事实对比见 [LifeWell 与 MyHeritage](https://lifewell.aoneahsan.com/compare/myheritage)。

## 转移您仍常联系的人

1. [登录 LifeWell](/getting-started/first-run)。
2. 浏览 MyHeritage 家族树，标出仍在世的人，再将他们加入[人物](/domains/people)。LifeWell 不能从 MyHeritage 导入数据，先从短清单开始更合适。
3. 连起人物关系，[家族树](/domains/people)便会自动绘制。
4. 把旧家庭照片连同日期和地点放进[回忆](/domains/memories)。文件本身保存在您自己的 Google Drive，而不是 LifeWell 的服务器上。
5. 匹配结果、档案线索和 DNA 结果继续留在 MyHeritage。

## 两者如何对应

| 功能 | LifeWell | MyHeritage |
|---|---|---|
| 绘制家族树 | 有 | 有（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带照片、日期和地点的回忆 | 有 | 部分支持（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 部分支持（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

MyHeritage 定价页没有说明是否支持每人一份记录、语音写入、分享链接、预约、健康记录、笔记、下载数据或家庭方案。

LifeWell 只能在屏幕上展示家族树，不能打印。
