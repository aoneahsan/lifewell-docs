# 从 Remento 转到 LifeWell

Remento 关注父母的声音。它无需应用或登录，就能发送口述提示，把每段录音写成书的一章，最终印成精装书；书上的二维码还能播放原声。

LifeWell 不是制作书籍的项目。它免费把人物、回忆、家族树和预约放在同一个地方。

最后核查：2026-11-26。本文事实也列在 [LifeWell 与 Remento](https://lifewell.aoneahsan.com/compare/remento)。

## 章节写完之后

1. 从 Remento 下载录音和照片。它允许您取回原始文件。
2. [登录 LifeWell](/getting-started/first-run)，在[人物](/domains/people)中加入讲故事的父母。
3. 为想放在他们身边的每个章节建立一条[回忆](/domains/memories)，附上照片和日期。
4. 新故事可用“说出来”录音并转写。录音只对您可见，直到您删除。
5. 印制的书和可播放声音的二维码，仍需使用 Remento。

## Remento 与 LifeWell

| 功能 | LifeWell | Remento |
|---|---|---|
| 带照片、日期和地点的回忆 | 有 | 部分支持（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 说出内容并转写成文字 | 有 | 有（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 没有（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 部分支持（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Remento 首页没有说明是否支持每人一份记录、家族树、分享链接、预约、健康记录、笔记或免费方案。

LifeWell 不印制书籍，也不打印家族树。
