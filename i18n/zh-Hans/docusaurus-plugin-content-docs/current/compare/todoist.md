# 从 Todoist 转到 LifeWell

Todoist 是待办事项清单，管理今天的任务、项目和提醒，也有免费方案。LifeWell 没有任务清单；如果您需要的是今日待办，可以继续使用 Todoist。

LifeWell 适合记录与人物有关的预约，而这些人物名下还能保存回忆、家族树和健康记录。

最后核查：2026-11-26。附来源的对比见 [LifeWell 与 Todoist](https://lifewell.aoneahsan.com/compare/todoist)。

## 两款应用一起使用

1. [登录 LifeWell](/getting-started/first-run)。
2. 在 Todoist 中找出与某个人有关的任务，例如儿子的牙医预约、去探望父亲，再把他们加入[人物](/domains/people)。
3. 将这些带日期的任务改为[预约](/features/calendar-and-appointments)，在清单中写下要问的问题，并设[提醒](/features/reminders)。
4. 其他任务继续留在 Todoist。LifeWell 不能导入普通任务，也没有放它们的地方。

## Todoist 与 LifeWell

| 功能 | LifeWell | Todoist |
|---|---|---|
| 带提醒的预约 | 有 | 部分支持（<a href="https://www.todoist.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.todoist.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Todoist 定价页没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、健康记录、笔记、下载数据、Android 应用或家庭方案。
