# 从 MyTherapy 转到 LifeWell

MyTherapy 免费提供用药提醒和服药日记，由制药公司等合作方资助，还能为医生生成健康报告和用药计划。

LifeWell 将用药记录与这个人放在一起，旁边还有他的回忆、家族树，以及您保存的其他生活内容。

最后核查：2026-11-26。附来源的对比见 [LifeWell 与 MyTherapy](https://lifewell.aoneahsan.com/compare/mytherapy)。

## 从 MyTherapy 的用药计划转到 LifeWell

1. 在 MyTherapy 生成健康报告和用药计划，以此作为复制内容的清单。
2. [登录](/getting-started/first-run)，在[健康](/domains/health)中逐一加入药物、剂量和服用时间；实际服下的剂量也记录在那里。
3. 把医生预约放进[日历](/features/calendar-and-appointments)，每条预约附上要问的问题清单。
4. MyTherapy 曾提醒您测量的血压、血糖和体重，在[健康](/domains/health)中各有自己的记录工具。
5. 如果医生通过 MyTherapy 的一次性代码查看计划，请继续保留该方式。LifeWell 不向医生的系统发送内容，也不提供医疗建议。

## MyTherapy 与 LifeWell

| 功能 | LifeWell | MyTherapy |
|---|---|---|
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 带提醒的预约 | 有 | 有（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 保存用药、疾病和检查结果 | 有 | 有（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 部分支持（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

MyTherapy 首页没有说明是否支持每人一份记录、家族树、回忆、语音写入、笔记、Android 应用或家庭方案。
