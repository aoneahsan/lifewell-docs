# 从 Findmypast 转到 LifeWell

Findmypast 是以英国和爱尔兰为中心的家谱订阅服务，收录人口普查、教区登记册和报纸。如果家族历史藏在这些资料中，它适合用来查找。

LifeWell 不搜索档案。它用免费方案记录您现在的家人，家族树只显示您亲手加入的人。

最后核查：2026-11-26。两款产品的对比见 [LifeWell 与 Findmypast](https://lifewell.aoneahsan.com/compare/findmypast)。

## 从 Findmypast 家族树开始

1. [登录](/getting-started/first-run)，先加入自己。
2. 从 Findmypast 家族树中挑出最近几代，在[人物](/domains/people)中逐一加入。LifeWell 不提供直接导入。
3. 连起人物间的关系，[家族树](/domains/people)就会随之呈现。
4. 档案说不出的故事，例如婚礼照片或街角的老房子，可连同日期、地点写入[回忆](/domains/memories)。
5. 人口普查、教区登记和报纸资料继续留在 Findmypast 订阅中。

## 两款产品各提供什么

| 功能 | LifeWell | Findmypast |
|---|---|---|
| 绘制家族树 | 有 | 有（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 向没有账号的人分享页面 | 有 | 部分支持（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 部分支持（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Findmypast 订阅页没有说明是否支持每人一份记录、回忆、语音写入、预约、健康记录、笔记、下载数据、免费方案或家庭方案。

LifeWell 不能打印它绘制的家族树。
