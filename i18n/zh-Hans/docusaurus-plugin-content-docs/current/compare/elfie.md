# 从 Elfie 转到 LifeWell

Elfie 是一款免费的生命体征与用药应用，每完成一项健康行为就会奖励金币。如果奖励能让您坚持测量，这也是使用它的合理理由。

LifeWell 不会因健康行为奖励金币或连续打卡天数。它安静地保存健康记录，并把它们与生活中的人、回忆和预约放在一起。可选的推荐积分与健康记录无关。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Elfie](https://lifewell.aoneahsan.com/compare/elfie)。

## 转移您的测量记录

1. [登录](/getting-started/first-run)。
2. 血压记录位于[健康](/domains/health)领域。输入想保留的数值；同一天的第二次记录会替代第一次。
3. 加入药物和用药时间。用药[提醒](/features/reminders)默认开启。
4. 如果您在照顾父母，可以在预约中记录就诊对象，让复诊清楚地出现在[日历](/features/calendar-and-appointments)上。
5. 如果金币能帮助您坚持，可以继续使用 Elfie。LifeWell 不提供医疗建议。

## Elfie 与 LifeWell

| 功能 | LifeWell | Elfie |
|---|---|---|
| 保存用药、疾病和检查结果 | 有 | 部分支持（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 家庭共用的方案 | 有 | 部分支持（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Elfie 首页没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、预约、笔记、下载数据或 Android 应用。
