# 从 Evernote 转到 LifeWell

如果笔记就是您要处理的全部内容，Evernote 提供笔记本、网页剪藏、扫描和文档搜索，并能在您的各种设备上使用。

在 LifeWell 中，笔记是人物记录的一部分，旁边还有回忆、健康记录和预约。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Evernote](https://lifewell.aoneahsan.com/compare/evernote)。

## 从笔记本转到人物

1. 先把想保留的 Evernote 笔记本导出为 PDF，留一份副本。
2. [登录](/getting-started/first-run)，并在[人物](/domains/people)中加入笔记提到的人。
3. 手动把笔记复制到[笔记](/domains/everyday)。在那里删除文件夹，不会删除其中的笔记。
4. Evernote 中带日期和提醒的笔记，可改为带[提醒](/features/reminders)的[预约](/features/calendar-and-appointments)。
5. 网页剪藏和文档扫描仍可继续用 Evernote。

## Evernote 与 LifeWell

|---|---|---|
| 带提醒的预约 | 有 | 部分支持（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 有（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 下载自己的数据 | 有 | 有（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| Android 应用 | 有 | 有（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 长期免费的方案 | 有 | 有（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Evernote 方案页没有说明是否支持每人一份记录、家族树、回忆、语音写入、分享链接、健康记录或家庭方案。
