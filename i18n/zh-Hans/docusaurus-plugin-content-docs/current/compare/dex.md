# 从 Dex 转到 LifeWell

Dex 是电子版人脉卡片盒。它把 LinkedIn、邮件和日历同步到一份联系人清单中，生成简报，并提醒您保持联系。

LifeWell 免费保存您在意的人，姓名旁可看到家族树、健康记录和预约。

最后核查：2026-11-26。并列对比见 [LifeWell 与 Dex](https://lifewell.aoneahsan.com/compare/dex)。

## 从人脉卡片盒转到人物记录

1. [登录 LifeWell](/getting-started/first-run)。
2. 如果您有 CSV 或 .vcf 联系人文件，[人物](/domains/people)的导入页面可以读取其中的姓名，文件中的其他内容不会导入。
3. 把每个人的笔记复制到此人的记录或[笔记](/domains/everyday)。
4. 把保持联系的日期变成[日历](/features/calendar-and-appointments)条目，并设[提醒](/features/reminders)。
5. 如果您使用过 Dex 的语音模式，可以用 LifeWell 的“说出来”口述新内容。请先读一遍转写结果，再确认保存。
6. LinkedIn 和收件箱同步继续留在 Dex。

| 带提醒的预约 | 有 | 部分支持（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |
| 笔记 | 有 | 有（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">来源</a>） |

Dex 定价页没有说明是否支持家族树、回忆、分享链接、健康记录、下载数据、免费方案或家庭方案。

每段“说出来”的录音都只属于您，直到您删除它。LifeWell 没有 iPhone 应用。
