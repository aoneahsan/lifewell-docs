# 献血

## 名录

[`/blood-donors`](https://lifewell.aoneahsan.com/blood-donors) 是公开页面，无需账号即可查看。

名录显示血型和大致地区。**不会显示电话号码**。这是设计本身，不是等待补上的功能。

## 登记为献血者

在 `/profile/blood-donor` 创建登记。它不会附带您的健康记录；献血者登记只包含血型、地区和您目前是否有空。

## 请求

您发出的请求保存在 `/dashboard/blood-requests`。请求会送达匹配的献血者，不会广播给所有人。

## 披露联系方式

献血者决定回应时，才会将联系方式**一次性提供给一位请求者**。

由此有两项明确的限制：

- **披露可以撤回。** 献血者撤回后，请求者的页面上也会移除联系方式。
- **联系方式不会进入导出文件。** 下载后的记录既不是一次性的，也无法撤回。请求者已经在应用内看到了联系方式；让它永久保留，不是献血者曾作出的选择。

您自己的献血登记和发出的请求包含在[导出文件](../reference/export-format.md)中。别人的电话号码不包含在内。

## 不会做什么

LifeWell 不安排献血、不核验献血资格，也不联系血液服务机构。它提供名录和提出请求的方式。之后的事，由两个人和医院决定。
