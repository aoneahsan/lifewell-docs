# 日历与预约

## 日历

`/calendar` 按月显示您的记录中所有带日期的内容。日常安排与就诊安排放在同一份日历里，因为生活中的一周不会分成两半。

## 预约

`/appointments` 展示的是同一批事件，但以列表而非日历网格呈现，并且只列出预约。

一条预约记录包含：

- 时间和地点；
- 约见的人；
- **一份清单**——您想问的问题，以及想带回家的检查结果。

这份清单常被写在信封背面，然后从停车场走到诊室的途中丢了。有了预约记录，它会一直留在那里，事后答案也能放在问题旁边。

## 提醒

表单可为有时间的预约设置提前一小时提醒。Android 设备在通知可用且获得授权时可以发出提醒。网页版会保存预约，但关闭标签页后浏览器无法发出设备提醒。参阅[提醒](./reminders.md)。

## 导出文件包含什么

日历事件以 **Calendar** 导出，清单以 **Appointment notes** 导出。两者都包含在 JSON 和 CSV 中；PDF 摘要不包含预约清单。事件带有日期，因此缩小导出日期范围也会缩小事件范围。参阅[导出格式](../reference/export-format.md)。

## 不会做什么

LifeWell 不连接 Google Calendar、Outlook 或其他外部日历。它不会从这些日历读取内容，也不会写入。您在 LifeWell 中记下的预约，只保存在 LifeWell 中。
