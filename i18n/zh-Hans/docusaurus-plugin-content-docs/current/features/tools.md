# 工具与计算器

[`/tools`](https://lifewell.aoneahsan.com/tools) 是工具目录。其中大多数工具位于独立网站 [ZTools](https://ztools.zaions.com)；点击卡片会带您前往对应页面。

这是有意安排。已有维护中的计算器，无须在这里再写一次。

## 哪些工具在 LifeWell 内运行

有四款计算器留了下来，因为 ZTools 尚未提供：

| 工具 | 地址 |
|---|---|
| 腰臀比 | `/tools/waist-hip-ratio` |
| 儿童生长 | `/tools/child-growth` |
| 体重增长 | `/tools/wellness-weight-gain` |
| 间歇计时器 | `/tools/interval-timer` |

另有 [`/baby-names`](https://lifewell.aoneahsan.com/baby-names)，它是名字浏览器，不是计算器。

这五项均公开可用，无需账号，也不会保存关于您的信息。

## 哪些工具迁走了

BMI、TDEE、BMR、宏量营养素、蛋白质、体脂、理想体重、心率区间、年龄和锻炼计时器，都重定向到 ZTools 对应工具。旧 LifeWell 地址仍然有效：它们会永久重定向，而不是返回 404，因为有人曾链接到这些地址。

另有几项工具**重定向到应用内部**的替代页面：`/tools/calorie-counter` → `/health/calories`、`/tools/fasting-tracker` → `/health/fasting`、`/tools/sleep-tracker` → `/health/sleep`、`/tools/step-counter` → `/health/steps`。

完整清单见[保持有效的地址](../reference/addresses.md#redirects)。

## `/health-tools`

[`/health-tools`](https://lifewell.aoneahsan.com/health-tools) 是健康相关计算器的索引。

:::note[已移除热度数字]
2.x 版本曾在每款工具旁显示搜索量，例如 *3.2M*，并按这些数字排序。那些数字没有来源，是编造的。3.0.0 已删除它们，改用有实际依据的方式排序。
:::

## 应用内计时器

`/health/workout-timer` 和[心灵](../domains/mind.md#guided-sessions)领域中的引导练习属于应用本身，而非工具目录。它们会写入您的记录，工具目录中的项目则不会。
