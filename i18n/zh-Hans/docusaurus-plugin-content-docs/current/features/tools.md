# 工具与计算器

[`/tools`](https://lifewell.aoneahsan.com/tools) 是工具目录。其中大多数工具位于独立网站 [ZTools](https://ztools.zaions.com)；点击卡片会带您前往对应页面。

这是有意安排。已有维护中的计算器，无须在这里再写一次。

## 哪些工具在 LifeWell 内运行

LifeWell 保留您选择保存的健康与家庭记录。儿童生长图在已保存的儿童记录中使用 WHO 参考数据。公开的婴儿名字浏览器也留在这里。

## 哪些工具迁走了

LifeWell 原有的四个计算器地址现永久重定向到 ZTools：

| ZTools | URL |
|---|---|
| [腰臀比](https://ztools.zaions.com/waist-hip-ratio-calculator) | `waist-hip-ratio-calculator` |
| [儿童生长](https://ztools.zaions.com/child-growth-percentile-calculator) | `child-growth-percentile-calculator` |
| [体重增长](https://ztools.zaions.com/pregnancy-weight-gain-calculator) | `pregnancy-weight-gain-calculator` |
| [间歇计时器](https://ztools.zaions.com/workout-timer) | `workout-timer` |

其他旧计算器地址仍通往 ZTools。四个旧记录工具地址转到 LifeWell 中保存记录的页面：`/tools/calorie-counter` → `/health/calories`、`/tools/fasting-tracker` → `/health/fasting`、`/tools/sleep-tracker` → `/health/sleep`、`/tools/step-counter` → `/health/steps`。

完整地址约定见[不会更改的地址](../reference/addresses.md#redirects)。

## `/health-tools`

[`/health-tools`](https://lifewell.aoneahsan.com/health-tools) 列出您可以在 LifeWell 保存的健康记录。

:::note[已移除热度数字]
2.x 版本曾在每款工具旁显示搜索量，例如 *3.2M*，并按这些数字排序。那些数字没有来源，是编造的。3.0.0 已删除它们，改用有实际依据的方式排序。
:::

## 应用内计时器

`/health/workout-timer` 和[心灵](../domains/mind.md#guided-sessions)领域中的引导练习属于应用本身，而非工具目录。它们会写入您的记录，工具目录中的项目则不会。
