# 地图与地点

`/maps` 在应用中叫“联系”。它展示已记录内容之间的关系，“地点”层列出附在回忆或事件上的地点名称。这里读取原始记录，不会另存副本，也不会推断地理坐标。

## 连接视图 \{#the-four-maps}

| 地址 | 打开的内容 |
|---|---|
| `/maps` | “联系”视图，可切换全部、人物、地点与位置历史层 |
| `/maps/memories` | 从一段回忆出发的有限关联视图 |
| `/maps/notes` | 从一条笔记出发的有限关联视图 |
| `/maps/people` | 人物及其关系图 |

`/maps/full` 移除周围页面，让人物关系图占据更多空间。日程和聊天记录也有相应的关联视图；日期和地点名称仍属于原始记录。

## 收藏地点

这里的地点是您输入的名称，并非 LifeWell 收集的位置。“地点”层列出带有地点名称的回忆和日程。已保存的地点数据也会出现在[导出文件](../reference/export-format.md)中。

## 位置历史

`/people/location-tracking` 和 `/people/location-history` 介绍一项**默认关闭**、需要您主动开启的独立功能。Android 3.31.0 及后续版本已实现后台位置记录器；开启记录时会请求单独的位置权限。已有历史仍可查看和删除。3.31.0 的 Google Play 版本尚待所有者上传并在真机上验证，因此目前商店提供的版本不能视为已具备此功能。

:::note[位置不会分享给其他账号]
分享链接可以包含追踪记录、您的用药信息或关系树，但不能包含位置。数据库中没有位置分享权限范围，并非页面只是没有提供这个选项。参阅[分享](../domains/sharing.md)。
:::

## 导出内容

已保存的地点记录和位置设置会出现在 JSON 与 CSV 中。PDF 只统计地点记录数量，不列出坐标。
