# 专业人员

`/professionals` 是从业者自行登记的名录。如果您也是从业者，可以在 `/profile` 创建自己的名录条目。

## LifeWell 不核验任何人的资质

这句话直接写在名录的首屏，也是本页最重要的信息。

条目中的所有内容都由登记者自己填写。页面完整显示其注册编号，并链接到发放编号的公开登记册，让您花大约一分钟自行核对。这是 LifeWell 能诚实提供的帮助。这里没有评分，也不会推荐任何人。

## 登记者的说法，以及核查结果

每条登记分三栏：对方告诉我们的内容、LifeWell 核查过的内容、您自行核查的方法。**中间一栏通常是空的，这正是设计用意。**

一个写着“已验证”的勾选符号，会把资质、注册、保险、身份和可预约情况这五种不同说法压成一个标志，而这个标志又无法准确代表其中任何一种。三栏结构则让您看清自己在相信哪句话，以及要找谁确认。名录没有“已验证”徽章；管理员填写的核查栏也不能由从业者自行设置。

LifeWell 唯一能确认的是邮箱地址可以收到邮件，因为登记者点开了发送到该地址的链接。只有服务器能写入这一状态，它不能证明对方的专业资质。

:::note[没有登记册的声明不能获批]
管理员可以对照具名的专业登记册记录核查结果。没有指明登记册的声明只能被拒绝。这项限制在数据库中执行，不靠审核者记忆；没有依据时，函数会报错，而不会写入核查结果。若不需要登记册就能获批，“已核查”便没有意义。
:::

每次批准和拒绝都会进入审计日志；拒绝必须附上原因。

## 提供预约时间

从业者可以发布可预约时段。有人预约后，会开启一次**咨询**，其形式是标记了不同类型的[对话](./community-and-chats.md#chats)。

有咨询关联的时段不能删除。因此，撤下名录条目时，系统会先关闭相关对话，不会留下失去关联的预约。

## 咨询与方案

咨询属于付费方案功能。Free 账号不能发起咨询，拒绝由服务器执行，不只是隐藏按钮。参阅[方案](../plans.md)。

## 导出文件包含什么

您的名录条目、您填写的个人信息、您提供的预约时段，以及针对您的登记册核查结果。其他人的条目属于其他人的记录。
