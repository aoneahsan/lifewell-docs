# 购物清单

可从饮食与餐食页面 `/diet-plan` 打开。

## 清单从哪里来

- **餐食计划。** 规划一周餐食后，食材会汇成清单。
- **已保存的餐食或食谱。**
- **手动添加。** 写下计划工具不知道的东西。

购物时可以逐项勾选。清单属于您，清空之前会一直留在您的记录中。

## 分享清单

有两种方式。按下分享按钮时，应用才会根据您使用的平台选择对应方式：

| 平台 | 操作 |
|---|---|
| 网页 | 打开应用内分享视图，并提供明确的复制到剪贴板操作 |
| Android | 打开系统分享面板 |

清单以**纯文本**分享。负责购物的人无需安装 LifeWell、注册账号，也不需要限时链接。

改变主意并关闭分享面板即可，不会发生其他操作。这不是错误，也不会显示报错。

## 导出文件包含什么

购物清单及其项目包含在 [JSON 和 CSV 导出文件](../reference/export-format.md)中。PDF 不包含它们：PDF 是交给临床医护人员阅读的文档，购物清单不属于其中。
