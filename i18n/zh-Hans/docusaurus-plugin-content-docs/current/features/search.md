# 搜索

`/search` 用顶部栏中的一个搜索框，查找您自己的笔记、回忆、人物、事件、用药等记录。

:::warning[页面尚未完成]
搜索本身已经存在：跨记录查询已经写好并部署。打开搜索的页面还没有建成。应用会说明这一点，而不是显示空白结果，让人误以为自己的记录中没有匹配项。
:::

## 搜索会覆盖什么，不会覆盖什么

- **仅限您自己的记录。** 搜索以您的身份运行，遵守与其他读取操作相同的行级权限规则。即使程序出错，也不应读到其他账号的记录。
- **搜索您的记录，不搜索公开页面。** 博客、功能介绍和工具页面是普通公开页面，可通过搜索引擎查找，不在这个搜索框的范围内。
- **不进入搜索索引。** `/search` 标记为 `noindex`，也特意没有列入网站地图。让账号内的搜索页进入公开搜索索引，会引来不必要的探查。
