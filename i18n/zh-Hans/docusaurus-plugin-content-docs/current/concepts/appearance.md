# 外观

顶部栏只有一个外观图标。打开后，所有外观设置都在同一面板里。无论是否登录、在哪个页面，都能使用。

## 八项设置

| 设置 | 改变什么 |
|---|---|
| 主题 | 浅色、深色或跟随系统 |
| 颜色 | 强调色及周围的中性色 |
| 圆角 | 各处边角的圆润程度 |
| 密度 | 每行占用多少空间 |
| 文字大小 | 整套文字尺寸，不只是正文 |
| 字体 | 应用使用的字形 |
| 表面样式 | 面板与页面的层次关系 |
| 动态效果 | 完整或减少 |

## 首屏显示前应用

设置会在**任何内容渲染之前**读取并应用到页面。因此，应用启动时不会先闪出错误的主题：主题在应用运行前就已经决定。

设置也因此集中保存在一处，并从同一张设置表应用，不散落在各个组件里。若组件把颜色或圆角写死，面板便无法改变它；统一入口正是为了避免这种遗漏。

## 动态效果 \{#motion}

**动态效果从不负责传达信息。** 开启减少动态效果，只会移除动画，不会移除内容。

设置保存的是解析后的值，而不是“跟随系统”这几个字。这个细节很重要：单靠 `prefers-reduced-motion` 媒体查询，会盖过应用内选择，让操作系统要求减少动态效果的人无法在应用中选择完整动画。先解析一次，才能保证选择“完整”后确实显示完整效果。

## 保存在哪里

您的选择会保存在当前设备上。如果在同一面板中开启**在设备间同步外观**，它也会保存到账号中，并在您登录另一台设备后跟随过去。若希望电脑与手机使用不同外观，可以关闭此项；这台设备会保留自己的选择。

## 对比度与触控目标

每个页面都以 AA 对比度和至少 44 像素的触控目标为基础，并提供可见焦点、完整键盘操作，以及适应 320 至 1920 像素宽度的布局。
