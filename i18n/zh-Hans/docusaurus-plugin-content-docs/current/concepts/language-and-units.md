# 语言与单位

## 选择语言

LifeWell 提供英语、简体中文、印地语、西班牙语、阿拉伯语、法语、巴西葡萄牙语、俄语、日语和乌尔都语。可以从顶部栏选择语言。阿拉伯语和乌尔都语还会将页面方向改为从右向左，方便阅读。

在另一台设备登录，或连接浏览器扩展程序时，语言选择会跟随您的 LifeWell 账号。它不会改变您为读数选择的计量单位。文档和公开页面都有各自的语言地址，可以直接把对方读得懂的版本发给他。

如果您需要查看翻译文件，还可以了解两点：

- **键名描述含义，不照抄英语原文。** 改写一句话，不会影响对应的键。
- **句子不会由翻译片段拼接。** 一个键对应完整句子，需要变化的值在其中插入，因为不同语言的语序并不相同。

## 单位是偏好设置，不由语言决定

在个人资料中选择公制或英制，**由您决定**，与语言设置分开。英国用户可能想用英石，另一个人可能想用千克；界面使用什么语言，都不能替他们决定。

底层记录会**用一个标准单位保存数值，在读取时换算**。因此：

- 更改偏好后，历史记录会按新设置重新显示，不会被重写。
- 每条记录仍保存写入时使用的单位，所以切换偏好不会悄悄改写十二年的读数含义。

## 日期、数字和一周的第一天

日期与数字会根据您选择的语言，通过设备的国际化功能显示。例如，英语中的日期可能是 *8 September 2026*，其他语言会采用不同顺序。一周从哪天开始是独立的设备设置；更改语言不会悄悄移动它。

一条记录属于哪一天，由**您的设备**而非服务器决定。参阅[数据模型](./data-model.md#the-date-comes-from-your-device)。

## 无障碍支持

界面使用 React Aria Components，由它负责交互控件的键盘行为和屏幕阅读器接线，而不是让每个页面自己记得实现。

每个页面都以 AA 对比度、可见焦点、完整键盘操作、至少 44 像素的触控目标，以及适应 320 至 1920 像素宽度的布局为基础。[减少动态效果](./appearance.md#motion)设置只移除动画，不移除信息。

图表会提供同一组数字的可读表格，因此图形从不是获取数值的唯一方式。
