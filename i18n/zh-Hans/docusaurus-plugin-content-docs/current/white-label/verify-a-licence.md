# 核验许可证

每份 LifeWell 授权版本都带有许可证密钥，并在自己的网站提供 `/.well-known/lifewell-white-label-license.json` 文件。您可以在[核验页面](https://lifewell.aoneahsan.com/verify-license)使用其中任意一项检查。结果来自我们的授权服务，而不是被检查的版本自身。

## 按密钥核查

| 结果 | 含义 |
|---|---|
| 有效 | 许可证有效。页面会显示获发机构、覆盖的网站和平台，以及相关日期 |
| 设置中 | 款项已支付，但授权版本尚未上线 |
| 已撤销 | 使用该密钥的版本没有有效授权 |
| 找不到该密钥的许可证 | 请对照证书核查密钥 |
| 不是 LifeWell 密钥 | LifeWell 密钥以 `LIFEWELL-` 开头 |

## 按网站核查

| 结果 | 含义 |
|---|---|
| 已授权 | 网站的许可证文件列出一份有效且覆盖该网站的许可证 |
| 不覆盖此网站 | 文件中的许可证授权给了其他网站 |
| 没有许可证文件 | 网站没有提供 LifeWell 许可证文件 |
| 无法访问 | 请过几分钟再试 |

核查只显示公开字段，绝不显示邮箱地址或价格。

## 授权版本内部的检查

授权版本启动时会检查自己的密钥，重新打开时也会再次检查。如果许可证被撤销，或不覆盖当前网站，页面会显示许可证未生效。任何人已记录的内容都不会因此删除；我们的服务发生故障时，也不会阻止授权版本运行。
