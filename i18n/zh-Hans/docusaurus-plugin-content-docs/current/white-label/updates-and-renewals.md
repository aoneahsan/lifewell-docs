# 更新与续期

每份授权和每次源码买断，从购买当天起都包含**六个月**的产品更新。

## 哪些内容算更新

LifeWell 自身收到的修复、改进和新功能，由我们应用到您的版本。只为您制作的变更不算产品更新，属于[定制工作](https://lifewell.aoneahsan.com/white-label/custom-work)。

## 六个月之后

您的版本会继续以最后更新的版本运行。续期三个月、六个月或十二个月后，即可继续获得更新。若当前期限尚未结束，续期从期限结束时开始；若已结束，则从当天开始。

在[更新页面](https://lifewell.aoneahsan.com/white-label/updates)输入许可证密钥和获发许可证时使用的邮箱地址即可续期。续期价格也列在该页面。
