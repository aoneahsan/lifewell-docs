# 设置授权版本

1. **付款。** 您可以在[价格页面](https://lifewell.aoneahsan.com/white-label/pricing)付款；若尚未开放付款，我们会发送报价。通过银行转账汇款至我们的 Wise 账户，并提供转账参考号。我们确认款项后，才会签发许可证。之后您会返回一个只读取一次订单信息的页面。
2. **接收邮件。** 邮件中附有许可证密钥和证书。请妥善保存密钥，续期时需要使用。
3. **提供品牌资料。** 我们会询问域名、希望显示的名称、标志和品牌颜色。Android 版本还需要您提供 Google Play 开发者账号的访问权限。
4. **部署您的版本。** 我们会在您的域名上部署，并发送访问地址。许可证文件随版本一同部署，许可证状态从“设置中”变为“已启用”。

只有确认付款后，许可证才会成立。订单返回页和邮件本身都不会授予使用权。
