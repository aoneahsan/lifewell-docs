# 白标与授权

白标许可证让机构以自己的名称、标志和颜色，在每个页面向成员提供 LifeWell。我们负责托管，将应用放在您的域名上，并持续更新。除非您选择一次性买断，源码仍由我们持有。

价格和购买表单见[白标页面](https://lifewell.aoneahsan.com/white-label)。本节说明您会得到什么，不重复列出价格，因为价格页面会实时读取当前数值。

## 适合哪些机构

适合与成员一起保存生活记录的机构：让家人记录长辈故事的养老机构、家族历史社团、将其作为员工福利的雇主或工会，以及社区或宗教机构。

## 两种购买方式

| 项目 | 许可证 | 买断 |
|---|---|---|
| 您会得到什么 | 以您的名称运行的 LifeWell | 网页和 Android 应用的源码 |
| 由谁运行 | 我们 | 您 |
| 是否独家 | 否，我们仍可授权其他机构 | 是，我们会停止向其他人出售 LifeWell |
| 更新 | 包含六个月，之后可续期 | 包含六个月，之后可续期 |
| 价格 | [按平台计价](https://lifewell.aoneahsan.com/white-label/pricing) | [一次性付款](https://lifewell.aoneahsan.com/white-label/buyout)，另加 LifeWell 持续产生的总收入中 7% 的特许权使用费 |

只为您的版本制作的变更属于[定制工作](https://lifewell.aoneahsan.com/white-label/custom-work)，会另行报价。

## 不会改变的事

使用您版本的人，保留所有 LifeWell 用户拥有的权利：输入的内容属于本人，可以在每张表最多 5,000 行的限制内导出所选日期范围，也能自行删除在线账号。它仍不是健康追踪器、医疗设备或临床病历，授权版本也不能以这些用途提供。

通俗版许可证说明见[许可条款](https://lifewell.aoneahsan.com/white-label/license-terms)；完整协议见[服务条款](https://lifewell.aoneahsan.com/terms#t-whitelabel)。
