# 参与文档维护

这份文档存放在[公开代码库](https://github.com/aoneahsan/lifewell-docs)。应用本身并未开源。

## 修正页面

每页底部都有**编辑此页面**链接。点击后会在 GitHub 打开对应文件，无需克隆代码库即可提出修改。

小修正最有用：错误的地址、过时的版本号、已经不符合现状的句子。提出这类修改之前，无需先讨论。

## 唯一的核心规则

**页面只能描述产品目前实际能做的事。**

这听起来理所当然，却是我们为 3.0.0 从头重写文档的原因。旧文档描述了已移除的 iOS 应用、尚未发布的浏览器扩展程序、应用不再使用的数据库，以及与真实情况相反的数据分析配置。这些话写下时都出于善意，但后来都不再准确。

因此：

- 尚未建成，就写**尚未建成**，不要写“即将推出”。
- 已建成但尚未启用，要说清楚哪些部分已启用。
- 能核对的数字，要从代码中查，而不是凭记忆填写。
- 限制要放在所限制的说法旁边，写在同一段里。隔了三节才补充的说明，很可能没人看到。

## 文风

使用第二人称。英文原文**不使用缩写**，会完整写出 *it is* 和 *does not*；不使用感叹号，采用英式英语，标题使用句首字母大写。

先用简短的陈述说清要点，再用稍长的句子补充限制或给读者选择空间。本站多数页面遵循这个节奏；掌握它，比机械照搬风格手册更有用。

不要使用 *empower*、*journey*、*seamless*、*unlock*、*effortless* 之类的套话，也不要把一个人记录中的空白说成失败。

## 本地运行

```bash
yarn install
yarn build
yarn serve
```

构建同时会检查链接：内部链接损坏时，构建会失败，不会带着坏链接发布。

## 不适合写在这里的内容

- 任何可能识别个人身份的信息，包括真实账号、真实邮箱地址或含有他人记录的截图。
- 任何凭据。这个代码库是公开的。
- 内部计划、路线图或任务清单。
