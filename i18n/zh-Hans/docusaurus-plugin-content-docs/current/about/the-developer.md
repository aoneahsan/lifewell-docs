# 谁创建了 LifeWell

**LifeWell 团队**开发和维护 LifeWell 及这份文档。

团队会坦白说明产品目前做不到什么：

- **问题汇集到同一个收件箱。** LifeWell 团队会阅读收到的每条消息。
- **并非所有功能都已建成。** 文档中有几处直接说明功能尚未完成，这比描述不存在的东西更好。
- **没有承诺时间表。** 对规划中的功能，文档会写“规划中”，而不是“即将推出”。

## 联系我们

使用应用中的 [`/contact`](https://lifewell.aoneahsan.com/contact) 或 [`/support`](https://lifewell.aoneahsan.com/support)。

## 参与建设

如果您想参与测试、撰写文案、审视设计，或提出尚无人想到的建议，可以从 [`/get-involved`](https://lifewell.aoneahsan.com/get-involved) 进入。

## 关于这份文档

文档与应用同步编写和维护，源码放在[公开代码库](https://github.com/aoneahsan/lifewell-docs)。每页底部都有编辑链接。如果此处有错误，点击链接是最直接的反馈方式——参阅[参与贡献](./contributing.md)。

应用本身并未开源。
