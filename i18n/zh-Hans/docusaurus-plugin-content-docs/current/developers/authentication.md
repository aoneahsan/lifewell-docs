# 访问令牌与身份验证

LifeWell 访问令牌是您在**设置 → 其他应用**中创建的一段长密钥。每次 API 请求都要通过 `Authorization: Bearer <token>` 发送。令牌只拥有您选择的权限范围，在您选定的日期过期，并且可以一键撤销。如果另一款应用想代表您连接，应使用 OAuth，您无须把令牌交给它。

## 如何创建令牌？

1. 打开**设置 → 其他应用 → 访问令牌**，选择**新建令牌**。
2. 起一个以后能认出来的名称——*厨房日历脚本*比*令牌 1*更清楚。
3. 选择权限范围和到期时间。
4. LifeWell 只显示一次完整令牌，并提供复制按钮。关闭面板前，请将它保存在安全位置。

之后的列表只显示每个令牌的名称、权限范围、前几个字符、创建时间和最近使用时间，不会显示完整令牌。每次创建令牌，LifeWell 都会给您发邮件；这样，陌生的令牌不容易被忽略。

## 可以再次查看令牌吗？ \{#can-i-see-a-token-again}

可以，但必须在**登录后的十分钟内**。在令牌所在行选择**显示**：

- **登录未满十分钟**：显示令牌。
- **登录已超过十分钟**：LifeWell 会说明情况，并提供**重新登录**入口；登录后会返回同一行。
- **已开启两步登录**：即使仍在十分钟内，也要输入身份验证器应用生成的验证码。

连续登录多天很方便，但失窃的笔记本电脑看起来也是这样。重新登录可以证明提出请求的人仍是您。每小时最多显示令牌十次，每次显示都会记入您的账号。令牌绝不会通过邮件发送。

## 权限范围是什么意思？

记录的每个部分最多有三种权限范围：

| 权限范围 | 令牌可以做什么 |
|---|---|
| `<resource>:read` | 读取该部分记录 |
| `<resource>:write` | 新增和修改该部分记录 |
| `<resource>:delete` | 删除该部分记录 |

`account:read` 可以读取您自己的账号资料。有哪些资源及其准确权限名称，见 [OpenAPI 文件](./api.md#where-is-the-full-reference)。

**删除权限不会自动附带。** 写入权限不包含删除；删除权限在页面上单独列出，默认关闭，只有您勾选才会授予。令牌创建后不能扩大权限：需要更多权限时，请创建新令牌并撤销旧令牌。任何令牌都不能拥有管理员权限。

## 令牌有效期多长？

可选 **30、90 或 365 天**。令牌到期前七天，LifeWell 会发邮件提醒。到期后令牌停止工作，使用它发出的请求会返回 `401`。

## 如何更换或撤销令牌？

- **轮换**会生成新令牌。旧令牌仍可使用 24 小时，方便您替换脚本中的密钥；之后它会被撤销。过渡期间，两者都会显示在列表中。
- **撤销**会立即停止令牌。下一次使用它的请求将返回 `401`。按两次确认，无须经过对话框。

删除 LifeWell 账号时，所有令牌、已连接应用、Webhook 和订阅源都会一并撤销。

## 应用如何不使用令牌也能连接？

通过 OAuth 2.1，也就是 AI 助手使用的同一种登录方式。应用会将您带到 LifeWell 的授权页面 `https://lifewell.aoneahsan.com/oauth/consent`，页面会显示：

- 应用名称，以及完成后要返回的地址；
- 即将连接的 LifeWell 账号；
- 它请求的操作，以完整句子按读取、写入和删除分组，各有独立勾选框；删除默认不勾选；
- 并排显示的**批准**和**拒绝**按钮。

如果开启了两步登录，批准时还要输入验证码。连接成功后，应用会出现在**设置 → 其他应用 → 已连接应用**中，您可以重命名或撤销它。撤销后，下次请求即失去权限，不必等当前登录自然过期。授权页面详情见 [AI 助手（MCP）](./mcp.md#what-does-the-consent-page-ask)。

## 速率限制是多少？ \{#what-are-the-rate-limits}

每个令牌和已连接应用每分钟最多发送 120 个请求。此外，整个账号还有由方案决定的每日总量：Free 每天 5,000 个，Pro 和 Family 每天 50,000 个。所有令牌和应用共享这一总量，所以创建更多令牌不会提高额度。设置 → 其他应用会在今日请求数旁显示限制。每个响应都包含：

| 响应头 | 含义 |
|---|---|
| `RateLimit-Limit` | 当前时间窗口允许的请求数 |
| `RateLimit-Remaining` | 当前时间窗口剩余的请求数 |
| `RateLimit-Reset` | 距离下一时间窗口开始的秒数 |

超过限制时，API 返回 `429`，并带有 `Retry-After` 响应头。等待所示秒数后再试。

同一瞬间发送大量请求，还可能在 LifeWell 接收前被托管平台返回 `546`。请依次发送，或一次只发送少量请求；遇到 `546` 时，一秒后重试。

## 错误响应是什么样？ \{#what-does-an-error-look-like}

所有路由都使用相同的错误结构：

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

程序应依据 `code` 处理错误；`message` 面向读者，措辞可能变化。如果您就失败的请求联系我们，请提供 `correlation_id`；我们用它定位那次请求，不会将它用于其他用途。

| 状态码 | 通常表示 |
|---|---|
| `401` | 没有令牌、令牌错误，或令牌已撤销、已过期 |
| `403` | 令牌缺少请求所需的权限范围（`details` 会说明），或需要重新登录 |
| `404` | 您的记录中不存在该 ID 的项目，包括属于其他人的内容 |
| `429` | 已达到速率限制；查看 `Retry-After` |

完整错误代码清单见 [OpenAPI 文件](./api.md#where-is-the-full-reference)。
