# 开发者更新日志

这里按时间倒序列出 LifeWell API、MCP 服务器、Webhook 和日历订阅源的每项变更。API 版本是地址的一部分——`/v1`；[OpenAPI 文件](./api.md#where-is-the-full-reference)始终描述其所在地址下的版本。

应用本身的变更见[主更新日志](../about/changelog.md)。

## 2026年11月19日

- LifeWell 已启用访问令牌（设置 → 其他应用）、附有 OpenAPI 文件的 `/v1` API、供 AI 助手使用的 MCP 服务器、Webhook、日历订阅源，以及两步登录（设置 → 安全）。
