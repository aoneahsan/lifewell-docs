# 简短导览

## 首页

打开 `/dashboard` 后，首先看到的是首页。这里有常用记录的快捷操作——一杯水、体重、心情。常做的事点一下就够，不必先翻菜单。

记录一件事只应花几秒，否则多半就不会记。这正是首页存在的理由。

## 菜单

左侧菜单按[七个领域](../domains/overview.md)分组。它只列出您已开启的领域，每个领域中也只列出适合您的页面——参阅[首次使用](./first-run.md#the-one-answer-that-changes-what-you-see)。

## 顶部栏

| 控件 | 作用 |
|---|---|
| 页面导览 | 星标旁的路标按钮。简短介绍当前页面——参阅[页面导览与操作演示](./tours-and-walkthrough.md) |
| 搜索 | 打开记录搜索。[仍在建设](../features/search.md) |
| 通知 | 应用发给您的内容——提醒、分享动态和管理通知 |
| 外观 | 一个图标打开一个面板，里面集中全部外观设置。参阅[外观](../concepts/appearance.md) |
| 您的账号 | 个人资料、方案、设置、退出登录 |

## 记录

`/tracking` 在同一个页面显示各项数字。它并不是独立于其他页面的第二份存储：`/health/water`、首页快捷操作和 `/tracking` 只是同一张表的三个视图。所以在其中一个入口记下一杯水，另外两个入口也会立即出现。

## 设置

`/settings` 保存的是账号相关选项，而不是某一条记录：

- **您的记录**——导出、删除一个领域、删除账号；
- **领域**——六个开关，以及没有开关的“分享”一行；
- **提醒**——允许应用向您发送什么；
- **分享**——谁能查看什么；
- **安全**——会话和退出登录。

## 哪里能找到坦白的说明

有四个公开页面，回答一个人将生活记录交给应用之前会问的问题：[`/privacy`](https://lifewell.aoneahsan.com/privacy) · [`/terms`](https://lifewell.aoneahsan.com/terms) · [`/permissions`](https://lifewell.aoneahsan.com/permissions) · [`/delete-account`](https://lifewell.aoneahsan.com/delete-account)。

这些页面是写给人读的，不是写给人硬着头皮读完的。没有全大写的定义术语，没有条款编号，也没有需要读第二遍才能懂的句子。
