# 页面导览与操作演示

认识 LifeWell 有两种方式。页面导览介绍您当前打开的页面；操作演示用六个画面带您看整个应用。

## 页面导览

每个重要页面的顶部栏都有**路标按钮**，就在星标旁边。按下后，简短导览会逐步介绍当前页面。

- **每页只提示一次。** 第一次打开页面时，会出现简短提示，指向路标按钮。之后无论在哪台设备上，这一页都不会再显示同一提示。
- **由您控制节奏。** 可以跳过、在任一步关闭，或直接跳到指定步骤。
- **手机也能使用。** 在小屏幕上，每一步都会从屏幕底部以面板形式打开。

## LifeWell 如何使用

**LifeWell 如何使用**包含六张应用的真实截图，顺序如下：

1. 您生活中的人
2. 与人相连的回忆
3. 一处看清每日安排
4. 用说的代替打字
5. 帮助生活过得更好的内容
6. 由您保存，也由您删除

电脑上从侧边栏底部进入；手机上从**更多**菜单底部进入。也可以直接访问 [lifewell.aoneahsan.com/how-lifewell-works](https://lifewell.aoneahsan.com/how-lifewell-works)。

## 任务

有些操作比点一下更久，例如导出文件，或“说出来”正在读取的录音。长任务列在菜单底部的**任务**中，每项显示状态：*等待中*、*处理中*、*已就绪*或*未完成*。任务运行时，您可以继续做别的事；准备好后，应用会通知您。
