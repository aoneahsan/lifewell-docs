# 首次使用

第一次登录后会开始五步设置。其中两步各只有一句说明；所有回答都不是永久决定，之后都能在设置中修改。

## 五个步骤

| 步骤 | 会问什么 | 能否跳过 |
|---|---|---|
| 欢迎 | 不提问，介绍应用的用途 | — |
| 关于您 | 显示名称、常用称呼，以及您的身份 | 可以，三项都能跳过 |
| 您关心什么 | 希望启用哪六个带开关的领域 | 可以，留空则六个领域全部保留 |
| 提醒 | 以后希望允许哪些提醒类别；此时不会创建每日提醒 | 可以 |
| 完成 | 不提问，带您进入首页 | — |

## 一个会改变所见内容的回答 \{#the-one-answer-that-changes-what-you-see}

**您的身份**决定菜单中是否显示六个页面：生理周期、备孕、排卵、多囊卵巢综合征、更年期和母乳喂养。

选择**男性**会让这些页面从菜单中移开。选择任何其他答案，包括*不愿透露*，都会保留全部页面。

*不愿透露*也是一个明确的回答，不是空白。应用会保存这个选择，不再追问，并继续显示所有页面。

从菜单中移开，并不等于消失。已记录的内容会保留；直接前往页面仍可打开。在个人资料中随时更改回答，无论改成什么，记录都不会被删除。

## 您关心什么

第三步列出六个可以关闭的[领域](../domains/overview.md)。在这里关闭，和之后在设置中关闭是同一个开关，行为也一样——页面变安静，内容不会删除。

“您自己”不在清单中，因为它是账号，不是可关闭的领域。“分享”也不在清单中，它是唯一没有关闭开关的领域。

## 完成设置后

设置中问过的内容，之后都能在两个地方找到：

- **个人资料**——您的名称、身份和基本健康信息。
- **设置**——六个领域开关、提醒、外观，以及关于您记录的所有选项。

首次设置没有任何无法重新考虑的一次性决定。
