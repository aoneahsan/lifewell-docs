# 在网页上使用 LifeWell

无需安装。打开 [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)，然后登录即可。

## 登录

**只能使用 Google 登录。** 应用没有邮箱加密码的表单。这是有意设计，并非功能尚未完成：既然没有密码，LifeWell 便不会看到或保存您的密码。

1. 打开 [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)。
2. 选择**使用 Google 继续**。
3. 选择要用来保存记录的 Google 账号。

记录属于您所选的账号。日后改用另一个账号，得到的是另一份记录，而不是原记录改了名称。

## 接下来会发生什么

首次登录会打开简短设置，共五步，大多数内容都可以留空。详见[首次使用](./first-run.md)。

## 浏览器支持

LifeWell 面向当前版本的 Chrome、Edge、Firefox 和 Safari。没有更详细的兼容性矩阵，也不会为旧版浏览器引擎另加兼容层。浏览器无法运行应用时，启动页面会直接说明，不会显示损坏的界面。

## 添加到主屏幕

网页版是一处普通网站。多数浏览器会提供添加到主屏幕或程序坞的选项，之后可用图标启动无地址栏窗口。这是浏览器功能，不是 LifeWell 另外安装了什么；不会额外下载，也不会改变应用的工作方式。

如果您希望使用 Android 版，获得本地提醒和系统通知功能，请参阅[在 Android 上安装](./install-android.md)。
