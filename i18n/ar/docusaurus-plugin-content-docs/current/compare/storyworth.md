# الانتقال من Storyworth إلى LifeWell

يرسل Storyworth إلى أحد الوالدين أو الأجداد سؤالاً أسبوعياً عبر البريد أو الهاتف، ويجمع إجابات السنة في كتاب بغلاف صلب. إنها هدية لها نهاية وكتاب في ختامها.

يحفظ LifeWell القصص عند سماعها، مجاناً وتحت اسم من رواها، طوال احتفاظك بالسجل.

آخر مراجعة في 2026-11-26. [مقارنة LifeWell وStoryworth](https://lifewell.aoneahsan.com/compare/storyworth).

## حفظ القصص بعد الكتاب \{#keeping-the-stories-after-the-book}

1. نزّل الكتاب الإلكتروني المجاني للقصص المسجلة حتى الآن، لتبقى لديك نسخة.
2. [سجّل الدخول إلى LifeWell](/getting-started/first-run) وأضف راوي القصة إلى [الأشخاص](/domains/people) مع صلته بك.
3. انقل القصص المهمة إلى [الذكريات](/domains/memories)، مع تاريخ ومكان وأشخاص كل منها.
4. في المرة المقبلة التي تروى فيها قصة حول الطاولة، استخدم Speak. يكتب الكلام ولا يحفظ شيئاً حتى تؤكده.
5. اترك الأسئلة الأسبوعية والكتاب المطبوع في Storyworth ما دامت خطته سارية.

| تنزيل بياناتك | نعم | جزئياً (<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| خطة واحدة للأسرة | نعم | جزئياً (<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |

لم تغطّ صفحات Storyworth التي راجعناها سجلاً لكل شخص أو شجرة عائلة أو روابط مشاركة أو مواعيد أو سجلات صحية أو ملاحظات أو تطبيق Android أو خطة مجانية.

يحفظ LifeWell تسجيل Speak خاصاً بك حتى تحذفه. لا يطبع كتاباً أو شجرة.
