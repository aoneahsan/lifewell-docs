# الانتقال من MyChart إلى LifeWell \{#moving-from-mychart-to-lifewell}

MyChart بوابة المرضى التي قد يقدمها مستشفاك أو عيادتك إذا كانت تستخدم Epic. تصل إليها النتائج والأدوية والفواتير ورسائل تلك العيادة.

أما LifeWell فهو سجل تحتفظ به أنت، عبر عياداتك المختلفة، إلى جانب الأشخاص والذكريات في حياتك.

آخر تحقق: 2026-11-26. شاهد [LifeWell وMyChart](https://lifewell.aoneahsan.com/compare/mychart) جنباً إلى جنب.

## الاحتفاظ بنسختك إلى جانب MyChart \{#keeping-your-own-copy-beside-mychart}

1. احتفظ بـMyChart؛ ما ترسله عيادتك يأتي منها، ولا يتصل LifeWell به.
2. [سجّل الدخول إلى LifeWell](/getting-started/first-run).
3. انسخ النتائج التي تريد الاحتفاظ بها إلى نتائج المختبر، والأدوية الحالية إلى صفحة الأدوية ضمن [الصحة](/domains/health).
4. أضف كل زيارة [موعداً](/features/calendar-and-appointments)، وضع أسئلتك في قائمة التحقق الخاصة به.
5. إذا كنت تدير رعاية طفل، فلأدويته قائمة مستقلة عن جرعات البالغين. LifeWell لا يقدم مشورة طبية.

## MyChart وLifeWell \{#mychart-and-lifewell}

| الميزة | LifeWell | MyChart |
|---|---|---|
| مشاركة صفحة مع شخص بلا حساب | نعم | جزئياً (<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| مواعيد مع تذكير | نعم | جزئياً (<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| حفظ الأدوية والحالات والنتائج | نعم | نعم (<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| خطة واحدة للأسرة | نعم | جزئياً (<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |

لم تعرض صفحة MyChart سعراً، ولم تذكر سجلاً لكل شخص أو شجرة عائلة أو ذكريات أو إملاء الإدخالات أو ملاحظات أو تنزيل بياناتك أو تطبيق Android أو خطة مجانية.

موقع MyChart: <a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">زيارة MyChart</a>.
