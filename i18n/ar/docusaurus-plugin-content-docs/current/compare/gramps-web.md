# الانتقال من Gramps Web إلى LifeWell

Gramps Web أداة مجانية مفتوحة المصدر لعلم الأنساب تشغّلها على خادمك. تقرأ GEDCOM وتكتبه، وترسم مخططات تفاعلية وتنتج تقارير كتب PDF للشجرة.

LifeWell لمن لا يريد إدارة خادم. إنه مستضاف وله تطبيق Android، ويحمل الأشخاص أنفسهم ذكرياتهم ومواعيدهم وسجلاتهم الصحية.

آخر مراجعة في 2026-11-26. [مقارنة LifeWell وGramps Web بالمصادر](https://lifewell.aoneahsan.com/compare/gramps-web).

## مغادرة الخادم الذي تديره \{#leaving-a-server-you-look-after}

1. احتفظ بتنزيل كامل لبيانات Gramps Web. لا يقرأ LifeWell صيغة GEDCOM، فيظل الملف نسختك البحثية الكاملة.
2. [سجّل الدخول إلى LifeWell](/getting-started/first-run).
3. إن كانت الأسماء أمامك، الصقها في صفحة الاستيراد في [الأشخاص](/domains/people)، اسماً في كل سطر. تُعرض القائمة قبل الحفظ. تنتقل الأسماء فقط؛ تضيف التواريخ والعلاقات بنفسك.
4. اربط الأشخاص، فتُرسم [الشجرة](/domains/people) من الروابط.
5. أضف الصور المهمة [ذكريات](/domains/memories) وحدد من يظهر فيها، كما تصنّف الأشخاص في Gramps Web.
6. احتفظ بخادم Gramps إذا احتجت كتب PDF أو قاعدة الأبحاث الكاملة.
