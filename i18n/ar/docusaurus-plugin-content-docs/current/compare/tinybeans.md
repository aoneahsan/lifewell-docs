# الانتقال من Tinybeans إلى LifeWell \{#moving-from-tinybeans-to-lifewell}

Tinybeans دفتر صور خاص لأيام الطفل. يتابع الأجداد أخباره عبر البريد الإلكتروني، وهذا الموجز البسيط هو فكرة التطبيق الأساسية.

صُمم LifeWell ليستمر بعد الطفولة. يرافق الأشخاص أنفسهم بشجرة عائلتهم وذكرياتهم وصحتهم، وتفاصيل خطته المجانية منشورة كاملة.

آخر تحقق: 2026-11-26. المقارنة في التطبيق: [LifeWell وTinybeans](https://lifewell.aoneahsan.com/compare/tinybeans).

## حين تصبح صور الطفل سجلاً للأسرة \{#when-the-baby-photos-become-a-family-record}

1. [سجّل الدخول](/getting-started/first-run) وأضف طفلك في [الأشخاص](/domains/people)، مع من يتابعون دفتره.
2. أضف الصور التي لا تريد فقدانها إلى [الذكريات](/domains/memories)، مع تاريخ ومكان لكل منها.
3. اربط الأشخاص بعضهم ببعض لتظهر [شجرة العائلة](/domains/people).
4. احتفظ بـTinybeans للموجز الذي يقرؤه الأجداد.

## Tinybeans وLifeWell \{#tinybeans-and-lifewell}

| الميزة | LifeWell | Tinybeans |
|---|---|---|
| ذكريات فيها صورة وتاريخ ومكان | نعم | نعم (<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| مشاركة صفحة مع شخص بلا حساب | نعم | جزئياً (<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |

لم نجد سعراً مقروءاً لـTinybeans عند التحقق؛ أعادت صفحات الأسعار والخطط والتطبيق رسالة «غير موجود». ولم تذكر الصفحة الرئيسية سجلاً لكل شخص أو شجرة عائلة أو إملاء إدخال أو مواعيد أو سجلات صحية أو ملاحظات أو تنزيل بياناتك أو تطبيق Android أو خطة مجانية أو خطة للأسرة.

لا يوجد تطبيق LifeWell أصلي لـiPhone. يعمل عليه عبر Safari؛ راجع [iOS](/platforms/ios).

موقع Tinybeans: <a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">زيارة Tinybeans</a>.
