# الانتقال من Journey إلى LifeWell

Journey دفتر يوميات: نسخة مجانية يمكن استخدامها بلا حد زمني، وعضوية تضيف تشفيراً من طرف إلى طرف ودفاتر مشتركة وتصديراً إلى ePub وDOCX.

يهتم LifeWell بالأشخاص بقدر الأيام. ترتبط الذكرى بمن فيها، بجانب شجرة العائلة وصحتهم ومواعيدهم.

آخر مراجعة في 2026-11-26. [مقارنة LifeWell وJourney](https://lifewell.aoneahsan.com/compare/journey).

## من إدخالات اليوميات إلى الأشخاص \{#from-diary-entries-to-people}

1. صدّر يومياتك من Journey إلى DOCX أو ePub عبر العضوية، لتحفظ النص كاملاً في ملف لديك.
2. [سجّل الدخول إلى LifeWell](/getting-started/first-run).
3. أضف الأشخاص الذين تتحدث عنهم إدخالاتك في [الأشخاص](/domains/people).
4. انقل ما تريد من الإدخالات إلى [الذكريات](/domains/memories)، مع الصور والتاريخ والمكان.
5. احتفظ بـJourney لليوميات الخاصة اليومية.

## Journey وLifeWell \{#journey-and-lifewell}

| الميزة | LifeWell | Journey |
|---|---|---|
| ذكريات بصورة وتاريخ ومكان | نعم | نعم (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| مشاركة صفحة مع شخص بلا حساب | نعم | نعم (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| تنزيل بياناتك | نعم | نعم (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |
| خطة مجانية دائمة | نعم | نعم (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">صفحتهم</a>) |

لم تذكر صفحة عضوية Journey سجلاً لكل شخص أو شجرة عائلة أو إدخالاً صوتياً أو مواعيد أو سجلات صحية أو ملاحظات أو تطبيق Android أو خطة للأسرة.

يعرض رابط Journey على الويب إدخال يوميات؛ أما رابط LifeWell فيعرض شجرة أو متابعة أو أدوية ([المشاركة](/domains/sharing)).
