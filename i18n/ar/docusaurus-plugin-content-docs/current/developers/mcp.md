# ربط مساعد ذكاء اصطناعي عبر MCP \{#connect-an-ai-assistant-mcp}

يسمح خادم MCP لمساعد الذكاء الاصطناعي بقراءة سجلك وتغييره عندما تطلب منه، مثل «من من عائلتي عيد ميلاده هذا الشهر؟» أو «أضف موعد طبيب الأسنان يوم الخميس في التاسعة والنصف». تعطيه عنواناً واحداً، وتسجل الدخول إلى LifeWell، وتختار في صفحة الموافقة ما يستطيع فعله. يعمل مع Claude وChatGPT وClaude Code وCursor وأي مساعد يدعم MCP.

## ما العنوان؟ \{#what-is-the-address}

```text
https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

تجده أيضاً تحت **الإعدادات ← التطبيقات الأخرى ← ربط مساعد ذكاء اصطناعي** مع زر نسخ. لا تلصق رمز وصول في المساعد؛ يكتشف تسجيل الدخول من هذا العنوان وينقلك إليه.

## كيف أربط كل مساعد؟ \{#how-do-i-connect-each-assistant}

تتغير قوائم هذه التطبيقات بين الإصدارات. إذا اختلفت الخطوات، ابحث عن **Connectors** في الإعدادات.

### Claude

1. افتح **Settings → Connectors** في Claude وأضف موصلاً مخصصاً.
2. الصق العنوان أعلاه.
3. سجّل الدخول إلى LifeWell عند الطلب، ووافق في صفحة الأذونات.

### ChatGPT

1. افتح **Settings → Connectors** في ChatGPT. قد تحتاج بعض الحسابات إلى تفعيل وضع المطور أولاً.
2. أضف موصلاً بالعنوان أعلاه.
3. سجّل الدخول إلى LifeWell عند الطلب، ووافق في صفحة الأذونات.

### Claude Code

```bash
claude mcp add --transport http lifewell https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

ثم شغّل `/mcp` داخل Claude Code، واختر **lifewell**، وسجّل الدخول في المتصفح المفتوح.

### Cursor

أضف LifeWell إلى `mcp.json`:

```json
{
  "mcpServers": {
    "lifewell": {
      "url": "https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp"
    }
  }
}
```

يطلب Cursor تسجيل الدخول أول مرة يستخدم فيها الاتصال.

## ماذا تطلب صفحة الموافقة؟ \{#what-does-the-consent-page-ask}

قبل وصول أي مساعد إلى سجلك، يعرض LifeWell على `https://lifewell.aoneahsan.com/oauth/consent`:

- **التطبيق الذي يطلب الوصول،** والعنوان الذي سيعيدك إليه؛
- **حساب LifeWell** الذي سيتصل به، ويستحق التحقق إذا كنت تستخدم أكثر من حساب؛
- **ما قد يفعله،** في جمل واضحة ضمن القراءة والكتابة والحذف، مع مربع اختيار لكل نوع، والحذف غير محدد افتراضياً؛
- زري **الموافقة** و**الرفض** جنباً إلى جنب.

إذا فعّلت [تسجيل الدخول بخطوتين](./two-step-sign-in.md)، تتطلب الموافقة رمزاً. لا يُوافق نيابة عنك على أي اتصال جديد. لا يرى المساعد إلا الأدوات التي تسمح بها اختياراتك؛ إذا منحت القراءة وحدها، لا يستطيع تغيير شيء.

## كيف يُعالج الحذف؟ \{#how-are-deletes-handled}

يستطيع المساعد **تحضير** طلب حذف، لكنك وحدك من **ينفذه**. حين تطلب منه إزالة شيء، يعرض ما سيُحذف ويعطيك رابطاً إلى LifeWell. تؤكد هناك خلال 10 دقائق، وإلا فلا يُحذف شيء. لا تستطيع جملة مخفية في صفحة ويب أو مستند ملصق إقناع المساعد بحذف جزء من سجلك، لأنه لا يقدر على تأكيد طلبه بنفسه.

ينطبق هذا إذا حددت صلاحية الحذف في صفحة الموافقة. دونها، لا يستطيع المساعد حتى تحضير الحذف.

## كيف أفصل المساعد؟ \{#how-do-i-disconnect-an-assistant}

افتح **الإعدادات ← التطبيقات الأخرى ← التطبيقات المتصلة** واختر **سحب** في صفه. ينتهي وصوله عند طلبه التالي. تعرض القائمة صلاحيات كل تطبيق وتاريخ اتصاله وآخر استخدام، ويظهر الاتصال الجديد فور موافقتك عليه. ويرسل LifeWell بريداً عند اتصال تطبيق.

## لماذا لا يعمل؟ \{#why-is-it-not-working}

| ما تراه | ما تفعله |
|---|---|
| يطلب المساعد الدخول مجدداً | انتهت جلسة دخوله؛ ادخل إلى LifeWell من خلاله |
| يقول إن صلاحية تنقصه | لم تمنحها. افصله وأعد ربطه وحددها في صفحة الموافقة |
| اختفى LifeWell من أدواته أو فشلت كل الاستدعاءات | سُحب الاتصال. راجع **التطبيقات المتصلة** وأعد الربط إن أردت |
| لم يحدث حذف | لم تؤكده في LifeWell خلال 10 دقائق. أعد الطلب |
| تريد معرفة ما فعله | تعرض **التطبيقات المتصلة** آخر استخدام لكل تطبيق |
