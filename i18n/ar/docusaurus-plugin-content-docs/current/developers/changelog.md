# سجل تغييرات المطورين \{#developer-changelog}

تُسجل هنا التغييرات على واجهة LifeWell البرمجية وخادم MCP وخطافات الويب وموجزات التقويم، الأحدث أولاً. إصدار الواجهة جزء من عنوانها، `/v1`، ويصف [ملف OpenAPI](./api.md#where-is-the-full-reference) الإصدار الموجود في العنوان نفسه.

تجد تغييرات التطبيق في [سجل التغييرات الرئيسي](../about/changelog.md).

## 19 نوفمبر 2026 \{#19-november-2026}

- فُعّلت في LifeWell: رموز الوصول (الإعدادات ← التطبيقات الأخرى)، وواجهة `/v1` مع ملف OpenAPI، وخادم MCP لمساعدي الذكاء الاصطناعي، وخطافات الويب، وموجزات التقويم، وتسجيل الدخول بخطوتين (الإعدادات ← الأمان).
