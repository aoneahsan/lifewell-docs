# البنية التقنية \{#architecture}

**تطبيق صفحة واحدة ثابت.** ينتج البناء مجلد ملفات، وهذا المجلد هو ما يُنشر كله. لا يوجد خادم Node في هذه البنية.

## الشكل العام \{#the-shape}

```text
المتصفح / Android WebView
        │
        ├──────────────► Postgres عبر PostgREST       (القراءات والكتابات العادية)
        │                 · أمان على مستوى الصف
        │                 · أذونات الأعمدة
        │                 · حد أقصى صارم: 50 صفاً للقائمة
        │
        └──────────────► دوال طرفية على Deno          (ما لا يجوز للمتصفح حمله)
                          · النموذجان العامان مع فحص الروبوتات
                          · فتح رابط مشاركة للقراءة فقط
                          · تبادل رمز Google Drive
                          · تقدير الذكاء الاصطناعي ومفتاحك الخاص به
                          · التصدير المجدول
                          · التحقق من مشتريات Play
                          · إجراءات إدارة المستخدمين
```

## القاعدة التي تحدد المسار \{#the-one-rule-that-decides-which}

> يتصل المتصفح بقاعدة البيانات مباشرة للبيانات العادية. لا تُستخدم الدالة الطرفية **إلا** عندما تحتاج العملية إلى شيء لا يجوز للمتصفح حمله: سر أو صلاحية مرتفعة أو تحقق من مدخلات المستخدم.

ما عدا ذلك استعلام مباشر بهويتك وتحت القواعد المذكورة في [الخصوصية والأمان](./privacy-and-security.md).

## لماذا يقع الحد في قاعدة البيانات؟ \{#why-the-boundary-sits-in-the-database}

إذا بقيت صلاحيات الوصول في شيفرة التطبيق، فلا بد من تذكر تطبيقها عند كل استدعاء. أمان الصفوف يجعل *قاعدة البيانات* ترفض الصفوف غير المصرح بها؛ فيعيد الاستعلام الخاطئ لا شيء بدلاً من سجلات شخص آخر.

ولهذا لا توجد طبقة ORM في التطبيق أثناء تشغيله. يُكتب المخطط بـTypeScript وتُنشأ منه الترحيلات خارج التشغيل، أما التطبيق فيستخدم مكتبة العميل بهوية المستخدم المسجل، فتطبق القواعد عليه.

## مما بُني؟ \{#what-it-is-built-from}

| الطبقة | الاختيار |
|---|---|
| الواجهة | React 19 |
| البناء | Vite 8، دون خرائط مصدر في الإنتاج |
| التنقل | مسارات ملفية بمعاملات بحث ذات أنواع محددة |
| حالة الخادم | TanStack Query |
| حالة العميل | Zustand، لا React context لحالة التطبيق |
| النماذج | React Hook Form وZod؛ وتتحقق مخططات Zod نفسها من الدوال الطرفية |
| إمكانية الوصول | React Aria Components يتولى عناصر DOM وربط ARIA ولوحة المفاتيح |
| الأنماط | Tailwind v4 بإعداد داخل CSS |
| الرسوم البيانية | D3 |
| النص المنسق | Tiptap؛ لا مربع كتابة نص بسيط في المنتج |
| التخزين المحلي | مكتبة واحدة هي الوحيدة التي تصل إلى تخزين المتصفح |
| Android | Capacitor 8 |

## لماذا لم نستخدم Firebase؟ \{#not-firebase}

عمل تطبيق 2.x على Firebase. ومن أسباب إعادة البناء أنه استهلك حصة القراءات المجانية وتوقف يوماً كاملاً.

السبب الآخر هو المشاركة. مشاركة جزء من السجل مع شخص محدد مسألة صفوف، ويعالجها Postgres داخل قاعدة البيانات. كان مخزن المستندات القديم يعالجها في ملف قواعد يجب أن يظل متوافقاً مع كل استعلام.

## حالة عنوان الصفحة \{#url-state}

تعيش النوافذ والتبويبات والمرشحات والفرز وتقسيم الصفحات وعبارات البحث في شريط العنوان، لا في حالة مكون. لا تفقد موضعك عند تحديث الصفحة، ويشير الرابط إلى ما تنظر إليه فعلاً.
