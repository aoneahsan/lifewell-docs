# AI معاون جوڑیں (MCP)

LifeWell MCP سرور AI معاون کو آپ کے کہنے پر ریکارڈ پڑھنے اور بدلنے دیتا ہے؛ مثلاً *”اس مہینے خاندان میں کس کی سالگرہ ہے؟“* یا *”جمعرات ساڑھے نو بجے دندان ساز کی ملاقات شامل کریں“*۔ آپ معاون کو ایک پتہ دیتے ہیں، LifeWell میں لاگ اِن ہوتے ہیں، اور اجازت کے صفحے پر اس کے کام چنتے ہیں۔ یہ Claude، ChatGPT، Claude Code، Cursor اور MCP سمجھنے والے دوسرے معاونین کے ساتھ کام کرتا ہے۔

## پتہ کیا ہے؟

```text
https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

یہی پتہ **Settings → Other apps → Connect an AI assistant** میں کاپی بٹن کے ساتھ ہے۔ معاون میں کبھی ٹوکن چسپاں نہ کریں۔ وہ اس پتے سے LifeWell کا لاگ اِن ڈھونڈ کر آپ کو وہاں بھیجتا ہے۔

## ہر معاون کیسے جوڑیں؟

ان ایپس کے مینو ریلیز کے ساتھ بدل سکتے ہیں۔ نیچے کا مرحلہ آپ کی اسکرین سے نہ ملے تو ایپ کی ترتیبات میں **Connectors** دیکھیں۔

### Claude

1. Claude میں **Settings → Connectors** کھولیں اور نیا کنیکٹر شامل کریں۔
2. اوپر والا پتہ چسپاں کریں۔
3. کہا جائے تو LifeWell میں لاگ اِن ہوں اور اجازت کے صفحے پر منظوری دیں۔

### ChatGPT

1. ChatGPT میں **Settings → Connectors** کھولیں۔ بعض اکاؤنٹس میں پہلے ڈویلپر موڈ فعال کرنا پڑتا ہے۔
2. اوپر والے پتے سے کنیکٹر شامل کریں۔
3. کہا جائے تو LifeWell میں لاگ اِن ہوں اور اجازت کے صفحے پر منظوری دیں۔

### Claude Code

```bash
claude mcp add --transport http lifewell https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

پھر Claude Code میں `/mcp` چلائیں، **lifewell** چنیں اور کھلنے والے براؤزر میں لاگ اِن ہوں۔

### Cursor

اپنے `mcp.json` میں LifeWell شامل کریں:

```json
{
  "mcpServers": {
    "lifewell": {
      "url": "https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp"
    }
  }
}
```

پہلی بار استعمال پر Cursor آپ سے لاگ اِن مانگتا ہے۔

## اجازت کا صفحہ کیا پوچھتا ہے؟ {/* #what-does-the-consent-page-ask */}

کوئی معاون آپ کے ریکارڈ تک پہنچنے سے پہلے LifeWell، `https://lifewell.aoneahsan.com/oauth/consent` پر دکھاتا ہے:

- **کون سی ایپ درخواست کر رہی ہے،** اور کس پتے پر آپ کو واپس لے جائے گی؛
- **کون سا LifeWell اکاؤنٹ** جڑنے والا ہے؛ ایک سے زیادہ ہوں تو دیکھ لیں؛
- **یہ کیا کر سکتی ہے،** سادہ جملوں میں پڑھنے، لکھنے اور حذف کرنے کے الگ گروپ، ہر اختیار کا اپنا خانہ؛ حذف شروع میں منتخب نہیں ہوتا؛
- **Approve** اور **Deny** ایک ساتھ۔

[دو مرحلہ لاگ اِن](./two-step-sign-in.md) فعال ہو تو منظوری پر کوڈ چاہیے۔ آپ کی طرف سے کچھ خودکار منظور نہیں ہوتا؛ ہر نیا رابطہ اس صفحے سے گزرتا ہے۔

معاون کو صرف وہ ٹولز دکھتے ہیں جن کی آپ نے اجازت دی۔ صرف پڑھنے کی اجازت دیں تو وہ کچھ بدل نہیں سکتا۔

## حذف کیسے ہوتا ہے؟

معاون حذف کی **تیاری** کر سکتا ہے؛ اسے **مکمل** صرف آپ کر سکتے ہیں۔ آپ کوئی چیز ہٹانے کو کہیں تو وہ بتاتا ہے کیا ہٹے گا اور LifeWell کا رابطہ دیتا ہے۔ آپ 10 منٹ کے اندر LifeWell ہی میں تصدیق کریں تو حذف ہو گا، ورنہ کچھ نہیں۔ ویب صفحے یا چسپاں کی ہوئی دستاویز میں چھپا جملہ معاون کو ریکارڈ حذف کرنے پر مجبور نہیں کر سکتا، کیونکہ معاون اپنی درخواست کی تصدیق خود نہیں کر سکتا۔

یہ طریقہ بھی صرف اس وقت دستیاب ہے جب اجازت کے صفحے پر آپ نے حذف کی اجازت چنی ہو۔ اس کے بغیر معاون حذف کی تیاری بھی نہیں کر سکتا۔

## معاون کا رابطہ کیسے ختم کریں؟

**Settings → Other apps → Connected apps** میں اس کی قطار پر **Revoke** چنیں۔ اگلی درخواست سے رسائی ختم ہو جائے گی۔ فہرست ہر ایپ کی اجازتیں، جڑنے اور آخری استعمال کا وقت دکھاتی ہے۔ منظوری دیتے ہی نیا رابطہ فہرست میں آ جاتا ہے۔ ایپ جڑنے پر LifeWell ای میل بھی کرتا ہے۔
