# LifeWell کو دوسری ایپس سے جوڑیں

LifeWell سے باہر چار طرح کی چیزیں آپ کے ریکارڈ تک پہنچ سکتی ہیں، اور ہر ایک کا اپنا راستہ ہے: **کیلنڈر ایپ** فیڈ سے، **اسکرپٹ** رسائی ٹوکن سے، **AI معاون** MCP سے، اور **دوسری ایپ** ویب ہکس سے۔ ہر راستہ آپ خود **Settings → Other apps** میں کھولتے ہیں، اور اسی صفحے سے دوبارہ بند کر سکتے ہیں۔

## یہ کس لیے ہے؟

عام خواہش یہی ہوتی ہے کہ LifeWell کھولے بغیر اس میں رکھی باتیں دیکھ سکیں۔ مثال کے طور پر خاندانی شجرہ دوسری استعمال ہونے والی ایپ میں، یا ملاقاتیں فون کے کیلنڈر میں کام کی ملاقاتوں کے پاس، کسی دوسرے کیلنڈر کو یاد رکھنے کی ضرورت کے بغیر۔

## مجھے کون سا راستہ چاہیے؟

| آپ کیا چاہتے ہیں | استعمال کریں | یہ کیا کر سکتا ہے | یہاں سے شروع کریں |
|---|---|---|---|
| LifeWell کیلنڈر Google Calendar، Apple Calendar یا Outlook میں دکھانا | کیلنڈر فیڈ | صرف کیلنڈر پڑھنا | [کیلنڈر فیڈز](./calendar-feeds.md) |
| اپنے کوڈ سے ریکارڈ پڑھنا یا بدلنا | رسائی ٹوکن اور API | وہ کام جن کی ٹوکن کی اجازت ہے | [توثیق](./authentication.md)، پھر [API](./api.md) |
| Claude، ChatGPT، Claude Code یا Cursor سے اپنے ریکارڈ کے بارے میں پوچھنا | MCP سرور | وہ کام جن کی منظوری آپ نے اجازت کے صفحے پر دی | [AI معاونین (MCP)](./mcp.md) |
| تبدیلی ہوتے ہی دوسری ایپ کو اطلاع دینا | ویب ہکس | واقعات وصول کرنا؛ ریکارڈ کی کوئی اور چیز نہیں پڑھ سکتا | [ویب ہکس](./webhooks.md) |

## ہر راستے میں کیا اصول یکساں رہتے ہیں؟

- **آپ کے کھولنے سے پہلے کچھ کھلا نہیں ہوتا۔** نئے اکاؤنٹ میں کوئی ٹوکن، فیڈ، رابطہ یا ویب ہک نہیں۔
- **حذف کی اجازت خود بخود نہیں ملتی۔** پڑھنے اور لکھنے کی اجازت دی جا سکتی ہے؛ حذف الگ اجازت ہے، جب تک آپ خود نہ چنیں بند رہتی ہے۔ AI معاون بھی LifeWell کے اندر آپ کی تصدیق کے بغیر کچھ حذف نہیں کر سکتا۔
- **رسائی رکھنے والی ہر چیز آپ دیکھ سکتے ہیں۔** Settings → Other apps ہر ٹوکن، جڑی ایپ، ویب ہک اور فیڈ کے ساتھ آخری استعمال کا وقت دکھاتا ہے۔
- **ریکارڈ پھر بھی صرف آپ کا ہے۔** ہر درخواست آپ کی شناخت سے، انہی اصولوں کے تحت پوری ہوتی ہے جو ایپ میں آپ کو دستیاب چیزیں طے کرتے ہیں۔ یہ کسی دوسرے شخص کے ریکارڈ تک نہیں پہنچتی۔

دو مرحلہ لاگ اِن اس سب کو محفوظ بناتا ہے۔ اسے فعال کریں تو ٹوکن دوبارہ دکھانے یا نئے رابطے کی منظوری کے لیے کوڈ مانگا جاتا ہے۔ [دو مرحلہ لاگ اِن](./two-step-sign-in.md) دیکھیں۔
