# ڈویلپرز کے لیے تبدیلیوں کی فہرست

LifeWell API، MCP سرور، ویب ہکس اور کیلنڈر فیڈز کی ہر تبدیلی یہاں درج ہے، نئی سے پرانی ترتیب میں۔ API کا ورژن اس کے پتے، یعنی `/v1`، میں شامل ہے۔ [OpenAPI فائل](./api.md#where-is-the-full-reference) ہمیشہ اسی ورژن کی وضاحت کرتی ہے جس کے ساتھ وہ موجود ہے۔

ایپ کی تبدیلیاں [مرکزی فہرست](../about/changelog.md) میں درج ہیں۔

## 19 نومبر 2026

- LifeWell میں رسائی ٹوکن (Settings → Other apps)، OpenAPI فائل سمیت `/v1` API، AI معاونین کے لیے MCP سرور، ویب ہکس، کیلنڈر فیڈز اور دو مرحلہ لاگ اِن (Settings → Security) فعال کیے گئے۔
