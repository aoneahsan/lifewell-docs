# ان دستاویزات میں حصہ ڈالیں

یہ دستاویزات [عوامی ذخیرے](https://github.com/aoneahsan/lifewell-docs) میں ہیں۔ ایپ کا ماخذی کوڈ عوامی نہیں۔

## صفحہ درست کرنا

ہر صفحے کے آخر میں **اس صفحے میں ترمیم کریں** کا رابطہ ہے۔ اس سے GitHub پر فائل کھلتی ہے، جہاں کچھ بھی اپنے کمپیوٹر پر لائے بغیر تبدیلی تجویز کی جا سکتی ہے۔

چھوٹی درستگیاں سب سے زیادہ مدد دیتی ہیں: غلط پتہ، پرانا ورژن، یا ایسا جملہ جو اب درست نہیں رہا۔ ان کے لیے پہلے گفتگو ضروری نہیں۔

## ایک بنیادی اصول

**صفحہ صرف وہی بات بیان کرے جو پروڈکٹ حقیقت میں کرتی ہے۔**

یہ واضح لگتا ہے، مگر اسی وجہ سے 3.0.0 کے لیے دستاویزات نئے سرے سے لکھی گئیں۔ پچھلا ورژن ہٹائی گئی iOS ایپ، اس وقت غیر شائع شدہ براؤزر ایکسٹینشن، اب استعمال نہ ہونے والے ڈیٹابیس اور اصل کے برعکس تجزیاتی نظام کو بیان کرتا تھا۔ سب باتیں نیک نیتی سے لکھی گئی تھیں، مگر درست نہیں تھیں۔

اس لیے:

- کچھ نہیں بنا تو صفحہ کہے **نہیں بنا**، *جلد آنے والا ہے* نہیں۔
- کچھ بن چکا مگر فعال نہیں ہوا تو صفحہ بتائے کون سا حصہ۔
- عدد کی تصدیق ہو سکتی ہو تو وہ یادداشت کے بجائے کوڈ سے لیا جائے۔
- کسی دعوے کی حد اسی پیراگراف میں، دعوے کے پاس لکھی جائے۔ تین حصے بعد کی وضاحت شاید کوئی نہ پڑھے۔

## اندازِ تحریر

قاری سے براہِ راست بات کریں۔ انگریزی متن میں مختصر شکلیں نہیں لکھی جاتیں: *it is* اور *does not* پورے لکھیں۔ حیرت کی علامت نہیں۔ برطانوی انگریزی استعمال ہوتی ہے، اور عنوان عام جملے کی طرح لکھا جاتا ہے۔

پہلے ایک مختصر، واضح جملہ؛ پھر ضرورت ہو تو قدرے لمبا جملہ جو شرط بتائے یا قاری کو اپنی رفتار اختیار کرنے دے۔ زیادہ تر صفحات اسی طرح لکھے گئے ہیں۔ محض انداز کی فہرست کی نقل سے یہ شکل ملانا زیادہ کارآمد ہے۔

*empower*، *journey*، *seamless*، *unlock*، *effortless* جیسے الفاظ نہ لکھیں، اور کسی کے ریکارڈ میں وقفے کو ناکامی نہ بنائیں۔

## مقامی طور پر چلانا

```bash
yarn install
yarn build
yarn serve
```

بلڈ رابطوں کی جانچ بھی کرتا ہے؛ اندرونی رابطہ ٹوٹا ہو تو شائع ہونے سے پہلے بلڈ ناکام ہوتا ہے۔

## یہاں کیا نہیں ہونا چاہیے؟

- کسی شخص کی شناخت کرانے والی چیز، جیسے حقیقی اکاؤنٹ، ای میل پتہ یا کسی کا ریکارڈ دکھاتی تصویر۔
- کسی بھی قسم کی خفیہ اسناد۔ یہ ذخیرہ عوامی ہے۔
- اندرونی منصوبہ بندی، روڈ میپ یا کاموں کی فہرستیں۔
