# اپنا ریکارڈ حذف کریں

`/settings` → **Your data**۔ اس اسکرین پر برآمد، حذف سے اوپر رکھی گئی ہے؛ یہ ترتیب دانستہ ہے۔

## اکاؤنٹ حذف کریں

پورا ریکارڈ اور اس کے پیچھے موجود اکاؤنٹ حذف ہوتا ہے۔

ترتیب یہ ہے: **Your data** → **Export a copy** → **Delete account** → تصدیق کے لیے `DELETE` ٹائپ کریں → فوراً لاگ آؤٹ، فعال ریکارڈ حذف۔

فعال اکاؤنٹ میں کوئی عارضی آرکائیو نہیں۔ رازداری کا صفحہ بتاتا ہے کہ خفیہ کردہ دستی بیک اپ میں پرانی نقل اگلی تبدیلی تک رہ سکتی ہے۔ ایپ آپ کے لاگ اِن سیشن سے اکاؤنٹ حذف کرنے کی خدمت کو درخواست بھیجتی ہے؛ آپ سے اکاؤنٹ کی شناخت درج نہیں کرواتی۔ لاگ اِن نہ کر سکیں تو عوامی [`/delete-account`](https://lifewell.aoneahsan.com/delete-account) صفحہ مدد مانگنے کا طریقہ بتاتا ہے۔

## ایک شعبہ حذف کریں {/* #delete-one-area */}

صحت یا یادوں جیسے ایک شعبے کا تمام مواد ہٹا کر باقی ریکارڈ رکھیں۔ یہ `/settings` → **Your data** → *Delete a single domain* میں ہے۔

- یہ **ایک ہی ڈیٹابیس کارروائی** میں ہوتا ہے۔ یا تمام جدولوں کی تبدیلی ایک ساتھ مکمل ہوتی ہے، یا کوئی نہیں ہوتی۔ آدھا حذف شدہ شعبہ، جس کے رکنے کی جگہ معلوم نہ ہو، دونوں نتائج سے برا ہے۔
- ایپ **جدول بہ جدول تعداد کے ساتھ بتاتی ہے** کہ کیا حذف ہوا۔
- آپ کے اکاؤنٹ کے اپنے ریکارڈ میں ایک سطر لکھی جاتی ہے، تاکہ حذف ہونا بعد میں محسوس ہونے والی محض غیر موجودگی کے بجائے درج شدہ کارروائی ہو۔
- آپ کو **الفاظ ٹائپ کرنا پڑتے ہیں**، مثلاً `DELETE HEALTH`، `DELETE MEMORIES`۔ سرور یہ شرط جانچتا ہے، صرف ڈائیلاگ نہیں۔ صرف ظاہری اسکرین کی تصدیق سہولت ہوتی؛ یہ ایک حد ہے۔

### حذف کے ایک اثر کو جانیں

**لوگ** حذف کرنے سے تصویروں کے وہ ٹیگز بھی ہٹتے ہیں جو بتاتے ہیں کہ تصویر میں کون ہے۔ وجہ یہ ہے کہ ٹیگ ایسے شخص کی طرف اشارہ کرتا ہے جو پھر موجود نہیں ہو گا۔ ان قطاروں کو گن کر رپورٹ کیا جاتا ہے، کسی ایسے شعبے میں خاموشی سے غائب نہیں ہونے دیا جاتا جسے آپ نے منتخب نہیں کیا تھا۔

### لوگ اور اشتراک الگ حذف ہوتے ہیں {/* #people-and-sharing-are-deleted-separately */}

**لوگ** حذف کرنے سے آپ کے لوگ، شجرے اور جگہیں ہٹتی ہیں، مگر آپ کی بانٹی ہوئی چیزیں نہیں بدلتی ہیں۔ **اشتراک** حذف کرنے سے ہر رابطے کی رسائی ختم ہوتی ہے، ہر رابطہ بند ہوتا ہے اور آپ کے منتظر جواب حذف ہوتے ہیں؛ آپ کے لوگ اپنی جگہ رہتے ہیں۔ رابطوں کی فہرست صاف کرنے سے ڈاکٹر کی پڑھنے کی رسائی خاموشی سے ختم نہیں ہونی چاہیے۔ [اشتراک](../domains/sharing.md) دیکھیں۔

### شعبہ حذف کرنے کے باوجود کیا رہتا ہے؟

| برقرار رہنے والی چیز | وجہ |
|---|---|
| اطلاعات | پہنچائی گئی اطلاع کا ریکارڈ کئی شعبوں سے متعلق ہو سکتا ہے۔ صحت حذف کرنے سے اشتراک کی اطلاع خاموشی سے نہیں مٹنی چاہیے۔ |
| آپ کی AI فراہم کنندہ کلید | یہ اکاؤنٹ کی سند ہے، کسی شعبے کا مواد نہیں۔ |
| Google Drive کا رابطہ | فعال سند اور بیرونی رابطہ؛ اسے ختم کرنے کا الگ اختیار ترتیبات میں ہے۔ |
| Play خریداری کا ریکارڈ | اکاؤنٹ سے متعلق ہے۔ اسے حذف کرنے سے ادا شدہ حق بے تعلق ہو جائے گا۔ |
| AI استعمال کی پیمائش | اکاؤنٹ سے متعلق ہے، اور اسی سے استعمال کی حد گنی جاتی ہے۔ |

## چھپانا حذف کرنا نہیں

[شعبہ بند کرنے](../domains/overview.md#switching-an-area-off) سے ہر قطار رہتی ہے۔ شعبہ حذف کرنے سے اس کی کوئی قطار نہیں رہتی۔ اسی لیے یہ دو اختیارات دو الگ جگہوں پر ہیں۔

## حذف کا عمل کہاں تک نہیں پہنچتا؟

- **آپ کی اپنی Google Drive کی فائلیں۔** LifeWell صرف حوالہ رکھتا ہے؛ ریکارڈ حذف ہونے سے حوالہ ہٹتا ہے۔ فائلیں Drive میں آپ کی ملکیت ہیں، اور انہیں آپ وہیں حذف کر سکتے ہیں۔ [آپ کا ریکارڈ کہاں رہتا ہے](./where-it-lives.md) دیکھیں۔
- **کسی اور کو بھیجی ہوئی چیزیں۔** آپ کا بھیجا پیغام اس کی گفتگو میں بھی موجود ہوتا ہے۔
- **اکاؤنٹ کے بارے میں انتظامی جانچ کی سطریں۔** جس کارروائی کرنے والے کو اپنا جانچ ریکارڈ مٹانے کی اجازت ہو، وہ جانچ ریکارڈ نہیں۔ ایسی سطریں اکاؤنٹ سے زیادہ عرصے رہتی ہیں اور آپ کے مواد کے بجائے کارروائی بیان کرتی ہیں۔
