# LifeWell

**اپنی زندگی کے لوگوں اور لمحوں کو ایک جگہ رکھیں، اور ان کے ساتھ جڑی باقی باتیں بھی۔**

LifeWell آپ کی زندگی کے لوگ اور لمحات ایک جگہ رکھتا ہے۔ آپ خود سے شروع کرتے ہیں، اپنے اہم لوگوں کو شامل کرتے ہیں، ان کے بارے میں جو جانتے ہیں اور جو لمحے ساتھ گزارتے ہیں وہ محفوظ کرتے ہیں۔ LifeWell کی باقی چیزیں اسی لیے ہیں کہ آپ کی زندگی اچھی طرح چل سکے۔

LifeWell صحت کا ٹریکر نہیں۔ صحت آپ کی زندگی کے لوگوں کے گرد ایک شعبہ ہے، ایپ کا مقصد نہیں۔

## سات شعبے، اور درمیان میں آپ

| شعبہ | کیا رکھتا ہے |
|---|---|
| [لوگ](./domains/people.md) | خاندان اور کام، خاندانی شجرہ، آپ کے جڑے ہوئے لوگ، گروپ اور گفتگو |
| [یادیں](./domains/memories.md) | تصاویر، البم، اسکریپ بُک اور وہ تفصیل جو بعد میں یاد کو پڑھنے کے قابل بناتی ہے |
| [روزمرہ](./domains/everyday.md) | کیلنڈر، نوٹس، محفوظ جگہیں، یاد دہانیاں، خریداری کی فہرست |
| [اشتراک](./domains/sharing.md) | جو آپ نے دوسروں کو پڑھنے دیا: روابط، ساتھی سے اشتراک اور واپس آنے والے جواب |
| [صحت](./domains/health.md) | پیمائشیں، ادویات، خوراک، حرکت، نیند، حالتیں، لیب کے نتائج |
| [ذہن](./domains/mind.md) | ڈائری، رہنمائی والے سیشن، کیفیت، شکر گزاری، سانس کی مشق |
| [زندگی کے مراحل](./domains/stages.md) | ماہواری، حمل کی کوشش، حمل، سن یاس اور بچے کے ابتدائی سال |

**آپ** سات شعبوں میں سے ایک نہیں۔ آپ اکاؤنٹ ہیں: پروفائل، منصوبہ، ترتیبات، اور اوپر کی تمام چیزوں پر اختیار۔

سات میں سے چھ شعبے [بند کیے جا سکتے ہیں](./domains/overview.md#switching-an-area-off)۔ بند کرنے کا مطلب خاموش ہونا ہے: مینو انہیں نہیں دکھاتا، آپ کے اندراجات رہتے ہیں، اور براہِ راست پتے سے صفحہ پھر بھی کھلتا ہے۔ اشتراک کا سوئچ نہیں، کیونکہ جو کچھ آپ نے دوسروں کو پڑھنے دیا ہے وہ آپ کو نظر آنا چاہیے۔

## آپ کے ریکارڈ کے بارے میں درست باتیں

- **چند فوری اندراجات آلے پر انتظار کر سکتے ہیں۔** آف لائن اندراج فعال کریں تو معاونت یافتہ پیمائشیں، ماہواری کے دن کی تبدیلیاں اور علامات کی کیفیتیں رابطہ بحال ہونے پر بھیجی جاتی ہیں۔ دوسرے صفحات آف لائن رک جاتے ہیں۔
- **تصاویر اور فائلیں آپ کی اپنی Google Drive میں جاتی ہیں،** ایسی رسائی کے ساتھ جو صرف LifeWell کی بنائی فائلوں تک پہنچتی ہے۔ [آپ کا ریکارڈ کہاں رہتا ہے](./your-data/where-it-lives.md) دیکھیں۔
- **منتخب تاریخوں کا ریکارڈ برآمد کر سکتے ہیں:** ایپ سے JSON یا CSV ڈیٹا، یا PDF خلاصہ۔ ہر برآمد میں ایک جدول کی حد 5,000 قطاریں ہے۔ ہر خانے کی تفصیل [فارمیٹ کے صفحے](./reference/export-format.md) پر ہے۔
- **فعال اکاؤنٹ یا اس کا ایک شعبہ حذف کر سکتے ہیں،** اور ایپ بتاتی ہے کون سی قطاریں ہٹیں۔ خفیہ کردہ دستی بیک اپ میں پرانی نقل اگلی تبدیلی تک رہ سکتی ہے، جیسا رازداری کا صفحہ بتاتا ہے۔

## ورژن

یہ دستاویزات **LifeWell 3.x** ایپ کے بارے میں ہیں، جسے جاری شدہ 2.x ورژن سے نئے بنیادی نظام پر دوبارہ بنایا گیا۔

:::warning[2.x سے 3.0.0 پر جانے سے ریکارڈ نئے نظام میں منتقل نہیں ہوئے]
بنیادی نظام تبدیل ہوا اور پرانے ریکارڈ کو منتقل کرنے کا راستہ نہیں تھا۔ 2.x سے سیدھی اپ ڈیٹ پر پرانا ریکارڈ 3.0.0 میں ساتھ نہیں آیا۔ یہ فیصلہ اس وقت ہوا جب ایپ کا کوئی حقیقی صارف نہیں تھا۔ پھر بھی یہاں درج ہے، کیونکہ ایپ کھولنے والے کے لیے دانستہ صفائی اور سنگین خرابی ایک جیسی لگ سکتی ہیں۔
:::
