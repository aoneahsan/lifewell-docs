# ظاہری انداز

اوپر کی پٹی میں ایک نشان اور اس کے اندر ایک پینل ہے۔ ظاہری انداز کی تمام ترتیبات وہیں ملتی ہیں، ہر صفحے پر، چاہے آپ لاگ اِن ہوں یا نہیں۔

## آٹھ ترتیبات {/* #the-eight-settings */}

| ترتیب | کیا بدلتا ہے |
|---|---|
| تھیم | روشن، تاریک یا ڈیوائس کی ترتیب کے مطابق |
| رنگ | نمایاں رنگ اور اس کے گرد سادہ رنگ |
| کونوں کی گولائی | تمام عناصر کے کونے کتنے گول ہیں |
| گنجائش | ہر قطار کتنی جگہ لیتی ہے |
| متن کا سائز | صرف عام متن نہیں، پوری تحریری پیمائش |
| فونٹ | ایپ میں استعمال ہونے والا خط |
| سطح کا انداز | پینل صفحے پر کیسے دکھائی دیتے ہیں |
| حرکت | مکمل یا کم حرکت |

## پہلی جھلک سے پہلے لاگو {/* #applied-before-the-first-paint */}

صفحہ کچھ دکھانے سے **پہلے** یہ ترتیبات پڑھی اور لاگو کی جاتی ہیں۔ ایپ کھلتے وقت غلط تھیم کی جھلک نہیں آتی، کیونکہ تھیم کا فیصلہ رینڈر ہونے سے پہلے ہو جاتا ہے۔

اسی لیے تمام انتخاب ایک جگہ محفوظ ہوتے ہیں اور ایک ہی جدول سے لاگو ہوتے ہیں۔ اگر کسی جزو میں رنگ یا کونوں کی گولائی مستقل لکھ دی جائے تو یہ پینل اسے بدل نہیں سکتا۔ ایک ہی کنٹرول رکھنے کا مقصد اسی خامی سے بچنا ہے۔

## حرکت {/* #motion */}

**حرکت کبھی معلومات کا واحد ذریعہ نہیں ہوتی۔** کم حرکت کا انتخاب معلومات ہٹائے بغیر اینیمیشن کم کرتا ہے۔

ترتیب میں *سسٹم* کا لفظ رکھنے کے بجائے اس کا طے شدہ نتیجہ رکھا جاتا ہے۔ یہ فرق اہم ہے: صرف `prefers-reduced-motion` میڈیا کوئری ہر انتخاب پر حاوی ہو سکتی ہے۔ نتیجہ ایک بار طے ہو جائے تو ڈیوائس نے کم حرکت مانگی ہو تب بھی آپ ایپ میں مکمل حرکت چن سکتے ہیں۔

## انتخاب کہاں محفوظ ہوتے ہیں {/* #where-it-is-kept */}

آپ کے انتخاب اسی ڈیوائس پر محفوظ ہوتے ہیں۔ اسی پینل میں **میرا ظاہری انداز دوسری ڈیوائسز پر بھی رکھیں** آن ہو تو یہ آپ کے اکاؤنٹ میں بھی محفوظ ہوتے ہیں اور دوسری لاگ اِن ڈیوائس پر آ سکتے ہیں۔ لیپ ٹاپ اور فون پر الگ انداز چاہیے تو اسے بند رکھیں؛ ہر ڈیوائس اپنا انتخاب محفوظ رکھتی ہے۔

## تضاد اور ٹچ اہداف {/* #contrast-and-targets */}

ہر صفحہ کم از کم AA رنگی تضاد اور 44 پکسل کے ٹچ ہدف کے لیے بنایا گیا ہے۔ نمایاں فوکس، کی بورڈ سے مکمل استعمال اور 320 سے 1920 پکسل چوڑائی تک درست ترتیب بھی اسی معیار کا حصہ ہیں۔
