# ساخت

یہ ایک **جامد سنگل پیج ایپ** ہے۔ بلڈ فائلوں کا ایک فولڈر بناتا ہے اور پورا ڈیپلائمنٹ وہی فولڈر ہے۔ اس نظام میں کوئی Node سرور نہیں۔

## نقشہ {/* #the-shape */}

```text
Browser / Android WebView
        │
        ├──────────────► Postgres via PostgREST    (عام پڑھنا اور لکھنا)
        │                 · ہر قطار کی رسائی کے قواعد
        │                 · کالم کی اجازتیں
        │                 · فہرست پر زیادہ سے زیادہ 50 قطاروں کی حد
        │
        └──────────────► Deno Edge Functions      (جو براؤزر میں نہیں ہونا چاہیے)
                          · دو عوامی فارم، بوٹ جانچ کے ساتھ
                          · صرف پڑھنے والا شیئر لنک کھولنا
                          · Google Drive ٹوکن کا تبادلہ
                          · AI تخمینہ اور آپ کی اپنی AI کلید
                          · مقررہ وقت کے ایکسپورٹ
                          · Play خریداری کی تصدیق
                          · منتظم کے اکاؤنٹ سے متعلق اقدامات
```

## فیصلہ کرنے والا ایک اصول {/* #the-one-rule-that-decides-which */}

> عام ڈیٹا کے لیے براؤزر براہ راست ڈیٹابیس سے بات کرتا ہے۔ Edge Function **صرف** اس وقت استعمال ہوتا ہے جب عمل کو ایسی چیز چاہیے جو براؤزر کے پاس نہیں ہونی چاہیے: راز، بلند اختیار یا صارف کی لکھی ہوئی بات پر خاص اعتماد۔

باقی ہر کام براہ راست آپ کی شناخت میں، [رازداری اور حفاظت](./privacy-and-security.md) کے قواعد کے تحت، درخواست کرتا ہے۔

## حد ڈیٹابیس میں کیوں ہے {/* #why-the-boundary-sits-in-the-database */}

اگر رسائی کا فیصلہ ایپ کے کوڈ میں ہو تو ہر جگہ اسے یاد رکھنا پڑتا ہے۔ قطار کی سطح کے حفاظتی قواعد کی وجہ سے **ڈیٹابیس** خود انکار کرتا ہے۔ غلط لکھی گئی درخواست کسی دوسرے شخص کی قطاریں دینے کے بجائے خالی نتیجہ دیتی ہے۔

اسی لیے چلتی ایپ میں ORM نہیں۔ ڈیٹابیس کی ساخت TypeScript میں لکھی جاتی ہے اور آف لائن مائگریشن بنتی ہے؛ لیکن ایپ چلتے وقت کلائنٹ لائبریری کے ذریعے لاگ اِن شخص کی حیثیت سے درخواست کرتی ہے، جہاں وہی قواعد لاگو ہوتے ہیں۔

## استعمال ہونے والی چیزیں {/* #what-it-is-built-from */}

| حصہ | انتخاب |
|---|---|

| بلڈ | Vite 8؛ پروڈکشن میں سورس میپ نہیں |

| سرور سے آنے والا ڈیٹا | TanStack Query |

| مقامی ذخیرہ | ایک لائبریری، جسے براؤزر کے ذخیرے تک رسائی کی اجازت ہے |

## Firebase کیوں نہیں {/* #not-firebase */}

LifeWell کا 2.x ورژن Firebase پر چلتا تھا۔ اس نے مفت قرأت کی حد ختم کر دی اور ایپ ایک دن کے لیے رک گئی؛ نئی ساخت اس خامی کو درست کرتی ہے۔

دوسری وجہ شیئرنگ ہے۔ ریکارڈ کا صرف چنا ہوا حصہ کسی نامزد شخص کو دکھانا قطار کی سطح کا سوال ہے۔ Postgres اس کا جواب ڈیٹابیس میں دیتا ہے؛ پرانا دستاویزی ذخیرہ ایک قواعدی فائل پر انحصار کرتا تھا جسے ہر درخواست کے ساتھ درست رکھنا پڑتا تھا۔

## پتے میں محفوظ حالت {/* #url-state */}

ڈائیلاگ، ٹیب، فلٹر، ترتیب، صفحہ بندی اور تلاش کے الفاظ جزو کی عارضی حالت کے بجائے پتے میں رہتے ہیں۔ صفحہ تازہ کرنے سے آپ کی جگہ نہیں کھوتی؛ جس چیز کو دیکھ رہے ہیں، اس کا لنک اسی چیز تک لے جاتا ہے۔
