# Gramps Web سے LifeWell پر آنا

Gramps Web خاندانی تاریخ کا مفت، کھلے ماخذ کا نظام ہے جسے آپ اپنے سرور پر چلاتے ہیں۔ یہ GEDCOM پڑھتا اور لکھتا ہے، انٹرایکٹو نقشے بناتا ہے، اور شجرے کی PDF کتابی رپورٹیں تیار کرتا ہے۔

LifeWell اس شخص کے لیے ہے جو سرور کی دیکھ بھال نہیں کرنا چاہتا۔ یہ ہوسٹڈ ہے، Android ایپ رکھتا ہے، اور انہی لوگوں کے ساتھ یادیں، ملاقاتیں اور صحت کا ریکارڈ بھی رکھتا ہے۔

آخری جانچ 2026-11-26 کو ہوئی۔ ماخذ کے ساتھ موازنہ: [LifeWell اور Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web)۔

## اپنے زیرِ انتظام سرور سے آنا {/* #leaving-a-server-you-look-after */}

1. Gramps Web کے پورے ڈیٹا کی ایک نقل ڈاؤن لوڈ کر کے رکھیں۔ LifeWell GEDCOM نہیں پڑھتا، اس لیے وہ فائل آپ کی مکمل تحقیقی نقل رہے گی۔
2. [LifeWell میں سائن اِن کریں](/getting-started/first-run)۔
3. نام موجود ہوں تو انہیں [لوگوں](/domains/people) کے درآمد والے صفحے میں ایک نام فی سطر چسپاں کریں۔ کچھ محفوظ ہونے سے پہلے یہ ہر ملنے والے شخص کو دکھاتا ہے۔ صرف نام آتے ہیں؛ تاریخیں اور رشتے آپ کو شامل کرنا ہوتے ہیں۔
4. لوگوں کے باہمی رشتے جوڑیں۔ [شجرہ](/domains/people) انہی روابط سے بنتا ہے۔
5. جن تصویروں کو رکھنا چاہتے ہیں انہیں [یادوں](/domains/memories) میں شامل کریں اور ہر تصویر میں موجود لوگ نشان زد کریں، جیسے Gramps Web میں افراد کو ٹیگ کرتے تھے۔
6. PDF کتابی رپورٹیں یا مکمل تحقیقی ڈیٹابیس چاہیے تو Gramps سرور بھی رکھیں۔
