# Storyworth سے LifeWell پر آنا

Storyworth والدین یا دادا دادی اور نانا نانی کو ہر ہفتے ای میل یا فون سے ایک سوال بھیجتا ہے، پھر سال بھر کے جواب سخت جلد والی کتاب میں باندھتا ہے۔ یہ ایسا تحفہ ہے جس کی مدت ختم ہوتی ہے اور آخر میں کتاب ملتی ہے۔

LifeWell کہانیاں سنتے وقت ہی مفت محفوظ کرتا ہے، انہیں سنانے والے شخص کے تحت رکھتا ہے، اور ریکارڈ رکھنے تک انہیں آپ کے پاس رہنے دیتا ہے۔

آخری جانچ 2026-11-26 کو ہوئی۔ دونوں کا موازنہ: [LifeWell اور Storyworth](https://lifewell.aoneahsan.com/compare/storyworth)۔

## کتاب کے بعد کہانیاں محفوظ رکھنا {/* #keeping-the-stories-after-the-book */}

1. اب تک کی کہانیوں کی مفت ای بک ڈاؤن لوڈ کریں۔ آگے جو بھی فیصلہ ہو، یہ نقل آپ کی رہے گی۔
2. [LifeWell میں سائن اِن کریں](/getting-started/first-run) اور کہانی سنانے والے شخص کو اپنے رشتے کے ساتھ [لوگوں](/domains/people) میں شامل کریں۔
3. اہم کہانیوں کو تاریخ، جگہ اور ان میں موجود لوگوں کے ساتھ [یادوں](/domains/memories) میں منتقل کریں۔
4. اگلی بار دسترخوان پر کوئی کہانی سنائے تو Speak it استعمال کریں۔ یہ بولی ہوئی بات لکھ دیتا ہے، اور آپ کی تصدیق تک کچھ محفوظ نہیں ہوتا۔
5. پلان جاری رہنے تک ہفتہ وار سوالات اور چھپی ہوئی کتاب Storyworth میں ہی رکھیں۔

Storyworth کے جن صفحات کو ہم نے پڑھا ان پر ہر شخص کا الگ ریکارڈ، خاندانی شجرہ، شیئر لنکس، ملاقاتیں، صحت کا ریکارڈ، نوٹس، Android ایپ یا مفت پلان درج نہیں تھا۔

LifeWell ہر Speak it ریکارڈنگ آپ کے لیے نجی رکھتا ہے، یہاں تک کہ آپ اسے حذف کریں۔ یہ نہ کتاب چھاپتا ہے نہ شجرہ۔
