# Evernote سے LifeWell کی طرف

Evernote وہاں کام آتا ہے جہاں اصل کام نوٹس ہی ہوں: نوٹ بکس، ویب سے مواد محفوظ کرنا، دستاویزیں اسکین کرنا اور اپنے ہر آلے پر تلاش کرنا۔

LifeWell میں نوٹس لوگوں کے بارے میں بنے ریکارڈ کا ایک حصہ ہیں۔ یادداشتیں، صحت اور ملاقاتیں بھی ساتھ رہتی ہیں۔

آخری جانچ 2026-11-26 کو ہوئی۔ موازنہ: [LifeWell اور Evernote](https://lifewell.aoneahsan.com/compare/evernote)۔

## نوٹ بکس سے لوگوں تک

1. Evernote سے مطلوبہ نوٹ بکس PDF میں برآمد کریں، تاکہ ایک نقل آپ کے پاس رہے۔
2. [سائن اِن کریں](/getting-started/first-run) اور جن لوگوں کے بارے میں نوٹس ہیں، انہیں [لوگ](/domains/people) میں شامل کریں۔
3. نوٹس کو [LifeWell کے نوٹس](/domains/everyday) میں نقل کریں۔ یہاں فولڈر حذف کرنے سے اس کے اندر کے نوٹس حذف نہیں ہوتے۔
4. Evernote کے تاریخ اور یاد دہانی والے نوٹس کو [کیلنڈر کی ملاقاتیں](/features/calendar-and-appointments) بنائیں، [یاد دہانی](/features/reminders) سمیت۔
5. ویب سے مواد محفوظ کرنے اور دستاویزیں اسکین کرنے کے لیے Evernote رکھیں۔
