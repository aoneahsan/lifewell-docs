# Elfie سے LifeWell پر آنا

Elfie جسمانی پیمائشوں اور دواؤں کی مفت ایپ ہے جو ہر صحت سے متعلق عمل پر سکے دیتی ہے۔ اگر انعامات آپ کو ریڈنگز درج کرتے رہنے میں مدد دیتے ہیں تو اسے استعمال کرنے کی یہ معقول وجہ ہے۔

LifeWell صحت سے متعلق کام درج کرنے پر سکے یا مسلسل دنوں کے انعام نہیں دیتا۔ یہ صحت کا خاموش ریکارڈ ہے جو آپ کی زندگی کے لوگوں، یادوں اور ملاقاتوں کے ساتھ رہتا ہے۔ اس کے اختیاری ریفرل پوائنٹس صحت کی نگرانی سے الگ ہیں۔

آخری جانچ 2026-11-26 کو ہوئی۔ ایپ میں موازنہ: [LifeWell اور Elfie](https://lifewell.aoneahsan.com/compare/elfie)۔

## اپنی ریڈنگز لانا {/* #moving-your-readings */}

1. [سائن اِن کریں](/getting-started/first-run)۔
2. بلڈ پریشر [صحت](/domains/health) میں ایک ٹریکر ہے۔ جو ریڈنگز رکھنا چاہتے ہیں درج کریں؛ ایک ہی دن کی دوسری ریڈنگ پہلی کی جگہ لے لیتی ہے۔
3. اپنی دوائیں اور ان کے اوقات شامل کریں۔ دواؤں کی [یاد دہانیاں](/features/reminders) پہلے سے فعال ہیں۔
4. والد یا والدہ کی دیکھ بھال کرتے ہیں؟ ملاقات میں یہ بھی درج ہوتا ہے کہ کس کے ساتھ ہے، تاکہ ان کا معائنہ [کیلنڈر](/features/calendar-and-appointments) میں واضح رہے۔
5. اگر Elfie کے سکے آپ کے لیے مددگار ہیں تو اسے بھی رکھیں۔ LifeWell طبی مشورہ نہیں دیتا۔
