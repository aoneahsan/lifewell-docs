# Any.do سے LifeWell کی طرف

Any.do گھر والوں کو کاموں، سودا سلف اور یاد دہانیوں کے لیے ایک مشترک جگہ دیتا ہے۔ مفت منصوبہ بھی ہے اور چار افراد کے لیے Family منصوبہ بھی۔ LifeWell میں کاموں کی عمومی فہرست نہیں۔

LifeWell میں خاندان کے ریکارڈ کی نوعیت الگ ہے: ہر فرد کا شجرے میں مقام، یادداشتیں، صحت سے متعلق نوٹس اور ملاقاتیں۔

آخری جانچ 2026-11-26 کو ہوئی۔ دونوں کا موازنہ ایک صفحے پر: [LifeWell اور Any.do](https://lifewell.aoneahsan.com/compare/any-do)۔

## خاندان کی مشترک جگہ کو تقسیم کرنا

1. [LifeWell میں سائن اِن کریں](/getting-started/first-run) اور گھر والوں کو [لوگ](/domains/people) میں شامل کریں۔
2. ڈاکٹر، دندان ساز اور اسکول کی ملاقاتیں [کیلنڈر](/features/calendar-and-appointments) میں درج کریں؛ ہر ملاقات کے ساتھ [یاد دہانی](/features/reminders) رکھ سکتے ہیں۔
3. سودا سلف Any.do میں رہنے دیں یا LifeWell کی [خریداری کی فہرست](/features/shopping-list) میں منتقل کریں۔ یہ کھانوں کے منصوبے سے بھی بھر سکتی ہے اور سادہ متن میں بھیجی جا سکتی ہے، اس لیے خریداری کرنے والے کو اکاؤنٹ نہیں چاہیے۔
4. گھر کے دوسرے کام Any.do میں ہی رکھیں۔
