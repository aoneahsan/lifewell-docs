# Короткий обзор

## Главная страница

После входа открывается `/dashboard`. Здесь есть быстрые действия для частых записей: стакана воды, веса, настроения. Обычное действие требует одного нажатия, а не поисков нужного раздела.

Запись должна занимать секунды, иначе её легко отложить. Для этого и нужна главная страница.

## Меню

Левое меню сгруппировано по [семи разделам](../domains/overview.md). Оно показывает только включённые вами разделы, а внутри них — экраны, которые относятся к вам. См. [Первый запуск](./first-run.md#ответ-который-меняет-меню).

## Верхняя панель

| Элемент | Что делает |
|---|---|
| Экскурсия по странице | Указатель рядом со звездой. Коротко знакомит с открытой страницей — см. [Экскурсии и пошаговый обзор](./tours-and-walkthrough.md) |
| Поиск | Открывает поиск по записям. [Находится в разработке](../features/search.md) |
| Уведомления | То, что прислало приложение: напоминания, события общего доступа, сообщения администратора |
| Внешний вид | Один значок и одна панель для всех настроек оформления. См. [Внешний вид](../concepts/appearance.md) |
| Учётная запись | Профиль, план, настройки, выход |

## Показатели

`/tracking` показывает все числа в одном месте. Он не хранит их отдельно от других экранов: `/health/water`, быстрое действие на главной и `/tracking` показывают записи одной таблицы. Поэтому стакан воды, добавленный на одном экране, сразу виден на двух других.

## Настройки

`/settings` содержит то, что относится к учётной записи, а не к отдельной записи:

- **Ваши данные** — экспорт, удаление раздела или учётной записи.
- **Разделы** — шесть переключателей и строка «Общий доступ» без переключателя.
- **Напоминания** — что приложение вправе отправлять вам.
- **Общий доступ** — кто и что может читать.
- **Безопасность** — сеансы и выход.

## Где найти прямые ответы

Четыре публичные страницы отвечают на вопросы, которые возникают перед тем, как доверить приложению личные записи:
[`/privacy`](https://lifewell.aoneahsan.com/privacy) ·
[`/terms`](https://lifewell.aoneahsan.com/terms) ·
[`/permissions`](https://lifewell.aoneahsan.com/permissions) ·
[`/delete-account`](https://lifewell.aoneahsan.com/delete-account).

Они написаны для чтения: без заглавных букв для определяемых терминов, нумерации пунктов и предложений, которые приходится перечитывать дважды.
