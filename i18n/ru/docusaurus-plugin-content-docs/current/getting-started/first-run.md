# Первый запуск

После первого входа открывается настройка из пяти шагов. Два шага состоят из одного предложения. Ответы можно изменить позже: для каждого есть место в настройках.

## Пять шагов

| Шаг | Что спрашивают | Можно пропустить |
|---|---|---|
| Приветствие | Ничего. Экран объясняет, для чего нужно приложение | — |
| О вас | Отображаемое имя, предпочитаемое имя и сведения о вас | Да, все три |
| Что важно | Какие из шести разделов с переключателем вы хотите видеть | Да. Если ничего не выбирать, останутся все шесть |
| Напоминания | Какие категории напоминаний вы хотите разрешить в будущем; ежедневное напоминание не создаётся | Да |
| Готово | Ничего. Открывается главная страница | — |

## Ответ, который меняет меню

Ответ на вопрос **«Кто вы?»** определяет, будут ли в меню перечислены шесть экранов: цикл, попытки зачать ребёнка, овуляция, СПКЯ, менопауза и грудное вскармливание.

При выборе **«Мужчина»** эти экраны убираются из меню. Любой другой ответ, включая *«Предпочитаю не отвечать»*, оставляет их на месте.

*«Предпочитаю не отвечать»* — полноценный ответ, а не пустое поле. Он сохраняется, приложение больше не задаёт вопрос, и все экраны остаются видимыми.

Убранный из меню экран не исчезает. Ваши записи сохраняются, а сам экран можно открыть напрямую. Ответ можно в любой момент изменить в профиле; записи при этом не удаляются.

## Что важно

На третьем шаге перечислены шесть [разделов](../domains/overview.md) с переключателями. Выключить раздел здесь — то же самое, что выключить его в настройках: он перестаёт показываться, но данные не удаляются.

Раздела «Вы» в списке нет: это учётная запись, а не отключаемый раздел. «Общий доступ» тоже не включён: у него нет переключателя.

## После настройки

Ответы на вопросы первого запуска затем находятся в двух местах:

- **Профиль** — ваши имена, сведения о вас и основные медицинские данные.
- **Настройки** — шесть переключателей разделов, напоминания, внешний вид и управление данными.

Любое решение, принятое при первом запуске, можно пересмотреть.
