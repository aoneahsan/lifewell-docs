# LifeWell в браузере

Устанавливать ничего не нужно. Откройте [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) и войдите.

## Вход

**Войти можно только через Google.** Отдельной формы с адресом электронной почты и паролем нет — это сделано намеренно. Мы не видим и не храним пароль, потому что в LifeWell его нет.

1. Откройте [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com).
2. Выберите **Продолжить через Google**.
3. Выберите учётную запись Google, с которой будут связаны ваши записи.

Записи принадлежат выбранной учётной записи. Если позже войти через другую, откроются другие записи, а не переименованные прежние.

## Что будет дальше

При первом входе откроется короткая настройка из пяти шагов. Большинство полей можно оставить пустыми. Подробнее — в разделе [Первый запуск](./first-run.md).

## Поддержка браузеров

LifeWell рассчитан на актуальные версии Chrome, Edge, Firefox и Safari. Отдельной таблицы совместимости и дополнительных средств для старых движков нет. Если браузер не может запустить приложение, об этом сообщит стартовый экран, а не сломанная страница.

## Значок на главном экране

Веб-версия работает как обычный сайт. Большинство браузеров предлагают добавить его на главный экран или в панель приложений. Тогда появятся значок и окно без адресной строки. Это возможность браузера; ничего дополнительного загружать не нужно, а работа приложения не меняется.

Если вам нужна версия Android с локальными напоминаниями и системными уведомлениями, см. [Установка на Android](./install-android.md).
