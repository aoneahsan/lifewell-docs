# Планы

Есть три уровня. Страница [`/plans`](https://lifewell.aoneahsan.com/plans) в приложении показывает действующие условия и строится из той же таблицы, по которой сервер проверяет доступ.

Цены указаны в долларах США.

| | Free | Pro | Family |
|---|---|---|---|
| За месяц | $0 | **$9.99** | **$8.99 за место** |
| За год | $0 | **$99.90** | **$89.90 за место** |
| Места | 1 | 1 | Не меньше 3, верхнего предела нет |
| Люди, о которых можно вести записи | 50 | Без ограничения | Без ограничения |
| Записи | Без ограничения | Без ограничения | Без ограничения |
| Хранилище | 5 ГБ | 50 ГБ | 200 ГБ |
| Экспорт выбранного периода, до 5 000 строк из каждой таблицы | Да | Да | Да |
| Ссылки для чтения | Да | Да | Да |
| Экспорт по расписанию | — | Да | Да |
| Действующие консультации | До 10 | Без ограничения | Без ограничения |
| Оценочные запросы к ИИ за месяц | 50 | 1 000 | 1 500 |

Family начинается с трёх мест: $26.97 в месяц за троих. При покупке вы выбираете число мест, а затем распределяете их.

## Места Family

Место меняет план человека и ничего больше.

- **Кому можно его дать.** Человеку, с которым вы уже связаны в LifeWell как семья и который находится в вашей [семейной группе](./domains/people.md#связи-и-группы). Незнакомому человеку место передать нельзя.
- **Записи не становятся общими.** Вы не видите журнал, записи, людей или файлы человека, занявшего ваше место, а он не видит ваши. Вам видны только факт использования места и дата, когда оно было занято.
- **Любая сторона может завершить использование места** в любое время.
- **Когда план заканчивается, все места закрываются.** Каждый журнал остаётся как был; всё, что превышает пределы Free, становится доступно только для чтения, пока человек не выберет свой план.

## Как определён бесплатный план

Планы различаются не объёмом доступных разделов, а **стоимостью их использования для сервиса**:

- Строка таблицы почти не требует расходов, поэтому Free щедр на записи: 50 людей, неограниченное число записей и ссылки для чтения.
- Хранилище стоит денег, хотя не за каждое действие. Поэтому его объём на Free меньше, но оно доступно.
- Каждый оценочный запрос к ИИ требует затрат, поэтому его предел самый строгий. **Собственный ключ снимает этот предел на любом плане, включая Free.**
- Задание по расписанию выполняется без нового запроса человека, поэтому экспорт по расписанию относится к платным возможностям.

**Экспорт есть на любом плане.** Это намеренно. Продукт, который хранит сведения о вашей жизни, не должен требовать плату, чтобы вы забрали копию.

## Два способа оплаты

### В веб-версии

`/profile/premium` показывает планы и способ оплаты. Платёж оформляется вручную, без формы для карты: вы платите, сообщаете нам, а администратор по вашему заявлению назначает план с датой окончания.

### На Android

На Android покупки проходят через **Google Play Billing**, поскольку Google требует продавать цифровые товары в Android-приложении этим способом. Внутри приложения нет ссылки на оплату в другом месте; панель Android не показывает цену веб-версии и не сравнивает их.

:::warning[Play Billing создан, но не включён]
Покупка, серверная проверка и уведомления Google о продлении реализованы, собираются и проверены по записанным ответам. **Настоящей покупки пока не было**, служебная учётная запись Play не настроена, а переключатель платформы для покупок по умолчанию выключен. Пока подписанную для внутреннего тестирования сборку не проверят настоящей покупкой на устройстве, оплату Android нужно считать неподтверждённой: вне сборки, подписанной Play, этот путь вообще нельзя проверить.
:::

## Как план ограничивает действия

Отказ возвращает сервер. Предел — не просто скрытая кнопка: если он превышен, база данных отклонит запись, даже если запрос пришёл не из приложения.

Пределы хранятся в строке плана и могут измениться без выпуска новой версии. Числа выше соответствуют действующим планам на момент подготовки страницы.

## Назначение плана и срок

У назначенного администратором плана есть дата окончания и записанная причина назначения. План с уже прошедшим сроком назначить нельзя: он не появился бы на экранах, а ошибка осталась бы незаметной.

[Награда за приглашение](./features/referrals.md) продлевает платный план, а не заменяет его.

## Изменение и завершение

- **Веб** — план действует до даты окончания. Автоматического продления, которое нужно отменять, нет.
- **Android** — управляйте подпиской или отмените её в Google Play, где проходит покупка. В LifeWell нет отдельной кнопки отмены: транзакцию хранит Google, и кнопка без действия была бы хуже её отсутствия.

Когда план заканчивается, ваши записи не меняются. Для новых действий действуют пределы Free; уже внесённые сведения остаются, а [экспорт](./your-data/export.md) доступен на каждом уровне.
