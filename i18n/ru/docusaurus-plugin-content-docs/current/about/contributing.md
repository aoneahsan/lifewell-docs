# Как помочь с документацией

Эта документация хранится в [публичном репозитории](https://github.com/aoneahsan/lifewell-docs). Код приложения не публикуется.

## Как исправить страницу

Внизу каждой страницы есть ссылка **«Изменить эту страницу»**. Она открывает файл на GitHub, где можно предложить правку без загрузки репозитория на компьютер.

Небольшие исправления особенно полезны: неверный адрес, устаревший номер версии, предложение, которое перестало соответствовать действительности. Их можно предложить без предварительного обсуждения.

## Главное правило

**Страница описывает только то, что продукт действительно делает.**

Именно поэтому документацию переписали с нуля для версии 3.0.0. Прошлая версия рассказывала об удалённом приложении iOS, ещё не выпускавшемся расширении браузера, базе данных, которой приложение уже не пользовалось, и неверном наборе аналитических сервисов. Все эти описания были написаны добросовестно, но не соответствовали продукту.

Поэтому:

- Если функция не создана, страница говорит **«не создана»**, а не *«скоро появится»*.
- Если функция создана, но не включена, страница уточняет её состояние.
- Число, которое можно проверить, берётся из кода, а не из памяти.
- Ограничение стоит рядом с утверждением, которое оно уточняет, в том же абзаце. Оговорку тремя разделами ниже почти никто не прочитает.

## Манера письма

Обращайтесь к читателю на **вы**. В английском тексте не используйте сокращения: пишите *it is* и *does not* полностью. Без восклицательных знаков. Британский вариант английского. В заголовках — обычный регистр предложения.

Сначала короткая ясная фраза, затем более длинная, которая её уточняет или даёт читателю выбор. Многие страницы построены так; сохранить этот ритм полезнее, чем строго следовать формальному руководству по стилю.

Избегайте английских *empower*, *journey*, *seamless*, *unlock*, *effortless* и формулировок, в которых пробел в чьих-то записях выглядит личной неудачей.

## Как запустить сайт локально

```bash
yarn install
yarn build
yarn serve
```

Сборка проверяет ссылки: при сломанной внутренней ссылке она не завершится успешно.

## Чему здесь не место

- Сведениям, по которым можно узнать человека: настоящей учётной записи, настоящему адресу почты или снимку экрана с чьим-то журналом.
- Любым учётным данным. Репозиторий открыт всем.
- Внутренним планам, дорожным картам и очередям задач.
