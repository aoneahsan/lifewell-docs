# Этапы жизни

Этот раздел охватывает то, что меняется в разные годы жизни.

## Шесть экранов, зависящих от сведений о вас

От одного ответа в профиле зависит, будут ли эти экраны перечислены в меню:

| Экран | Что в нём хранится |
|---|---|
| Цикл | Прогнозы по вашей истории, а не по среднему циклу других людей |
| Попытки зачать ребёнка | Периоды, тесты и заметки в одном месте, вместо нескольких приложений и блокнота |
| Овуляция | Вероятные дни фертильности с оговоркой, что цикл может меняться |
| СПКЯ | Записи о состоянии здоровья: симптомы, встречи и слова специалиста |
| Менопауза | Симптомы и их изменения на протяжении месяцев, доступные для перечитывания |
| Грудное вскармливание | Кормления и их время в отдельном журнале ребёнка |

При выборе **«Мужчина»** эти части убираются из меню. Любой другой ответ оставляет их на месте. Записи при этом не удаляются.

Убранный из меню экран остаётся доступен по прямому адресу. Всё, что вы записали, сохраняется.

## Цикл

`/period` хранит дни цикла и рассчитывает следующий период по **вашей** истории, а не по предположению о цикле в 28 дней. На странице есть оговорка: если цикл меняется, прогноз тоже может меняться. Приложение не выдаёт предполагаемую дату за установленный факт.

## Ребёнок

`/baby` хранит записи о ранних годах ребёнка отдельно для каждого ребёнка, а не общим списком:

- **Кормления** — `/baby/feeding`.
- **Сон** — `/baby/sleep`.
- **Подгузники** — `/baby/diapers`.
- **Рост** — `/baby/growth`, с графиком вместо одной таблицы.
- **Этапы развития** — `/baby/milestones`.

`/tools/child-growth` — публичный калькулятор, связанный с графиком роста. Он работает без учётной записи.

## Имена для ребёнка

[`/baby-names`](https://lifewell.aoneahsan.com/baby-names) — публичная страница. Для неё не нужна учётная запись, и она ничего не сохраняет о вас.

## Как поделиться частью раздела

Партнёру или родственнику можно разрешить читать только часть этого раздела, а не всё сразу. Это настройка доступа, а не этапа жизни. См. [Общий доступ](./sharing.md).
