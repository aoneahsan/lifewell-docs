# Переход с Journey на LifeWell

Journey — дневник с бесплатной версией без срока окончания. Подписка добавляет сквозное шифрование, общие дневники и экспорт в ePub и DOCX.

LifeWell хранит записи не только по дням, но и рядом с людьми, о которых они. Воспоминание связано с человеком, семейным деревом, сведениями о здоровье и встречами.

Последняя проверка: 26 ноября 2026 г. Сравнение в приложении: [LifeWell и Journey](https://lifewell.aoneahsan.com/compare/journey).

## От дневника к людям

1. Экспортируйте дневник Journey в DOCX или ePub через подписку, чтобы полный текст остался у вас в файле.
2. [Войдите в LifeWell](/getting-started/first-run).
3. Добавьте людей из записей в раздел [«Люди»](/domains/people).
4. Перенесите нужные записи как [воспоминания](/domains/memories) со снимками, датой и местом.
5. Оставьте Journey для личного ежедневного дневника.

## Journey и LifeWell

| Возможность | LifeWell | Journey |
|---|---|---|
| Воспоминания с фотографией, датой и местом | Да | Да (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">страница подписки</a>) |
| Доступ к странице человеку без учётной записи | Да | Да (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">страница подписки</a>) |
| Скачивание своих данных | Да | Да (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">страница подписки</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">страница подписки</a>) |

На странице подписки Journey не были заявлены отдельный журнал для каждого человека, семейное дерево, запись голосом, встречи, сведения о здоровье, заметки, приложение Android или семейный план.

Веб-ссылка Journey показывает запись дневника. Ссылка LifeWell вместо неё может открыть дерево, показатель или лекарства ([общий доступ](/domains/sharing)).
