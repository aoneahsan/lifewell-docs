# Переход с Evernote на LifeWell

Evernote подходит, когда главная задача — заметки: блокноты, сохранение веб-страниц, сканирование и поиск документов на разных устройствах.

В LifeWell заметки — одна часть журнала о людях. Рядом с ними находятся воспоминания, сведения о здоровье и встречи.

Последняя проверка: 26 ноября 2026 г. Сравнение: [LifeWell и Evernote](https://lifewell.aoneahsan.com/compare/evernote).

## От блокнотов к людям

1. Экспортируйте нужные блокноты из Evernote в PDF, чтобы сохранить копию.
2. [Войдите](/getting-started/first-run) и добавьте людей из этих заметок в раздел [«Люди»](/domains/people).
3. Перенесите текст в [заметки](/domains/everyday). Удаление папки в LifeWell не удалит находившиеся в ней заметки.
4. Заметки Evernote с датой и напоминанием превратите во [встречи](/features/calendar-and-appointments) с [напоминанием](/features/reminders).
5. Сохраните Evernote для сбора веб-страниц и сканирования документов.

## Evernote рядом с LifeWell

| Возможность | LifeWell | Evernote |
|---|---|---|
| Встречи с напоминанием | Да | Частично (<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Заметки | Да | Да (<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Скачивание своих данных | Да | Да (<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Приложение Android | Да | Да (<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |

На странице планов Evernote не упоминались отдельный журнал для каждого человека, семейное дерево, воспоминания, запись голосом, общие ссылки, сведения о здоровье или семейный план.
