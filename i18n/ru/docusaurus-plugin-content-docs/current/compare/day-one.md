# Переход с Day One на LifeWell

Day One — ежедневный дневник со сквозным шифрованием, вопросами-подсказками, звуком, местами и печатными книгами из записей. Если вы пишете каждый день, он создан для этой привычки.

LifeWell связывает воспоминание с людьми, к которым оно относится, а его бесплатный план не ограничивается одной фотографией.

Последняя проверка: 26 ноября 2026 г. Сравнение: [LifeWell и Day One](https://lifewell.aoneahsan.com/compare/day-one).

## От дневниковых записей к воспоминаниям

1. Сначала экспортируйте дневник из Day One. Выгрузка CSV и JSON сохранит полный текст во время перехода; LifeWell не умеет импортировать эти файлы.
2. [Войдите в LifeWell](/getting-started/first-run).
3. Добавьте людей, которые часто появляются в дневнике, в раздел [«Люди»](/domains/people).
4. Переносите важные записи по одной как [воспоминания](/domains/memories): снимок, дата, название места и люди рядом.
5. Когда удобнее рассказать, чем печатать, Speak it запишет ваши слова и попросит подтвердить результат.
6. Оставьте Day One для ежедневных записей и печатной книги.

## Day One и LifeWell

| Возможность | LifeWell | Day One |
|---|---|---|
| Воспоминания с фотографией, датой и местом | Да | Да (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |
| Сказать вслух, чтобы сохранилась запись | Да | Да (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |
| Доступ к странице человеку без учётной записи | Да | Частично (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |
| Скачивание своих данных | Да | Да (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |
| Приложение Android | Да | Да (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |

На странице цен Day One не упоминались отдельный журнал для каждого человека, семейное дерево, встречи, сведения о здоровье, заметки или семейный план.

Записи звука, переданные Speak it, доступны только вам до удаления. Приложения iPhone нет: на iPhone LifeWell работает в Safari ([iOS](/platforms/ios)).
