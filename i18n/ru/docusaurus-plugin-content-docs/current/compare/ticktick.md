# Переход с TickTick на LifeWell

TickTick объединяет задачи, привычки и календарь на разных устройствах. Есть бесплатный план и годовой Premium. В LifeWell списка задач нет.

Календарь LifeWell связан с людьми, а рядом с ними хранятся воспоминания, дерево и сведения о здоровье.

Последняя проверка: 26 ноября 2026 г. Сравнение по пунктам: [LifeWell и TickTick](https://lifewell.aoneahsan.com/compare/ticktick).

## Как пользоваться TickTick вместе с LifeWell

1. [Войдите](/getting-started/first-run).
2. Найдите в TickTick списки о семье — лекарства родителя, встречи ребёнка — и добавьте людей в раздел [«Люди»](/domains/people).
3. Датированные пункты семейного списка перенесите в [календарь](/features/calendar-and-appointments) LifeWell. На странице месяца они будут рядом с другими событиями журнала.
4. Если список состоял из чьих-то лекарств, внесите их в раздел [«Здоровье»](/domains/health) с дозой, расписанием и [напоминанием](/features/reminders).
5. Привычки и задачи оставьте в TickTick.

## TickTick рядом с LifeWell

| Возможность | LifeWell | TickTick |
|---|---|---|
| Сказать вслух, чтобы сохранилась запись | Да | Частично (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Встречи с напоминанием | Да | Частично (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Заметки | Да | Частично (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Приложение Android | Да | Частично (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">страница планов</a>) |

На странице планов TickTick не были заявлены отдельный журнал для каждого человека, семейное дерево, воспоминания, общие ссылки, сведения о здоровье, скачивание данных или семейный план.

Записи, созданные через Speak it, остаются личными, пока вы их не удалите.
