# Переход с Remento на LifeWell

Remento сохраняет голос родителя. Он присылает вопросы для устного ответа без приложения и входа, превращает каждую запись в главу текста и печатает книгу в твёрдом переплёте с QR-кодом для прослушивания голоса.

LifeWell не создаёт книгу. Это бесплатное место для людей, их воспоминаний, дерева и встреч.

Последняя проверка: 26 ноября 2026 г. Все приведённые факты также есть в сравнении [LifeWell и Remento](https://lifewell.aoneahsan.com/compare/remento).

## После того как главы записаны

1. Скачайте из Remento записи голоса и фотографии. Сервис позволяет забрать оригиналы.
2. [Войдите в LifeWell](/getting-started/first-run) и добавьте родителя, рассказавшего истории, в раздел [«Люди»](/domains/people).
3. Для каждой нужной главы создайте [воспоминание](/domains/memories) рядом с ним, со снимками и датой.
4. Новые истории можно записывать через Speak it: он сохранит голос и текст. Запись доступна только вам, пока вы её не удалите.
5. Оставьте Remento для печатной книги и QR-кода, воспроизводящего голос.

## Remento и LifeWell

| Возможность | LifeWell | Remento |
|---|---|---|
| Воспоминания с фотографией, датой и местом | Да | Частично (<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Сказать вслух, чтобы сохранилась запись | Да | Да (<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Скачивание своих данных | Да | Да (<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Приложение Android | Да | Нет (<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Один план для семьи | Да | Частично (<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На главной странице Remento не были заявлены отдельный журнал для каждого человека, семейное дерево, общие ссылки, встречи, сведения о здоровье, заметки или бесплатный план.

LifeWell не печатает книги или деревья.
