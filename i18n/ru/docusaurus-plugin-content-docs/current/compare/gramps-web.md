# Переход с Gramps Web на LifeWell

Gramps Web — бесплатный генеалогический проект с открытым исходным кодом, который вы размещаете на собственном сервере. Он читает и записывает GEDCOM, строит интерактивные схемы и создаёт PDF-книги о семейном дереве.

LifeWell подойдёт, если вы не хотите обслуживать сервер. Сервис размещён для вас, у него есть приложение для Android, а рядом с людьми в записях живут воспоминания, встречи и данные о здоровье.

Последняя проверка — 26 ноября 2026 г. Сравнение с источниками: [LifeWell и Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web).

## Если вы уходите со своего сервера

1. Сохраните полную выгрузку данных Gramps Web. LifeWell не читает GEDCOM, поэтому этот файл останется полной копией ваших генеалогических исследований.
2. [Войдите в LifeWell](/getting-started/first-run).
3. Если список имён под рукой, вставьте их на странице импорта в разделе [«Люди»](/domains/people), по одному имени в строке. Перед сохранением LifeWell покажет всех найденных людей. Переносятся только имена; даты и связи нужно добавить самостоятельно.
4. Укажите связи между людьми. По ним строится [дерево](/domains/people).
5. Добавьте важные фотографии в [воспоминания](/domains/memories) и отметьте людей на каждой — как при привязке людей к снимкам в Gramps Web.
6. Сохраните сервер Gramps, если вам нужны PDF-книги или полная база исследований.

## Gramps Web и LifeWell рядом

| Возможность | LifeWell | Gramps Web |
|---|---|---|
| Отдельная запись о каждом человеке в вашей жизни | Да | Да (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |
| Семейное дерево | Да | Да (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |
| Воспоминания с фотографией, датой и местом | Да | Частично (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |
| Ссылка для человека без аккаунта | Да | Частично (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |
| Выгрузка собственных данных | Да | Да (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |
| Постоянный бесплатный план | Да | Да (<a href="https://www.grampsweb.org/" target="_blank" rel="noopener noreferrer nofollow">страница проекта</a>) |

На страницах Gramps Web не упоминаются голосовой ввод записей, встречи, данные о здоровье, заметки, приложение для Android и семейный план.

LifeWell не умеет печатать дерево и не создаёт книги о нём.
