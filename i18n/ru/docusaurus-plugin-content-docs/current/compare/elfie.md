# Переход с Elfie на LifeWell

Elfie — бесплатное приложение для жизненных показателей и лекарств, которое выдаёт монеты за полезные действия. Если награды помогают вам регулярно измерять показатели, это веская причина пользоваться им.

LifeWell не выдаёт монеты или серии достижений за действия со здоровьем. Он хранит спокойный журнал здоровья рядом с людьми, воспоминаниями и встречами. Необязательные баллы за приглашения отделены от показателей здоровья.

Последняя проверка: 26 ноября 2026 г. Сравнение в приложении: [LifeWell и Elfie](https://lifewell.aoneahsan.com/compare/elfie).

## Перенос показаний

1. [Войдите](/getting-started/first-run).
2. Кровяное давление записывается в разделе [«Здоровье»](/domains/health). Внесите показания, которые хотите сохранить; второе значение за день заменит первое.
3. Добавьте лекарства с расписанием. [Напоминания](/features/reminders) о лекарствах изначально включены.
4. Заботитесь о родителе? В записи о встрече можно указать участника, чтобы его осмотр был понятен в вашем [календаре](/features/calendar-and-appointments).
5. Оставьте Elfie, если монеты помогают вам продолжать. LifeWell не даёт медицинских советов.

## Elfie рядом с LifeWell

| Возможность | LifeWell | Elfie |
|---|---|---|
| Хранение лекарств, состояний и результатов | Да | Частично (<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Один план для семьи | Да | Частично (<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На главной странице Elfie не упоминались отдельный журнал для каждого человека, семейное дерево, воспоминания, запись голосом, общие ссылки, встречи, заметки, скачивание данных или приложение Android.
