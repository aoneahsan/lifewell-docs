# Переход с MyTherapy на LifeWell

MyTherapy бесплатно напоминает о лекарствах и ведёт дневник приёма. Работу сервиса оплачивают партнёры, включая фармацевтические компании. Для врача можно создать отчёт о здоровье и план приёма лекарств.

LifeWell хранит сведения о лекарствах рядом с записями о самом человеке: воспоминаниями, семейным деревом и остальной жизнью.

Последняя проверка: 26 ноября 2026 г. Сравнение с источниками: [LifeWell и MyTherapy](https://lifewell.aoneahsan.com/compare/mytherapy).

## От плана MyTherapy к LifeWell

1. Создайте в MyTherapy отчёт о здоровье и план лекарств. По ним будет проще перенести список.
2. [Войдите](/getting-started/first-run) и добавьте каждое лекарство с дозой и расписанием в разделе [«Здоровье»](/domains/health). Там же отмечаются действительно принятые дозы.
3. Встречи с врачом внесите в [календарь](/features/calendar-and-appointments) со списком вопросов для каждой.
4. Для показателей, о которых напоминал MyTherapy — давления, сахара крови, веса, — в разделе [«Здоровье»](/domains/health) есть отдельные экраны.
5. Сохраните одноразовый код MyTherapy, если врач читает ваш план по нему. LifeWell ничего не отправляет в систему врача и не даёт медицинских советов.

## MyTherapy и LifeWell

| Возможность | LifeWell | MyTherapy |
|---|---|---|
| Доступ к странице человеку без учётной записи | Да | Частично (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Встречи с напоминанием | Да | Да (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Хранение лекарств, состояний и результатов | Да | Да (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Скачивание своих данных | Да | Частично (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На главной странице MyTherapy не упоминались отдельный журнал для каждого человека, семейное дерево, воспоминания, запись голосом, заметки, приложение Android или семейный план.
