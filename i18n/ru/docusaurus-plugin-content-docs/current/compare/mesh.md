# Переход с Mesh на LifeWell

Mesh помогает поддерживать большой круг профессиональных контактов. Он импортирует контакты из почты, LinkedIn и календаря, отслеживает важные события в жизни людей и подсказывает, когда стоит возобновить общение. Есть приложения для macOS, Windows и iOS.

LifeWell рассчитан на семью и друзей. Рядом с каждым человеком можно хранить воспоминания и сведения о здоровье. Для бесплатного плана банковская карта не нужна.

Последняя проверка — 26 ноября 2026 г. Сравнение двух продуктов: [LifeWell и Mesh](https://lifewell.aoneahsan.com/compare/mesh).

## Выберите близких из контактов Mesh

1. [Войдите в LifeWell](/getting-started/first-run).
2. Выберите среди контактов Mesh родных и близких друзей и добавьте их в раздел [«Люди»](/domains/people).
3. Важные для них даты внесите в [календарь](/features/calendar-and-appointments), установив [напоминание](/features/reminders) для каждого события.
4. Профессиональные контакты оставьте в Mesh. LifeWell ничего не считывает из вашей почты или LinkedIn и не подключается к внешним календарям.

## Mesh и LifeWell рядом

| Возможность | LifeWell | Mesh |
|---|---|---|
| Отдельная запись о каждом человеке в вашей жизни | Да | Да (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Встречи с напоминаниями | Да | Частично (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Постоянный бесплатный план | Да | Да (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На странице цен Mesh не указаны семейное дерево, воспоминания, голосовой ввод записей, ссылки для совместного доступа, данные о здоровье, заметки, выгрузка своих данных, приложение для Android и семейный план.

У Mesh есть приложение для iOS. У LifeWell его нет; на iPhone сервис работает в Safari.
