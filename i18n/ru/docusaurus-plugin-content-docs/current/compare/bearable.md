# Переход с Bearable на LifeWell

Bearable помогает людям с длительными состояниями увидеть, как со временем меняются симптомы, настроение, сон и приём лекарств. Большая часть возможностей бесплатна; данные можно экспортировать и полностью удалить в самом приложении.

LifeWell хранит сведения о здоровье рядом с остальной жизнью: людьми, воспоминаниями и встречами.

Последняя проверка: 26 ноября 2026 г. Оба продукта на одной странице: [LifeWell и Bearable](https://lifewell.aoneahsan.com/compare/bearable).

## Как уйти из Bearable со своей историей

1. Сначала экспортируйте данные из Bearable.
2. [Войдите](/getting-started/first-run).
3. Для настроения и сна есть отдельные экраны в разделе [«Здоровье»](/domains/health), где последняя запись за день заменяет прежнюю. Лекарства внесите на страницу лекарств.
4. Каждое состояние здоровья добавьте как постоянную запись, а эпизоды записывайте под ней.
5. Встречи добавьте в [календарь](/features/calendar-and-appointments) со списком тем для обсуждения.
6. Сохраните Bearable для отчётов, которые берёте на приём. LifeWell не даёт медицинских советов.

## Bearable и LifeWell

| Возможность | LifeWell | Bearable |
|---|---|---|
| Хранение лекарств, состояний и результатов | Да | Частично (<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Скачивание своих данных | Да | Да (<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Бесплатный план без срока окончания | Да | Да (<a href="https://bearable.app/pricing" target="_blank" rel="noopener noreferrer nofollow">страница цен</a>) |

На проверенных страницах Bearable не были заявлены отдельный журнал для каждого человека, семейное дерево, воспоминания, запись голосом, общие ссылки, встречи, заметки, приложение Android или семейный план.
