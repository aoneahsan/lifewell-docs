# Переход с Withings+ на LifeWell

Withings+ дополняет весы и часы Withings. Сервис превращает их показания в ежедневные оценки, предлагает помощника по здоровью и создаёт PDF для дистанционного приёма у врача.

LifeWell рассчитан на тех, кто записывает данные вручную и не пользуется такими устройствами. Сведения о здоровье хранятся рядом с записями о людях и воспоминаниями.

Последняя проверка — 26 ноября 2026 г. Сравнение: [LifeWell и Withings+](https://lifewell.aoneahsan.com/compare/withings-plus).

## Если вы перестаёте пользоваться устройствами

1. Сначала выгрузите PDF-отчёт о здоровье из Withings, чтобы сохранить показания.
2. [Войдите в LifeWell](/getting-started/first-run).
3. Внесите нужные показатели вручную. Для веса, артериального давления и пульса в разделе [«Здоровье»](/domains/health) есть отдельные трекеры. LifeWell ничего не считывает с весов или часов.
4. Дистанционный приём можно добавить в [календарь](/features/calendar-and-appointments) как обычную встречу.
5. Если вы по-прежнему пользуетесь устройствами, сохраните бесплатное приложение Withings. LifeWell не даёт медицинских рекомендаций.

## Withings+ и LifeWell рядом

| Возможность | LifeWell | Withings+ |
|---|---|---|
| Хранение лекарств, заболеваний и результатов | Да | Частично (<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Выгрузка собственных данных | Да | Частично (<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Постоянный бесплатный план | Да | Да (<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Один план для семьи | Да | Частично (<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На странице Withings+ не упоминаются отдельная запись о каждом человеке, семейное дерево, воспоминания, голосовой ввод записей, ссылки для совместного доступа, встречи, заметки и приложение для Android.

| План | Цена | Источник |
