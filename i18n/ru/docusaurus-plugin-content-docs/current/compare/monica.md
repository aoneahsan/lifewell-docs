# Переход с Monica на LifeWell

Monica — персональная CRM с открытым исходным кодом. Её можно бесплатно запустить на своём сервере или пользоваться размещённой версией. В ней хранятся записи о людях, отношениях, разговорах и напоминания вроде «позвонить маме».

LifeWell размещён для вас и доступен сейчас на Android и в браузере. К записям о тех же людях он добавляет воспоминания, семейное дерево и данные о здоровье.

Последняя проверка — 26 ноября 2026 г. Сравнение с источниками: [LifeWell и Monica](https://lifewell.aoneahsan.com/compare/monica).

## Перенесите людей из Monica

1. [Войдите в LifeWell](/getting-started/first-run).
2. Если у вас есть список имён или файл контактов (.vcf), вставьте список или выберите файл на странице импорта в разделе [«Люди»](/domains/people). Импортируются только имена; перед сохранением можно проверить всех найденных людей.
3. Дополните каждую запись вручную: кем вам приходится человек и какие сведения о нём вы вели в Monica.
4. Напоминания из Monica перенесите как [события](/features/calendar-and-appointments), установив для каждого [напоминание](/features/reminders).
5. Записи о человеке можно сохранить в [заметках](/domains/everyday), разложив по папкам.
6. Не отключайте сервер Monica, пока не перенесёте всё нужное.

## Monica и LifeWell

| Возможность | LifeWell | Monica |
|---|---|---|
| Отдельная запись о каждом человеке в вашей жизни | Да | Да (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Семейное дерево | Да | Частично (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Встречи с напоминаниями | Да | Частично (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Заметки | Да | Да (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Выгрузка собственных данных | Да | Да (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |
| Постоянный бесплатный план | Да | Да (<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">страница сервиса</a>) |

На страницах Monica не указаны воспоминания, голосовой ввод записей, ссылки для совместного доступа, данные о здоровье, приложение для Android и семейный план.

У LifeWell нет приложения для iPhone.
