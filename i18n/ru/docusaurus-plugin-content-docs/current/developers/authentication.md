# Токены доступа и авторизация

Токен доступа LifeWell — длинный секрет, который вы создаёте в **Настройки → Другие приложения** и передаёте с каждым запросом API как `Authorization: Bearer <token>`. Он разрешает выбранные вами действия, действует до выбранной даты и отзывается одним нажатием. Приложение, которое подключается от вашего имени, использует OAuth: передавать ему токен вручную не нужно.

## Как создать токен?

1. Откройте **Настройки → Другие приложения → Токены доступа** и выберите **Создать токен**.
2. Назовите его так, чтобы потом узнать: *скрипт кухонного календаря* понятнее, чем *токен 1*.
3. Выберите права и срок действия.
4. LifeWell один раз покажет токен с кнопкой копирования. Сохраните его в надёжном месте перед закрытием панели.

В списке затем видны название токена, права, первые символы, дата создания и последнего использования. Полный токен там не показывается. При создании токена LifeWell отправляет вам письмо, чтобы вы заметили токен, который сами не создавали.

## Можно ли снова увидеть токен?

Да, в течение **десяти минут после входа**. В строке токена выберите **«Показать»**:

- **После входа прошло меньше десяти минут** — токен показывается.
- **Прошло больше десяти минут** — LifeWell предлагает **войти снова** и затем возвращает к той же строке.
- **Включена дополнительная проверка при входе** — даже в пределах десяти минут нужно ввести код из приложения-аутентификатора.

Оставаться в системе много дней удобно. Но со стороны это похоже на доступ к украденному ноутбуку. Новый вход подтверждает, что токен запрашиваете вы. Показывать токен разрешено не более десяти раз в час; каждый показ записывается в учётной записи. По почте токен никогда не отправляется.

## Что означают права?

Для каждой части журнала есть до трёх областей доступа:

| Область | Что разрешено токену |
|---|---|
| `<resource>:read` | Читать эту часть журнала |
| `<resource>:write` | Добавлять и изменять записи |
| `<resource>:delete` | Удалять записи |

`account:read` разрешает читать сведения о собственной учётной записи. Список ресурсов и точные названия областей приведены в [файле OpenAPI](./api.md#где-полный-справочник).

**Удаление разрешается отдельно.** Право записи не включает удаление. Области удаления стоят отдельно и изначально не отмечены. После создания токена расширить его права нельзя: если нужны новые, создайте токен и отзовите прежний. Административных прав у токена быть не может.

## Сколько действует токен?

Вы выбираете **30, 90 или 365 дней**. LifeWell отправляет письмо за семь дней до окончания срока. После даты окончания токен перестаёт работать, а запросы с ним получают `401`.

## Как заменить или отозвать токен?

- **«Заменить»** создаёт новый токен. Старый действует ещё 24 часа, чтобы вы успели поменять его в скрипте, а затем отзывается. До этого оба видны в списке.
- **«Отозвать»** прекращает действие сразу. Следующий запрос с токеном получит `401`. Для подтверждения нужно нажать дважды; отдельного диалога нет.

Удаление учётной записи LifeWell также отзывает все токены, подключённые приложения, вебхуки и календарные подписки.

## Как приложение подключается без передачи токена?

Через OAuth 2.1, который также используют ИИ-помощники. Приложение направляет вас на страницу разрешения LifeWell по адресу `https://lifewell.aoneahsan.com/oauth/consent`. Там указаны:

- название приложения и адрес возврата;
- подключаемая учётная запись LifeWell;
- запрошенные действия простыми фразами, сгруппированные по чтению, записи и удалению; у каждого свой флажок, а удаление изначально не отмечено;
- кнопки **«Одобрить»** и **«Отказать»** рядом друг с другом.

Если включена дополнительная проверка при входе, для одобрения нужен код. Затем приложение появляется в **Настройки → Другие приложения → Подключённые приложения**, где его можно переименовать или отозвать. Отзыв закрывает доступ уже при следующем запросе, а не после окончания текущего сеанса. Подробнее о странице разрешения — в разделе [ИИ-помощники (MCP)](./mcp.md#что-спрашивает-страница-разрешения).

## Какие действуют пределы запросов?

Каждый токен и каждое подключённое приложение могут отправлять 120 запросов в минуту. Кроме того, у всей учётной записи есть дневной предел по плану: 5 000 на Free, 50 000 на Pro и Family. Он общий для всех ваших токенов и приложений; дополнительные токены его не увеличивают. В «Настройки → Другие приложения» показаны пределы и число запросов за сегодня. Каждый ответ содержит:

| Заголовок | Значение |
|---|---|
| `RateLimit-Limit` | Разрешённое число запросов в текущем окне |
| `RateLimit-Remaining` | Сколько запросов осталось |
| `RateLimit-Reset` | Секунды до начала нового окна |

После превышения предела API отвечает `429` с заголовком `Retry-After`. Подождите указанное число секунд перед повтором.

Если отправить много запросов одновременно, платформа может вернуть `546` ещё до того, как запрос увидит LifeWell. Отправляйте их последовательно или небольшими группами и повторяйте запрос после `546` через секунду.

## Как выглядит ошибка?

У ошибок всех маршрутов одна структура:

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

В коде ориентируйтесь на `code`; `message` предназначен человеку и может меняться. Если вы напишете нам о неудачном запросе, укажите `correlation_id`: по нему мы найдём запрос без других личных сведений.

| Статус | Обычно означает |
|---|---|
| `401` | Токена нет, он неверный, отозван или просрочен |
| `403` | Токену не хватает права (оно указано в `details`) или нужен новый вход |
| `404` | Записи с таким идентификатором нет в вашем журнале, в том числе если она принадлежит другому человеку |
| `429` | Превышен предел запросов; см. `Retry-After` |

Полный список кодов есть в [файле OpenAPI](./api.md#где-полный-справочник).
