# Вебхуки

Вебхук LifeWell — подписанный запрос `POST` на принадлежащий вам адрес, который отправляется при изменении журнала. Добавьте адрес в **Настройки → Другие приложения → Вебхуки**, выберите события и проверяйте подпись каждого запроса, чтобы знать, что он действительно пришёл от LifeWell.

## Какие бывают события?

Имена имеют вид `resource.verb`: часть журнала и действие с ней. Полный каталог с содержимым каждого события находится в [файле OpenAPI](./api.md#где-полный-справочник). Эта страница не дублирует каталог, чтобы не устареть отдельно от него.

Одно событие есть всегда: `webhook.test`. Оно отправляется при нажатии **«Отправить тестовое событие»**.

## Какие адреса принимаются?

- Только `https://` на порту 443 или 8443, без имени пользователя и пароля в адресе.
- Частный или локальный адрес запрещён: `localhost`, `127.0.0.1`, `10.x.x.x`, `192.168.x.x`, локальные адреса связи и имена, разрешающиеся в такие адреса. Проверка выполняется при сохранении и перед каждой отправкой. Перенаправление на частный адрес тоже отклоняется.
- Ваш сервер должен ответить за десять секунд.

## Что содержит запрос?

LifeWell следует спецификации [Standard Webhooks](https://www.standardwebhooks.com/). В каждом запросе три заголовка:

| Заголовок | Содержимое |
|---|---|
| `webhook-id` | Идентификатор события. Он одинаков при каждом повторе, поэтому по нему можно пропустить дубликат |
| `webhook-timestamp` | Время отправки в секундах с начала 1970 года |
| `webhook-signature` | Подпись HMAC-SHA256 в base64 с префиксом `v1,`; подписей может быть несколько, разделённых пробелами |

Секрет подписи начинается с `whsec_`. Снова показать его можно по тому же [десятиминутному правилу](./authentication.md#можно-ли-снова-увидеть-токен), что и токен. Действие **«Заменить»** выдаёт новый секрет и 24 часа подписывает сообщения обоими. Получатель, принимающий любой из них, продолжит работать, пока вы меняете секрет.

## Как проверить запрос?

Проверяйте подпись до разбора тела, по точно полученным байтам. Если разобрать JSON и затем записать его заново, байты могут отличаться и подпись не совпадёт.

В примерах используются библиотеки Standard Webhooks: `standardwebhooks` версии 1.3.0 в npm и PyPI, а также `standard-webhooks/standard-webhooks` версии 1.3.0 в Packagist. Версии проверены 19 ноября 2026 г.

### Node

```js
import { Webhook } from 'standardwebhooks';

const wh = new Webhook(process.env.LIFEWELL_WEBHOOK_SECRET);   // the whsec_… value

app.post('/hooks/lifewell', express.raw({ type: 'application/json' }), (req, res) => {
  let event;
  try {
    event = wh.verify(req.body, req.headers);                  // throws on a bad signature or old timestamp
  } catch {
    return res.sendStatus(400);
  }
  if (alreadyHandled(req.headers['webhook-id'])) return res.sendStatus(200);
  queue.add(event);                                            // answer fast, work later
  res.sendStatus(200);
});
```

### Python

```python
from standardwebhooks.webhooks import Webhook
wh = Webhook(os.environ["LIFEWELL_WEBHOOK_SECRET"])
payload = wh.verify(request.get_data(), dict(request.headers))
```

### PHP

```php
$wh = new \StandardWebhooks\Webhook(getenv('LIFEWELL_WEBHOOK_SECRET'));
$payload = $wh->verify(file_get_contents('php://input'), getallheaders());
```

### На любом языке

1. `secret = base64decode(значение whsec без префикса "whsec_")`.
2. `signed = webhook-id + "." + webhook-timestamp + "." + необработанное тело` (точно полученные байты).
3. `expected = base64(HMAC_SHA256(secret, signed))`.
4. Сравните `expected` с каждым значением `v1,` из `webhook-signature` за постоянное время. Любое совпадение подходит.
5. Отклоните запрос, если `|сейчас − webhook-timestamp| > 300`.

## Что будет, если сервер не ответит?

Любой ответ `2xx` означает доставку. Другой статус, ожидание сверх срока или отклонённый адрес считаются неудачной попыткой. LifeWell повторяет отправку по расписанию:

| Попытка | Когда отправляется |
|---|---|
| 1 | Сразу |
| 2 | Через 5 секунд |
| 3 | Через 5 минут |
| 4 | Через 30 минут |
| 5 | Через 2 часа |
| 6 | Через 5 часов |
| 7 | Через 10 часов |
| 8 | Ещё через 10 часов |

Адрес отключается в трёх случаях:

- **`410 Gone`** — сразу. Возвращайте его, если намеренно закрыли адрес.
- **Все восемь попыток одного события не удались.**
- **Адрес не работает пять дней подряд.**

После отключения LifeWell отправляет письмо с последней ошибкой и ссылкой для повторного включения.

## Как проверить и повторить доставку?

- **«Отправить тестовое событие»** немедленно отправляет `webhook.test` на адрес.
- **Журнал доставки** для адреса перечисляет все попытки: состояние, номер попытки, код ответа, длительность и срок следующего повтора. Он обновляется по мере доставки без перезагрузки.
- **«Повторить»** отправляет одну доставку ещё раз с тем же `webhook-id`. После сбоя можно повторить все неудачные доставки с выбранного момента, до 1 000 за один раз.
- **«Приостановить»** прекращает отправку на адрес, пока вы её не возобновите.
