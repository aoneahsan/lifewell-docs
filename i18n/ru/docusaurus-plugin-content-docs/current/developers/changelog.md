# Изменения для разработчиков

Здесь перечислены все изменения API LifeWell, сервера MCP, вебхуков и календарных лент, начиная с новых. Версия API входит в его адрес — `/v1`. [Файл OpenAPI](./api.md#где-полный-справочник) всегда описывает версию, к которой относится.

Изменения самого приложения приведены в [основной истории изменений](../about/changelog.md).

## 19 ноября 2026 г.

- В LifeWell включены токены доступа («Настройки → Другие приложения»), API `/v1` и файл OpenAPI, сервер MCP для ИИ-помощников, вебхуки, календарные ленты и двухэтапный вход («Настройки → Безопасность»).
