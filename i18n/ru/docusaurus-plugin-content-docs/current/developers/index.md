# Подключение LifeWell к другим приложениям

Получить доступ к вашему журналу извне LifeWell можно четырьмя способами: **календарное приложение** читает подписку, **ваш скрипт** использует токен доступа, **ИИ-помощник** подключается через MCP, а **другое приложение** получает события через вебхуки. Каждый доступ вы открываете сами в разделе **Настройки → Другие приложения**. Там же его можно закрыть.

## Для чего это нужно?

Чаще всего — чтобы видеть сведения из LifeWell там, где вы уже работаете. Например, семейное дерево в другом привычном приложении. Или встречи из LifeWell в календаре телефона рядом с рабочими встречами, чтобы не проверять второй календарь отдельно.

## Какой способ выбрать?

| Что вы хотите | Способ | Что он позволяет | С чего начать |
|---|---|---|---|
| Показать календарь LifeWell в Google Calendar, Apple Calendar или Outlook | Календарная подписка | Читать только ваш календарь | [Календарные подписки](./calendar-feeds.md) |
| Читать или менять журнал из своего кода | Токен доступа и API | Действия, разрешённые областями доступа токена | [Авторизация](./authentication.md), затем [API](./api.md) |
| Спросить Claude, ChatGPT, Claude Code или Cursor о своём журнале | Сервер MCP | Действия, одобренные вами на странице согласия | [ИИ-помощники (MCP)](./mcp.md) |
| Сообщать другому приложению об изменениях | Вебхуки | Получать события без доступа к другим данным | [Вебхуки](./webhooks.md) |

## Что действует для любого способа?

- **Доступ появляется только по вашему решению.** У новой учётной записи нет токенов, подписок, подключений и вебхуков.
- **Удаление разрешается отдельно.** Можно дать доступ на чтение и запись. Право на удаление включается только вашей отдельной отметкой, а ИИ-помощник не может ничего удалить без подтверждения внутри LifeWell.
- **Все открытые способы доступа видны вам.** В разделе «Настройки → Другие приложения» перечислены токены, подключённые приложения, вебхуки и подписки с датой последнего использования.
- **Ваш журнал остаётся вашим.** Каждый запрос выполняется от вашего имени и подчиняется тем же правилам доступа, что и приложение. Записи другого человека недоступны.

Дополнительная проверка при входе защищает эти подключения: если она включена, для повторного показа токена или одобрения нового подключения нужен код. См. [Дополнительная проверка при входе](./two-step-sign-in.md).
