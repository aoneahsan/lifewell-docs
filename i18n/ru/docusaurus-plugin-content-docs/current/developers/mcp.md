# Подключение ИИ-помощника (MCP)

Сервер MCP LifeWell позволяет ИИ-помощнику по вашему запросу читать и менять журнал: *«У кого из моей семьи день рождения в этом месяце?»*, *«Добавь стоматолога на четверг в половине десятого»*. Вы указываете помощнику один адрес, входите в LifeWell и выбираете на странице разрешения, какие действия ему доступны. Поддерживаются Claude, ChatGPT, Claude Code, Cursor и другие помощники с MCP.

## Какой адрес использовать?

```text
https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

Тот же адрес с кнопкой копирования находится в **Настройки → Другие приложения → Подключить ИИ-помощника**. Вставлять токен в помощника не нужно: по адресу он найдёт вход LifeWell и направит вас туда.

## Как подключить помощника?

Меню этих приложений меняются между версиями. Если указанный ниже шаг не совпадает с вашим экраном, найдите раздел **Connectors** в настройках.

### Claude

1. В Claude откройте **Settings → Connectors** и добавьте собственное подключение.
2. Вставьте адрес выше.
3. По запросу войдите в LifeWell и одобрите доступ на странице разрешения.

### ChatGPT

1. В ChatGPT откройте **Settings → Connectors**. Для некоторых учётных записей сначала нужно включить режим разработчика.
2. Добавьте подключение с адресом выше.
3. По запросу войдите в LifeWell и одобрите доступ на странице разрешения.

### Claude Code

```bash
claude mcp add --transport http lifewell https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

Затем в Claude Code запустите `/mcp`, выберите **lifewell** и войдите через открывшийся браузер.

### Cursor

Добавьте LifeWell в `mcp.json`:

```json
{
  "mcpServers": {
    "lifewell": {
      "url": "https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp"
    }
  }
}
```

При первом использовании Cursor предложит войти.

## Что спрашивает страница разрешения?

Прежде чем помощник получит доступ к журналу, LifeWell по адресу `https://lifewell.aoneahsan.com/oauth/consent` показывает:

- **какое приложение запрашивает доступ** и адрес возврата;
- **к какой учётной записи LifeWell** оно подключится — проверьте, если у вас их несколько;
- **какие действия оно сможет выполнять**: простые предложения, сгруппированные по чтению, записи и удалению, с отдельным флажком у каждого. Удаление изначально не отмечено;
- кнопки **«Одобрить»** и **«Отказать»** рядом.

Если включена [дополнительная проверка при входе](./two-step-sign-in.md), для одобрения нужен код. Новое подключение всегда проходит через эту страницу; ничего не разрешается за вас.

Помощник видит только инструменты, доступные по выбранным вами правам. Если разрешено лишь чтение, изменить запись он не сможет.

## Как подтверждается удаление?

Помощник может **подготовить** удаление; **выполнить** его можете только вы. По вашему запросу он показывает, что будет удалено, и даёт ссылку в LifeWell. Там нужно подтвердить действие в течение десяти минут, иначе ничего не удалится. Скрытая фраза на веб-странице или во вставленном документе не сможет заставить помощника удалить часть журнала: он не вправе подтвердить собственный запрос.

Это работает только при отмеченном вами праве на удаление на странице разрешения. Без него помощник не может даже подготовить удаление.

## Как отключить помощника?

Откройте **Настройки → Другие приложения → Подключённые приложения** и выберите **«Отозвать»** в его строке. Доступ прекратится при следующем запросе. Список показывает права приложения, дату подключения и последнего использования; новое подключение появляется сразу после одобрения. LifeWell также отправляет письмо при подключении приложения.

## Почему подключение не работает?

| Что вы видите | Что сделать |
|---|---|
| Помощник снова просит войти | Срок его сеанса истёк. Войдите в LifeWell из помощника ещё раз |
| Сообщение об отсутствии права | Вы не дали это право. Отключите помощника, подключите заново и отметьте нужное действие на странице разрешения |
| LifeWell исчез из списка инструментов или все вызовы неудачны | Доступ был отозван. Проверьте **«Подключённые приложения»** и подключите снова, если хотите |
| Удаление не произошло | Вы не подтвердили его в LifeWell в течение десяти минут. Запросите действие снова |
| Хотите узнать, использовалось ли подключение | В **«Подключённых приложениях»** указана дата последнего использования |
