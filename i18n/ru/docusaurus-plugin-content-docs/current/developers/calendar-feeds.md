# Календарные подписки

Подписка показывает события LifeWell в календарном приложении, которым вы уже пользуетесь. Создайте её в **Настройки → Другие приложения → Календарные подписки**, скопируйте адрес и добавьте в Google Calendar, Apple Calendar, Outlook или другое приложение, принимающее подписку `.ics`. Доступ только для чтения: календарное приложение показывает события LifeWell, но не меняет их.

## Как подписаться?

1. В LifeWell откройте **Настройки → Другие приложения → Календарные подписки** и выберите **Создать подписку**.
2. Скопируйте выданный адрес.
3. В календарном приложении добавьте календарь **по URL** (в Google Calendar — *From URL*, в Apple Calendar — *New Calendar Subscription*) и вставьте адрес.

Частоту обновления определяет ваше календарное приложение, а не LifeWell. Одни приложения проверяют подписку раз в несколько минут, Google Calendar может обновлять её несколько часов. Поэтому изменения из LifeWell иногда появляются с задержкой.

## Что входит в подписку?

События из [календаря LifeWell](../features/calendar-and-appointments.md) за период от 90 дней назад до примерно 13 месяцев вперёд, не более 2 000 событий. Другие части журнала через подписку недоступны; личные заметки в неё не включаются.

Время сохраняется по местным часам, как в LifeWell: *стоматолог в 09:30* останется в 09:30 при смене часового пояса, а не сдвинется.

## Адрес нужно хранить в тайне?

Да. Календарные приложения не передают отдельный токен, поэтому секрет доступа включён в адрес. Любой, у кого есть адрес, сможет прочитать этот календарь. Подписка поэтому открывает как можно меньше:

- доступен **один календарь**, только для чтения, без остальных записей;
- адрес не является токеном доступа и не работает с [API](./api.md);
- повторно показать его можно только по тому же [правилу десяти минут](./authentication.md#можно-ли-снова-увидеть-токен), что и токен.

Если адрес попал не туда, отзовите подписку и создайте новую.

## Как отключить подписку?

В строке подписки выберите **Отозвать**. После этого адрес возвращает `404`, а календарное приложение уберёт события при следующей проверке. Для каждого приложения лучше создать отдельную подписку: отзыв одной не затронет остальные.
