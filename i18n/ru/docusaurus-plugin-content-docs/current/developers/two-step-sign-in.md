# Дополнительная проверка при входе

После входа через Google LifeWell запрашивает шестизначный код из приложения-аутентификатора. Если кто-то получит доступ к вашему аккаунту Google, без вашего телефона он всё равно не откроет журнал LifeWell. Для обычной учётной записи эта проверка добровольна; для всех, кто работает с панелью администратора, обязательна.

## Как включить проверку?

1. Откройте **Настройки → Безопасность → Дополнительная проверка при входе**.
2. Считайте QR-код приложением-аутентификатором — Google Authenticator, Microsoft Authenticator, 1Password, Bitwarden или любым другим, создающим шестизначные коды. Если считать код не получается, введите ключ под ним вручную.
3. Введите код из приложения. Проверка включится после подтверждения LifeWell.

## Для чего нужны резервные коды?

При включении LifeWell один раз показывает **10 резервных кодов**. Каждый позволяет войти один раз, если телефон потерян или очищен. Скачайте коды или сохраните их отдельно от телефона.

- Каждый код действует один раз.
- Использование резервного кода отключает дополнительную проверку и сразу переводит к её настройке на новом телефоне.
- Действие **«Создать новые коды»** заменяет весь набор; старые коды перестают работать. Сначала потребуется действующий код.

## Что значит «Запомнить этот браузер на семь дней»?

После ввода кода экран входа предлагает **«Запомнить этот браузер на семь дней»**. Изначально флажок снят и остаётся снятым, пока вы сами его не поставите.

- **Флажок снят** — при следующем входе LifeWell снова запросит код.
- **Флажок установлен** — этот браузер на этом устройстве пропускает запрос кода семь дней. В другом браузере или на другом устройстве код всё равно потребуется.

Выход из учётной записи завершает доверие к этому браузеру. В **Настройки → Безопасность → Доверенные браузеры** перечислены все запомненные браузеры с датой добавления и окончания срока. **«Забыть»** удаляет один, **«Забыть все»** — все. Выключение дополнительной проверки также удаляет все доверенные браузеры.

Даже в запомненном браузере код нужен, чтобы показать токен доступа или секрет вебхука, изменить саму дополнительную проверку и открыть панель администратора.

## Когда ещё запрашивается код?

- **При повторном показе токена или секрета** — см. [Токены доступа](./authentication.md#можно-ли-снова-увидеть-токен).
- **При одобрении нового приложения или ИИ-помощника** на странице разрешений — см. [ИИ-помощники](./mcp.md#что-спрашивает-страница-разрешения).
- **При выключении дополнительной проверки** — понадобится действующий код.

## Обязательна ли проверка для администраторов?

Да. Без кода, введённого в текущем сеансе, [панель администратора](../admin.md) LifeWell не откроется. Доверенного браузера для административных экранов недостаточно.
