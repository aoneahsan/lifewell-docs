# Проверка лицензии

Каждая лицензированная копия LifeWell имеет ключ и размещает на своём сайте файл `/.well-known/lifewell-white-label-license.json`. Проверить можно и ключ, и сайт на [странице проверки](https://lifewell.aoneahsan.com/verify-license). Ответ приходит из нашего сервиса лицензирования, а не от проверяемой копии.

## По ключу

| Ответ | Значение |
|---|---|
| Активна | Лицензия действительна. Страница показывает получателя, сайты, платформы и даты. |
| Настраивается | Оплата подтверждена, но копия ещё не опубликована. |
| Отозвана | Копия с этим ключом не лицензирована. |
| Лицензия не найдена | Сверьте ключ с сертификатом. |
| Ключ не относится к LifeWell | Ключи начинаются с `LIFEWELL-`. |

## По сайту

| Ответ | Значение |
|---|---|
| Лицензирован | Файл сайта указывает действующую лицензию, покрывающую этот сайт. |
| Не покрывает этот сайт | В файле указана лицензия для другого адреса. |
| Файл лицензии отсутствует | Сайт не размещает файл лицензии LifeWell. |
| Не удалось открыть сайт | Повторите проверку через несколько минут. |

Проверка показывает только открытые поля. Адрес электронной почты и цена никогда не отображаются.

## Внутри лицензированной копии

Копия проверяет собственный ключ при запуске и при повторном открытии. Если лицензия отозвана или не покрывает сайт, копия показывает, что лицензия неактивна. Записи пользователей не удаляются, а сбой на нашей стороне не останавливает работу копии.
