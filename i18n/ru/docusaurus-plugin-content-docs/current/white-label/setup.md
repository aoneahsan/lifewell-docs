# Настройка копии по лицензии

1. **Вы оплачиваете заказ** на [странице цен](https://lifewell.aoneahsan.com/white-label/pricing) либо получаете предложение от нас, если приём оплаты недоступен. Оплата выполняется банковским переводом на наш счёт Wise; вы передаёте номер перевода. Лицензия выдаётся после нашего подтверждения. После возвращения вы один раз попадаете на страницу своего заказа.
2. **Приходит письмо** с ключом лицензии и сертификатом. Сохраните его: ключ потребуется для продления.
3. **Мы просим данные для вашей марки**: домен, имя в нужном написании, логотип и цвета. Для Android также понадобится доступ к вашему аккаунту разработчика Google Play.
4. **Мы размещаем вашу копию** на вашем домене и сообщаем адрес. Вместе с ней публикуется файл лицензии, а статус лицензии меняется с настройки на активный.

Лицензия появляется только после подтверждения оплаты. Страница возвращения и письмо сами по себе ничего не предоставляют.
