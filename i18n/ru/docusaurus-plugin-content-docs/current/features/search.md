# Поиск

`/search` должен искать в ваших записях — заметках, воспоминаниях, людях, событиях, лекарствах и других разделах — из одного поля в верхней панели.

:::warning[Страница ещё не готова]
Сам поиск существует: запрос по вашим записям написан и размещён на сервере. Страница для его запуска пока не создана. Приложение сообщает об этом, а не показывает пустой список, который выглядел бы как сообщение *«ничего не найдено»*.
:::

## Что попадёт в поиск, а что нет

- **Только ваши записи.** Поиск выполняется от вашего имени с теми же правилами доступа на уровне строк, что и другие запросы. Даже ошибка приложения не должна открыть строки другой учётной записи.
- **Ваши записи, а не открытые страницы.** Блог, страницы функций и инструменты доступны всем и находятся через поисковые системы, а не через это поле.
- **Без индексации.** Страница `/search` помечена `noindex` и намеренно отсутствует в карте сайта. Индексируемая страница поиска провоцировала бы попытки её исследовать.
