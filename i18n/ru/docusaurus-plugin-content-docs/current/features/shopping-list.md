# Список покупок

Открывается из раздела еды и блюд по адресу `/diet-plan`.

## Откуда берётся список

- **Из плана питания.** Запланируйте неделю, и ингредиенты станут списком.
- **Из сохранённого блюда или рецепта.**
- **Вручную** — для того, чего не знает планировщик.

В магазине можно отмечать купленные товары. Список принадлежит вам и остаётся в ваших записях, пока вы его не очистите.

## Как отправить список

Есть два способа. Нужный выбирается при нажатии кнопки, а не при загрузке страницы:

| Где | Что произойдёт |
|---|---|
| Веб | Откроется окно отправки внутри приложения с явной кнопкой копирования в буфер обмена |
| Android | Откроется системное меню отправки |

Список отправляется **обычным текстом**. Человеку, который идёт в магазин, не нужны LifeWell, учётная запись или ссылка с ограниченным сроком действия.

Если вы передумаете и закроете меню отправки, ничего не произойдёт. Это не ошибка, поэтому сообщение об ошибке не появится.

## Что входит в экспорт

Списки покупок и их позиции входят в [экспорт](../reference/export-format.md) в форматах JSON и CSV. В PDF их нет: этот документ предназначен для врача, которому список покупок не нужен.
