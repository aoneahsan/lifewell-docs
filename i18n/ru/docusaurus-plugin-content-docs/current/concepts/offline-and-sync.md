# Работа без связи и синхронизация

LifeWell проверяет соединение настоящим запросом к приложению. Когда связь пропадает, полноэкранное сообщение оставляет текущую страницу на месте. Оно исчезает после восстановления связи и успешного нового запроса; страница продолжает работу без перезагрузки.

## Что работает без сигнала

Если в настройках устройства включено **«Продолжать без связи»**, сообщение предлагает **«Продолжить записи без связи»**. Текущая страница открывается с узкой полосой состояния. Поддерживаемые показатели, изменения дней цикла и эпизоды симптомов могут сохраняться на этом устройстве и отправляться после восстановления связи. Размер очереди ограничен; если запись не удалось сохранить для отправки, приложение показывает это и не выдаёт неудачную запись на сервер за успешную.

Напоминание Android, уже запланированное на устройстве, может прийти и без подключения.

## Что требует связи

- **Новые страницы и ещё не загруженные ресурсы.** Сервисный работник не сохраняет страницы и не перехватывает запросы. Чтобы открыть страницу, которая ещё не загружалась, нужна связь.
- **Чтение с сервера и другие изменения.** Сообщения, сообщество, доступ к записям других людей, фотографии, встречи и вход требуют сервиса. Локальная очередь доступна только для перечисленных выше поддерживаемых записей.
- **Первый запуск без связи.** У LifeWell нет автономной оболочки, с которой можно открыть закрытую вкладку без подключения.

## Как разрешается конфликт

Очередь отправляется после восстановления настоящего соединения. У каждой операции есть идентификатор, позволяющий повторить отправку без дублирования. Дальше действует правило самого раздела:

- Раздел, который **суммирует**, считает вторую запись ещё одним показанием.
- Раздел, который хранит **последнее значение**, считает его исправлением.

Две записи о воде остаются двумя записями; раздел с последним значением обрабатывает исправление по своим правилам. Пока сервер не принял запись из очереди, другое устройство её не видит.

## Сообщение о соединении

По умолчанию оно блокирует приложение и предлагает повторить проверку. Обойти его можно только действием **«Продолжить записи без связи»**, когда настройка устройства включена. Узкая полоса затем напоминает о состоянии соединения. После восстановления связи LifeWell отправляет очередь и обновляет открытые данные без перезагрузки страницы.

## Что намеренно не предусмотрено

Нет сохранённой автономной копии всего приложения и фоновой синхронизации при закрытой вкладке. Очередь быстрых записей — узкий способ не потерять небольшое изменение при временной потере связи.
