# Android

То же приложение, что и веб-версия, в оболочке Capacitor. Одна учётная запись и один журнал.

| | |
|---|---|
| Идентификатор приложения | `com.aoneahsan.lifewell` — постоянный |
| Минимальная версия | **Android 9 (API 28)** |
| Текущая версия исходного кода | **3.31.0**; доступную вашему устройству версию смотрите в Google Play |
| Распространение | [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.lifewell) |

:::note[Минимум — Android 9, а не Android 7]
В прежней версии документации был указан Android 7.0. Это ошибка: минимальный SDK сборки — 28, то есть Android 9. На устройстве с более ранней версией установить приложение нельзя; Play просто скрывает страницу без объяснения причины.
:::

## Разрешения

Приложение объясняет заявленные разрешения на странице [`/permissions`](https://lifewell.aoneahsan.com/permissions).

| Разрешение | Для чего нужно |
|---|---|
| Камера | Снять фотографию для воспоминания или записи. Запрашивается при первом нажатии *«Сфотографировать»*. При отказе файл можно выбрать с устройства |
| Микрофон | Запись в Speak it. Запрашивается при нажатии кнопки записи. При отказе текст можно ввести вручную. LifeWell не слушает в фоне |
| Приблизительное местоположение | Определить положение, пока открыта страница специалистов, для сортировки по расстоянию. Запрашивается при нажатии *«Использовать моё положение»* и не сохраняется |
| Чтение контактов | Один выбранный вами контакт при нажатии **«Контакты»** рядом с номером телефона: его имя и номера, чтобы заполнить выбранным номером поле. Не запрашивается при запуске |
| Изменение контактов | Ни для чего. Android выдаёт чтение и изменение контактов одним разрешением; LifeWell только читает и не добавляет, не меняет и не удаляет контакты |
| Уведомления | Доставить напоминание, которое вы запросили |
| Интернет | Синхронизировать журнал |
| Состояние сети | Понять, возможна ли синхронизация, и объяснить отсутствие связи вместо тихой ошибки |
| Запуск после включения устройства | Сохранить напоминания после перезагрузки |
| Удержание устройства активным | Доставить запланированное напоминание |
| Рекламный идентификатор | Объявлен; подробности ниже |

Страницы `/people/location-tracking` и `/people/location-history` описывают отдельную функцию, **выключенную по умолчанию**. Фоновая запись местоположения реализована для Android 3.31.0 и следующих версий. При включении записи приложение запрашивает отдельные разрешения на доступ к местоположению. Существующую историю по-прежнему можно просмотреть и удалить. Сборку 3.31.0 ещё предстоит загрузить в Google Play и проверить на настоящем устройстве; не рассчитывайте на эту функцию в версии, которая сейчас доступна в магазине.

Если отказать в доступе к контактам, номер можно ввести вручную. Каждое поле телефона работает обоими способами. Адресная книга целиком не загружается, не просматривается и не сохраняется.

Приложение не запрашивает SMS, историю вызовов или широкий доступ к фотографиям и файлам.

### Два разрешения удалены из сборки

Библиотека уведомлений объявляет в своём манифесте `SCHEDULE_EXACT_ALARM` и `USE_EXACT_ALARM`. LifeWell **удаляет оба** из сборки.

Android оставляет точные сигналы будильникам и календарям. Если сохранить эти разрешения, приложение такого типа запросит то, чего Google ему не выдаёт. Начиная с Android 12 вызов планирования без разрешения открыл бы системные настройки *«Будильники и напоминания»* вместо создания сигнала. Поэтому напоминания планируются без точного времени и могут прийти на несколько минут раньше или позже.

### Рекламный идентификатор

Он объявлен в манифесте. **Рекламной сети и стороннего рекламного кода в приложении нет.** Объявление нужно, чтобы ответ в магазине соответствовал возможностям сборки, а не потому, что вам показывают стороннюю рекламу.

## Что добавляет сборка Android

- **Локальные напоминания**, которые доставляет сам Android, в том числе при закрытом приложении. См. [Напоминания](../features/reminders.md).
- **Нативный вход** с хранением сеанса в защищённом хранилище платформы вместо хранилища браузера.

## Push и Play Billing

### Push-уведомления

Если вы включили push и подписка устройства стала активной, LifeWell может получать общие сообщения команды через OneSignal. Приложение не отправляет автоматически push о событиях учётной записи. Это отдельный механизм от локальных напоминаний, которые Android планирует на устройстве. См. [Напоминания](../features/reminders.md#push-уведомления).

### Google Play Billing

Покупка, проверка на сервере и уведомления Google о продлении реализованы и собираются. Преобразование ответа Google в право доступа проверено на записанных ответах. **Настоящей покупки пока не было**, служебная учётная запись не настроена, а переключатель платформы для покупок по умолчанию выключен. Проверить оплату можно только в сборке, подписанной Play и установленной из тестового канала. Поэтому до внутреннего теста путь покупки не подтверждён. См. [Планы](../plans.md#на-android).

## Обновления по сети

Для совместимых установок Android LifeWell поддерживает подписанные пакеты Native Update. Приложение проверяет подпись перед применением и сохраняет обновление после холодного запуска. Открытый ключ проверки встроен в нативную сборку, поэтому старая установка без ключа не сможет получить эту возможность позже. Нативный код и разрешения по-прежнему приходят через Google Play. Запись о выпуске внутри приложения также сообщает, когда новая версия требует обновления.
