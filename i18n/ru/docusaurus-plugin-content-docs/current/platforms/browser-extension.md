# Расширение браузера

**Готово для Chrome и Firefox. Пока не опубликовано ни в одном магазине.**

## Текущее положение

После переработки версии 3.0.0 осталась папка старого расширения. Нынешнее дополнение — отдельное расширение на WXT со сборками для Chrome и Firefox. Оно ещё не отправлено ни в один магазин, поэтому сейчас нет страницы магазина для установки.

## Что дополнение держит под рукой

Во всплывающем окне доступны напоминания о воде и перерывах, общие сведения о приготовлении еды с указанием источников и встречи во время работы в браузере. Личные записи о самочувствии и сведения о встречах остаются в хранилище браузера. Подключение учётной записи LifeWell не загружает их в ваши записи LifeWell.

## Подключение учётной записи

Расширение начинает подключение и открывает сайт LifeWell. Прежде чем разрешить доступ этому браузеру, сравните короткий код в обоих местах. Затем расширение получает собственный сеанс учётной записи и читает выбранный язык профиля. Отключить его можно в самом расширении.

Во всплывающем окне могут появляться другие продукты Zaions. Такие объявления собственных продуктов считаются рекламой в описании для магазина.
