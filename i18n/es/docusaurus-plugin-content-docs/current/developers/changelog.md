# Cambios para desarrolladores \{#developer-changelog}

Aquí aparecen todos los cambios en la API, el servidor MCP, los webhooks y los calendarios de LifeWell, empezando
por los más recientes. La versión de la API forma parte de su dirección —`/v1`— y el [archivo OpenAPI](./api.md#where-is-the-full-reference)
describe siempre la versión a la que pertenece.

Los cambios de la aplicación están en el [historial principal](../about/changelog.md).

## 19 de noviembre de 2026 \{#19-november-2026}

- Se activaron en LifeWell los tokens de acceso (Configuración → Otras aplicaciones), la API `/v1` con su archivo
  OpenAPI, el servidor MCP para asistentes de IA, los webhooks, los calendarios y el inicio de sesión en dos pasos
  (Configuración → Seguridad).
