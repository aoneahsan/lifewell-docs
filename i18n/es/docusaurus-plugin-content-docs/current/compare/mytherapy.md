# Pasar de MyTherapy a LifeWell \{#moving-from-mytherapy-to-lifewell}

MyTherapy ofrece gratis recordatorios de medicación y un diario de tomas. Se financia mediante socios como empresas farmacéuticas e incluye un informe de salud y un plan de medicación para tu médico.

LifeWell guarda los medicamentos junto al registro de la persona: recuerdos, árbol familiar y otros datos de su vida.

Comprobado el 26 de noviembre de 2026. Comparación con fuentes: [LifeWell y MyTherapy](https://lifewell.aoneahsan.com/compare/mytherapy).

## Del plan de MyTherapy a LifeWell \{#from-mytherapys-plan-to-lifewell}

1. Prepara en MyTherapy el informe de salud y el plan de medicación. Utilízalos como referencia al copiar.
2. [Inicia sesión](/getting-started/first-run) y añade cada medicamento con dosis y horario en [Salud](/domains/health). También puedes registrar las dosis que tomaste.
3. Añade las citas médicas al [calendario](/features/calendar-and-appointments), con una lista de preguntas para cada una.
4. La presión arterial, glucemia y peso tienen seguimientos propios en [Salud](/domains/health).
5. Conserva el código de un solo uso de MyTherapy si tu médico consulta allí el plan. LifeWell no envía datos al sistema del médico ni proporciona consejo médico.

## MyTherapy frente a LifeWell \{#mytherapy-and-lifewell}

| Función | LifeWell | MyTherapy |
|---|---|---|
| Compartir una página con alguien sin cuenta | Sí | Parcialmente (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Citas con recordatorio | Sí | Sí (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Medicamentos, condiciones y resultados | Sí | Sí (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Descargar tus datos | Sí | Parcialmente (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página principal de MyTherapy no mencionaba registros por persona, árbol familiar, recuerdos, dictado, notas, aplicación para Android ni un plan para el hogar.
