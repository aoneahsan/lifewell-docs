# Pasar de Mesh a LifeWell \{#moving-from-mesh-to-lifewell}

Mesh ayuda a mantener una red profesional amplia. Importa contactos de correo, LinkedIn y calendario, detecta novedades en sus vidas y recomienda cuándo retomar el contacto. Tiene aplicaciones para macOS, Windows e iOS.

LifeWell está pensado para familiares y amigos, no para una red profesional. Cada persona puede tener recuerdos y datos de salud. El plan gratuito no pide tarjeta.

Comprobado el 26 de noviembre de 2026. Comparación: [LifeWell y Mesh](https://lifewell.aoneahsan.com/compare/mesh).

## Elegir a familiares y amigos de Mesh \{#picking-family-and-friends-out-of-mesh}

1. [Inicia sesión](/getting-started/first-run).
2. De los contactos de Mesh, elige a familiares y amigos cercanos. Añádelos en [Personas](/domains/people).
3. Coloca las fechas importantes en el [calendario](/features/calendar-and-appointments), con [recordatorios](/features/reminders).
4. Conserva tu red profesional en Mesh. LifeWell no lee tu correo ni LinkedIn y no se conecta con calendarios externos.

## Mesh frente a LifeWell \{#mesh-beside-lifewell}

| Función | LifeWell | Mesh |
|---|---|---|
| Un registro por persona | Sí | Sí (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Citas con recordatorio | Sí | Parcialmente (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página de precios de Mesh no mencionaba árbol familiar, recuerdos, dictado, enlaces compartidos, registros de salud, notas, descarga de datos, aplicación para Android ni un plan para el hogar.

Mesh tiene una aplicación para iOS. LifeWell no; en iPhone funciona desde Safari.
