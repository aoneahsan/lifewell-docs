# Pasar de Journey a LifeWell \{#moving-from-journey-to-lifewell}

Journey es un diario con una versión gratuita sin límite de tiempo. Su membresía añade cifrado de extremo a extremo, diarios compartidos y exportación a ePub y DOCX.

LifeWell trata de personas y también de días. Cada recuerdo queda asociado a quienes estuvieron allí, junto a su árbol familiar, datos de salud y citas.

Comprobado el 26 de noviembre de 2026. Comparación: [LifeWell y Journey](https://lifewell.aoneahsan.com/compare/journey).

## De entradas del diario a personas \{#from-diary-entries-to-people}

1. Exporta tu diario a DOCX o ePub con la membresía de Journey para conservar el texto completo en un archivo propio.
2. [Inicia sesión en LifeWell](/getting-started/first-run).
3. Añade en [Personas](/domains/people) a quienes aparecen en tus entradas.
4. Copia las entradas que quieras como [recuerdos](/domains/memories), con fotos, fecha y lugar.
5. Conserva Journey para tu diario privado de cada día.

## Journey frente a LifeWell \{#journey-and-lifewell}

| Función | LifeWell | Journey |
|---|---|---|
| Recuerdos con foto, fecha y lugar | Sí | Sí (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Compartir una página con alguien sin cuenta | Sí | Sí (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Descargar tus datos | Sí | Sí (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página de membresía de Journey no mencionaba registros por persona, árbol familiar, dictado, citas, registros de salud, notas, aplicación para Android ni un plan para el hogar.

Un enlace web de Journey muestra una entrada del diario. Un enlace de LifeWell puede mostrar un árbol, un seguimiento o medicamentos. Consulta [Compartir](/domains/sharing).
