# Pasar de Dex a LifeWell \{#moving-from-dex-to-lifewell}

Dex es una agenda digital. Sincroniza LinkedIn, correo y calendario en una lista de contactos, prepara resúmenes y te recuerda mantener el contacto.

LifeWell ofrece un registro gratuito de las personas importantes, con árbol familiar, salud y citas junto a cada nombre.

Comprobado el 26 de noviembre de 2026. Comparación: [LifeWell y Dex](https://lifewell.aoneahsan.com/compare/dex).

## De una agenda a un registro personal \{#from-a-rolodex-to-a-record}

1. [Inicia sesión en LifeWell](/getting-started/first-run).
2. Si tienes un CSV o archivo .vcf de contactos, impórtalo desde [Personas](/domains/people). Solo se copian los nombres.
3. Copia las notas de cada persona a su registro o a [Notas](/domains/everyday).
4. Convierte las fechas para mantener el contacto en eventos del [calendario](/features/calendar-and-appointments) con [recordatorios](/features/reminders).
5. Si utilizabas la voz en Dex, el dictado de LifeWell te permite añadir datos hablando. Léelos y confírmalos antes de guardarlos.
6. Conserva Dex para sincronizar LinkedIn y el correo.

La página de precios de Dex no mencionaba árbol familiar, recuerdos, enlaces compartidos, registros de salud, descarga de datos, plan gratuito ni un plan para el hogar.

Cada grabación dictada permanece privada hasta que la eliminas. LifeWell no tiene aplicación para iPhone.
