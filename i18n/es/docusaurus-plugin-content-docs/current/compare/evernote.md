# Pasar de Evernote a LifeWell \{#moving-from-evernote-to-lifewell}

Evernote se centra en las notas: libretas, recortes, escaneo y búsqueda de documentos en todos tus dispositivos.

En LifeWell, las notas forman parte de un registro de personas. Los recuerdos, datos de salud y citas se guardan junto a ellas.

Comprobado el 26 de noviembre de 2026. Comparación directa: [LifeWell y Evernote](https://lifewell.aoneahsan.com/compare/evernote).

## De libretas a personas \{#from-notebooks-to-people}

1. Exporta desde Evernote las libretas que quieres conservar como PDF, para tener una copia.
2. [Inicia sesión](/getting-started/first-run) y añade en [Personas](/domains/people) a quienes se refieren esas notas.
3. Copia su contenido a [Notas](/domains/everyday). Allí, eliminar una carpeta no elimina las notas que contenía.
4. Convierte las notas con fecha y aviso de Evernote en [citas](/features/calendar-and-appointments) con [recordatorios](/features/reminders).
5. Conserva Evernote para recortar y escanear documentos.
