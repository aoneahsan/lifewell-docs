# Pasar de Day One a LifeWell \{#moving-from-day-one-to-lifewell}

Day One es un diario cotidiano con cifrado de extremo a extremo, sugerencias para escribir, audio, ubicación y libros impresos de tus entradas. Está pensado para quien escribe a diario.

LifeWell organiza cada recuerdo bajo las personas con quienes se relaciona. Su plan gratuito permite más de una foto.

Comprobado el 26 de noviembre de 2026. Comparación directa: [LifeWell y Day One](https://lifewell.aoneahsan.com/compare/day-one).

## Convertir entradas del diario en recuerdos \{#turning-journal-entries-into-memories}

1. Exporta primero tu diario desde Day One. Sus archivos CSV y JSON conservan el texto completo mientras cambias de aplicación. LifeWell no puede importarlos.
2. [Inicia sesión en LifeWell](/getting-started/first-run).
3. Añade en [Personas](/domains/people) a quienes aparecen a menudo en tus entradas.
4. Traslada una a una las entradas que quieras conservar como [recuerdos](/domains/memories): foto, fecha, lugar y personas presentes.
5. Cuando prefieras hablar a escribir, la función de dictado transcribe lo que dices y te pide confirmarlo.
6. Conserva Day One para la escritura diaria y el libro impreso.

| Compartir una página con alguien sin cuenta | Sí | Parcialmente (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Descargar tus datos | Sí | Sí (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Aplicación para Android | Sí | Sí (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página de precios de Day One no mencionaba registros individuales de personas, árbol familiar, citas, registros de salud, notas ni un plan para el hogar.

El audio que proporcionas al dictado permanece privado hasta que lo eliminas. No hay aplicación para iPhone: allí LifeWell funciona en Safari. Consulta [iOS](/platforms/ios).
