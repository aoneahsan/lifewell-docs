# Pasar de Notion a LifeWell \{#moving-from-notion-to-lifewell}

Notion es un espacio de trabajo que configuras: páginas, bases de datos y calendario. También sirve para el trabajo. A algunas personas les gusta diseñar allí su organizador personal.

LifeWell ya tiene una estructura. Personas, recuerdos, árbol, salud y citas están relacionados entre sí sin que tengas que diseñar las tablas.

Comprobado el 26 de noviembre de 2026. Comparación: [LifeWell y Notion](https://lifewell.aoneahsan.com/compare/notion).

## Desde una base de datos de Notion \{#out-of-a-notion-database}

1. Exporta el espacio de Notion como CSV. También admite HTML, Markdown y PDF.
2. [Inicia sesión en LifeWell](/getting-started/first-run) y abre la importación de [Personas](/domains/people). Elige el CSV de tu base de personas. La primera columna se interpreta como el nombre, así que coloca allí los nombres.
3. Completa los datos de cada persona y vincula a los familiares para formar el [árbol](/domains/people).
4. Convierte las filas con fecha en [citas](/features/calendar-and-appointments), con [recordatorios](/features/reminders) cuando quieras. El texto libre puede ir a [Notas](/domains/everyday), con formato enriquecido y carpetas.
5. Conserva Notion para el trabajo. LifeWell no ofrece páginas o bases de datos que debas configurar.

## Notion frente a LifeWell \{#notion-and-lifewell}

| Función | LifeWell | Notion |
|---|---|---|
| Citas con recordatorio | Sí | Parcialmente (<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Notas | Sí | Sí (<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Descargar tus datos | Sí | Sí (<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página de precios de Notion no mencionaba registros por persona, árbol familiar, recuerdos, dictado, enlaces compartidos, registros de salud, aplicación para Android ni un plan para el hogar.
