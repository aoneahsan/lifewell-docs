# Pasar de Gramps Web a LifeWell \{#moving-from-gramps-web-to-lifewell}

Gramps Web es una herramienta gratuita y de código abierto para genealogía que alojas en tu servidor. Lee y escribe GEDCOM, dibuja gráficos interactivos y genera informes de libros del árbol en PDF.

LifeWell está pensado para quien no quiere mantener un servidor. Está alojado, tiene aplicación Android y relaciona a las personas con recuerdos, citas y datos de salud.

Comprobado el 26 de noviembre de 2026. Comparación con fuentes: [LifeWell y Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web).

## Dejar un servidor propio \{#leaving-a-server-you-look-after}

1. Descarga una copia completa de tus datos de Gramps Web. LifeWell no lee GEDCOM; ese archivo seguirá siendo tu copia de investigación completa.
2. [Inicia sesión en LifeWell](/getting-started/first-run).
3. Si tienes los nombres a mano, pégalos en la importación de [Personas](/domains/people), uno por línea. Puedes revisar los resultados antes de guardarlos. Solo se importan los nombres; tú debes añadir fechas y relaciones.
4. Vincula a las personas para que se dibuje el [árbol](/domains/people).
5. Añade las fotos importantes como [recuerdos](/domains/memories) e indica quién aparece en cada una, como al etiquetar personas en Gramps Web.
6. Conserva el servidor de Gramps si necesitas sus informes en PDF o la base completa de investigación.

LifeWell no imprime su árbol ni prepara informes de libros.
