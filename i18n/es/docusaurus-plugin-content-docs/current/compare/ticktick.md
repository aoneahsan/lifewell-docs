# Pasar de TickTick a LifeWell \{#moving-from-ticktick-to-lifewell}

TickTick reúne tareas, hábitos y calendario en varias plataformas. Tiene una versión gratuita y un plan Premium anual. LifeWell no incluye una lista de tareas.

El calendario de LifeWell está relacionado con personas, cuyos registros también contienen recuerdos, árbol familiar y datos de salud.

Comprobado el 26 de noviembre de 2026. Comparación: [LifeWell y TickTick](https://lifewell.aoneahsan.com/compare/ticktick).

## Utilizar TickTick y LifeWell juntos \{#using-ticktick-and-lifewell-together}

1. [Inicia sesión](/getting-started/first-run).
2. Identifica en TickTick las listas sobre familiares, como los medicamentos de un padre o las citas de un niño. Añade a esas personas en [Personas](/domains/people).
3. Pasa los elementos con fecha al [calendario](/features/calendar-and-appointments) de LifeWell. La vista mensual los muestra junto a los demás eventos fechados.
4. Si una lista contiene medicamentos de alguien, añádelos a [Salud](/domains/health) con dosis, horario y [recordatorio](/features/reminders).
5. Conserva los hábitos y tareas en TickTick.

## TickTick frente a LifeWell \{#ticktick-beside-lifewell}

| Función | LifeWell | TickTick |
|---|---|---|
| Dictado y transcripción | Sí | Parcialmente (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Citas con recordatorio | Sí | Parcialmente (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Notas | Sí | Parcialmente (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Aplicación para Android | Sí | Parcialmente (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |
| Plan gratuito permanente | Sí | Sí (<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">su página</a>) |

La página de actualización de TickTick no mencionaba registros por persona, árbol familiar, recuerdos, enlaces compartidos, registros de salud, descarga de datos ni un plan para el hogar.

Las grabaciones de dictado permanecen privadas hasta que las eliminas.
