# Usar LifeWell en la web \{#use-lifewell-on-the-web}

No tienes que instalar nada. Abre [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) e inicia sesión.

## Iniciar sesión \{#signing-in}

**Google es la única forma de entrar.** No hay formulario de correo y contraseña. Es una decisión deliberada:
no vemos ni guardamos una contraseña porque no existe una contraseña de LifeWell que guardar.

1. Abre [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com).
2. Elige **Continuar con Google**.
3. Elige la cuenta de Google bajo la que quieres guardar tu registro.

El registro pertenece a la cuenta que eliges. Cambiar de cuenta más adelante abre otro registro, no cambia
el nombre del anterior.

## Qué ocurre después \{#what-happens-next}

El primer inicio de sesión abre una preparación breve: cinco pasos, la mayoría de los cuales puedes dejar
en blanco. Consulta [El primer uso](./first-run.md).

## Navegadores compatibles \{#browser-support}

LifeWell está pensado para las versiones actuales de Chrome, Edge, Firefox y Safari. No hay una tabla de
compatibilidad más amplia ni una capa de adaptación para navegadores antiguos. Si uno no puede ejecutar la
aplicación, la pantalla de inicio lo indica en lugar de mostrar una página rota.

## Añadirla a la pantalla de inicio \{#adding-it-to-your-home-screen}

La versión web es un sitio normal. Muchos navegadores permiten añadirlo a la pantalla de inicio o al dock,
para abrirlo con un icono y sin barra de direcciones. Es una función del navegador: no se descarga nada
adicional y la aplicación sigue funcionando igual.

Si prefieres la aplicación Android, con recordatorios locales y el manejo de notificaciones del sistema,
consulta [Instalar en Android](./install-android.md).
