# Lista de compras

Você encontra a lista na área de alimentos e refeições, em `/diet-plan`.

## De onde vem a lista

- **Do planejamento de refeições.** Planeje uma semana e os ingredientes formam uma lista.
- **De uma refeição salva ou receita.**
- **De você**, para o que nenhum planejador conhece.

Você pode marcar os itens enquanto faz compras. A lista é sua e permanece no seu registro até que você a limpe.

## Levar a lista para fora do aplicativo

Há dois caminhos. O aplicativo decide qual usar quando você toca no botão, não ao carregar a página:

| Onde | O que acontece |
|---|---|
| Web | Abre uma janela de compartilhamento no aplicativo, com botão explícito para copiar |
| Android | Abre a janela de compartilhamento do sistema |

A lista sai como **texto simples**. Quem faz as compras não precisa do LifeWell, de uma conta nem de um link com prazo de validade.

Se você mudar de ideia e fechar a janela de compartilhamento, nada acontece. Não é uma falha e não gera uma mensagem de erro.

## O que entra na exportação

As listas de compras e seus itens aparecem nos formatos JSON e CSV da [exportação](../reference/export-format.md). Não entram no PDF: ele é um documento para levar a uma consulta, e uma lista de compras não é útil para esse leitor.
