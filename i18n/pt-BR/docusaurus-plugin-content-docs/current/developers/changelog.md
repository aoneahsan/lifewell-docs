# Histórico de mudanças para desenvolvedores

Todas as mudanças na API, no servidor MCP, nos webhooks e nos feeds de calendário do LifeWell aparecem aqui, da mais recente à mais antiga. A versão da API faz parte do endereço — `/v1` — e o [arquivo OpenAPI](./api.md#onde-está-a-referência-completa) sempre descreve a versão correspondente.

As mudanças no aplicativo estão no [histórico principal](../about/changelog.md).

## 19 de novembro de 2026

- Foram ativados no LifeWell: chaves de acesso (Configurações → Outros aplicativos), API `/v1` com arquivo OpenAPI, servidor MCP para assistentes de IA, webhooks, feeds de calendário e autenticação em duas etapas (Configurações → Segurança).
