# Migrar do Notion para o LifeWell

O Notion é um espaço que você monta: páginas, bancos de dados e calendário, com a mesma ferramenta usada no trabalho. Algumas pessoas gostam de criar ali seu próprio organizador da vida.

O LifeWell já vem organizado. Pessoas, memórias, árvore familiar, saúde e compromissos estão estruturados e ligados entre si, sem precisar desenhar o sistema.

Última conferência: 26/11/2026. Veja [Notion e LifeWell lado a lado](https://lifewell.aoneahsan.com/compare/notion).

## Sair de um banco de dados do Notion

1. Exporte o espaço do Notion em CSV. Também há opções HTML, Markdown e PDF.
2. [Entre no LifeWell](/getting-started/first-run) e abra a importação em [Pessoas](/domains/people). Selecione o CSV da sua lista de pessoas. A primeira coluna é lida como nome; coloque os nomes ali.
3. Complete cada pessoa e ligue os familiares para formar a [árvore](/domains/people).
4. Linhas com data viram [compromissos](/features/calendar-and-appointments), com [lembretes](/features/reminders) onde quiser. Textos livres viram [notas](/domains/everyday) formatadas em pastas.
5. Continue usando o Notion para o trabalho. O LifeWell não oferece páginas ou bancos de dados para você montar.
