# Migrar do Gramps Web para o LifeWell

O Gramps Web é um serviço gratuito e de código aberto de genealogia que você instala no próprio servidor. Lê e grava GEDCOM, desenha gráficos interativos e cria livros em PDF com a árvore.

O LifeWell serve a quem não quer cuidar de um servidor. É hospedado, tem aplicativo Android e reúne memórias, compromissos e informações de saúde das mesmas pessoas.

Última conferência: 26/11/2026. Veja a [comparação com fontes](https://lifewell.aoneahsan.com/compare/gramps-web).

## Sair de um servidor sob seus cuidados

1. Baixe uma cópia completa dos seus dados no Gramps Web. O LifeWell não lê GEDCOM; esse arquivo continuará sendo sua cópia integral da pesquisa.
2. [Entre no LifeWell](/getting-started/first-run).
3. Se tiver os nomes à mão, cole-os na importação em [Pessoas](/domains/people), um por linha. A página mostra todos antes de salvar. Só os nomes são transferidos; você precisará acrescentar datas e relações.
4. Ligue as pessoas entre si. A [árvore](/domains/people) é desenhada a partir dessas relações.
5. Adicione as fotos importantes em [Memórias](/domains/memories) e marque quem aparece, como você faria no Gramps Web.
6. Mantenha o servidor Gramps se quiser os livros em PDF ou o banco completo de pesquisa.

## Gramps Web ao lado do LifeWell

| Recurso | LifeWell | Gramps Web |
|---|---|---|
| Um registro para cada pessoa da sua vida | Sim | Sim (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Desenha sua árvore genealógica | Sim | Sim (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Memórias com foto, data e lugar | Sim | Parcialmente (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Página compartilhada com alguém sem conta | Sim | Parcialmente (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Download dos próprios dados | Sim | Sim (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Plano gratuito permanente | Sim | Sim (<a href="https://www.grampsweb.org/" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |

As páginas do Gramps Web não mencionavam entrada por voz, compromissos, dados de saúde, notas, aplicativo Android ou plano familiar.

O LifeWell não imprime sua árvore nem cria livros dela.
