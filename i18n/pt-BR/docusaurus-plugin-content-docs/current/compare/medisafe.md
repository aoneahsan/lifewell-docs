# Migrar do Medisafe para o LifeWell

O Medisafe foi criado para ajudar a tomar medicamentos no horário, com notificações para um cuidador. A página de download descreve um aplicativo gratuito, sem informar preço de plano pago para consumidores.

No LifeWell, medicamentos são uma página dentro de registros mais amplos sobre pessoas, memórias e compromissos da sua vida. Os preços são públicos.

Última conferência: 26/11/2026. Veja [Medisafe e LifeWell lado a lado](https://lifewell.aoneahsan.com/compare/medisafe).

## Transferir uma lista de medicamentos

1. Anote tudo o que o Medisafe guarda: medicamento, dose e horários.
2. [Entre no LifeWell](/getting-started/first-run) e cadastre cada item na página de medicamentos em [Saúde](/domains/health), com dose e programação.
3. Os [lembretes](/features/reminders) de medicamentos começam ativos. Desligue individualmente aqueles de que não precisa.
4. Cuida de uma criança? Os medicamentos dela ficam numa lista separada, para que doses pediátricas não se misturem às dos adultos.
5. Coloque no [calendário](/features/calendar-and-appointments) as consultas sobre medicamentos e as perguntas que quer fazer.
6. Continue usando o Medisafe enquanto o cuidador depender das notificações dele. O LifeWell não oferece aconselhamento médico nem se conecta ao sistema do seu médico.
