# Migrar do Journey para o LifeWell

O Journey é um diário com uma versão gratuita por tempo indeterminado. A assinatura acrescenta criptografia de ponta a ponta, diários compartilhados e exportação em ePub e DOCX.

No LifeWell, as pessoas têm tanta importância quanto os dias. Cada memória é ligada a quem participou dela, ao lado da árvore de família, saúde e compromissos.

Última conferência: 26/11/2026. Compare os dois em [LifeWell e Journey](https://lifewell.aoneahsan.com/compare/journey).

## Das entradas do diário para as pessoas

1. Com a assinatura Journey, exporte o diário em DOCX ou ePub para guardar o texto completo num arquivo seu.
2. [Entre no LifeWell](/getting-started/first-run).
3. Adicione em [Pessoas](/domains/people) quem aparece nas entradas.
4. Copie as entradas desejadas para [Memórias](/domains/memories), com fotos, data e lugar.
5. Continue usando o Journey para o diário privado do dia a dia.

## Journey e LifeWell

| Recurso | LifeWell | Journey |
|---|---|---|
| Memórias com foto, data e lugar | Sim | Sim (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Página compartilhada com alguém sem conta | Sim | Sim (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Download dos próprios dados | Sim | Sim (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |
| Plano gratuito permanente | Sim | Sim (<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">página oficial</a>) |

A página de assinatura do Journey não declarava registro por pessoa, árvore genealógica, entrada por voz, compromissos, dados de saúde, notas, aplicativo Android ou plano familiar.

Um link web do Journey mostra uma entrada do diário. Um link LifeWell mostra árvore, acompanhamento ou medicamentos. Veja [Compartilhamento](/domains/sharing).
