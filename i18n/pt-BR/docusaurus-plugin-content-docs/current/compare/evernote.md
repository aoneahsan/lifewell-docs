# Migrar do Evernote para o LifeWell

O Evernote serve quando as notas são a atividade principal: cadernos, recortes da web, digitalização e busca de documentos, em todos os seus dispositivos.

No LifeWell, as notas são parte dos registros sobre pessoas. Memórias, saúde e compromissos ficam junto delas.

Última conferência: 26/11/2026. Veja [LifeWell e Evernote lado a lado](https://lifewell.aoneahsan.com/compare/evernote).

## Dos cadernos para as pessoas

1. Exporte como PDF os cadernos do Evernote que deseja guardar, para manter uma cópia.
2. [Entre no LifeWell](/getting-started/first-run) e adicione em [Pessoas](/domains/people) quem aparece nessas notas.
3. Copie o conteúdo para [Notas](/domains/everyday). Excluir uma pasta ali nunca apaga as notas que estavam nela.
4. Notas com data e lembrete no Evernote podem virar [compromissos](/features/calendar-and-appointments) com [lembrete](/features/reminders).
5. Mantenha o Evernote para capturar páginas e digitalizar documentos.
