# Usar o LifeWell na web

Não é preciso instalar nada. Abra [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) e entre na conta.

## Entrar na conta

**O Google é o único modo de entrar.** Não há formulário de e-mail e senha. É uma escolha deliberada: não vemos nem guardamos uma senha, porque o LifeWell não usa uma.

1. Abra [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com).
2. Escolha **Continuar com o Google**.
3. Escolha a conta Google à qual você quer vincular seu registro.

O registro pertence à conta escolhida. Trocar de conta depois leva a outro registro, não a uma mudança de nome.

## O que acontece depois

Na primeira entrada, aparece uma configuração curta de cinco etapas. A maioria das respostas pode ficar em branco. Veja [O primeiro acesso](./first-run.md).

## Navegadores compatíveis

O LifeWell funciona nas versões atuais de Chrome, Edge, Firefox e Safari. Não há uma lista de suporte além disso nem uma camada de adaptação para navegadores antigos. Se o navegador não conseguir executar o aplicativo, a tela inicial informa o problema em vez de exibir algo quebrado.

## Adicionar à tela inicial

A versão web é um site comum. A maioria dos navegadores oferece a opção de adicioná-lo à tela inicial ou ao dock, com ícone e janela sem barra de endereços. É um recurso do navegador, não uma instalação separada do LifeWell: nada mais é baixado e o aplicativo continua funcionando da mesma forma.

Se você preferir a versão Android, com lembretes locais e notificações do sistema, veja [Instalar no Android](./install-android.md).
