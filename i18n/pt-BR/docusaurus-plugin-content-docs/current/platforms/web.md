# Web

[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) abre o LifeWell no navegador. O aplicativo Android usa a mesma conta e os mesmos registros; notificações do aparelho e compartilhamento dependem da plataforma.

## Navegadores

Versões atuais de Chrome, Edge, Firefox e Safari. Se o navegador for antigo demais para executar o aplicativo, a tela inicial informa isso em vez de mostrar uma página quebrada.

## O que a versão web não oferece

Algumas ações dependem do navegador e do sistema operacional:

- **Lembretes locais que chegam com o aplicativo fechado.** O Android agenda alertas compatíveis de eventos e bem-estar quando as notificações são permitidas. Uma aba fechada não consegue entregar esses alertas do aparelho; as doses de remédio pendentes aparecem na caixa de entrada do LifeWell quando você abre a lista de medicamentos.
- **A janela de compartilhamento do sistema.** Na web, compartilhar uma [lista de compras](../features/shopping-list.md) abre a janela do aplicativo com uma ação clara para copiar, em vez da janela do sistema.

A mesma conta e os registros salvos estão disponíveis nas duas plataformas. Consulte o guia de cada recurso para entender a entrega de alertas e as permissões necessárias.

## Adicionar à tela inicial

A maioria dos navegadores oferece a instalação, com ícone e janela sem barra de endereços. Nenhum programa extra é baixado e o funcionamento do aplicativo não muda; esse é um recurso do navegador.

## Sem conexão

O aplicativo web bloqueia a página atual enquanto a conexão está indisponível. Com a opção **Continuar registrando sem conexão** ativada, você pode escolher guardar alguns registros rápidos no dispositivo; o restante ainda precisa do servidor. O aplicativo não guarda páginas em cache para abri-las sem conexão. Veja [Uso sem conexão e sincronização](../concepts/offline-and-sync.md).

## Páginas públicas

Alguns endereços funcionam sem conta: [ferramentas](../features/tools.md), busca de nomes de bebês, diretório de doadores de sangue, blog, páginas de recursos e quatro páginas legais. São páginas comuns, renderizadas como HTML real em vez de serem montadas por JavaScript depois do carregamento. Assim, um mecanismo de busca ou assistente de IA lê as mesmas palavras que você.
