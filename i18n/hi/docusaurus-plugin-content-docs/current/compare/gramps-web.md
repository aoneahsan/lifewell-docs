# Gramps Web से LifeWell पर आना

Gramps Web मुफ़्त, खुले स्रोत वाला वंशावली सॉफ़्टवेयर है जिसे आप अपने सर्वर पर चलाते हैं। यह GEDCOM पढ़ता और लिखता है, क्लिक करके देखे जा सकने वाले चार्ट बनाता है और वंशवृक्ष की PDF किताब जैसी रिपोर्ट तैयार करता है।

LifeWell उन लोगों के लिए है जो सर्वर की देखभाल नहीं करना चाहते। यह होस्ट की गई सेवा है, इसका Android ऐप है और उन्हीं लोगों के साथ यादें, मुलाक़ातें व स्वास्थ्य रिकॉर्ड रखता है।

पिछली जाँच 2026-11-26 को हुई थी। स्रोतों के साथ तुलना [LifeWell और Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web) पर है।

## अपने सर्वर से जानकारी लाना

1. Gramps Web के पूरे डेटा की एक प्रति डाउनलोड करके रखें। LifeWell GEDCOM नहीं पढ़ता, इसलिए वह फ़ाइल आपके पूरे शोध की प्रति रहेगी।
2. [LifeWell में साइन इन करें](/getting-started/first-run)।
3. नाम तैयार हों तो [लोग](/domains/people) के आयात पृष्ठ में हर नाम अलग पंक्ति पर चिपकाएँ। कुछ भी सहेजने से पहले मिले हुए सभी नाम दिखते हैं। केवल नाम आते हैं; तारीखें और रिश्ते आपको खुद जोड़ने होंगे।
4. लोगों को एक-दूसरे से रिश्तों के ज़रिए जोड़ें। इन्हीं से [वंशवृक्ष](/domains/people) बनेगा।
5. महत्वपूर्ण तस्वीरों को [यादों](/domains/memories) में जोड़ें और हर तस्वीर में मौजूद लोगों के नाम दर्ज करें, जैसे Gramps Web में तस्वीरों पर लोगों को टैग करते थे।
6. PDF किताब जैसी रिपोर्ट या पूरे शोध डेटाबेस के लिए Gramps सर्वर जारी रखें।

| परिवार का वंशवृक्ष बनाना | हाँ | हाँ (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">उनका पृष्ठ</a>) |

| बिना खाते वाले व्यक्ति से पृष्ठ साझा करना | हाँ | आंशिक रूप से (<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">उनका पृष्ठ</a>) |

Gramps Web के पृष्ठों पर बोलकर दर्ज करना, मुलाक़ातें, स्वास्थ्य रिकॉर्ड, नोट्स, Android ऐप या पूरे परिवार का प्लान नहीं बताया गया था।

LifeWell अपना वंशवृक्ष प्रिंट नहीं कर सकता और किताब जैसी रिपोर्ट नहीं बनाता।
