# बनावट

एक **स्थिर एक पेज वाला ऐप**। बिल्ड फ़ाइलों का फ़ोल्डर बनाता है और वही पूरा प्रकाशित ऐप है। अलग Node सर्वर नहीं है।

## रूपरेखा

```text
ब्राउज़र / Android WebView
        │
        ├──────────────► PostgREST से Postgres         (सामान्य पढ़ना और लिखना)
        │                 · पंक्ति स्तर की सुरक्षा
        │                 · कॉलम की अनुमतियाँ
        │                 · सूची में अधिकतम 50 पंक्तियाँ
        │
        └──────────────► Deno पर Edge Function       (जो ब्राउज़र में नहीं रखा जा सकता)
                          · बॉट जाँच के पीछे दो सार्वजनिक फ़ॉर्म
                          · केवल पढ़ने वाला साझा लिंक खोलना
                          · Google Drive टोकन बदलना
                          · AI अनुमान और आपकी अपनी AI कुंजी
                          · तय समय के एक्सपोर्ट
                          · Play ख़रीद की पुष्टि
                          · एडमिन के उपयोगकर्ता संबंधी काम
```

## कौन सा रास्ता चुना जाए—एक नियम

> सामान्य डेटा के लिए ब्राउज़र सीधे डेटाबेस से बात करता है। Edge Function **केवल** तब लगती है जब काम में ऐसी चीज़ चाहिए जो ब्राउज़र के पास कभी नहीं होनी चाहिए—गुप्त कुंजी, ऊँची अनुमति या उपयोगकर्ता के लिखे मान पर भरोसा करने का फ़ैसला।

बाकी हर काम आपके रूप में सीधी क्वेरी है। उस पर [गोपनीयता और सुरक्षा](./privacy-and-security.md) के नियम लागू होते हैं।

## सुरक्षा की सीमा डेटाबेस में क्यों है

ऐप कोड में रखी अनुमति हर जगह इस्तेमाल करते समय याद रखनी पड़ती है। पंक्ति स्तर की सुरक्षा में *डेटाबेस* मना करता है। इसलिए ग़लत लिखी क्वेरी दूसरे व्यक्ति की पंक्तियाँ देने के बजाय कुछ नहीं लौटाती।

इसी कारण चलते ऐप में ORM नहीं है। संरचना TypeScript में लिखी जाती है और ऑफ़लाइन माइग्रेशन में बदली जाती है; चलता ऐप केवल क्लाइंट लाइब्रेरी से साइन इन किए व्यक्ति के रूप में बात करता है और वही नियम लागू होते हैं।

## किससे बना है

| परत | चुनाव |
|---|---|
| फ़्रेमवर्क | React 19 |
| बिल्ड | Vite 8, प्रकाशित बिल्ड में स्रोत नक्शे नहीं |
| पेजों का रास्ता | फ़ाइल आधारित, खोज पैरामीटर के तय प्रकार सहित |
| सर्वर से आया डेटा | TanStack Query |
| ऐप में रखी स्थिति | Zustand—ऐप स्थिति के लिए React context नहीं |
| फ़ॉर्म | React Hook Form और Zod; वही Zod नियम Edge Function भी जाँचते हैं |
| सुगम पहुँच | React Aria Components हर घटक का DOM, ARIA और कीबोर्ड व्यवहार सँभालता है |
| रूप-रंग | Tailwind v4, अलग कॉन्फ़िग फ़ाइल के बजाय CSS में सेट |
| चार्ट | D3 |
| फ़ॉर्मैट वाला पाठ | Tiptap—ऐप में साधारण पाठ बॉक्स नहीं |
| स्थानीय स्टोरेज | एक लाइब्रेरी; ब्राउज़र स्टोरेज को छूने की अनुमति केवल उसी को है |
| Android | Capacitor 8 |

## Firebase नहीं

2.x ऐप Firebase पर था। उसका मुफ़्त पढ़ने वाला कोटा भर गया और ऐप एक दिन बंद रहा। नए संस्करण का एक मक़सद यह समस्या सुधारना था।

दूसरा कारण साझा करने का तरीका है। किसी नाम वाले व्यक्ति को रिकॉर्ड का हिस्सा देना पंक्ति स्तर का सवाल है। Postgres इसे डेटाबेस में हल करता है; पुराना दस्तावेज़ स्टोर इसे नियम फ़ाइल में करता था जिसे हर क्वेरी के साथ मिलाकर रखना पड़ता था।

## पते में स्थिति

पॉपअप, टैब, फ़िल्टर, क्रम, पेज और खोज के शब्द घटक की स्थिति के बजाय पते में रहते हैं। पेज फिर खोलने से आपकी जगह नहीं खोती; जिस दृश्य का लिंक भेजें, वही खुलता है।
