# डेवलपर बदलावों का रिकॉर्ड

LifeWell API, MCP सर्वर, वेबहुक और कैलेंडर फ़ीड में हर बदलाव यहाँ सबसे नए से शुरू करके दर्ज है। API का संस्करण उसके पते `/v1` में शामिल है। [OpenAPI फ़ाइल](./api.md#पूरा-संदर्भ-कहाँ-है) हमेशा उसी संस्करण का विवरण देती है जिसके तहत वह रखी गई है।

ऐप में हुए बदलाव [मुख्य बदलावों के रिकॉर्ड](../about/changelog.md) में हैं।

## 19 नवंबर 2026

- LifeWell में एक्सेस टोकन (सेटिंग्स → दूसरे ऐप), OpenAPI फ़ाइल वाला `/v1` API, AI सहायकों के लिए MCP सर्वर, वेबहुक, कैलेंडर फ़ीड और दो चरणों वाला साइन इन (सेटिंग्स → सुरक्षा) चालू किए गए।
