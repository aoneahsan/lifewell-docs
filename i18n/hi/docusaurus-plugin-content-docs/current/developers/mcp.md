# AI सहायक जोड़ें (MCP)

LifeWell MCP सर्वर से AI सहायक आपके कहने पर आपका रिकॉर्ड पढ़ और बदल सकता है—जैसे *“इस महीने मेरे परिवार में किसका जन्मदिन है?”* या *“गुरुवार सुबह साढ़े नौ बजे दंत चिकित्सक का अपॉइंटमेंट जोड़ें।”* आप सहायक को एक पता देते हैं, LifeWell में साइन इन करते हैं और अनुमति पेज पर तय करते हैं कि वह क्या कर सके। Claude, ChatGPT, Claude Code, Cursor और MCP समझने वाले दूसरे सहायक इससे जुड़ सकते हैं।

## पता क्या है?

```text
https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

यही पता **सेटिंग्स → दूसरे ऐप → AI सहायक जोड़ें** में कॉपी बटन के साथ है। सहायक में टोकन चिपकाने की ज़रूरत नहीं। वह इस पते से LifeWell का साइन इन ढूँढ़कर आपको वहाँ भेजता है।

## हर सहायक को कैसे जोड़ें?

इन ऐप के मेन्यू रिलीज़ के साथ बदलते हैं। नीचे कोई चरण आपकी स्क्रीन से अलग हो तो ऐप की सेटिंग में **Connectors** ढूँढ़ें।

### Claude

1. Claude में **Settings → Connectors** खोलकर अपना कनेक्टर जोड़ें।
2. ऊपर का पता चिपकाएँ।
3. पूछे जाने पर LifeWell में साइन इन करें और अनुमति पेज पर स्वीकार करें।

### ChatGPT

1. ChatGPT में **Settings → Connectors** खोलें। कुछ खातों में पहले डेवलपर मोड चालू करना पड़ता है।
2. ऊपर के पते से कनेक्टर जोड़ें।
3. पूछे जाने पर LifeWell में साइन इन करें और अनुमति पेज पर स्वीकार करें।

### Claude Code

```bash
claude mcp add --transport http lifewell https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

फिर Claude Code में `/mcp` चलाएँ, **lifewell** चुनें और खुले ब्राउज़र में साइन इन करें।

### Cursor

अपने `mcp.json` में LifeWell जोड़ें:

```json
{
  "mcpServers": {
    "lifewell": {
      "url": "https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp"
    }
  }
}
```

पहली बार इस्तेमाल करने पर Cursor साइन इन माँगता है।

## अनुमति पेज क्या पूछता है?

कोई सहायक रिकॉर्ड तक पहुँचने से पहले LifeWell `https://lifewell.aoneahsan.com/oauth/consent` पर यह दिखाता है:

- **कौन सा ऐप माँग रहा है** और आपको किस पते पर लौटाएगा;
- **कौन सा LifeWell खाता** खुलेगा—एक से अधिक खाते हों तो यह देख लें;
- **वह क्या कर सकेगा**, पूरे वाक्यों में पढ़ने, लिखने और मिटाने के समूह में, हर एक के अपने निशान बॉक्स के साथ। मिटाने पर शुरू में निशान नहीं है;
- **स्वीकार करें** और **मना करें**, साथ-साथ।

[दो चरणों वाला साइन इन](./two-step-sign-in.md) चालू हो तो स्वीकार करने पर कोड माँगा जाता है। आपकी ओर से कुछ अपने आप स्वीकार नहीं होता; हर नया कनेक्शन इसी पेज से गुजरता है।

सहायक को केवल वही साधन दिखते हैं जिनकी आपने अनुमति दी। केवल पढ़ने की अनुमति दें तो वह कुछ बदल नहीं सकता।

## मिटाने का काम कैसे होता है?

सहायक मिटाने की कार्रवाई **तैयार** कर सकता है; उसे **पूरा** केवल आप कर सकते हैं। किसी चीज़ को हटाने के लिए कहें तो वह बताता है क्या हटेगा और LifeWell का लिंक देता है। 10 मिनट के भीतर LifeWell में आप पुष्टि करें, वरना कुछ नहीं मिटता। वेब पेज में छिपा वाक्य या चिपकाया दस्तावेज़ सहायक से रिकॉर्ड नहीं मिटवा सकता, क्योंकि वह अपनी माँग की पुष्टि खुद नहीं कर सकता।

यह तभी लागू है जब आपने अनुमति पेज पर मिटाने की अनुमति दी हो। उसके बिना सहायक मिटाने की तैयारी भी नहीं कर सकता।

## सहायक का कनेक्शन कैसे हटाएँ?

**सेटिंग्स → दूसरे ऐप → जुड़े ऐप** खोलें और उसकी पंक्ति में **रद्द करें** चुनें। अगले अनुरोध से उसकी पहुँच बंद हो जाती है। सूची हर ऐप की अनुमतियाँ, जुड़ने की तारीख़ और आख़िरी इस्तेमाल दिखाती है। नया कनेक्शन स्वीकार करते ही वहाँ दिखता है। ऐप जुड़ने पर LifeWell ईमेल भी भेजता है।

| आपको क्या दिखता है | क्या करें |
|---|---|
| सहायक फिर साइन इन माँगता है | उसका सत्र ख़त्म हुआ। सहायक से LifeWell में फिर साइन इन करें |
| अनुमति न होने की बात कहता है | वह अनुमति नहीं दी गई थी। कनेक्शन हटाकर फिर जोड़ें और अनुमति पेज पर निशान लगाएँ |
| LifeWell उसकी साधन सूची से ग़ायब है या हर कॉल असफल है | पहुँच रद्द हो गई थी। **जुड़े ऐप** देखें और चाहें तो फिर जोड़ें |
| मिटाने पर कुछ नहीं हुआ | LifeWell में 10 मिनट के भीतर पुष्टि नहीं हुई थी। फिर अनुरोध करें |
| जानना चाहते हैं उसने क्या किया | **जुड़े ऐप** हर ऐप का आख़िरी इस्तेमाल दिखाता है |
