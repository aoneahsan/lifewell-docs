# Une courte visite

## Le tableau de bord \{#the-dashboard}

`/dashboard` est votre point d’arrivée. Il propose des actions rapides pour les notes les plus courantes — un verre d’eau, un poids, une humeur — afin qu’un geste suffise.

Noter quelque chose doit prendre quelques secondes. Sinon, le tableau de bord a manqué son rôle.

## Le menu \{#the-menu}

Le menu de gauche suit les [sept espaces](../domains/overview.md). Il ne montre que les espaces actifs et, dans chacun, les écrans qui vous concernent. Voir [Votre première ouverture](./first-run.md#the-one-answer-that-changes-what-you-see).

## La barre supérieure \{#the-top-bar}

| Commande | Ce qu’elle fait |
|---|---|
| Visite de page | Le panneau indicateur près de l’étoile. Une courte visite de la page actuelle — voir [la visite de page et le parcours de découverte](./tours-and-walkthrough.md) |
| Recherche | Ouvre la recherche dans votre dossier. [État actuel](../features/search.md) |
| Notifications | Les messages envoyés par l’application : rappels, activité de partage, avis d’administration |
| Apparence | Une icône, un panneau, tous les réglages d’apparence. Voir [Apparence](../concepts/appearance.md) |
| Votre compte | Profil, offre, paramètres et déconnexion |

## Suivi \{#tracking}

`/tracking` rassemble tous les chiffres sur un seul écran. Il ne conserve pas une copie séparée : `/health/water`, l’action rapide du tableau de bord et `/tracking` présentent la même table. Un verre noté à un endroit apparaît donc immédiatement aux deux autres.

## Paramètres \{#settings}

`/settings` contient ce qui concerne le compte plutôt qu’une note :

- **Vos données** — exporter, supprimer un espace, supprimer le compte.
- **Espaces** — six interrupteurs, ainsi qu’une ligne Partage sans interrupteur.
- **Rappels** — ce que l’application peut vous envoyer.
- **Partage** — qui peut lire quoi.
- **Sécurité** — sessions et déconnexion.

## Les réponses sans détour \{#where-the-honest-answers-are}

Quatre pages publiques répondent aux questions à se poser avant de confier une partie de sa vie à une application : [`/privacy`](https://lifewell.aoneahsan.com/privacy) · [`/terms`](https://lifewell.aoneahsan.com/terms) · [`/permissions`](https://lifewell.aoneahsan.com/permissions) · [`/delete-account`](https://lifewell.aoneahsan.com/delete-account).

Elles sont écrites pour être lues : aucun terme défini en majuscules, aucune suite de clauses numérotées, aucune phrase qui oblige à revenir en arrière.
