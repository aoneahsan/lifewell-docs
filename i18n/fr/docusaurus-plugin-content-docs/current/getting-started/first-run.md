# Votre première ouverture

À la première connexion, cinq étapes vous accueillent. Deux se résument à une phrase. Aucune réponse n’est définitive : vous pourrez toutes les retrouver ensuite dans les paramètres.

## Les cinq étapes \{#the-five-steps}

| Étape | Ce qui est demandé | Facultative |
|---|---|---|
| Bienvenue | Rien. L’écran explique à quoi sert l’application | — |
| À propos de vous | Un nom affiché, un prénom d’usage et la manière dont vous vous définissez | Oui, les trois champs |
| Ce qui compte | Lesquels des six espaces avec interrupteur vous souhaitez garder | Oui — si vous ne choisissez rien, les six restent actifs |
| Rappels | Les catégories de rappels que vous souhaitez autoriser plus tard ; aucun rappel quotidien n’est créé | Oui |
| Terminé | Rien. Vous arrivez au tableau de bord | — |

## La réponse qui change ce que vous voyez \{#the-one-answer-that-changes-what-you-see}

**La manière dont vous vous définissez** détermine si six écrans figurent au menu : cycle, conception, ovulation, SOPK, ménopause et allaitement.

Le choix **Homme** masque ces écrans dans le menu. Toutes les autres réponses, y compris *Je préfère ne pas répondre*, les laissent visibles.

*Je préfère ne pas répondre* est une réponse, pas un champ vide. Elle est enregistrée, empêche l’application de vous reposer la question et laisse tout visible.

Masqué ne veut pas dire supprimé. Les écrans disparaissent du menu, mais vos notes restent et leurs pages s’ouvrent directement. Vous pouvez modifier cette réponse à tout moment dans votre profil ; rien n’est supprimé dans un cas comme dans l’autre.

## Ce qui compte \{#what-matters}

La troisième étape présente les six [espaces](../domains/overview.md) dotés d’un interrupteur. En désactiver un ici revient à utiliser le même réglage dans les paramètres : il se fait discret, sans être supprimé.

**Vous** ne figurez pas dans cette liste, car il s’agit du compte et non d’un espace désactivable. Le Partage n’y figure pas non plus : c’est le seul espace sans interrupteur.

## Après ces étapes \{#afterwards}

Vous retrouverez toutes vos réponses à deux endroits :

- **Profil** — vos noms, la manière dont vous vous définissez et vos informations médicales de base.
- **Paramètres** — les six interrupteurs des espaces, les rappels, l’apparence et les réglages de vos informations.

Aucune décision prise ici n’est irréversible.
