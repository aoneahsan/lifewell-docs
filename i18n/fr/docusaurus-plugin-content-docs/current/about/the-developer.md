# Qui crée LifeWell

**L’équipe LifeWell** crée et entretient LifeWell ainsi que cette documentation.

Elle dit clairement ce que le produit ne peut pas faire :

- **Les questions arrivent dans une seule boîte de réception.** L’équipe LifeWell lit chaque message qui y parvient.
- **Tout n’est pas construit.** Plusieurs pages le disent sans détour : mieux vaut cela qu’une page décrivant une fonction inexistante.
- **Il n’y a pas de calendrier promis.** Lorsqu’une fonction est prévue, cette documentation dit « prévue » et non « bientôt ».

## Contact

Utilisez [`/contact`](https://lifewell.aoneahsan.com/contact) dans l’application, ou [`/support`](https://lifewell.aoneahsan.com/support).

## Participer \{#get-involved}

[`/get-involved`](https://lifewell.aoneahsan.com/get-involved) vous permet de proposer votre aide : essais, rédaction, regard sur la conception ou idée à laquelle personne n’a encore pensé.

## Cette documentation \{#this-documentation}

Elle est écrite et entretenue avec l’application, dans un [dépôt public](https://github.com/aoneahsan/lifewell-docs). Un lien de modification figure au bas de chaque page. Si vous relevez une erreur, c’est le chemin le plus court pour la signaler. Voir [Contribuer](./contributing.md).

Le code de l’application n’est pas public.
