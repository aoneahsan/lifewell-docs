# Extension de navigateur

**Construite pour Chrome et Firefox. Pas encore publiée dans leurs boutiques.**

## Situation actuelle \{#where-this-stands}

Un ancien dossier d’extension était resté dans le projet après la reconstruction pour la version 3.0.0. Le compagnon actuel est une extension WXT indépendante, compilée pour Chrome et Firefox. Elle n’a encore été soumise à aucune des deux boutiques : vous ne pouvez donc pas l’y installer aujourd’hui.

## Ce que l’extension garde à portée de main \{#what-the-extension-keeps-close}

La fenêtre de l’extension propose des rappels pour boire de l’eau et faire une pause, des informations générales sourcées sur la préparation des aliments et vos rendez-vous pendant la navigation. Vos notes de bien-être locales et les détails de rendez-vous restent dans le stockage du navigateur. Connecter votre compte LifeWell ne les ajoute pas à votre dossier LifeWell.

## Connecter votre compte \{#connecting-your-account}

L’extension lance la connexion et ouvre le site LifeWell. Comparez le code court affiché aux deux endroits avant d’autoriser ce navigateur. L’extension reçoit alors sa propre session et lit la langue de votre profil. Vous pouvez la déconnecter depuis l’extension.

La fenêtre peut aussi présenter d’autres produits Zaions. Ces promotions de nos propres produits comptent comme des publicités dans la fiche de la boutique.

## Cette adresse \{#the-address}

Cette page conserve son adresse pour que les anciens liens vers les instructions de l’extension arrivent sur les informations actuelles. Elle renverra vers les fiches des boutiques après publication.

En attendant, [l’application Web](./web.md) est disponible.
