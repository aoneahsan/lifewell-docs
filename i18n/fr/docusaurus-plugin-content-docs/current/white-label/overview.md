# Marque blanche et licences

Une licence en marque blanche permet à une organisation de proposer LifeWell à ses membres, avec son nom, son logo et ses couleurs sur chaque écran. Nous l’hébergeons, le plaçons sur votre domaine et le tenons à jour. Le code source reste notre propriété, sauf si vous le rachetez entièrement.

Les prix et le formulaire d’achat se trouvent sur [les pages marque blanche](https://lifewell.aoneahsan.com/white-label). Cette section explique ce que vous recevez sans répéter les montants : la page des prix lit leurs valeurs actuelles.

## À qui cela s’adresse \{#who-it-suits}

Aux organisations dont les membres construisent une vie ensemble : une maison de retraite où les familles gardent les histoires d’un parent, une association d’histoire familiale, un employeur ou un syndicat offrant un avantage à son personnel, une communauté ou une organisation religieuse.

## Deux façons d’acheter \{#two-ways-to-buy}

| | Une licence | Un rachat |
|---|---|---|
| Ce que vous recevez | LifeWell exploité pour vous, à votre nom | Le code source des applications Web et Android |
| Qui l’exploite | Nous | Vous |
| Exclusivité | Non — d’autres organisations peuvent obtenir une licence | Oui — nous cessons de vendre LifeWell |
| Mises à jour | Six mois, puis renouvellement | Six mois, puis renouvellement |
| Prix | [Par plateforme](https://lifewell.aoneahsan.com/white-label/pricing) | [Un achat unique](https://lifewell.aoneahsan.com/white-label/buyout), puis une redevance de 7 % du chiffre d’affaires brut tant qu’il existe |

Les changements réservés à votre copie sont des [travaux personnalisés](https://lifewell.aoneahsan.com/white-label/custom-work), facturés sur devis.

## Ce qui ne change pas \{#what-does-not-change}

Les personnes qui utilisent votre copie conservent les mêmes droits que dans LifeWell : ce qu’elles saisissent leur appartient, elles peuvent exporter une période choisie dans la limite de 5 000 lignes par table et supprimer elles-mêmes leur compte actif. LifeWell reste distinct d’un suivi médical, d’un dispositif médical et d’un dossier clinique ; une copie sous licence ne peut pas être présentée comme tel.

La licence en termes simples : [conditions de licence](https://lifewell.aoneahsan.com/white-label/license-terms). L’accord complet : les [conditions d’utilisation](https://lifewell.aoneahsan.com/terms#t-whitelabel).
