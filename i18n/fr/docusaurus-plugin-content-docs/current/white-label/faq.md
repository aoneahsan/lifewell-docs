# Questions sur la marque blanche

## Recevons-nous le code source avec une licence ? \{#do-we-get-the-source-code-with-a-licence}

Non. Une licence donne accès à une copie de LifeWell exploitée pour vous, à votre nom. Le code source n’est transmis qu’en cas de [rachat](https://lifewell.aoneahsan.com/white-label/buyout).

## Pouvez-vous aussi vendre LifeWell à une autre organisation ? \{#can-you-sell-lifewell-to-someone-else-as-well}

Oui, tant que personne ne l’a racheté intégralement. Une licence n’est pas exclusive. Après un rachat, nous cessons de vendre LifeWell. Les licences vendues auparavant conservent leurs conditions.

## Faut-il encore payer après un rachat ? \{#is-there-anything-to-pay-after-a-buyout}

Oui, une redevance. L’acheteur nous verse chaque trimestre 7 % du chiffre d’affaires brut généré par LifeWell, hors taxe sur les ventes ou TVA collectée, avec un relevé des recettes. Elle reste due tant que LifeWell génère des revenus, même après une revente. Les [conditions de licence](https://lifewell.aoneahsan.com/white-label/license-terms#wlt-buyout) le précisent.

## Comment payons-nous ? \{#how-do-we-pay}

Par virement sur notre compte Wise. La page de paiement indique les coordonnées et demande la référence du virement. Après confirmation de notre part, vous recevez votre clé de licence par e-mail.

## Que se passe-t-il après les six mois de mises à jour ? \{#what-happens-when-the-six-months-of-updates-end}

Votre copie continue de fonctionner dans sa version actuelle. Un renouvellement de trois, six ou douze mois rétablit les mises à jour.

## Existe-t-il une application iPhone ? \{#is-there-an-iphone-app}

LifeWell est actuellement distribué sur le Web et Android. La licence mobile couvre les deux types de téléphone ; la version iOS est construite lorsque vous fournissez ou financez un compte développeur Apple.

## De quoi avez-vous besoin pour commencer ? \{#what-do-you-need-from-us-to-start}

De votre domaine, du nom à afficher, d’un logo — de préférence en SVG — et de vos couleurs. Pour Android, nous avons également besoin de l’accès à votre compte développeur Google Play.

## Pouvons-nous vous contacter avant d’acheter ? \{#can-we-ask-before-buying}

Oui. Vous pouvez [demander un devis, un travail personnalisé ou un appel](https://lifewell.aoneahsan.com/white-label/custom-work).
