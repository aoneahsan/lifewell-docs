# Passer d’Any.do à LifeWell

Any.do offre au foyer un espace partagé pour les tâches ménagères, les courses et les rappels, gratuitement, avec une offre Family pour quatre personnes. LifeWell n’a pas de liste de tâches.

La différence de LifeWell tient à ce que contient la fiche d’une personne : l’arbre familial, les souvenirs, les notes de santé et les rendez-vous.

Dernière vérification le 26 novembre 2026. Les deux produits sur une page : [LifeWell et Any.do](https://lifewell.aoneahsan.com/compare/any-do).

## Répartir les usages familiaux \{#splitting-the-family-space}

1. [Connectez-vous à LifeWell](/getting-started/first-run) et ajoutez les membres du foyer dans [Personnes](/domains/people).
2. Les rappels de rendez-vous chez le médecin ou le dentiste et de réunions scolaires vont dans les [rendez-vous](/features/calendar-and-appointments), chacun avec un [rappel](/features/reminders).
3. Les courses peuvent rester dans Any.do ou passer dans la [liste de courses](/features/shopping-list) de LifeWell. Elle se remplit à partir de votre planning de repas et se partage en texte brut : la personne qui fait les courses n’a pas besoin de compte.
4. Les tâches ménagères restent dans Any.do.

## Any.do et LifeWell \{#anydo-and-lifewell}

| Fonction | LifeWell | Any.do |
|---|---|---|
| Rendez-vous avec rappel | Oui | Oui (<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Offre gratuite sans limite de durée | Oui | Oui (<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |
| Une offre pour tout le foyer | Oui | Oui (<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">leur page</a>) |

La page des tarifs d’Any.do ne précisait pas s’il existe une fiche par personne, un arbre familial, des souvenirs, la dictée d’une entrée, des liens de partage, des dossiers de santé, des notes, le téléchargement de vos données ou une application Android.
