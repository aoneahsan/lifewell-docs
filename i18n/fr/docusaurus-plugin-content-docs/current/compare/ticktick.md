# Passer de TickTick à LifeWell

TickTick réunit tâches, habitudes et calendrier dans une application sur toutes les plateformes, gratuitement, avec une offre Premium annuelle. LifeWell n’a pas de liste de tâches.

Le calendrier de LifeWell est lié aux personnes qui y figurent, avec leurs souvenirs, leur arbre familial et leurs dossiers de santé.

Dernière vérification le 26 novembre 2026. Les deux produits point par point : [LifeWell et TickTick](https://lifewell.aoneahsan.com/compare/ticktick).

## Utiliser TickTick et LifeWell ensemble \{#using-ticktick-and-lifewell-together}

1. [Connectez-vous](/getting-started/first-run).
2. Repérez les listes TickTick qui concernent vraiment la famille — les médicaments d’un parent, les rendez-vous d’un enfant — et ajoutez ces personnes dans [Personnes](/domains/people).
3. Déplacez les éléments datés d’une liste familiale dans le [calendrier](/features/calendar-and-appointments) de LifeWell. La vue mensuelle les montre avec tout ce qui porte une date dans votre dossier.
4. Si une liste concernait les médicaments d’une personne, ajoutez-les plutôt dans [Santé](/domains/health), avec la dose, le rythme de prise et un [rappel](/features/reminders).
5. Les habitudes et les tâches restent dans TickTick.

Les enregistrements créés avec Parlez, c’est écrit restent privés jusqu’à ce que vous les supprimiez.
