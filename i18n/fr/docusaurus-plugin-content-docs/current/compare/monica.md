# Passer de Monica à LifeWell

Monica est un gestionnaire de relations personnelles libre, gratuit sur votre propre serveur, et également proposé en version hébergée. Il conserve simplement les personnes, les relations, les conversations et des rappels comme « appeler votre mère ».

LifeWell est une application hébergée que vous pouvez utiliser dès maintenant, sur Android ou sur le web. Elle associe souvenirs, arbre familial et dossiers de santé aux mêmes personnes.

Dernière vérification le 26 novembre 2026. Les deux produits et leurs sources : [LifeWell et Monica](https://lifewell.aoneahsan.com/compare/monica).

## Reprendre vos proches depuis Monica \{#moving-your-people-out-of-monica}

1. [Connectez-vous à LifeWell](/getting-started/first-run).
2. Si vous avez une liste de noms ou un fichier de contacts (.vcf), collez-la ou sélectionnez-le sur la page d’import de [Personnes](/domains/people). Elle ne lit que les noms et affiche toutes les personnes trouvées avant l’enregistrement.
3. Complétez chaque fiche à la main : le lien avec vous et les renseignements que vous gardiez dans Monica.
4. Les rappels Monica deviennent des [rendez-vous](/features/calendar-and-appointments), chacun avec son [rappel](/features/reminders).
5. Vos écrits sur une personne vont dans les [notes](/domains/everyday), classées par dossiers.
6. Gardez votre serveur Monica en service jusqu’à ce que tout ce dont vous avez besoin soit repris.

LifeWell n’a pas d’application iPhone.
