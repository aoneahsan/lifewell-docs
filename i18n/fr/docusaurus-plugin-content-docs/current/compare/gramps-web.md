# Passer de Gramps Web à LifeWell

Gramps Web est un outil de généalogie gratuit et libre que vous hébergez sur votre propre serveur. Il lit et écrit des fichiers GEDCOM, dessine des graphiques interactifs et crée des livres PDF sur l’arbre.

LifeWell s’adresse à ceux qui préfèrent ne pas gérer de serveur. Il est hébergé, dispose d’une application Android et associe les souvenirs, rendez-vous et dossiers de santé aux mêmes personnes.

Dernière vérification le 26 novembre 2026. La comparaison et ses sources figurent sur [LifeWell et Gramps Web](https://lifewell.aoneahsan.com/compare/gramps-web).

## Quitter un serveur que vous gérez \{#leaving-a-server-you-look-after}

1. Téléchargez une copie complète de vos données Gramps Web. LifeWell ne lit pas le format GEDCOM : gardez ce fichier comme copie intégrale de vos recherches.
2. [Connectez-vous à LifeWell](/getting-started/first-run).
3. Si vous avez les noms sous la main, collez-les dans la page d’import de [Personnes](/domains/people), un par ligne. Elle affiche toutes les personnes trouvées avant d’enregistrer quoi que ce soit. Seuls les noms sont repris : ajoutez vous-même les dates et liens de parenté.
4. Reliez les personnes entre elles. L’[arbre](/domains/people) se dessine à partir de ces liens.
5. Ajoutez les photos auxquelles vous tenez comme [souvenirs](/domains/memories) et indiquez qui y figure, comme lorsque vous identifiez des personnes dans Gramps Web.
6. Gardez le serveur Gramps si vous souhaitez ses livres PDF ou sa base de recherche complète.

LifeWell ne peut pas imprimer son arbre ni produire un livre.
