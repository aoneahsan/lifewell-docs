# Esprit

C’est le plus petit espace en nombre d’écrans, avec les règles les plus strictes sur ce qui peut en sortir.

## Le journal \{#the-journal}

Vous y accédez par `/health/mood-journal`. Une entrée peut contenir ce que vous avez remarqué. C’est une note pour vous, pas une théorie ; rien sur cette page n’en fera un diagnostic.

Le journal accueille plusieurs types d’entrées : humeur, gratitude, rêves et écriture libre. Elles sont conservées dans un même espace, avec un type par ligne. Un mois se lit ainsi comme un mois, pas comme quatre listes sans lien.

:::note[Le journal ne figure jamais dans l’exportation PDF]
Un PDF peut être imprimé, remis à un secrétariat ou laissé sur une table. Le journal est la seule partie de LifeWell qui ne doit pas sortir ainsi. Il figure dans les exportations JSON et CSV, que vous ouvrez vous-même. Voir [le format d’exportation](../reference/export-format.md#what-each-format-leaves-out).
:::

## Séances guidées \{#guided-sessions}

`/health/breathing`, `/health/meditation`, `/health/sleep-sounds`, `/health/affirmations`, `/health/panic-attack` et `/health/stress-assessment`.

Les séances ne sont enregistrées que si vous le demandez. Une liste vide indique simplement que la page a fait son travail sans bruit.

## Pauses au bureau \{#desk-wellness}

`/wellness` propose trois courtes pauses pendant le travail : repos des yeux, mouvement et posture. Chacune a son propre horaire et commence désactivée. L’eau se note dans son suivi ; les messages pour une dose de médicament due et non marquée apparaissent dans la boîte LifeWell lorsque vous ouvrez la liste des médicaments.

## Ce qui est volontairement absent \{#what-is-deliberately-absent}

Aucune note d’humeur, aucun indice de bien-être, aucun bilan hebdomadaire qui juge votre semaine. LifeWell garde ce que vous avez écrit et vous le présente sous une forme lisible ; il n’en tire pas de jugement.

Si un chiffre vous serait utile, les suivis de [Santé](./health.md) peuvent en conserver un. Le choix vous appartient, pas à l’application.
