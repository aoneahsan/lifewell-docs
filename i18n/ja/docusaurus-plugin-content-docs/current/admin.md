# 管理画面

`/admin`は一般の利用者が使う画面ではありません。ただし、プランの上限や投稿の管理、管理者がアカウントについて見られるものを決めるため、ここで説明します。

## 3つの役割

| 役割 | 利用できる範囲 |
|---|---|
| **モデレーター** | 投稿管理の待ち一覧を読み取り専用で開き、担当者向けの一覧を見られます |
| **管理者** | 下記の機能をすべて使えます |
| **最上位管理者** | 管理者と同じ機能に加え、役割を付与できます |

待ち一覧を読むことと、そこにある案件を決定することは、意図して**別の権限**にしています。モデレーターは一覧を扱えても、決定はできません。役割を加えるのと同時に投稿を非表示にする権限まで与えると、十分に確認されていない役割がほかの人の発言を決めてしまいます。

## 10の画面

| 画面 | できること |
|---|---|
| `/admin` | 概要 |
| `/admin/users` | アカウント一覧、役割の付与と取り消し、停止と再開、削除、個別アカウントの上限変更 |
| `/admin/plans` | プランの作成・変更・終了、プラン申告の処理、終了日付きの付与、支払い方法、Play商品の対応付け、端末での購入記録 |
| `/admin/moderation` | 通報の待ち一覧と、各通報についての判断 |
| `/admin/verifications` | 専門職の登録情報の確認、承認または却下 |
| `/admin/inbox` | 参加希望のメッセージ |
| `/admin/announcements` | お知らせの作成、公開、終了。他製品の紹介を含みます |
| `/admin/content` | 健康に関する情報一覧と、システムの記録種別 |
| `/admin/settings` | システム設定、メンテナンスモード、機能の切り替え、2つの決済切り替え、紹介制度の数値、お問い合わせ先 |
| `/admin/audit` | 監査記録 |

これらの画面の背後にある32の管理操作は、通常の利用者による実行をすべて拒否します。コードを読むだけでなく、管理者ではないアカウントで各操作を実行して確認しています。

## 管理者にも見えないもの

**あなたの記録の内容です。** アカウント一覧と詳細画面が返す列は限定され、健康に関する列は含まれません。アカウントを管理することは、日記を読むことではありません。

さらに、意図して見えないものが2つあります。

- **Google Playの購入トークンと領収書の原本**は、画面が読める列に含まれません。前者はGoogleに対する認証情報で、後者は領収書全体です。どちらも「いつ期限が切れるか」に答えるためには不要です。
- **紹介の一覧は表示できません。** 読み取り権限は本人の行だけに限定されるため、管理者も全件を閲覧できません。これは機能ではなく現在の制限で、管理画面から紹介の不正な輪を見つけることはできません。

## 監査記録

`/admin/audit`の行は、操作を実行するサーバー関数から**だけ**追加されます。誰にも直接の追加、更新、削除権限はありません。実行者が書き換えたり消したりできる記録では、監査になりません。

この仕組みには2つの結果があります。

- アカウントを削除する処理は**先に**監査行を書き込みます。書き込みに失敗したら削除を拒否します。
- 監査行は、対象のアカウントが消えたあとも残ります。記録の内容ではなく、実行された操作を示します。

## 利用者にも影響する管理画面の操作

- **プラン上限はコードではなくデータベースの行です。** リリースなしで変更でき、新しいプランも1行の追加です。無料より条件の悪い有料プランは保存できず、その検査は同じトランザクション内でデータベースが行います。
- **プランの付与には終了日と理由が付きます。** 期限切れの付与は、どの画面にも現れずエラーも出ない状態を避けるため拒否されます。
- **投稿管理の判断には必ず説明が付きます。** 投稿者と通報者には、それぞれに向けた文面が表示されます。
- **専門職の確認には照合した登録簿の名前が付きます。** 登録簿のない申告は却下しかできません。
- **個別アカウントの上限変更にも説明が付きます。** 理由が分からない例外は、あとで解除する判断もできません。

## 見た目ほどの制限にならない2つの操作

誤解しやすいため、ここに明記します。

- **機能の切り替えをオフにしても、書き込みは止まりません。** メニュー項目と画面を隠す表示上の設定で、保護の境界ではありません。
- **メンテナンスモードは利用者への案内です。** 表示を変えますが、データベースを閉じるものではありません。

## 画面のない操作

紹介を無効にするサーバー関数には画面がなく、データベースに対して直接実行します。理由を添えなければ拒否されます。理由の分からない無効化は、後から取り消すことも難しくなるためです。
