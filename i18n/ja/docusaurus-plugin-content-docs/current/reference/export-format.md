# エクスポートファイルの形式

[コピーをエクスポート](../your-data/export.md)で作られるファイルの説明です。ほかのアプリが内容を推測せずに読み取れるようにしています。

LifeWell独自の形式ではありません。JSONは一般的なJSONで、アーカイブは普通のCSVファイルをまとめたzipです。

## 3種類のファイル

| 形式 | ファイル名 | メディアタイプ | 範囲 |
|---|---|---|---|
| JSON | `lifewell-export-<YYYY-MM-DD>.json` | `application/json` | 選択した期間。テーブルごとに5,000行 |
| CSV | `lifewell-export-<YYYY-MM-DD>.zip` | `application/zip` | 選択した期間。テーブルごとに5,000行 |
| PDF | `lifewell-export-<YYYY-MM-DD>.pdf` | `application/pdf` | 要約。詳細は以下を参照 |

日付はサーバーの日付ではなく、自分の端末での現地日付です。ダウンロードフォルダーで探しやすいよう、ファイル名はどの言語でも同じASCII形式です。

## JSON文書

1つのオブジェクトです。短いヘッダーの後に、各テーブル名をキーとする行の配列が続きます。

```json
{
  "exportedAt": "2026-09-08T11:04:22.417Z",
  "schema": 1,
  "range": { "from": "2026-01-01", "to": "2026-09-08" },
  "rowCap": 5000,
  "truncated": ["metric_entries"],
  "profile": { "id": "…", "display_name": "…" },
  "conditions": [],
  "medications": [ { "…": "…" } ]
}
```

| ヘッダーのフィールド | 型 | 意味 |
|---|---|---|
| `exportedAt` | ISO 8601形式のUTC文字列 | ファイルを作成した時刻 |
| `schema` | 数値 | 形式のバージョン。現在は**1** |
| `range.from` / `range.to` | ISO日付または`null` | 選択した期間。`null`は端の指定なし |
| `rowCap` | 数値 | 適用されたテーブルごとの上限。**5000** |
| `truncated` | テーブル名の配列 | 上限に達したテーブル。空なら切り詰めなし |
| `profile` | オブジェクトまたは`null` | プロフィールの行。1行の配列ではなく、そのまま格納 |

読み取りプログラムを書く前に、次の点を確認してください。

- **行がないテーブルは、キーを省かず空の配列になります。** `"meals": []`は行がないことを明示します。`meals`キー自体がない場合とは意味が違います。
- **ファイルが一部だけかどうかを示すのは`truncated`だけです。** 履歴がないと判断する前に確認してください。
- **JSONは2スペースで整形されています。** 人が開いて検索することを想定しています。8MBが1行にまとまったファイルにはしません。

## CSVアーカイブ

テーブルごとに**1つの`.csv`**を含むzipで、名前は`<table>.csv`です。列は各テーブルの列に対応します。

| 項目 | 値 |
|---|---|
| 改行 | RFC 4180に従うCRLF |
| 文字コード | **バイトオーダーマーク付き**UTF-8 |
| 引用 | RFC 4180に従い、引用符を二重にし、`"`、`,`、CR、LFを含むフィールドを引用 |
| 空のセル | `null`も`undefined`も空のセル |
| 入れ子の値 | 行へ展開せず、セル内にJSONとして保持 |

不具合に見えるかもしれませんが、次の2点は意図した動作です。

- **行がないテーブルにも、ヘッダー行だけのファイルができます。** ファイルがなければエクスポート失敗との区別ができません。ヘッダーがあれば、そのテーブルを処理したと分かります。
- **セルの文字列が`=`、`+`、`-`、`@`、タブ、復帰文字で始まる場合、先頭にアポストロフィーが付きます。** 表計算ソフトが数式として扱う文字だからです。自分のデータを自分から守るためではなく、ファイルを渡された人を守るための処理です。渡す相手は医師の場合もあります。表計算ソフトで開かず解析する場合は、先頭のアポストロフィーを取り除いてください。

Windows版ExcelはバイトオーダーマークのないUTF-8を地域設定の文字コードとして読んでしまい、名前などの文字が崩れるため、マークを付けています。

## ファイルに含まれるすべてのテーブル

65テーブルを所属するエリアごとに示します。

- **期間**：*日付付き*の行には選んだ期間が適用されます。*継続*の行は常に含まれます。薬がない状態で服薬記録だけがあると、データが失われたように見えるためです。
- **PDFでの扱い**：*全件掲載*は行を印刷します。*件数のみ*は件数と期間を印刷し、行は掲載しません。*掲載なし*はPDFに含まれません。

## 各形式に含まれないもの \{#what-each-format-leaves-out}

**JSONとCSVには、選択した期間に対応するテーブルが含まれます。** 期間外の日付付き行は省かれ、5,000行を超えるテーブルは上限で切り詰められてヘッダーに名前が記録されます。これらは含まれるデータを読んだり移したりするための形式で、現在LifeWellにはファイルからアカウントを復元する機能はありません。

**PDFは全記録ではありません。それがPDFの目的です。** PDFは印刷して受付に渡したり、机に置いたりする文書です。そのため、医療者が読む情報に絞っています。

- **全件掲載**：健康状態、薬、トラッカーの種類と目標、子ども、成長の測定値、節目、人物、つながり、共有、カレンダー、リマインダー、プロフィールなどの継続的な記録。
- **件数のみ**：トラッカーの測定値、服薬、食事、運動、月経周期、子どもの記録、ガイド付きセッション、メディア、保存した場所など件数の多い日付付き記録。4,000行から40行だけを載せれば、*あなたの記録*と題された文書でも実際は一部の例にすぎず、読む人を誤解させます。行を掲載するテーブルでも最大**60行**です。
- **PDFに掲載しない**：日記、思い出、メモ、スクラップブック、メッセージ、コミュニティの返信など、自分のために書いた内容。

:::warning[日記はPDFに含まれません。これは好みの設定ではありません]
このページのほかの選択は、何が役立つかに基づいています。日記だけは、机に置かれる紙へ出してはいけない内容です。自分で開くJSONとCSVには含まれます。
:::

## どの形式にも含まれないもの

次の7項目は**どの**エクスポートにも含まれません。選択期間とテーブルの上限によって、ほかの行も除外される場合があります。

| 含まれないもの | 理由 |
|---|---|
| **メディアファイル本体** | 画像は自分のGoogle Driveにあります。エクスポートに含むのは参照、説明、日付です。ファイル本体はLifeWellが渡せるものではありません |
| **自分に共有されたもの** | 他人が貸した記録です。共有を取り消せばアクセスできなくなりますが、自分のファイルに複製してしまうとそうなりません |
| **削除済みの行** | 削除したものです。エクスポートの裏にごみ箱はありません |
| **運用ログ** | 利用制限の計数や閉じたお知らせなど。記録ではなく画面の状態です |
| **パスワード** | ありません。Googleでサインインし、LifeWellがパスワードを見たり保存したりすることはありません |
| **AIプロバイダーのキー** | 暗号化されて保管されている有効な認証情報です。自分にメールするかもしれない平文ファイルへ書き出すと、情報漏えいになります |
| **AI利用量の計測値** | 利用上限を数えるための値で、自分が書いた記録ではありません |

さらに次の5つのテーブルも、認証情報や他人の記録に関わるため除外します。

| 除外するもの | 理由 |
|---|---|
| 投稿について送った報告 | 本人を含め、そのテーブルは読み戻せません。モデレーション用の一覧がダウンロード経由で漏れることも、漏えいです |
| 献血者が開示した連絡先 | 一度、特定の相手にだけ開示され、後で取り消せます。ファイル内の行ではその制御ができません |
| Google Driveの接続情報 | 有効な更新トークンが含まれます |
| Google Playでの購入記録 | Googleが受け付ける購入トークンが含まれます。利用権はプロフィールに含まれます |
| 閉じたお知らせ | どのお知らせを閉じたかという画面の状態です |

さらに4つのテーブルは個人の記録ではなく共有参照データです。プラン一覧、コミュニティの一覧、食品データベース、稼働確認に使う内部テーブルが該当します。

## 読み戻すことはできますか？

インポート機能はありません。LifeWellはこれらのファイルを読み戻しません。

この形式を説明するのは、**ほかのもの**が読めるようにするためです。スクリプト、表計算ソフト、別のアプリ、あるいは5年後にテキストエディターを開く自分かもしれません。そのために、次の2点を意図して設けています。

1. ファイル内の識別子はデータベースの列名そのままです。JSON、CSV、このページで列の意味が一致します。
2. ヘッダーに上限が記載されます。一部だけのファイルは、冒頭の10行以内にそのことが示されます。

## このページが変わるとき

テーブルを追加するたびに上の一覧へ行を追加し、一覧とスキーマが双方向に一致することをテストで確認します。一方にしかないテーブルがあれば、公開前にビルドが失敗します。

読み取りプログラムでは`schema`を見てください。現在は`1`で、上記の形式の意味を変える前に値を増やします。
