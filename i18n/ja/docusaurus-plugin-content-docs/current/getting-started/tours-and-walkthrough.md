# ページツアーと操作ガイド

LifeWellを知る方法は2つあります。ページツアーは今開いているページを案内し、操作ガイドは6つの画面でアプリ全体を紹介します。

## ページツアー

主要なページには、上部バーの星の横に**道しるべのボタン**があります。押すと、そのページを1段階ずつ短く案内します。

- **案内は1度だけ。** ページを初めて開くと、短い説明が道しるべを指します。その後は、どの端末でもそのページでは再表示されません。
- **進め方は自分で選べます。** ツアーを飛ばす、途中で閉じる、好きな段階へ移ることができます。
- **スマートフォンでも使えます。** 小さい画面では、各段階が画面下から開くシートになります。

## LifeWellの仕組み

**LifeWellの仕組み**は、実際のアプリ画面を使った6画面のガイドです。次の順に紹介します。

1. あなたの人生にいる人
2. そこに写る人と一緒に残す思い出
3. 1か所で見る毎日のこと
4. 文字を打つ代わりに話す
5. 暮らしを支えるもの
6. 残すのも削除するのも、あなたが決める

パソコンではサイドバー、スマートフォンでは**その他**メニューの下部から開けます。[lifewell.aoneahsan.com/how-lifewell-works](https://lifewell.aoneahsan.com/how-lifewell-works)から直接開くこともできます。

## 処理の一覧

エクスポートや、Speak itが録音を読み取る処理には、1回のタップより時間がかかります。長い処理はメニュー下部の**処理の一覧**に並び、*待機中*、*処理中*、*準備完了*、*完了できませんでした*の状態が示されます。処理中は別のことを続けられ、準備ができると通知されます。
