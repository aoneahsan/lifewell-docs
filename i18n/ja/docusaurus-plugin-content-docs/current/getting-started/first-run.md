# 初回の利用

初めてログインすると、5つの手順で設定が始まります。うち2つは説明を読むだけです。ここで選んだ答えは固定されません。あとからすべて設定で見直せます。

## 5つの手順

| 手順 | 聞かれること | 飛ばせますか |
|---|---|---|
| ようこそ | 入力はありません。アプリの目的を説明します | — |
| あなたについて | 表示名、呼ばれたい名前、あなた自身について | はい。3つとも飛ばせます |
| 大切なこと | 切り替え設定のある6つの領域のうち、使いたいもの | はい。選ばなければ6つすべてが有効です |
| リマインダー | 今後許可するリマインダーの種類。毎日の通知は作成されません | はい |
| 完了 | 入力はありません。ダッシュボードへ進みます | — |

## 表示内容を変える1つの答え \{#the-one-answer-that-changes-what-you-see}

**あなた自身について**の答えによって、月経周期、妊娠を考えること、排卵、PCOS、更年期、授乳の6つの画面をメニューに表示するかが決まります。

**男性**を選ぶと、これらの項目はメニューに表示されません。*回答しない*を含むほかの答えでは表示されたままです。

*回答しない*は空欄ではなく、1つの回答です。保存されるため、アプリから再度尋ねられず、すべての画面が表示されます。

メニューから見えなくなっても、記録は消えません。各画面のアドレスを直接開けば使えます。プロフィールでいつでも答えを変えられ、どちらの選択でも記録は削除されません。

## 大切なこと

3つ目の手順には、切り替え設定のある6つの[領域](../domains/overview.md)が並びます。ここでオフにするのは設定画面の切り替えと同じで、記録は削除されず、メニューから見えなくなります。

「あなた自身」はアカウントであり、オフにできる領域ではないため一覧にありません。共有にも切り替え設定がないため、ここには並びません。

## 設定を終えたあと

初回設定で答えた内容は、あとから次の2か所で変更できます。

- **プロフィール** — 名前、あなた自身について、医療に関する基本情報。
- **設定** — 6つの領域の切り替え、リマインダー、表示、記録の管理。

初回設定で、二度と変えられない選択をする必要はありません。
