# 短いツアー

## ダッシュボード

ログイン後は`/dashboard`が開きます。水を1杯飲んだこと、体重、気分など、よく記録する内容にすぐ届く操作があります。メニューを探さず、1回のタップで記録できます。

記録に時間がかかりすぎるなら、続けにくくなります。ダッシュボードはそのためにあります。

## メニュー

左側のメニューは[7つの領域](../domains/overview.md)ごとに分かれます。有効にした領域だけが並び、その中にはあなたに当てはまる画面だけが表示されます。詳しくは[初回の利用](./first-run.md#the-one-answer-that-changes-what-you-see)をご覧ください。

## 上部バー

| 操作 | できること |
|---|---|
| ページツアー | 星の横にある道しるべのボタンです。開いているページを短く案内します。[ページツアーと操作ガイド](./tours-and-walkthrough.md)をご覧ください |
| 検索 | 記録の検索を開きます。[現在開発中](../features/search.md)です |
| 通知 | リマインダー、共有の動き、管理者からのお知らせを表示します |
| 表示設定 | 1つのアイコンから、すべての表示設定を開きます。[表示設定](../concepts/appearance.md)をご覧ください |
| アカウント | プロフィール、プラン、設定、ログアウトを開きます |

## 記録の一覧

`/tracking`は、すべての数値を1か所で見る画面です。個別の画面とは別の保存先ではありません。`/health/water`、ダッシュボードの簡単な入力、`/tracking`は同じテーブルを見る3つの方法です。どこかで水を1杯記録すると、残りの2か所にもすぐ反映されます。

## 設定

`/settings`には、個別の記録ではなくアカウントに関わる項目があります。

- **あなたの記録** — エクスポート、領域の削除、アカウントの削除
- **領域** — 6つの切り替えと、切り替えのない共有の項目
- **リマインダー** — アプリから届く通知の許可
- **共有** — 誰が何を読めるか
- **セキュリティ** — セッションとログアウト
