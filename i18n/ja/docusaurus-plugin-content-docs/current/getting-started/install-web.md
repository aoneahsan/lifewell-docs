# ウェブでLifeWellを使う

インストールは不要です。[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)を開き、ログインしてください。

## ログイン

**ログイン方法はGoogleのみです。** メールアドレスとパスワードのフォームがないのは未完成だからではありません。保存するパスワード自体がないため、私たちがパスワードを見たり保存したりすることもありません。

1. [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)を開きます。
2. **Googleで続ける**を選びます。
3. 記録を保存するGoogleアカウントを選びます。

選んだアカウントが記録の持ち主になります。あとから別のアカウントに切り替えると、名前だけが変わるのではなく、別の記録が開きます。

## 次に起こること

初回ログインでは短い設定が開きます。5つの手順があり、ほとんどは空欄のまま進めます。[初回の利用](./first-run.md)で説明しています。

## 対応ブラウザー

LifeWellは現在のChrome、Edge、Firefox、Safariを対象とします。それ以上に細かい対応表や、古いブラウザーエンジン向けの補助機能はありません。アプリを実行できないブラウザーでは、壊れた画面を見せる代わりに起動画面でそのことを伝えます。

## ホーム画面への追加

ウェブ版は通常のサイトです。多くのブラウザーではホーム画面やDockに追加できます。アイコンとアドレスバーのないウィンドウで開けますが、これはブラウザーの機能です。追加のファイルがダウンロードされたり、アプリの動作が変わったりするわけではありません。

端末の通知機能やローカルのリマインダーが必要なら、[Androidへのインストール](./install-android.md)をご覧ください。
