# MyChartからLifeWellへ移る

MyChartはEpicを使う病院やクリニックが提供する患者向けポータルです。その医療機関からの検査結果、薬、請求、メッセージが届きます。

LifeWellは、医療機関をまたいで自分で保管する記録です。生活に関わる人や思い出も一緒に置けます。

最終確認日：2026-11-26。[LifeWellとMyChart](https://lifewell.aoneahsan.com/compare/mychart)で比較できます。

## MyChartの横に自分のコピーを残す

1. MyChartは使い続けてください。医療機関から届く情報はそこで確認できます。LifeWellは接続しません。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 残したい検査結果と現在の薬を、[健康](/domains/health)の検査結果と薬のページに転記します。
4. 受診ごとに[予定](/features/calendar-and-appointments)を作り、聞きたいことをチェックリストに入れます。
5. 子どもの健康を管理する場合、薬は大人の用量と別の子ども用一覧に置きます。LifeWellは医療上の助言を提供しません。

## MyChartとLifeWellの比較

| 機能 | LifeWell | MyChart |
|---|---|---|
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | あり（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

MyChartのページに価格はなく、人物ごとの記録、家系図、思い出、声での入力、メモ、データのダウンロード、Androidアプリ、無料プランへの記載もありませんでした。

MyChartのページ：<a href="https://www.mychart.com/" target="_blank" rel="noopener noreferrer nofollow">MyChartのWebサイト</a>。
