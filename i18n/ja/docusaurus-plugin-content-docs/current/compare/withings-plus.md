# Withings+からLifeWellへ移る

Withings+はWithingsの体重計や時計と組み合わせて使います。測定値を毎日のスコアにまとめ、健康アシスタントや遠隔診療用のPDFを提供します。

LifeWellは機器を持たず、手動で記録する人向けです。健康を、生活に関わる人や思い出と並べて保管します。

最終確認日：2026-11-26。[LifeWellとWithings+](https://lifewell.aoneahsan.com/compare/withings-plus)で比べられます。

## 機器を使わなくなる場合

1. まずWithingsから健康レポートのPDFをダウンロードし、測定値を残します。
2. [サインイン](/getting-started/first-run)します。
3. 残したい測定値を手動で入力します。体重、血圧、心拍数にはそれぞれ[健康](/domains/health)のトラッカーがあります。LifeWellは体重計や時計から何も読み取りません。
4. 遠隔診療は、ほかの受診と同じく[カレンダー](/features/calendar-and-appointments)に入れます。
5. 機器をまだ使うなら、無料のWithingsアプリを残してください。LifeWellは医療上の助言を提供しません。

## Withings+とLifeWellの比較

| 機能 | LifeWell | Withings+ |
|---|---|---|
| 薬、健康状態、検査結果の記録 | あり | 一部あり（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.withings.com/us/en/withings-plus" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Withings+のページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、予定、メモ、Androidアプリへの言及がありませんでした。
