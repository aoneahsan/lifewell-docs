# DexからLifeWellへ移る

Dexはデジタルの住所録です。LinkedIn、メール、カレンダーを1つの連絡先一覧に同期し、相手についての要約を作り、連絡を続けるために知らせてくれます。

LifeWellは、大切な人の無料の記録です。各人の名前の横に、家系図、健康、予定を置けます。

最終確認日：2026-11-26。両者を並べた比較は[LifeWellとDex](https://lifewell.aoneahsan.com/compare/dex)をご覧ください。

## 住所録から人物の記録へ

1. [LifeWellにサインイン](/getting-started/first-run)します。
2. 連絡先をCSVか`.vcf`で持っている場合は、[人](/domains/people)のインポートページで名前を読み取れます。ファイル内のほかの情報は取り込まれません。
3. 人物ごとのメモを、その人の記録か[メモ](/domains/everyday)へ移します。
4. 連絡する予定を[リマインダー](/features/reminders)付きの[カレンダー](/features/calendar-and-appointments)項目にします。
5. Dexの音声モードを使っていた場合、LifeWellでは「話す」で声から追加できます。書き起こしを読み返し、確認してから保存します。
6. LinkedInや受信箱との同期にはDexを使い続けてください。

## DexとLifeWellの比較

| 機能 | LifeWell | Dex |
|---|---|---|
| 生活に関わる人物ごとの記録 | あり | あり（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 声で話した内容を書き起こす | あり | 一部あり（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| メモ | あり | あり（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://getdex.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Dexの価格ページには、家系図、思い出、共有リンク、健康記録、データのダウンロード、無料プラン、家族向けプランへの言及がありませんでした。

「話す」の録音は削除するまで本人だけのものとして保管されます。iPhoneアプリはありません。
