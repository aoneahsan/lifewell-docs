# Gramps WebからLifeWellへ移る

Gramps Webは自分のサーバーで運用する、無料のオープンソース家系調査ソフトです。GEDCOMの読み書き、操作できる図表、家系図のPDF書籍レポートを備えています。

LifeWellはサーバーの管理をしたくない人向けです。ホストされたサービスとAndroidアプリがあり、同じ人物に思い出、予定、健康記録を結び付けます。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとGramps Web](https://lifewell.aoneahsan.com/compare/gramps-web)をご覧ください。

## 管理していたサーバーから移る

1. Gramps Webのデータをすべてダウンロードして保管します。LifeWellはGEDCOMを読み取らないため、このファイルが調査記録の完全なコピーになります。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 名前を用意できるなら、[人](/domains/people)のインポート画面に1行1人で貼り付けます。保存前に見つけた全員を確認できます。移るのは名前だけで、日付と関係は自分で追加します。
4. 人物同士を結びます。[家系図](/domains/people)はその関係から描かれます。
5. 大切な写真を[思い出](/domains/memories)として追加し、写っている人を指定します。Gramps Webで人物にタグを付けるのと同じ目的です。
6. PDF書籍レポートや完全な調査データベースが必要なら、Grampsのサーバーを残してください。

## Gramps WebとLifeWellの比較

| 機能 | LifeWell | Gramps Web |
|---|---|---|
| 生活に関わる人物ごとの記録 | あり | あり（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家系図を描く | あり | あり（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 写真、日付、場所を添えた思い出 | あり | 一部あり（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://www.grampsweb.org/features/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.grampsweb.org/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Gramps Webのページには、声での入力、予定、健康記録、メモ、Androidアプリ、家族向けプランへの言及がありませんでした。

LifeWellは家系図を印刷できず、書籍レポートも作りません。
