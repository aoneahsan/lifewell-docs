# AncestryからLifeWellへ移る

Ancestryは有料の家族史調査サービスです。月額契約で、記録の候補、DNAによる一致、80か国以上の資料を調べられる大きなアーカイブが強みです。先祖をたどるなら、そのための道具です。

LifeWellは過去の資料調査をしません。実際に知っている人を、思い出や予定とともに無料で記録します。

最終確認日：2026-11-26。以下の各行には出典へのリンクがあります。詳しい比較は[LifeWellとAncestry](https://lifewell.aoneahsan.com/compare/ancestry)をご覧ください。

## Ancestryの家系図からLifeWellの記録へ

1. [サインイン](/getting-started/first-run)し、自分から始めます。
2. Ancestryの家系図から、まず誕生日を覚えているような、今いる人たちを選びます。[人](/domains/people)に一人ずつ追加してください。Ancestryからのインポート機能はありません。
3. 人物同士を結びます。LifeWellの[家系図](/domains/people)に表示されるのは自分で入力した人だけなので、知っている家族の範囲に収まります。写真は日付と場所を添えて[思い出](/domains/memories)へ入れます。
4. Ancestryアプリで音声メモを使っていたなら、LifeWellでは「話す」を使えます。話した内容が文字になり、保存前に自分で確認します。
5. 調査を続けている間は契約を残してください。記録の候補、資料集、DNAによる一致はAncestryにあり、LifeWellには代わりの機能がありません。

Ancestryの契約ページには、人物ごとの記録、日付と場所を添えた思い出、予定、健康記録、データのダウンロードへの言及がありませんでした。そのため、これらは表に載せていません。

「話す」の録音は本人のために非公開で保管され、削除すると消えます。LifeWellには家系図の印刷機能もiPhoneアプリもありません。
