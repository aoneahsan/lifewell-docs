# EvernoteからLifeWellへ移る

Evernoteは、ノートが主な目的の人向けです。ノートブック、Webの切り抜き、スキャン、文書検索を、手元のさまざまな端末で使えます。

LifeWellではメモは人物に関する記録の一部です。思い出、健康、予定をその横に保管します。

最終確認日：2026-11-26。並べた比較は[LifeWellとEvernote](https://lifewell.aoneahsan.com/compare/evernote)をご覧ください。

## ノートブックから人物へ

1. 残したいノートブックをEvernoteからPDFとしてエクスポートし、コピーを保管します。
2. [サインイン](/getting-started/first-run)し、ノートに登場する人を[人](/domains/people)に追加します。
3. 内容を[メモ](/domains/everyday)に書き写します。そこでフォルダーを削除しても、中のメモは削除されません。
4. Evernoteで日付とリマインダーを付けたメモは、[リマインダー](/features/reminders)付きの[予定](/features/calendar-and-appointments)にします。
5. Webの切り抜きや文書のスキャンにはEvernoteを使い続けてください。

| 機能 | LifeWell | Evernote |
|---|---|---|
| リマインダー付きの予定 | あり | 一部あり（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

| Androidアプリ | あり | あり（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://evernote.com/compare-plans" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Evernoteのプランページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、健康記録、家族向けプランへの言及がありませんでした。
