# Any.doからLifeWellへ移る

Any.doには、家事、買い物、リマインダーを家族で共有する無料のスペースと、4人向けFamilyプランがあります。LifeWellにはタスクリストはありません。

LifeWellで家族の記録に含まれるのは、家系図、思い出、健康に関するメモ、人物ごとの予定です。

最終確認日：2026-11-26。[LifeWellとAny.do](https://lifewell.aoneahsan.com/compare/any-do)では、両者を1ページで比べられます。

## 家族の情報を分けて移す

1. [LifeWellにサインイン](/getting-started/first-run)し、[人](/domains/people)に家族を追加します。
2. 医師、歯科医、学校の面談は[予定](/features/calendar-and-appointments)に移し、それぞれに[リマインダー](/features/reminders)を付けます。
3. 買い物リストはAny.doに残すことも、LifeWellの[買い物リスト](/features/shopping-list)へ移すこともできます。献立から項目を追加でき、プレーンテキストで渡せるので、買い物をする人にアカウントは要りません。
4. 家事のタスクはAny.doに残します。

## Any.doとLifeWellの比較

| 機能 | LifeWell | Any.do |
|---|---|---|
| リマインダー付きの予定 | あり | あり（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | あり（<a href="https://www.any.do/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Any.doの価格ページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、健康記録、メモ、データのダウンロード、Androidアプリについて記載されていませんでした。
