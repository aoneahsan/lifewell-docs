# MedisafeからLifeWellへ移る

Medisafeは薬を時間どおりに飲むことを中心に作られ、介護する人への通知もあります。アプリのダウンロードページには無料アプリとありますが、消費者向け有料プランの価格は記載されていません。

LifeWellでは薬を、人、思い出、予定を含むもっと広い記録の1ページとして保管します。LifeWellの料金は公開されています。

最終確認日：2026-11-26。[LifeWellとMedisafe](https://lifewell.aoneahsan.com/compare/medisafe)で両者を比較できます。

## 薬の一覧を移す

1. Medisafeに記録した薬、用量、服用時刻を書き出します。
2. [LifeWellにサインイン](/getting-started/first-run)し、[健康](/domains/health)の薬ページに、用量と予定を付けて1つずつ入力します。
3. 服薬の[リマインダー](/features/reminders)は初期状態で有効です。案内が不要な薬だけ無効にしてください。
4. 子どもの世話をしている場合、その薬は子ども用の別の一覧に入れます。子どもの用量が大人の一覧に混ざりません。
5. 薬について相談する受診は、質問をチェックリストに付けて[カレンダー](/features/calendar-and-appointments)へ入れます。
6. 介護者がMedisafeの通知を頼りにしている間は使い続けてください。LifeWellは医療上の助言を提供せず、医師のシステムにも接続しません。
