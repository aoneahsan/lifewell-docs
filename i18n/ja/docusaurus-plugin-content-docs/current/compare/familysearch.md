# FamilySearchからLifeWellへ移る

FamilySearchは非営利で運営される無料の家族史サイトです。世界で共有する1つの家系図と、何十億件もの歴史資料があります。教区の記録で曾祖母を探すような場所で、地域のセンターでは対面の手助けも受けられます。

LifeWellは、今も電話をかけられる家族のためのものです。家系図を非公開で保管し、同じ人たちに思い出、予定、健康記録を結び付けます。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとFamilySearch](https://lifewell.aoneahsan.com/compare/familysearch)をご覧ください。

## 自分につながる家族を移す

1. [LifeWellにサインイン](/getting-started/first-run)し、まず自分を登録します。関係はすべて自分を起点にします。
2. FamilySearchを横に開き、自分につながる今いる人たち、親、祖父母、きょうだい、子どもを[人](/domains/people)へ一人ずつ入力します。LifeWellはFamilySearchの家系図を読み取りません。
3. 各人と自分の関係を指定します。[家系図](/domains/people)はその関係から世代ごとに描かれます。
4. 知っている話は、写真、日付、場所、写っている人とともに[思い出](/domains/memories)に残します。
5. 先祖、歴史資料、世界で共有する家系図はFamilySearchに残します。その調査は引き続き無料でできます。

## FamilySearchとLifeWellを項目ごとに比較

| 機能 | LifeWell | FamilySearch |
|---|---|---|
| 家系図を描く | あり | あり（<a href="https://www.familysearch.org/en/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 写真、日付、場所を添えた思い出 | あり | あり（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.familysearch.org/en/home/about" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

確認したFamilySearchのページには、人物ごとの記録、声での入力、共有リンク、予定、健康記録、メモ、データのダウンロード、家族向けプランへの言及がありませんでした。そのため表にも載せていません。

LifeWellの家系図は画面に表示するだけで、壁に飾るための印刷はできません。
