# FindmypastからLifeWellへ移る

Findmypastは英国とアイルランドを中心とした有料の家系調査サービスで、国勢調査、教区の記録、新聞を扱います。家族史がこれらの資料につながるなら、調べる場所はここです。

LifeWellは資料を検索しません。今いる家族を無料プランで記録し、自分で入力した人だけを家系図に表示します。

最終確認日：2026-11-26。[LifeWellとFindmypast](https://lifewell.aoneahsan.com/compare/findmypast)で両者を比べられます。

## Findmypastの家系図から始める

1. [サインイン](/getting-started/first-run)し、まず自分を登録します。
2. Findmypastの家系図から最近の世代を選び、[人](/domains/people)に一人ずつ追加します。LifeWellにはインポート機能はありません。
3. 人物間の関係を付けると、[家系図](/domains/people)に反映されます。
4. 資料からは分からない結婚式の写真や街角の家の話は、日付と場所を付けて[思い出](/domains/memories)へ入れます。
5. 国勢調査、教区の記録、新聞の調査はFindmypastの契約に残します。

## それぞれにできること

| 機能 | LifeWell | Findmypast |
|---|---|---|
| 家系図を描く | あり | あり（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://www.findmypast.co.uk/subscribe" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Findmypastの契約ページには、人物ごとの記録、思い出、声での入力、予定、健康記録、メモ、データのダウンロード、無料プラン、家族向けプランへの記載がありませんでした。

LifeWellで描いた家系図は印刷できません。
