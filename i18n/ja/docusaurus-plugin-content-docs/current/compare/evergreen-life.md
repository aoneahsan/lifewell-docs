# Evergreen LifeからLifeWellへ移る

Evergreen Lifeは、イングランドのかかりつけ医に登録している人向けの無料アプリです。医療記録を取り込み、診療予約やNHSの定期処方薬の注文ができます。

LifeWellはイングランド以外に住む人や、自分で記録を書き、大切な人それぞれの情報を思い出や家系図とともに置きたい人に向いています。

最終確認日：2026-11-26。項目ごとの比較は[LifeWellとEvergreen Life](https://lifewell.aoneahsan.com/compare/evergreen-life)をご覧ください。

## かかりつけ医の記録と併用する

1. Evergreen Lifeから医療記録をダウンロードし、ファイルを保管します。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 自分の記録に残したい健康状態、薬、予防接種を[健康](/domains/health)に転記します。
4. 支えている人を[人](/domains/people)に追加し、その人の予定を[リマインダー](/features/reminders)とともに[カレンダー](/features/calendar-and-appointments)へ入れます。
5. 診療予約と処方薬の注文には引き続きEvergreen Lifeを使ってください。LifeWellはNHSやかかりつけ医に接続せず、医療上の助言も提供しません。

## Evergreen LifeとLifeWellの比較

| 機能 | LifeWell | Evergreen Life |
|---|---|---|
| リマインダー付きの予定 | あり | 一部あり（<a href="https://www.evergreen-life.co.uk/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | あり（<a href="https://www.evergreen-life.co.uk/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://www.evergreen-life.co.uk/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | あり（<a href="https://www.evergreen-life.co.uk/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.evergreen-life.co.uk/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Evergreen Lifeのホームページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、メモ、家族向けプランへの記載がありませんでした。
