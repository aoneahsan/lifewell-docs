# Day OneからLifeWellへ移る

Day Oneは毎日書くための日記アプリです。エンドツーエンド暗号化、書くきっかけになる質問、音声、場所、日記を印刷した本があります。毎日書く人のために作られています。

LifeWellでは思い出を関係する人物と結び付けます。無料プランでも写真を1枚に制限しません。

最終確認日：2026-11-26。[LifeWellとDay One](https://lifewell.aoneahsan.com/compare/day-one)で両者を並べています。

## 日記を思い出として残す

1. まずDay Oneから日記をエクスポートします。CSVとJSONで全文を保管できます。LifeWellにはインポート機能がありません。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 日記によく登場する人を[人](/domains/people)に追加します。
4. 残したい記録を、写真、日付、場所、一緒にいた人とともに、1件ずつ[思い出](/domains/memories)へ移します。
5. 文字で打つより話したい日は、「話す」が声を書き起こします。保存前に自分で確認します。
6. 毎日の日記や印刷した本にはDay Oneを使い続けてください。

## Day OneとLifeWellの比較

| 機能 | LifeWell | Day One |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 声で話した内容を書き起こす | あり | あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://dayoneapp.com/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Day Oneの価格ページには、人物ごとの記録、家系図、予定、健康記録、メモ、家族向けプランへの言及がありませんでした。

「話す」に渡した音声は削除するまで本人だけに非公開で保管されます。iPhoneアプリはなく、iPhoneではSafariでLifeWellを使います（[iOS](/platforms/ios)）。
