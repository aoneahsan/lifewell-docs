# RementoからLifeWellへ移る

Rementoが残すのは親の声です。アプリもログインも必要ない音声の質問を送り、録音を文章の章にし、その声を再生できるQRコード付きのハードカバー本を印刷します。

LifeWellは本を作るサービスではありません。人、思い出、家系図、予定を一か所に無料で保管します。

最終確認日：2026-11-26。ここにある事実は[LifeWellとRemento](https://lifewell.aoneahsan.com/compare/remento)でも確認できます。

## 章を書き終えたら

1. Rementoから録音と写真をダウンロードします。取り出せる元の資料です。
2. [LifeWellにサインイン](/getting-started/first-run)し、話をしてくれた親を[人](/domains/people)に追加します。
3. その人の横に残したい章ごとに、写真と日付を添えて[思い出](/domains/memories)を作ります。
4. 新しい話には「話す」を使えます。声を録音して書き起こします。録音は削除するまで本人だけに非公開で保管されます。
5. 印刷した本や声を再生するQRコードにはRementoを使い続けてください。

## RementoとLifeWellの比較

| 機能 | LifeWell | Remento |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | 一部あり（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 声で話した内容を書き起こす | あり | あり（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | なし（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.remento.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Rementoのホームページには、人物ごとの記録、家系図、共有リンク、予定、健康記録、メモ、無料プランへの記載がありませんでした。

LifeWellは本も家系図も印刷しません。
