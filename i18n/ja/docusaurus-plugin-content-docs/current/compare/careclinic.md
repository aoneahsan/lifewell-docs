# CareClinicからLifeWellへ移る

CareClinicは慢性的な健康状態を管理するアプリです。症状、薬、検査、ワクチン、画像を検索できる場所にまとめ、検証済みの評価、ケアプラン、医療者向けの30日間レポートを提供します。

LifeWellでは、薬、検査結果、予定をより簡潔な形で無料プランに記録し、生活に関わる人たちと並べて保管します。

最終確認日：2026-11-26。機能を並べた比較は[LifeWellとCareClinic](https://lifewell.aoneahsan.com/compare/careclinic)にあります。

## CareClinicから記録を移す

1. CareClinicで30日間のレポートを作り、転記の元にします。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 検査結果と予防接種を[健康](/domains/health)の各ページに入力します。健康状態は継続的な記録とし、症状が強まった回をその下に記録します。
4. 受診の要約は、質問ごとの回答を一緒に残せるよう、チェックリスト付きの[予定](/features/calendar-and-appointments)にします。
5. 医療者に見せるときは、LifeWellのPDFエクスポートを使えます（[エクスポート](/your-data/export)）。意図して省かれる内容もあります。
6. ケアプランがCareClinicにあるなら、引き続き使ってください。LifeWellは医療上の助言を提供しません。

## CareClinicとLifeWellの比較

| 機能 | LifeWell | CareClinic |
|---|---|---|
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | あり（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://careclinic.io/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | あり（<a href="https://careclinic.io/pricing/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://careclinic.io/getting-started/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

CareClinicの開始案内には、ほとんどの機能が無料とありますが、確認したページにプレミアムの価格はありませんでした。人物ごとの記録、家系図、思い出、声での入力、メモ、家族向けプランへの言及もありませんでした。
