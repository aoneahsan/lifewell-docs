# ClozeからLifeWellへ移る

Clozeはメールとカレンダーを読み取り、連絡先とのやり取りの履歴を自動で埋め、返信のリマインダーや差し込みメールも扱います。受信箱が忙しい人のための道具です。

LifeWellでは自分で記録を書きます。無料で使え、家族の思い出や健康記録を同じ人物に結び付けられます。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとCloze](https://lifewell.aoneahsan.com/compare/cloze)をご覧ください。

## Clozeの後、自分で記録を書く

1. [サインイン](/getting-started/first-run)します。
2. 家族や友人を[人](/domains/people)に追加します。仕事上の連絡先はClozeに残せます。
3. Clozeで連絡先に結び付いていたメモは、その人物の記録か[メモ](/domains/everyday)に手動で移します。
4. 私的な面会や次に連絡する予定は、[リマインダー](/features/reminders)とともに[カレンダー](/features/calendar-and-appointments)へ入れます。LifeWellは受信箱を読み取らず、外部カレンダーにも接続しません。
5. 差し込みメールと受信箱の履歴にはClozeを使い続けてください。
