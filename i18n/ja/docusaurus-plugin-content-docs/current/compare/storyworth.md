# StoryworthからLifeWellへ移る

Storyworthは親や祖父母に毎週1つ、メールや電話で質問を送り、1年分の答えをハードカバー本にまとめます。期間の終わりに本ができる贈り物です。

LifeWellでは聞いた話を、話してくれた人の記録に無料で残します。記録を保つ限り、そこにあります。

最終確認日：2026-11-26。比較は[LifeWellとStoryworth](https://lifewell.aoneahsan.com/compare/storyworth)をご覧ください。

## 本ができた後も話を残す

1. これまでの話を無料の電子書籍としてダウンロードします。そのコピーは今後の使い方に関係なく自分のものです。
2. [LifeWellにサインイン](/getting-started/first-run)し、話してくれた人と自分との関係を[人](/domains/people)に登録します。
3. 大切な話を、日付、場所、登場する人とともに[思い出](/domains/memories)へ移します。
4. 次に食卓で話を聞いたら「話す」を使えます。話した内容を書き起こし、自分が確認するまでは保存されません。
5. 毎週の質問と印刷した本は、プランの間Storyworthに残します。

## StoryworthとLifeWellの比較

| 機能 | LifeWell | Storyworth |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | 一部あり（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 声で話した内容を書き起こす | あり | あり（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://welcome.storyworth.com/faq" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

確認したStoryworthのページには、人物ごとの記録、家系図、共有リンク、予定、健康記録、メモ、Androidアプリ、無料プランへの記載がありませんでした。

LifeWellは「話す」の録音を削除するまで非公開で保管します。本も家系図も印刷しません。
