# MeshからLifeWellへ移る

Meshは大きな仕事上の人脈を保つためのサービスです。メール、LinkedIn、カレンダーから連絡先を取り込み、近況を見て再び連絡する時期を知らせます。macOS、Windows、iOSのアプリがあります。

LifeWellは人脈管理ではなく、家族や友人のためのものです。人物ごとに思い出と健康を置け、無料プランにカードは要りません。

最終確認日：2026-11-26。両者を並べた[LifeWellとMesh](https://lifewell.aoneahsan.com/compare/mesh)をご覧ください。

## Meshから家族と友人を選ぶ

1. [サインイン](/getting-started/first-run)します。
2. Meshの連絡先から家族や親しい友人だけを選び、[人](/domains/people)に追加します。
3. 大切な日付を、[リマインダー](/features/reminders)付きで[カレンダー](/features/calendar-and-appointments)に入れます。
4. 仕事上の人脈はMeshに残します。LifeWellはメールやLinkedInから何も読み取らず、外部カレンダーにも接続しません。

## MeshとLifeWellの比較

| 機能 | LifeWell | Mesh |
|---|---|---|
| 生活に関わる人物ごとの記録 | あり | あり（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://me.sh/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Meshの価格ページには、家系図、思い出、声での入力、共有リンク、健康記録、メモ、データのダウンロード、Androidアプリ、家族向けプランへの記載がありませんでした。

MeshにはiOSアプリがあります。LifeWellにはなく、iPhoneではSafariで動作します。
