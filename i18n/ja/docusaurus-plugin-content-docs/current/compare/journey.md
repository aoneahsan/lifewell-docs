# JourneyからLifeWellへ移る

Journeyは日記アプリです。期限なく使える無料版と、エンドツーエンド暗号化、共有日記、ePub・DOCXへのエクスポートが付く会員プランがあります。

LifeWellは日々だけでなく人についても記録します。思い出は写っている人に結び付けられ、その人の家系図、健康、予定の横に置かれます。

最終確認日：2026-11-26。アプリ上の比較は[LifeWellとJourney](https://lifewell.aoneahsan.com/compare/journey)をご覧ください。

## 日記から人物の記録へ

1. Journeyの会員機能で日記をDOCXかePubにエクスポートし、全文のファイルを保管します。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 日記に登場する人を[人](/domains/people)に追加します。
4. 残したい記録を、写真、日付、場所とともに[思い出](/domains/memories)へ移します。
5. 私的な毎日の日記にはJourneyを使い続けてください。

## JourneyとLifeWellの比較

| 機能 | LifeWell | Journey |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | あり（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | あり（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://journey.cloud/membership" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Journeyの会員ページには、人物ごとの記録、家系図、声での入力、予定、健康記録、メモ、Androidアプリ、家族向けプランへの記載がありませんでした。

JourneyのWebリンクは日記の1件を表示します。LifeWellのリンクが表示するのは家系図、トラッカー、薬などです（[共有](/domains/sharing)）。
