# FamilyAlbumからLifeWellへ移る

FamilyAlbumは子どもの写真と動画を無制限に入れられる無料アルバムです。月ごとに並び、親族と共有でき、印刷物やフォトブックも購入できます。

LifeWellではアルバムを家族全体の記録の中に置きます。写真の横に家系図、健康に関するメモ、予定があります。

最終確認日：2026-11-26。詳しい比較は[LifeWellとFamilyAlbum](https://lifewell.aoneahsan.com/compare/familyalbum)をご覧ください。

## 子どものアルバムを移す

1. [サインイン](/getting-started/first-run)し、子ども、自分、アルバムを見ている親族を[人](/domains/people)に追加します。
2. 初めての日や初めての旅行など、物語を伝える写真を選び、日付と場所を付けて[思い出](/domains/memories)にします。各ファイルは自分のGoogle Driveに保存されます。
3. 写真に写る人を指定すると、その人の記録にも思い出が表示されます。
4. アルバムにはなかった予防接種や薬を[健康](/domains/health)に、予定を[カレンダー](/features/calendar-and-appointments)に追加します。
5. 親族との写真共有にはFamilyAlbumを使い続けてください。LifeWellのリンクで共有できるのは家系図、トラッカー、薬などで、アルバムではありません（[共有](/domains/sharing)）。

## FamilyAlbumとLifeWellの比較

| 機能 | LifeWell | FamilyAlbum |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | あり（<a href="https://family-album.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| メモ | あり | 一部あり（<a href="https://family-album.com/premium" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://family-album.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | あり（<a href="https://family-album.com/premium" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

FamilyAlbumのページには、人物ごとの記録、家系図、声での入力、共有リンク、予定、健康記録、データのダウンロード、Androidアプリへの言及がありませんでした。
