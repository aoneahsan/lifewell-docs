# TickTickからLifeWellへ移る

TickTickはタスク、習慣、カレンダーを各プラットフォームの1つのアプリにまとめます。無料で使え、年額のPremiumもあります。LifeWellにはタスクリストはありません。

LifeWellのカレンダーは人物に関わる予定のためにあり、その人たちに思い出、家系図、健康記録を結び付けます。

最終確認日：2026-11-26。項目ごとの比較は[LifeWellとTickTick](https://lifewell.aoneahsan.com/compare/ticktick)をご覧ください。

## TickTickとLifeWellを併用する

1. [サインイン](/getting-started/first-run)します。
2. TickTickの一覧から、親の薬や子どもの受診など家族に関わるものを探し、その人を[人](/domains/people)に追加します。
3. 家族の一覧のうち日付のある項目をLifeWellの[カレンダー](/features/calendar-and-appointments)へ移します。月表示では記録内のほかの日付付き項目と並びます。
4. 薬の一覧なら、用量、予定、[リマインダー](/features/reminders)とともに[健康](/domains/health)へ入れます。
5. 習慣とタスクはTickTickに残します。

## TickTickとLifeWellの比較

| 機能 | LifeWell | TickTick |
|---|---|---|
| 声で話した内容を書き起こす | あり | 一部あり（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| メモ | あり | 一部あり（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://ticktick.com/about/upgrade" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

TickTickのアップグレードページには、人物ごとの記録、家系図、思い出、共有リンク、健康記録、データのダウンロード、家族向けプランへの言及がありませんでした。

「話す」で作った録音は、削除するまで本人だけに非公開で保管されます。
