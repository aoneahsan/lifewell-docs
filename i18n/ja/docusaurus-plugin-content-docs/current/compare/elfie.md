# ElfieからLifeWellへ移る

Elfieはバイタルや服薬を記録する無料アプリで、健康に関する行動ごとにコインを受け取れます。特典が測定を続ける助けになるなら、使い続ける理由になります。

LifeWellは健康行動にコインや連続記録の特典を付けません。健康記録を人、思い出、予定とともに静かに保管します。任意の紹介ポイントは健康記録とは別の仕組みです。

最終確認日：2026-11-26。比較は[LifeWellとElfie](https://lifewell.aoneahsan.com/compare/elfie)をご覧ください。

## 測定値を移す

1. [サインイン](/getting-started/first-run)します。
2. 血圧は[健康](/domains/health)のトラッカーにあります。残したい値を入力してください。同じ日の2回目の測定値は1回目を置き換えます。
3. 薬と服用予定を追加します。服薬の[リマインダー](/features/reminders)は初期状態で有効です。
4. 親を支えている場合、予定に相手を記録できるので、誰の健診か[カレンダー](/features/calendar-and-appointments)で分かります。
5. コインが継続の助けになるならElfieを残してください。LifeWellは医療上の助言を提供しません。

## ElfieとLifeWellの比較

| 機能 | LifeWell | Elfie |
|---|---|---|
| 薬、健康状態、検査結果の記録 | あり | 一部あり（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.elfie.co/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Elfieのホームページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、予定、メモ、データのダウンロード、Androidアプリへの言及がありませんでした。
