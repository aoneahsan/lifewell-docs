# NotionからLifeWellへ移る

Notionはページ、データベース、カレンダーを自分で組み立てる作業空間で、仕事にも使えます。生活の整理をそこで作るのが好きな人もいます。

LifeWellはすでに形ができています。人、思い出、家系図、健康、予定が結び付いており、自分で設計する必要はありません。

最終確認日：2026-11-26。比較は[LifeWellとNotion](https://lifewell.aoneahsan.com/compare/notion)をご覧ください。

## Notionのデータベースから移す

1. Notionから作業空間をCSVでエクスポートします。HTML、Markdown、PDFも選べます。
2. [LifeWellにサインイン](/getting-started/first-run)し、[人](/domains/people)のインポート画面を開きます。人物データベースのCSVを選びます。最初の列を名前として読むため、名前をそこに置いてください。
3. 各人物の情報と家族関係を追加すると、[家系図](/domains/people)が描かれます。
4. 日付のある行は、必要なら[リマインダー](/features/reminders)付きの[予定](/features/calendar-and-appointments)にします。自由に書いた文章は、フォルダーに整理できるリッチテキストの[メモ](/domains/everyday)へ入れます。
5. 仕事にはNotionを使い続けてください。LifeWellに自由に設計するページやデータベースはありません。

| リマインダー付きの予定 | あり | 一部あり（<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

| 自分のデータをダウンロード | あり | あり（<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.notion.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Notionの価格ページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、健康記録、Androidアプリ、家族向けプランへの記載がありませんでした。
