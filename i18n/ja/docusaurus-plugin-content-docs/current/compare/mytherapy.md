# MyTherapyからLifeWellへ移る

MyTherapyは無料の服薬リマインダーと服薬日記です。製薬会社などの提携先から資金を得ており、医師に渡す健康レポートと服薬計画も作れます。

LifeWellでは薬の記録をその人に結び付け、思い出、家系図、生活のほかの情報と一緒に保管します。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとMyTherapy](https://lifewell.aoneahsan.com/compare/mytherapy)をご覧ください。

## MyTherapyの計画からLifeWellへ

1. MyTherapyで健康レポートと服薬計画を作ります。転記するための一覧になります。
2. [サインイン](/getting-started/first-run)し、[健康](/domains/health)で薬ごとに用量と予定を入力します。実際に服用した分もそこで記録できます。
3. 医師の予約は[カレンダー](/features/calendar-and-appointments)へ入れ、聞きたい質問をチェックリストに付けます。
4. MyTherapyで測定を促されていた血圧、血糖値、体重には、それぞれ[健康](/domains/health)のトラッカーがあります。
5. 医師がMyTherapyのワンタイムコードで計画を見る場合は、引き続き使ってください。LifeWellは医師のシステムへ何も送らず、医療上の助言も提供しません。

## MyTherapyとLifeWellの比較

| 機能 | LifeWell | MyTherapy |
|---|---|---|
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | あり（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | あり（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.mytherapyapp.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

MyTherapyのホームページには、人物ごとの記録、家系図、思い出、声での入力、メモ、Androidアプリ、家族向けプランへの言及がありませんでした。
