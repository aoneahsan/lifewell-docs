# MyHeritageからLifeWellへ移る

MyHeritageは先祖をたどる大きな家系図を作れます。250人までは無料で、記録との一致、写真の修復と着色、DNAの一致を年額プランで提供します。何世代も過去へさかのぼるためのサービスです。

LifeWellは今を生きる世代のためのものです。その人たちの思い出、健康、予定を家系図と同じ記録に置けます。

最終確認日：2026-11-26。同じ事実をアプリ上で並べた[LifeWellとMyHeritage](https://lifewell.aoneahsan.com/compare/myheritage)をご覧ください。

## 今も話す人たちを移す

1. [LifeWellにサインイン](/getting-started/first-run)します。
2. MyHeritageの家系図で今いる人を確認し、[人](/domains/people)に追加します。MyHeritageからのインポートはないため、短い一覧から始めるとよいでしょう。
3. 人物同士を結び付けると[家系図](/domains/people)が描かれます。
4. 古い家族写真は日付と場所を付けて[思い出](/domains/memories)に入れます。ファイル本体はLifeWellのサーバーではなく自分のGoogle Driveに保存されます。
5. 記録の一致候補やDNAの結果はMyHeritageに残します。

## 両者の機能

| 機能 | LifeWell | MyHeritage |
|---|---|---|
| 家系図を描く | あり | あり（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 写真、日付、場所を添えた思い出 | あり | 一部あり（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.myheritage.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

MyHeritageの価格ページには、人物ごとの記録、声での入力、共有リンク、予定、健康記録、メモ、データのダウンロード、家族向けプランへの記載がありませんでした。

LifeWellの家系図は画面で表示でき、印刷はできません。
