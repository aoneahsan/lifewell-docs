# BearableからLifeWellへ移る

Bearableは、長期的な健康状態と向き合う人が、症状、気分、睡眠、服薬の変化を数か月にわたって見比べるためのアプリです。多くの機能は無料で、アプリ内からすべてをエクスポート・削除できます。

LifeWellでは健康記録を、人、思い出、予定など生活のほかの部分と一緒に保管します。

最終確認日：2026-11-26。両者を並べた比較は[LifeWellとBearable](https://lifewell.aoneahsan.com/compare/bearable)をご覧ください。

## 履歴を残してBearableから移る

1. まずBearable内でデータをエクスポートします。
2. [サインイン](/getting-started/first-run)します。
3. 気分と睡眠は[健康](/domains/health)のトラッカーに入力します。同じ日の入力では最後の記録が採用されます。薬は服薬ページへ入れます。
4. 健康状態ごとに継続的な記録を作り、各症状の発生をその下に記録します。
5. 受診予定は、相談したいことのチェックリストとともに[カレンダー](/features/calendar-and-appointments)へ入れます。
6. 受診時に見せるレポートにはBearableを使い続けてください。LifeWellは医療上の助言を提供しません。

## BearableとLifeWellの比較

| 機能 | LifeWell | Bearable |
|---|---|---|
| 薬、健康状態、検査結果の記録 | あり | 一部あり（<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://bearable.app/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://bearable.app/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Bearableのページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、予定、メモ、Androidアプリ、家族向けプランへの言及がありませんでした。
