# TinybeansからLifeWellへ移る

Tinybeansは子どもの日々を残す非公開の写真日記です。祖父母はメールで近況を追えます。そのシンプルなフィードが中心です。

LifeWellは子どもの成長後も使うためのものです。同じ人たちに家系図、思い出、健康を結び付けられ、無料プランの内容もすべて公開しています。

最終確認日：2026-11-26。アプリ上の比較は[LifeWellとTinybeans](https://lifewell.aoneahsan.com/compare/tinybeans)をご覧ください。

## 赤ちゃんの写真を家族の記録へ

1. [サインイン](/getting-started/first-run)し、子どもと日記を見ている人たちを[人](/domains/people)に追加します。
2. 失いたくない写真を日付と場所付きの[思い出](/domains/memories)として追加します。
3. 人物同士を結び付けると[家系図](/domains/people)が表示されます。
4. 祖父母が読むフィードにはTinybeansを使い続けてください。

## TinybeansとLifeWellの比較

| 機能 | LifeWell | Tinybeans |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | あり（<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

確認時、Tinybeansの価格、Premium、プラン、アプリの各ページはいずれも「見つかりません」となり、読める価格がありませんでした。ホームページには、人物ごとの記録、家系図、声での入力、予定、健康記録、メモ、データのダウンロード、Androidアプリ、無料プラン、家族向けプランへの言及がありませんでした。

LifeWellにiPhoneアプリはなく、iPhoneではSafariで使えます（[iOS](/platforms/ios)）。

Tinybeansのページ：<a href="https://tinybeans.com/" target="_blank" rel="noopener noreferrer nofollow">TinybeansのWebサイト</a>。
