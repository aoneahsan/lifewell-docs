# ObsidianからLifeWellへ移る

Obsidianはメモを自分の端末に通常のファイルとして保存します。制限なく無料で使え、同期と公開は有料です。

LifeWellでは自分で設計しなくても、人、家系図、思い出、健康、予定が結び付いた構成を使えます。

最終確認日：2026-11-26。[LifeWellとObsidian](https://lifewell.aoneahsan.com/compare/obsidian)で比較できます。

## ファイルの保管庫から人物の記録へ

1. [サインイン](/getting-started/first-run)します。
2. 人物ごとのメモがあるなら、[人](/domains/people)のインポート画面に名前を1行ずつ貼り付けます。保存前に見つかった全員を確認できます。
3. 各人物のメモ本文を、その人の記録かリッチテキストの[メモ](/domains/everyday)に移します。
4. 健診や記念日など日付のあるメモは、[リマインダー](/features/reminders)付きで[カレンダー](/features/calendar-and-appointments)に入れます。
5. 元の保管庫は残してください。LifeWellで何をしても、Markdownファイルは端末に残ります。

## ObsidianとLifeWellの比較

| 機能 | LifeWell | Obsidian |
|---|---|---|
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| メモ | あり | あり（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://obsidian.md/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Obsidianの価格ページには、人物ごとの記録、家系図、思い出、声での入力、予定、健康記録、データのダウンロード、家族向けプランへの言及がありませんでした。

LifeWellの記録は端末上のファイルではなくデータベースにあります。選択した期間を、テーブルごとに最大5,000行までJSONまたはCSVとして[エクスポート](/your-data/export)でき、PDFの要約もダウンロードできます。さらに必要なら別の期間を選んでください。
