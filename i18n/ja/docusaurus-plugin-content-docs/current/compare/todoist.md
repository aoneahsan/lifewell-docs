# TodoistからLifeWellへ移る

Todoistは今日のタスク、プロジェクト、リマインダーを扱うToDoリストで、無料プランがあります。LifeWellにはタスクリストがありません。今日の作業一覧が必要ならTodoistを使い続けてください。

LifeWellは人に関わる予定と、その人の思い出、家系図、健康記録のためのものです。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとTodoist](https://lifewell.aoneahsan.com/compare/todoist)をご覧ください。

## 両方を使う

1. [LifeWellにサインイン](/getting-started/first-run)します。
2. Todoistのタスクから、息子の歯科や父への訪問など、人物の名前が付くものを探します。その人たちを[人](/domains/people)に追加します。
3. 日付のあるタスクを、聞きたい質問のチェックリストと[リマインダー](/features/reminders)を付けた[予定](/features/calendar-and-appointments)にします。
4. ほかのタスクはTodoistに残します。インポート機能はなく、LifeWellには単なるタスクを置く場所もありません。

## TodoistとLifeWellの比較

| 機能 | LifeWell | Todoist |
|---|---|---|
| リマインダー付きの予定 | あり | 一部あり（<a href="https://www.todoist.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| ずっと無料で使えるプラン | あり | あり（<a href="https://www.todoist.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Todoistの価格ページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、健康記録、メモ、データのダウンロード、Androidアプリ、家族向けプランへの記載がありませんでした。
