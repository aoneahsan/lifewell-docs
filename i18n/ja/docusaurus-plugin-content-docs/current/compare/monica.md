# MonicaからLifeWellへ移る

Monicaはオープンソースの個人向けCRMです。自分のサーバーなら無料で運用でき、ホスト型もあります。人物、関係、会話、「母に電話する」といったリマインダーを簡潔に記録します。

LifeWellはAndroidとWebですぐ使えるホスト型アプリです。同じ人物に、思い出、家系図、健康記録を結び付けます。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとMonica](https://lifewell.aoneahsan.com/compare/monica)をご覧ください。

## Monicaから人物を移す

1. [LifeWellにサインイン](/getting-started/first-run)します。
2. 名前の一覧か連絡先ファイル（`.vcf`）があれば、[人](/domains/people)のインポート画面に貼り付けるか選びます。読み取るのは名前だけで、保存前に全員を確認できます。
3. 各人と自分との関係や、Monicaに残した詳細を手動で入力します。
4. Monicaのリマインダーを、[リマインダー](/features/reminders)付きの[予定](/features/calendar-and-appointments)にします。
5. 人物について書いた内容は、フォルダーに整理できる[メモ](/domains/everyday)へ入れます。
6. 必要なものを移し終えるまでMonicaのサーバーを動かしておいてください。

| 機能 | LifeWell | Monica |

| 家系図を描く | あり | 一部あり（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| リマインダー付きの予定 | あり | 一部あり（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

| 自分のデータをダウンロード | あり | あり（<a href="https://www.monicahq.com/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Monicaのページには、思い出、声での入力、共有リンク、健康記録、Androidアプリ、家族向けプランへの記載がありませんでした。

LifeWellにiPhoneアプリはありません。
