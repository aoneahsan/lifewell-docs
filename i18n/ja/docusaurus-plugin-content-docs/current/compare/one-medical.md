# One MedicalからLifeWellへ移る

One Medicalは医療機関そのものです。米国のプライマリーケアの会員サービスで、対面やビデオで受診でき、アプリからその医療機関の記録を見られます。

LifeWellは医療サービスではありません。複数の医療機関にまたがる予定や健康を、生活に関わる人と一緒に自分で無料で記録する場所です。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとOne Medical](https://lifewell.aoneahsan.com/compare/one-medical)をご覧ください。

## One Medicalでの受診を自分の記録に残す

1. 医療を受けるための会員資格は維持してください。LifeWellは予約を取らず、One Medicalにも接続しません。
2. [LifeWellにサインイン](/getting-started/first-run)します。
3. 対面またはビデオで受診したら、聞いたことと伝えられたことをチェックリストに添えて[予定](/features/calendar-and-appointments)に入れます。
4. 検査結果と薬は[健康](/domains/health)に入れます。
5. 子どもの薬は、大人の用量とは別の一覧に保管します。LifeWellは医療上の助言を提供しません。

## One MedicalとLifeWellの比較

| 機能 | LifeWell | One Medical |
|---|---|---|
| リマインダー付きの予定 | あり | あり（<a href="https://www.onemedical.com/membership/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | 一部あり（<a href="https://www.onemedical.com/membership/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| Androidアプリ | あり | 一部あり（<a href="https://www.onemedical.com/membership/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.onemedical.com/membership/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

One Medicalの会員ページには、人物ごとの記録、家系図、思い出、声での入力、共有リンク、メモ、データのダウンロード、無料プランへの記載がありませんでした。
