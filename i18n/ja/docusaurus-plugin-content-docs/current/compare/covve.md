# CovveからLifeWellへ移る

Covveは、イベントから名刺を何枚も持ち帰る人のためのアプリです。名刺の読み取り、タグ付け、エクスポートができ、座席ごとの月額・年額料金があります。

LifeWellで記録するのは見込み客ではない人たちです。家族や友人の思い出、家系図、健康を無料の記録にまとめます。

最終確認日：2026-11-26。詳しい比較は[LifeWellとCovve](https://lifewell.aoneahsan.com/compare/covve)をご覧ください。

## Covveから私的な連絡先を移す

1. Covveからスマートフォンの連絡先かExcelにエクスポートします。どちらも価格ページに記載されています。その後[LifeWellにサインイン](/getting-started/first-run)します。
2. 表計算ファイルをCSVとして保存し、[人](/domains/people)のインポートページで選びます。取り込まれるのは名前だけで、保存前に一覧を確認できます。見込み客は含めないでください。
3. Androidでは、電話番号欄の横の「連絡先」ボタンで端末の番号を入力できます。LifeWellが読むのは選んだ連絡先だけです。
4. Covveのメモは各人物の記録か[メモ](/domains/everyday)に書き写します。
5. 友人との予定は[カレンダー](/features/calendar-and-appointments)に入れ、必要なら[リマインダー](/features/reminders)を付けます。
6. 名刺の読み取りにはCovveを使い続けてください。

## CovveとLifeWellの比較

|---|---|---|
| 生活に関わる人物ごとの記録 | あり | あり（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| メモ | あり | あり（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | あり（<a href="https://www.covve.com/pricing" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

Covveの価格ページには、家系図、思い出、声での入力、共有リンク、予定、健康記録、Androidアプリ、無料プラン、家族向けプランへの記載がありませんでした。
