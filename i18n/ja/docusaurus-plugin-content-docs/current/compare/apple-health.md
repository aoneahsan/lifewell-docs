# Apple HealthからLifeWellへ移る

Apple HealthはiPhoneとiPadで使います。Apple Watchがあれば、心拍、睡眠、月経周期、聴覚の測定値を自動で集めます。

LifeWellは、AndroidやWebで健康記録を、人生に関わる人、思い出、予定と一緒に保管したい人向けです。

最終確認日：2026-11-26。出典付きの比較は[LifeWellとApple Health](https://lifewell.aoneahsan.com/compare/apple-health)をご覧ください。

## iPhoneの記録からLifeWellへ

1. [Androidアプリ](/getting-started/install-android)をインストールするか、iPhoneならSafariで[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)を開きます。iPhoneアプリはありません。
2. [サインイン](/getting-started/first-run)します。
3. Apple Healthに登録した薬を、用量と服用予定とともに[健康](/domains/health)へ入力します。
4. 残したい体重、血圧、心拍数などの測定値を、各トラッカーに手動で入力します。LifeWellはApple Healthや時計からデータを読み取りません。
5. LifeWellの[カレンダー](/features/calendar-and-appointments)に予定を入力します。外部カレンダーには接続しません。
6. 時計が測る情報には引き続きApple Healthを使ってください。LifeWellは医療上の助言を提供せず、医師のシステムにも接続しません。

## Apple HealthとLifeWellの比較

| 機能 | LifeWell | Apple Health |
|---|---|---|
| 写真、日付、場所を添えた思い出 | あり | 一部あり（<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| アカウントのない人へページを共有 | あり | 一部あり（<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 薬、健康状態、検査結果の記録 | あり | あり（<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 自分のデータをダウンロード | あり | 一部あり（<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |
| 家族で使う1つのプラン | あり | 一部あり（<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">出典</a>） |

AppleのHealthページには価格が表示されず、人物ごとの記録、家系図、声での入力、予定、メモ、Androidアプリ、無料プランへの言及もありませんでした。

iPhoneのSafariでは、LifeWellはAndroidアプリが端末上に設定するリマインダーを予約できません（[iOS](/platforms/ios)）。

Appleのページ：<a href="https://www.apple.com/ios/health/" target="_blank" rel="noopener noreferrer nofollow">Apple HealthのWebサイト</a>。
