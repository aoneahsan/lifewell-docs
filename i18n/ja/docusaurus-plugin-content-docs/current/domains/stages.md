# 人生の段階

毎年同じではない、人生の時期に関わる領域です。

## あなたについての答えで表示が変わる6画面

プロフィールの1つの答えによって、次の画面をメニューに表示するか決まります。

| 画面 | 残せるもの |
|---|---|
| 月経周期 | ほかの人の平均ではなく、自分の履歴に合わせて変わる予測 |
| 妊娠を考える | 時期、検査、メモを、3つのアプリとノートに分けずに記録 |
| 排卵 | 周期の中で妊娠しやすいと考えられる日。周期には個人差があることも示します |
| PCOS | ほかの症状の記録と同じように、症状、受診、医療機関で聞いたこと |
| 更年期 | 数か月にわたる症状の変化を、あとで読み返せる形で記録 |
| 授乳 | 子どもごとの記録に、授乳とその時刻を保存 |

**男性**を選ぶと、これらはメニューに表示されなくなります。ほかの答えではすべて表示されたままで、どちらを選んでも記録は削除されません。

見えなくなっても消えたわけではありません。メニューから外れるだけで、以前の記録は残り、アドレスを直接開けば各画面を使えます。

## 月経周期

`/period`には日付を記録します。次回の予測は一律28日ではなく、**自分の**履歴から計算します。ページには予測の限界も示します。周期が変動すれば予測も変動するため、日付を確定事項として示しません。

## 子どもの記録

`/baby`には幼い時期の記録を残します。全員を混ぜた1つの一覧ではなく、子どもごとに分かれます。

- **授乳・食事** — `/baby/feeding`
- **睡眠** — `/baby/sleep`
- **おむつ** — `/baby/diapers`
- **成長** — `/baby/growth`。表ではなくグラフで表示します
- **節目** — `/baby/milestones`

`/tools/child-growth`は成長グラフに使う公開の計算機で、アカウントなしで利用できます。

## 赤ちゃんの名前

[赤ちゃんの名前](https://lifewell.aoneahsan.com/baby-names)は公開ページです。アカウントは不要で、あなたについての情報も保存しません。
