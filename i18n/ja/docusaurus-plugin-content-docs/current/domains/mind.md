# 心

画面の数は最も少ない領域で、何を外へ出すかについては最も厳しく扱います。

## 日記

`/health/mood-journal`から書けます。気付いたことを、自分へのメモとして残す場所です。ここに書いた内容をアプリが診断のような判断に変えることはありません。

気分、感謝、夢、自由記述など、いくつかの種類があります。行ごとに種類を持つ1つの保存先なので、1か月を4つの別々の一覧ではなく、1か月として読み返せます。

:::note[日記はPDFエクスポートに含まれません]
PDFは印刷して受付に渡したり、机に置いたりする文書です。LifeWellの日記は、その方法で外へ出してはいけない内容です。自分で開くJSONとCSVのエクスポートには含まれます。[形式ごとの省略内容](../reference/export-format.md#what-each-format-leaves-out)をご覧ください。
:::

## ガイド付きセッション \{#guided-sessions}

`/health/breathing`、`/health/meditation`、`/health/sleep-sounds`、`/health/affirmations`、`/health/panic-attack`、`/health/stress-assessment`です。

セッションは、あなたが求めたときだけ記録されます。ここが空欄なら、ページが静かに役割を果たしてきたということです。

## 仕事中の休憩

`/wellness`には、仕事中の短い中断が3つあります。目の休憩、体を動かす休憩、姿勢についての案内です。それぞれ予定を別に設定し、初期状態はオフです。水分は測定項目に記録します。服薬時刻の案内は、薬の一覧を開くとLifeWellの受信箱に表示されます。

14日間に休憩が100回あっても、連続記録にはなりません。途切れたことを気にする必要はなく、何もしない日曜日はただ静かな日曜日です。

## 意図してないもの

気分の点数も、健康指数も、1週間の出来を評価する報告もありません。LifeWellは書いたことを保ち、読み返せる形で示します。それについて判断を下しません。

数字を残したい場合は、[健康](./health.md)の測定項目を使えます。それを決めるのはアプリではなく、あなたです。
