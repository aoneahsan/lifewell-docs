# 思い出

説明文も日付もない写真は、ただのファイルです。この領域では、あとで読み返せるようにする部分を残します。

## 写真と思い出

`/photos`は写真の一覧です。思い出には1枚または複数の写真と、意味を持たせる日付、説明文、場所、写っている人を添えます。

`/memories/create`で作成します。`/scrapbook`はもっと自由で、決まったフォームを埋めずに、残しておきたいものを置けます。

## ファイルの実際の保存先

**自分のGoogle Drive**です。私たちのサーバーではありません。

LifeWellが求めるDriveの権限は、LifeWell自身が作成したファイルにだけ届きます。Drive内のほかの内容は見えません。これは私たちの行動の約束だけでなく、権限自体の性質です。

私たちが持つのはファイルの参照情報で、ファイル自体ではありません。実際には次のようになります。

- Driveの接続を切ると、説明文、日付、アルバムは残りますが、画像を開けなくなります。
- Driveでファイルを削除すると画像は消えます。LifeWellには画像があったことが残ります。
- [エクスポート](../your-data/export.md)には参照情報と説明文が含まれます。画像のデータ自体は、私たちが持っていないため含まれません。

詳しくは[記録の保存先](../your-data/where-it-lives.md)をご覧ください。

## アルバム、タグ、人

- **アルバム**は思い出をまとめます。
- **タグ**は分類をまたいで使えます。同じタグをメモ、思い出、スクラップブックの項目に付けられます。
- **写真に写る人**は、思い出を[人](./people.md)に登録した相手と結び付けます。

最後のつながりには、使う前に知っておきたい結果があります。人の領域を削除すると、存在しなくなる人を指す写真のタグも削除されます。アプリは行数を数えて伝え、選んでいない領域の中で黙って消しません。[1つの領域を削除する](../your-data/delete.md#delete-one-area)をご覧ください。

## 思い出のつながり

`/maps/memories`は、思い出と日付、場所の名前、関連する記録のつながりを示します。場所は自分で入力した名前で、LifeWellが写真から推測した座標ではありません。同じ行を読み、別の地理情報のコピーは作りません。
