# 7つの領域

6つのアプリがあなたの一部ずつを知っていました。どれも、あなた全体を知りませんでした。

LifeWellには、**あなた自身**を囲む7つの領域があります。あなた自身はアカウント、プロフィール、プラン、設定であり、オフにするものではないので7つには含めません。

まず人から始まります。大切な人を加え、その人について知っていることや一緒に過ごした出来事を残します。思い出、日々のこと、共有はそこにつながります。健康、心、人生の段階はその周りにあり、暮らしを支えます。健康も1つの領域ですが、アプリの中心ではありません。

| 領域 | メニューの分類 | 内容 |
|---|---|---|
| [人](./people.md) | 家族と仕事 | 人、家系図、場所、メッセージ、コミュニティ、専門職、献血者 |
| [思い出](./memories.md) | 思い出 | 写真と思い出、メモ |
| [日々のこと](./everyday.md) | 日々のこと | カレンダー |
| [共有](./sharing.md) | 共有 | ほかの人に読むことを許した情報、リンク、パートナーとの共有、届いた返信 |
| [健康](./health.md) | 健康 | 測定項目、薬、食事、運動、症状 |
| [心](./mind.md) | 心 | 日記、呼吸と睡眠、仕事中の休憩 |
| [人生の段階](./stages.md) | 人生の段階 | 月経周期、子ども、成長 |

## アドレスと領域名が一致しない理由 \{#why-the-addresses-do-not-match-the-areas}

`/health/mood-journal`は**心**にあります。`/health/menopause`は**人生の段階**、`/people/share-links`は**共有**にあります。アドレスの先頭は領域名と違いますが、意図してそのままにしています。

これらは2.x版で検索エンジンに登録されたアドレスです。既にリンクした人にとって、そのURLは行き先の約束です。再構築でコードは変えてもアドレスは変えません。全一覧は[変えないアドレス](../reference/addresses.md)をご覧ください。

領域は製品の考え方です。アドレスの先頭は過去から引き継いだ事実で、同じものとして扱いません。

## 領域をオフにする \{#switching-an-area-off}

`/settings?tab=domains`には6つの切り替えがあります。共有も一覧にはありますが、切り替えはありません。ほかの人に読むことを許した内容は、あなたから常に見える必要があるためです。[共有](./sharing.md#why-it-has-no-switch)をご覧ください。

**オフにすると静かになります。次の3点が実際に変わります。**

- メニューに表示されなくなります。
- 以前の記録は、今も後も削除されずに残ります。
- アドレスからページを直接開けます。なぜメニューにないのかを冒頭の1行で説明します。

このパネルに保存ボタンはありません。保存を別に押さないと反映されない切り替えは、操作した時点で変わったように見せてしまいます。そこで切り替えのたびに直ちに書き込み、切り替え自体が確認になります。書き込みに失敗したら元に戻して知らせます。

## 非表示は削除ではありません

意図して分けた2つの操作です。

| 操作 | 場所 | 起こること |
|---|---|---|
| 領域をオフにする | `/settings` → 領域 | メニューから消えます。すべての行は残ります |
| [領域を削除する](../your-data/delete.md#delete-one-area) | `/settings` → あなたの記録 | その領域の行を1つのトランザクションで削除し、件数を知らせます |

前者を望んだ人が後者を実行したら、元には戻せません。後者で確認用の文字を入力させるのはそのためです。

## 表示する画面の決め方

答えは次の2つだけです。

1. **どの領域をオンにしているか** — 上の6つの切り替えです。
2. **あなた自身についての答え** — プロフィールの1項目で、人生の段階に関する6画面の表示が決まります。[初回の利用](../getting-started/first-run.md#the-one-answer-that-changes-what-you-see)をご覧ください。

両方に当てはまる人には、どちらの画面でも同じ説明を表示します。意図した動作です。
