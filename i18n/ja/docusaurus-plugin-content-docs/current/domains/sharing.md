# 共有

初期状態では何も共有されません。

共有は切り替え設定のない唯一の領域で、独自の生活記録を持ちません。ほかの6領域について、誰が何をいつまで読めるかという選択を管理します。選択ごとに個別に止められます。

| メニュー項目 | アドレス | 内容 |
|---|---|---|
| 概要 | `/sharing` | 現在共有中の内容、開いているリンク、待機中の返信 |
| パートナーとの共有 | `/people/connections` | LifeWellアカウントを持ち、あなたとつながった人 |
| リンク | `/people/share-links` | 作成したすべてのリンクと、そこから届いた返信 |
| 共有の管理 | `/people/data-sharing` | 人と項目の一覧。1件ごとに取り消せます |

リンクは無料プランを含むすべてのプランで使えます。

## 切り替えがない理由 \{#why-it-has-no-switch}

ほかの6領域はオフにできます。共有だけはできません。ほかの人に読めるようにした内容を、自分から見えなくしてはいけないためです。`/settings?tab=domains`にも操作のない行として表示されます。何も共有していないなら、空のページになります。

[領域の削除](../your-data/delete.md#people-and-sharing-are-deleted-separately)は別の操作です。すべてのリンクとつながりを一度に終了しますが、登録した人は残ります。

## 3種類のリンク

| 種類 | 起こること |
|---|---|
| **読み取りリンク** | 選んだ内容を相手が開きます。読み取り専用です |
| **収集リンク** | 相手に情報を尋ねます。相手は自分の名前と、希望すればあなたとの関係、生年月日、連絡用メールアドレスを送れます。さらに1件の返信で最大20人を追加できます |
| **読み取りリンクへの追加提案** | 家系図を含む読み取りリンクでは、人の追加を受け付けられます。*載っていない人を追加できる*を選ぶと、開いた人はリンクで既に見えた人につながる人物だけを提案できます |

相手が送った内容が自動で自分の記録に入ることはありません。返信として待機し、読んでから採用するかを決めます。

`/people/share-links`または対象の画面からリンクを作れます。各記録項目と薬のページには**これを共有**、2つの関係図には**この家系図を共有**があります。同じダイアログが開き、対象には初めからチェックが付きます。

## リンクを開ける相手

**アドレスを知っている誰でも開けます。** 長くて推測しにくいアドレスですが、それだけが保護です。通常は7日で期限が切れ、30日または*取り消すまで*も選べます。パスワードを送るときと同じ慎重さで送ってください。取り消さないリンクは3年後も動く可能性があります。

**つながっている1人だけにも送れます。** 既につながった相手を選ぶと、アドレスは作られません。相手は自分の共有ページの*あなたと共有*から、本人としてログインして読みます。つながりを終えると共有も終了します。含む内容の変更や取り消しはいつでもでき、その操作は相手に通知されません。

## リンクに含められるもの \{#what-a-link-can-carry}

記録項目、薬、家系図の3つだけです。1つのリンクに複数を含められ、共有したものごとにタブができます。1つだけならタブは表示されません。

### 記録項目

実際に自分で使っている項目だけを共有できます。タブには、過去7日、14日、90日のグラフ、横の数字、測定値の表が表示されます。表は**日時 · 値 · 単位 · メモ**の順で、新しいものから並び、メモを含めて入力した内容のままです。

血圧は上の数値と下の数値を2つのグラフで示し、目標線はありません。測定値の達成を示す線は、体についての評価をほかの人に見せることになります。LifeWellはその判断をしません。

### 薬

現在の服薬予定として、薬の名前、強さ、量、時刻、メモを読み取り専用で示します。

服用したかどうかは、そのリンクについて*直近14日間の服用状況も含める*にチェックした場合だけ渡ります。選ぶと、服用済みと印を付けた割合、日ごと・薬ごとの服用、飛ばした服用、未服用の件数も見えます。印を付けた時刻、服用について書いた内容、14日より前の情報は見えません。選ばなければ、リンクに含まれないことが表示されます。

この割合が数えるのは印で、錠剤ではありません。飲んでも印を付けなかった分は含まれません。

### 家族または仕事の関係図

家系図は生きているほかの人についての文書で、その人たちはあなたのリンクに載ることを選んでいません。そこで、各リンクで共有範囲を選びます。

| 段階 | 含まれるもの |
|---|---|
| **関係の形だけ** | 各人を呼ぶ名前と、相互の線 |
| **自分が見ている関係図** — 初期状態で選択 | 上の2つに、あなたとの関係と、既に亡くなった人かどうかを追加 |
| **家族の詳細な記録** | 上の4項目に生年月日と記録上の名前を加えた全6項目 |
| **項目を自分で選ぶ** | 同じ6項目を個別に選択 |

- **記録上の名前**は医療機関や銀行で使う名前です。最も広い段階、または自分で選んだ場合だけ渡ります。氏名と正確な生年月日がそろうと、他人が本人になりすます材料になり得ます。
- **生年月日**は全部を渡すか、まったく渡さないかです。氏名の横に年だけを置くと正確に見えますが、実際には不正確です。
- **その人について書いたこと**は、どの段階のどのリンクでも渡りません。

リンクを作る前に、相手が見る文章をダイアログに表示します。あとから広げることも狭めることもできますが、狭めても既に読まれた内容は取り戻せません。

## 相手に見えるもの

ページにはあなたの名前、共有した項目の数、リンクが使えなくなる日付、それより前に終了できることが示されます。家系図のリンクには**このリンクに含まれないもの**もあり、関係図にいる人が何を見られないか分かります。

相手はログインしておらず、リンクが開かれた事実以外は記録されません。あなたの一覧には開かれた回数と最終日時が表示されます。ページは検索エンジンに登録されません。

リンクごとの**相手に見える内容を確認**では、自分の記録を使った同じページを見られます。

> **リンクで見える内容です。** 表示しているのは自分の記録で、ほかの人のものではありません。ここを見てもリンクの閲覧回数には含まれず、ここから内容を送信することもできません。

## 返信と「これを残す」

収集リンクや追加提案から届いた内容は**確認待ちの返信**に並びます。まだ自分の記録には入りません。

- **これを残す**を押すと、含まれる人を自分の記録に加えます。押すまで追加されません。
- **断る**を押しても記録はそのままです。リンクは返答を約束していないため、送った人にはどちらの選択も通知されません。

追加提案では名前の入力を求めないため、返信には*名前のない返信*と、届いたリンクが表示されます。

## リンクを終了する

| 操作 | 起こること |
|---|---|
| **取り消す** | アドレスが直ちに使えなくなります。開いた人にはリンクが終了したと表示されます |
| **編集** | 名前、内容、共有範囲、期限、追加の可否を変えられます。新しい期限は変更した日から数えます |
| **もう一度共有** | 終了したリンクと同じ内容で、新しいアドレスを作ります。再送が必要です。取り消した古いアドレスは復活しません |
| **削除** | 終了したリンクの記録を消します。情報を求めたリンクなら、既読・未読を問わず届いた返信も消えます |

取り消しても、相手が既に読んだことは取り消せません。開いたページは開いたままで、撮られた画面写真も残ります。

## アドレスをコピーして送る

アドレス自体に内容は書かれていません。名前や家系図、共有内容を含まない64文字のランダムな文字列です。メッセージ内で見た人は、開くまで中身を知りません。コピーした端末のアドレスではなくLifeWell自身のウェブアドレスから作られるため、ウェブ用とAndroid用に分かれず、同じリンクをどこへ送ってもブラウザーで開けます。

LifeWellが保存するのは、元に戻せない形にしたアドレスのハッシュと、リンクを見分けるための先頭8文字だけです。完全なアドレスはあなたの端末で作られ、私たちには送られません。そのため、あとから再びコピーしたり送ったりできるのは作成した端末だけです。

作成した端末では、行に**リンクをコピー**と**共有**が表示されます。

> アドレスは`8f3c…`で始まります。この端末で作成し、完全なアドレスを保持しています。ここから再びコピーまたは送信できます。私たちには送られていません。

別の端末では次のように表示されます。

> アドレスは`5d0e…`で始まります。この端末には完全なアドレスがありません。作成した端末だけが保持し、その端末からログアウトすると消えます。この端末から送るには、元のリンクを取り消して新しいものを作ってください。

リンクを取り消すか終了すると、端末からもアドレスが消え、使えないものを再送できなくなります。つながった1人に向けた共有にはアドレスがなく、コピーもできません。**共有**を押すと、ウェブではLifeWell内の共有画面、Androidでは端末の共有画面が開きます。

## 決して外へ出ないもの

- **リンクで指定していないもの。** リンクが含められるのは記録項目、薬、家系図だけです。日記、思い出、写真、メモ、カレンダー、位置情報をアドレスの先で公開する設定は、データベースに存在しません。
- **記録の残り。** 共有ページから、ほかの記録へ進む経路はありません。
- **関係図にいる人がLifeWellを使っているか。** どの共有段階でも表示されません。

関係図の各段階と薬の設定で省かれる内容は、[リンクに含められるもの](#what-a-link-can-carry)に記載しています。
