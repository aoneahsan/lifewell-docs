# LifeWellを作っている人

**LifeWellチーム**が、LifeWellとこのドキュメントを開発・保守しています。

できないことも率直に伝えます。

- **質問は1つの窓口に届きます。** LifeWellチームはそこに届いたメッセージをすべて読みます。
- **まだ完成していないものがあります。** このドキュメントには未完成と明記したものがあります。存在しない機能を説明するより、そのほうが正確です。
- **公開時期は約束しません。** 計画段階のものは、*まもなく*ではなく計画中と書きます。

## 連絡先

アプリの[お問い合わせ](https://lifewell.aoneahsan.com/contact)または[サポート](https://lifewell.aoneahsan.com/support)から連絡できます。

## 協力する

テスト、文章、デザインの確認、まだ誰も気付いていないことなどに協力したい場合は、[参加する](https://lifewell.aoneahsan.com/get-involved)をご覧ください。

## このドキュメント

アプリと並行して[公開リポジトリ](https://github.com/aoneahsan/lifewell-docs)で執筆・保守しています。各ページの末尾に編集リンクがあります。誤りを見つけたら、そのリンクから知らせるのが最短です。詳しくは[協力について](./contributing.md)をご覧ください。

アプリ本体のソースコードは公開されていません。
