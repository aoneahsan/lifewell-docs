# 変更履歴

2.xアプリを全面的に作り直しました。製品は同じですが、コードを一新し、バックエンドも変更しました。

:::warning[3.22.0では記録がリセットされます]
**重要：LifeWell 3.0は新しい状態から始まります。以前のバージョンに入力したデータは引き継がれません。このバージョンでは新しいアカウントシステムを使い、過去の入力内容は移行されません。**

バックエンドを置き換えましたが、**移行手段はありません**。2.xに保存された記録は引き継がれません。実際の利用者がまだいない時点で意図して決めたことですが、利用者から見れば意図したリセットと重大な不具合は同じように見えます。そのため、明確にお伝えします。

2.xに残したいものがあれば、[更新前にエクスポート](../your-data/export.md)してください。
:::

主な変更点は次のとおりです。

- 全面再構築により、速度と軽さを改善しました。家族、思い出、日常を中心に、健康、心、ライフステージをその周りに整理しています。
- 写真とファイルはLifeWellのサーバーではなく、自分のGoogle Driveに保存されます。
- どの端末でもGoogleでサインインします。

以下では、これらを詳しく説明します。

## 2026年10月29日

- **スマートフォンでホーム画面がより早く表示されます。** スタイルをページ内に含めたため、最初の画面が別ファイルを待たずに表示され、起動時の最長の待ち時間も短くなりました。
- **プロフィールのリンクで持ち主が分かります。** スクリーンリーダーはイニシャルとともに「自分のプロフィール」と読み上げ、新しいタブを開くリンクもそのことを伝えます。
- **全ページでブラウザーのセキュリティポリシーを適用します。** スクリプト、通信、フレームの読み込みを許すサービスを列挙し、それ以外はブラウザーが拒否します。
- **非公開ページを検索エンジンにホームページとして提示しません。** アプリ内のURLは検索エンジンに掲載しないよう指定します。
- **存在しない手順番号をURLから取り除きます。** *LifeWellの使い方*に6つ以外の手順番号でアクセスすると、最初の手順へ移り、不要な番号がURLから消えます。

## 2026年10月27日・28日

- **本人確認書類の画像を保存・削除できます。** 人物の書類の表裏を追加すると両方保存され、書類を削除すると画像も消えます。[本人確認書類の画像](../domains/people.md#identity-card-pictures)をご覧ください。
- **Familyの座席について通知が届きます。** 家族としてつながっている人に座席を渡す、または取り戻すと、その人の受信箱に通知されます。
- **名前が長すぎる場合に理由を示します。** 名前の上限は60文字です。超える場合は「60文字を超えています。名やAmmiだけで十分です」と表示します。
- **権限ページにAndroidの3つの権限を追加しました。** インストール時に許可されるアプリアイコンの件数表示、通知の受信、Google Playでの購入です。[`/permissions`](https://lifewell.aoneahsan.com/permissions)をご覧ください。
- **アプリアイコンを変更しました。** アイコン、ブラウザーのタブ、Androidの起動画面に、アプリのヘッダーと同じマークを使います。Androidアプリには次回のGoogle Play更新から反映されます。

## 2026年10月：3.23から3.25

バージョン3.25.0はGoogle PlayとWebで公開されています。Webアプリは自動更新され、Androidアプリは同じ変更をアプリ内更新で受け取ります。

- **人から始まる構成に。** ホームページには「人生をともにする人と、その瞬間を一か所に」と表示します。メニューは自分、家族と仕事、思い出から始まり、スマートフォン下部には「今日」「人」「話す」「思い出」「もっと見る」が並びます。[人](../domains/people.md)をご覧ください。
- **大切なページにツアーを追加しました。** ヘッダーにツアーボタンがあり、各ページには一度だけヒントが表示されます。スマートフォンでもデスクトップでも、スキップ、終了、任意の手順への移動ができます。[`/how-lifewell-works`](https://lifewell.aoneahsan.com/how-lifewell-works)では実際の画面を使ってアプリ全体を案内します。[ツアーと使い方](../getting-started/tours-and-walkthrough.md)をご覧ください。
- **ジョブ。** エクスポートと「話す」が読み取っている録音を`/jobs`で確認でき、エクスポートが完成すると通知されます。[ジョブ](../your-data/export.md#jobs)をご覧ください。
- **最初の表示を高速化しました。** 公開ページはスクリプトの実行前から内容が表示されます。
- **チャットで予定を共有できます。** *記録から共有*では、今後の予定へのリンクを送ります。記録の複製は送りません。[チャットで予定を共有](../features/community-and-chats.md#sharing-an-appointment-in-a-chat)をご覧ください。
- **権限ページにマイクを記載しました。** Webでは「話す」で録音するときだけブラウザーがマイクの許可を求めます。[`/permissions`](https://lifewell.aoneahsan.com/permissions)をご覧ください。
- **無料枠が使えない間もAIが動作します。** 無料のAI利用枠は時間単位で割り当てられます。利用できない場合、低コストの有料モデルが通常のプラン内の枠で応答します。追加の枠や請求はありません。[プライバシーポリシー](https://lifewell.aoneahsan.com/privacy)には、関係するAIサービスをすべて記載しています。

## 2026年9月25日

- **価格は米ドルです。** Proは月額$9.99または年額$99.90です。Familyは1座席あたり月額$8.99または年額$89.90で、3座席から上限なく選べます。購入後に、すでに家族としてつながっている人へ座席を割り当てます。座席を渡しても何も共有されず、どちら側からでも終了でき、プランが終了すればすべての座席も終了します。Androidの購入経路にはGoogle Play Billingを使いますが、端末とストアでの確認が済むまで無効です。アプリから別の購入ページへ案内することはありません。[プラン](../plans.md#family-seats)をご覧ください。
- **連絡先から番号を選べます。** 電話番号欄の横にある*連絡先*ボタンから、番号を1つ選べます。Androidでは連絡先の読み取りと変更が1つの権限として求められますが、LifeWellが読むのは選んだ連絡先だけで、端末の連絡先を書き換えません。[人](../domains/people.md#choosing-a-number-from-your-contacts)をご覧ください。
- **記録内の人物の本人確認書類の画像。** 表裏をLifeWellで暗号化して保管し、確認のために管理者だけが開けます。本人、登録した利用者、リンクの閲覧者には表示されません。[人](../domains/people.md#identity-card-pictures)をご覧ください。
- **メニューを短くしました。** ページに星を付けると、最大12件をメニュー上部の*お気に入り*に置けます。下部の*すべてのページ*には全ページがあり、各ページ末尾には*ほかの…*の行を置きました。*サインアウト*も、スマートフォンでは名前の下、デスクトップではサイドバーの下部、プロフィール、および設定 → セキュリティの先頭から見つけられます。
- **つながりの招待は1回の依頼です。** 相手の記録にメールアドレスがない、自分のアドレスを指定した、依頼を送りすぎた場合は、送れない理由をアプリが示します。

## 2つのバージョン番号

ストアの掲載名は**LifeWell 3.0**で、ビルドのバージョン文字列は**3.22.0**です。同じリリースを指します。

LifeWellのバージョン名の中央の数字はAndroidのバージョンコードです。このリリースは22なので、表記は3.22.0でなければなりません。一致しなければビルドが失敗します。各バージョンのリリースノートは[Google Playの掲載ページ](https://play.google.com/store/apps/details?id=com.aoneahsan.lifewell)にあります。

## バックエンドの変更

2.xで使用した文書データベースからPostgresに移しました。

流行に合わせた変更ではありません。2.xは1日の無料読み取り枠を使い切り、リセットされるまで実際の利用者全員が1日使えなくなりました。また、記録の一部を指定した相手だけに共有することは行単位の判断です。Postgresなら、各クエリと整合を保つ別の規則ファイルではなく、データベース内で制御できます。

利用者に関わる変化は、読み取り枠の枯渇がなくなり、一覧はデータベースで件数が制限され、共有の規則もデータのある場所で適用されることです。

## トラッカーの保存先を1つに

`/tracking`、`/health/water`、ダッシュボードのクイック操作は、同じ数値を書き込む3つの場所でしたが、内容がずれることがありました。今は1つの保存先を3か所から見ています。どこで記録した水1杯も、すぐにすべての場所に表示されます。

## このリリースの新機能

- **[カレンダーと予定](../features/calendar-and-appointments.md)**。各予定にチェックリストを付けられます。
- **[リマインダー](../features/reminders.md)**。Android端末自身が届け、3つの主設定と端末単位の通知しない時間帯があります。
- **[コミュニティとチャット](../features/community-and-chats.md)**。グループ、投稿、返信、メッセージ、ブロック、報告者を投稿者に知らせないモデレーション経路があります。
- **[専門家](../features/professionals.md)**。確認が証明する内容は1つに限られます。
- **[献血](../features/blood-donation.md)**。連絡先の開示は1回だけで、取り消せます。
- **[買い物リスト](../features/shopping-list.md)**。プレーンテキストで共有できます。
- **[6つのエリアの切り替え](../domains/overview.md#switching-an-area-off)**。内容を削除せずにエリアを無効にできます。
- **[共有](../domains/sharing.md)**。7つ目のエリアで、切り替えがない唯一のものです。リンクでは、トラッカー、薬、家系図を選んだ範囲で表示でき、共有対象ごとにタブがあります。
- **[性別に応じた画面](../getting-started/first-run.md#the-one-answer-that-changes-what-you-see)**。1つの回答によって、6つのライフステージ画面を一覧に表示するか決まります。
- **[3形式でのエクスポート](../your-data/export.md)**。端末上で作成され、有料プランでは定期エクスポートもできます。
- **[外観設定パネル](../concepts/appearance.md)**。8つの設定が最初の表示前に適用されます。
- **[管理パネル](../admin.md)**。直接書き換えられない監査ログを備えた10画面があります。
- **[紹介プログラム](../features/referrals.md)**。サーバー側の仕組みです。

## 削除したもの

- **iOS。** Apple Developerアカウントがないため、2026年7月16日に削除しました。[iOS](../platforms/ios.md)をご覧ください。
- **3.0.0リリース時のブラウザー拡張機能。** このリリースの対象外でした。その後ChromeとFirefox用の別の補助拡張機能を作りましたが、どちらもストアでは未公開です。[ブラウザー拡張機能](../platforms/browser-extension.md)をご覧ください。
- **`/health-tools`に表示していた根拠のない人気度。** 2.xでは各ツールの横に出典のない検索数を表示し、一覧の順序にも使っていました。数値は作り物だったため削除しました。
- **ZToolsと重複する計算ツール。** 10件はZToolsへリダイレクトし、ZToolsにない4件を残しました。[ツール](../features/tools.md)をご覧ください。

## 文書内の訂正

2.xの文書には製品について誤った記述がありました。黙って書き換えず、ここで訂正します。
