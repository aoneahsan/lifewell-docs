# このドキュメントへの協力

このドキュメントは[公開リポジトリ](https://github.com/aoneahsan/lifewell-docs)にあります。アプリ自体のリポジトリは公開されていません。

## ページを訂正する

各ページの末尾には**このページを編集**というリンクがあります。GitHubの対象ファイルが開くので、リポジトリを複製せずに変更を提案できます。

間違ったアドレス、古いバージョン番号、もう事実ではない文章など、小さな訂正は特に助かります。先に相談する必要はありません。

## 1つの基準

**ページには、製品が実際にできることだけを書きます。**

当たり前に聞こえるかもしれませんが、3.0.0に向けてドキュメントを最初から書き直した理由です。以前の版は、提供を終了したiOSアプリ、未公開のブラウザー拡張機能、アプリが使わなくなったデータベース、実際とは逆の分析ツール構成を説明していました。意図して書いた誤りではありませんが、どれも事実ではありませんでした。

そのため、次を守ります。

- 未実装なら、*まもなく公開*ではなく**未実装**と書きます。
- 完成していても有効でなければ、その状態を明記します。
- 確認できる数字は記憶ではなくコードから調べます。
- 制限は、制限される機能と同じ段落に書きます。3節先にある注意書きでは、必要な人に届きません。

## 文章の声

読者に直接語りかけます。英語では省略形や感嘆符を使わず、英国式のつづりと文頭だけを大文字にする見出しを使います。

短い文で要点を伝え、次の長めの文で条件や選択の余地を説明します。多くのページはこの形です。形式だけをまねるより、この流れを守るほうが役立ちます。

*empower*、*journey*、*seamless*、*unlock*、*effortless*のような言葉や、記録が途切れたことを失敗と扱う表現は使いません。

## ローカルで確認する

```bash
yarn install
yarn build
yarn serve
```

ビルドはリンクの検証も行います。内部リンクが切れていれば、公開する前に失敗します。

## ここに載せないもの

- 実在のアカウント、メールアドレス、誰かの記録が写った画像など、個人を特定できるもの。
- 認証情報。このリポジトリは公開されています。
- 内部の計画、開発予定、作業一覧。
