# アクセストークンと認証

LifeWellのアクセストークンは、**設定 → ほかのアプリ**で作成する長い秘密情報です。APIリクエストごとに`Authorization: Bearer <token>`として送ります。選んだ権限範囲と有効期限が適用され、1回の操作で取り消せます。利用者に代わって接続するアプリはOAuthを使うため、トークンを渡す必要はありません。

## トークンの作り方は？

1. **設定 → ほかのアプリ → アクセストークン**を開き、**新しいトークン**を選びます。
2. あとで分かる名前を付けます。*キッチンのカレンダースクリプト*なら、*トークン1*より用途が伝わります。
3. 権限範囲と有効期限を選びます。
4. LifeWellはトークンを一度だけ表示します。画面を閉じる前にコピーして安全な場所に保管してください。

以後の一覧には、名前、権限範囲、冒頭の数文字、作成日時、最終利用日時が表示されます。トークン全体は表示されません。トークンを作成するとLifeWellからメールが届くので、心当たりのない作成にも気付けます。

## トークンを再表示できますか？ \{#can-i-see-a-token-again}

はい。**サインインから10分以内**なら再表示できます。トークンの行で**表示**を選びます。

- **サインインから10分未満**：トークンが表示されます。
- **10分以上経過**：LifeWellが理由を示し、**再度サインイン**を案内します。サインイン後は同じ行に戻ります。
- **二段階認証が有効**：10分以内でも、認証アプリのコードが必要です。

何日もサインインしたまま使えるのは便利ですが、盗まれたノートパソコンも同じ状態です。新しいサインインで、操作しているのが本人だと確かめます。再表示は1時間に10回までで、毎回アカウントに記録されます。トークンがメールで送られることはありません。

## 権限範囲とは？

記録の各部分には、最大3つの権限範囲があります。

| 権限範囲 | 許可される操作 |
|---|---|
| `<resource>:read` | その部分を読み取る |
| `<resource>:write` | 追加・変更する |
| `<resource>:delete` | 削除する |

`account:read`は自分のアカウント情報を読み取ります。対象リソースと正確な権限範囲名は[OpenAPIファイル](./api.md#where-is-the-full-reference)に記載されています。

**削除の権限は自動的には付きません。** 書き込みに削除は含まれず、削除権限は画面でも別に表示され、選ぶまで無効です。作成後にトークンの権限を増やすことはできません。追加が必要なら新しいトークンを作り、古いものを取り消してください。管理者権限を持つトークンは作れません。

## トークンの有効期間は？

**30日、90日、365日**から選べます。期限の7日前にLifeWellからメールが届きます。期限後はトークンが使えず、リクエストには`401`が返ります。

## トークンの交換・取り消しは？

- **ローテーション**で新しいトークンを作ります。古いものは、スクリプトに差し替えるため24時間使え、その後取り消されます。それまでは両方が一覧に表示されます。
- **取り消す**とすぐに使えなくなり、次のリクエストには`401`が返ります。確認のため2回押します。ダイアログはありません。

LifeWellアカウントを削除すると、すべてのトークン、接続済みアプリ、Webhook、フィードも取り消されます。

## アプリはトークンなしでどう接続しますか？

AIアシスタントと同じくOAuth 2.1を使います。アプリはLifeWellの同意ページ`https://lifewell.aoneahsan.com/oauth/consent`を開き、次の内容を表示します。

- アプリ名と、承認後に戻るURL。
- 接続するLifeWellアカウント。
- 求める権限。読み取り・書き込み・削除に分けた平易な説明と、個別のチェック欄。削除は最初は選択されません。
- 横並びの**承認**と**拒否**。

二段階認証が有効なら、承認時にコードが必要です。接続後、アプリは**設定 → ほかのアプリ → 接続済みアプリ**に表示され、名前の変更や取り消しができます。取り消すと次のリクエストからアクセスできません。現在のサインイン期限までは待ちません。同意ページについては[AIアシスタント（MCP）](./mcp.md#what-does-the-consent-page-ask)もご覧ください。

## 利用制限は？ \{#what-are-the-rate-limits}

各トークンと接続済みアプリは、1分間に120リクエストを送れます。さらに、アカウント全体の1日上限はプランによって決まり、Freeは5,000件、ProとFamilyは50,000件です。すべてのトークンとアプリで共有するため、トークンを増やしても上限は増えません。設定 → ほかのアプリには、上限と当日の件数が表示されます。すべてのレスポンスに次のヘッダーが含まれます。

| ヘッダー | 意味 |
|---|---|
| `RateLimit-Limit` | 現在の期間に許可されたリクエスト数 |
| `RateLimit-Remaining` | 残りのリクエスト数 |
| `RateLimit-Reset` | 次の期間が始まるまでの秒数 |

上限を超えると、APIは`Retry-After`ヘッダー付きの`429`を返します。指定された秒数を待って再試行してください。

同時に大量のリクエストを送ると、LifeWellが受け取る前にホスティング基盤から`546`が返ることもあります。順番に、または少数ずつ送り、`546`の場合は1秒後に再試行してください。

## エラーの形式は？ \{#what-does-an-error-look-like}

どのルートのエラーも同じ形式です。

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

プログラムでは`code`を判定してください。`message`は人が読むための文で、表現が変わることがあります。失敗したリクエストについて問い合わせる場合は、`correlation_id`を伝えてください。そのリクエストを特定するために使います。

| ステータス | 主な意味 |
|---|---|
| `401` | トークンがない、誤っている、取り消された、期限切れ |
| `403` | 必要な権限範囲がない（`details`に表示）、または再サインインが必要 |
| `404` | そのIDの記録がない。他人の記録も含む |
| `429` | 利用制限に達した。`Retry-After`を確認 |

コードの全一覧は[OpenAPIファイル](./api.md#where-is-the-full-reference)に記載されています。
