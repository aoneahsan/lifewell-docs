# AIアシスタントを接続する（MCP）

LifeWellのMCPサーバーを使うと、依頼に応じてAIアシスタントが記録を読み取り、変更できます。たとえば「今月誕生日を迎える家族は誰？」「木曜日の9時半に歯科の予約を追加して」と頼めます。アシスタントにURLを登録し、LifeWellにサインインして、同意画面で許可する操作を選びます。Claude、ChatGPT、Claude Code、CursorなどMCP対応のアシスタントで利用できます。

## 接続先URLは？

```text
https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

同じURLが**設定 → ほかのアプリ → AIアシスタントを接続**にもあり、コピーできます。トークンをアシスタントに貼り付ける必要はありません。アシスタントがこのURLからLifeWellのサインイン先を見つけ、案内します。

## アシスタントごとの接続方法は？

アプリのメニューは更新で変わることがあります。以下の手順と画面が違う場合は、設定の**コネクター**を探してください。

### Claude

1. Claudeで**設定 → コネクター**を開き、カスタムコネクターを追加します。
2. 上記のURLを貼り付けます。
3. 案内に従ってLifeWellにサインインし、同意画面で承認します。

### ChatGPT

1. ChatGPTで**設定 → コネクター**を開きます。アカウントによっては、先に開発者モードを有効にする必要があります。
2. 上記のURLでコネクターを追加します。
3. 案内に従ってLifeWellにサインインし、同意画面で承認します。

### Claude Code

```bash
claude mcp add --transport http lifewell https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp
```

次にClaude Code内で`/mcp`を実行し、**lifewell**を選び、開いたブラウザーでサインインします。

### Cursor

`mcp.json`にLifeWellを追加します。

```json
{
  "mcpServers": {
    "lifewell": {
      "url": "https://mednqghfhaazsikbmtiz.supabase.co/functions/v1/mcp"
    }
  }
}
```

Cursorで初めて使うときにサインインを求められます。

## 同意画面では何を聞かれますか？ \{#what-does-the-consent-page-ask}

アシスタントが記録にアクセスする前に、LifeWellは`https://lifewell.aoneahsan.com/oauth/consent`で次を表示します。

- **接続を求めるアプリ**と、承認後に戻るURL。
- **接続先のLifeWellアカウント**。複数ある場合は確認してください。
- **許可する操作**。読み取り・書き込み・削除に分けた文と、それぞれのチェック欄。削除は最初は選択されていません。
- 横並びの**承認**と**拒否**。

[二段階認証](./two-step-sign-in.md)が有効なら、承認時にコードが必要です。新しい接続は毎回この画面を通ります。自動で承認されることはありません。

アシスタントに見えるのは、選んだ権限で使えるツールだけです。読み取りのみを許可した場合は変更できません。

## 削除はどう扱われますか？

アシスタントができるのは削除の**準備**までです。実行できるのは本人だけです。何かを消すよう頼むと、削除対象を示し、LifeWellへのリンクを渡します。10分以内にLifeWell内で確認しなければ、何も削除されません。Webページや貼り付けた文書に紛れた指示では削除を実行できません。アシスタント自身が確認を完了できないためです。

これは同意画面で削除権限を選んだ場合に限ります。許可していなければ、削除の準備もできません。

## 接続を解除するには？

**設定 → ほかのアプリ → 接続済みアプリ**を開き、該当する行の**取り消す**を選びます。次のリクエストからアクセスできません。一覧には権限、接続日時、最終利用日時が表示され、新しい接続も承認後すぐに追加されます。アプリ接続時にはLifeWellからメールも届きます。

## 動かないときは？

| 表示されること | 対処 |
|---|---|
| アシスタントが再サインインを求める | サインインの有効期限が切れています。アシスタントからLifeWellに再度サインインしてください |
| 権限がないと言われる | その権限を許可していません。接続を解除してつなぎ直し、同意画面で選んでください |
| ツール一覧からLifeWellが消えた、または毎回失敗する | 接続が取り消されています。**接続済みアプリ**を確認し、必要なら再接続してください |
| 削除されなかった | 10分以内にLifeWellで確認されませんでした。再度依頼してください |
| 何をしていたか知りたい | **接続済みアプリ**で各アプリの最終利用日時を確認できます |
