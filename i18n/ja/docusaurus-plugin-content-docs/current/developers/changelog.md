# 開発者向け変更履歴

LifeWell API、MCPサーバー、Webhook、カレンダーフィードの変更を、新しい順に記録します。APIのバージョンはURLの`/v1`に含まれ、[OpenAPIファイル](./api.md#where-is-the-full-reference)には、そのURLのバージョンが記述されています。

アプリ自体の変更は[主な変更履歴](../about/changelog.md)をご覧ください。

## 2026年11月19日

- LifeWellで、アクセストークン（設定 → ほかのアプリ）、OpenAPIファイルを含む`/v1` API、AIアシスタント向けMCPサーバー、Webhook、カレンダーフィード、二段階認証（設定 → セキュリティ）を有効にしました。
