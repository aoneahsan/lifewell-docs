# LifeWellをほかのアプリにつなぐ

LifeWellの記録を外部から利用する方法は4つあります。**カレンダーアプリ**はフィード、**スクリプト**はアクセストークン、**AIアシスタント**はMCP、**ほかのアプリ**はWebhookを使います。どれも**設定 → ほかのアプリ**から自分で有効にし、同じページから無効にできます。

## 何に使えますか？

LifeWellを開かずに、記録を確認したいときに役立ちます。たとえば、普段使うアプリで家系図を見たり、LifeWellの予定を仕事の予定と並べてスマートフォンのカレンダーに表示したりできます。

## どの方法を選べばよいですか？

| したいこと | 方法 | できること | はじめに読むページ |
|---|---|---|---|
| LifeWellのカレンダーをGoogle Calendar、Apple Calendar、Outlookに表示する | カレンダーフィード | カレンダーの読み取りのみ | [カレンダーフィード](./calendar-feeds.md) |
| 自分のコードから記録を読み取り、変更する | アクセストークンとAPI | トークンに許可した範囲の操作 | [認証](./authentication.md)、次に[API](./api.md) |
| Claude、ChatGPT、Claude Code、Cursorに記録について質問する | MCPサーバー | 同意画面で許可した操作 | [AIアシスタント（MCP）](./mcp.md) |
| 変更をすぐにほかのアプリへ知らせる | Webhook | イベントの受信。ほかの記録は読み取れません | [Webhook](./webhooks.md) |

## どの方法にも共通することは？

- **自分で有効にするまで接続はありません。** 新しいアカウントには、トークン、フィード、接続、Webhookはありません。
- **削除の許可は別です。** 読み取りや書き込みを許可しても、削除は自動的に許可されません。削除は別の権限で、明示的に選ぶまで無効です。AIアシスタントによる削除には、LifeWell内での確認も必要です。
- **接続をすべて確認できます。** 設定 → ほかのアプリに、トークン、接続済みアプリ、Webhook、フィードと、それぞれの最終利用日時が表示されます。
- **ほかの人の記録にはアクセスできません。** リクエストには、アプリ内と同じアクセス規則が自分の権限で適用されます。

二段階認証を有効にすると、トークンの再表示や新しい接続の承認にコードが必要です。詳しくは[二段階認証](./two-step-sign-in.md)をご覧ください。

## 変更履歴はどこにありますか？

API、MCPサーバー、Webhook、フィードの変更は[開発者向け変更履歴](./changelog.md)にまとめています。
