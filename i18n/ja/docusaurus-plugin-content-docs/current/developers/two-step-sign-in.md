# 二段階認証

二段階認証を有効にすると、Googleでのサインイン後に、認証アプリが生成する6桁のコードが毎回必要になります。Googleアカウントにほかの人が入れたとしても、スマートフォンがなければLifeWellの記録には入れません。一般の利用者には任意で、管理パネルを使う人には必須です。

## 有効にするには？

1. **設定 → セキュリティ → 二段階認証**を開きます。
2. Google Authenticator、Microsoft Authenticator、1Password、Bitwardenなど、6桁のコードを生成する認証アプリでQRコードを読み取ります。読み取れない場合は、その下に表示されるキーを入力します。
3. アプリに表示されたコードを入力します。LifeWellがコードを受け付けると有効になります。

## 復旧コードとは？

有効にすると、LifeWellは**10個の復旧コード**を一度だけ表示します。スマートフォンを紛失または初期化した場合、各コードで1回サインインできます。ダウンロードするか、スマートフォン以外の場所にコピーして保管してください。

- 各コードは1回だけ使えます。
- 使うと二段階認証が無効になり、新しいスマートフォンでの再設定画面に進みます。
- **新しいコードを作る**と10個すべてが置き換わり、古いコードは使えなくなります。先に現在のコードが必要です。

## 「このブラウザーを7日間記憶する」とは？

コードを入力すると、サインイン画面に**このブラウザーを7日間記憶する**が表示されます。初期状態では選択されておらず、自分で選ばない限りそのままです。

- **選ばない場合**、次のサインインでもコードが必要です。
- **選んだ場合**、この端末のこのブラウザーでは、その時点から7日間コードを省略できます。ほかのブラウザーや端末では引き続きコードが必要です。

サインアウトすると、そのブラウザーの記憶は終了します。**設定 → セキュリティ → 信頼済みブラウザー**には、記憶した日時と有効期限が表示されます。**忘れる**で1つ、**すべて忘れる**ですべてを終了できます。二段階認証を無効にした場合も、すべて終了します。

記憶済みのブラウザーでも、アクセストークンやWebhookのシークレットの表示、二段階認証の変更、管理パネルの利用にはコードが必要です。

## ほかにどんなときコードが必要ですか？

- **トークンやシークレットの再表示**：[アクセストークン](./authentication.md#can-i-see-a-token-again)をご覧ください。
- **新しいアプリやAIアシスタントの承認**：[AIアシスタント](./mcp.md#what-does-the-consent-page-ask)をご覧ください。
- **二段階認証を無効にする場合**：現在のコードが必要です。

## 管理者にも必要ですか？

はい。そのセッションでコードを入力しなければ、LifeWellの[管理パネル](../admin.md)は開けません。記憶済みのブラウザーだけでは足りません。
