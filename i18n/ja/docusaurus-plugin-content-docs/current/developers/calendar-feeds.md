# カレンダーフィード

カレンダーフィードを使うと、普段使うカレンダーアプリにLifeWellの予定を表示できます。**設定 → ほかのアプリ → カレンダーフィード**でフィードを作り、URLをコピーして、Google Calendar、Apple Calendar、Outlookなど`.ics`購読に対応したアプリに登録します。フィードは読み取り専用です。カレンダーアプリからLifeWellの予定は変更できません。

## 購読するには？

1. LifeWellで**設定 → ほかのアプリ → カレンダーフィード**を開き、**新しいフィード**を選びます。
2. 表示されたURLをコピーします。
3. カレンダーアプリで**URLから**カレンダーを追加し、URLを貼り付けます。Google Calendarでは*URLから*、Apple Calendarでは*新規カレンダーの照会*に相当します。

フィードを確認する頻度は、LifeWellではなくカレンダーアプリが決めます。数分ごとに確認するアプリもありますが、Google Calendarでは数時間かかる場合があります。そのため、LifeWellでの変更が反映されるまで時間がかかることがあります。

## フィードには何が含まれますか？

[LifeWellのカレンダー](../features/calendar-and-appointments.md)の予定が、過去90日から約13か月先まで、最大2,000件含まれます。フィードから記録のほかの部分にはアクセスできず、非公開のメモも含まれません。

時刻はLifeWellと同じく現地時刻として扱われます。たとえば*歯科の予約が09:30*なら、タイムゾーンを変えても09:30のままです。

## URLは秘密にする必要がありますか？

はい。カレンダーアプリはトークンを送れないため、フィードの認証情報がURLに含まれます。URLを知っている人は、そのカレンダーを読み取れます。このため、フィードで公開される範囲は次のように限られています。

- 読み取れるのは**1つのカレンダー**だけで、記録のほかの部分にはアクセスできません。
- アクセストークンではなく、[API](./api.md)には使用できません。
- 再表示には、トークンと同じ[10分間の規則](./authentication.md#can-i-see-a-token-again)が適用されます。

URLが意図しない場所で共有された場合は、そのフィードを取り消して新しく作成してください。

## フィードを止めるには？

フィードの行で**取り消す**を選びます。以後、そのURLは`404`を返します。カレンダーアプリは次の確認時に予定を削除します。購読するアプリごとにフィードを作れば、1つを取り消してもほかは使い続けられます。
