# ライセンスを確認する

LifeWellのライセンス版にはキーがあり、そのウェブサイトの`/.well-known/lifewell-white-label-license.json`にライセンスファイルが置かれます。[確認ページ](https://lifewell.aoneahsan.com/verify-license)では、どちらからでも調べられます。答えは確認対象のコピーではなく、私たちのライセンスサービスから届きます。

## キーで調べる

| 結果 | 意味 |
|---|---|
| 有効 | ライセンスは有効です。発行先、対象サイト、プラットフォーム、日付を表示します |
| 設定中 | 支払い済みで、コピーはまだ公開されていません |
| 取り消し済み | このキーを使うコピーにはライセンスがありません |
| このキーのライセンスはありません | 証明書に記載されたキーと照らしてください |
| LifeWellのキーではありません | キーは`LIFEWELL-`で始まります |

## ウェブサイトで調べる

| 結果 | 意味 |
|---|---|
| ライセンスあり | サイトのファイルに、そのサイトを対象とする有効なライセンスが示されています |
| このサイトは対象外 | ファイルのライセンスは別の場所を対象としています |
| ライセンスファイルなし | サイトはLifeWellのライセンスファイルを公開していません |
| 接続できませんでした | 数分後にもう一度試してください |

確認結果には公開情報だけが表示されます。メールアドレスや料金は表示されません。

## ライセンス版の内部で

ライセンス版は起動時と再度開かれたときに、自身のキーを確認します。ライセンスが取り消されたか、サイトを対象にしていない場合は、有効でないことを表示します。利用者が記録したものは削除されません。私たちの側で障害が起きても、コピーの動作は止まりません。
