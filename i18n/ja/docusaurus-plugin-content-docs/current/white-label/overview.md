# ホワイトラベルとライセンス

ホワイトラベルライセンスでは、組織が自分たちの名前、ロゴ、色をすべての画面に使ってLifeWellを提供できます。私たちがホストし、組織のドメインで公開し、更新します。買い取りをしない限り、ソースコードの所有者は私たちのままです。

料金と購入フォームは[ホワイトラベルのページ](https://lifewell.aoneahsan.com/white-label)にあります。この節では提供内容を説明します。料金ページは現在の金額を直接読み取るため、ここで数字を重複させません。

## 対象となる組織

人とその暮らしの記録を大切にする組織です。たとえば、家族が親の話を残す介護施設、家族史の団体、福利厚生として提供する雇用主や労働組合、地域や信仰の団体が当てはまります。

## 2つの購入方法

| | ライセンス | 買い取り |
|---|---|---|
| 提供内容 | 組織の名前で私たちが運用するLifeWell | ウェブとAndroidアプリのソースコード |
| 運用する人 | 私たち | 購入者 |
| 独占性 | なし。他の組織にもライセンスできます | あり。ほかの人へのLifeWellの販売を停止します |
| 更新 | 6か月。その後は更新期間の延長が可能 | 6か月。その後は更新期間の延長が可能 |
| 料金 | [プラットフォームごと](https://lifewell.aoneahsan.com/white-label/pricing) | [一括払い](https://lifewell.aoneahsan.com/white-label/buyout)に加え、収益がある限り総収益の7％を使用料として支払います |

購入者のコピーだけに加える変更は[個別の作業](https://lifewell.aoneahsan.com/white-label/custom-work)として、別途見積もります。

## 変わらないこと

ライセンス版を使う人にも、通常のLifeWell利用者と同じ権利があります。入力した内容は本人のもので、選んだ期間を各テーブル最大5,000行の範囲でエクスポートでき、稼働中のアカウントを自分で削除できます。LifeWellは健康管理専用アプリでも、医療機器でも、診療記録でもありません。ライセンス版をそのようなものとして提供することもできません。

分かりやすい説明は[ライセンス条件](https://lifewell.aoneahsan.com/white-label/license-terms)、正式な合意内容は[利用規約](https://lifewell.aoneahsan.com/terms#t-whitelabel)をご覧ください。
