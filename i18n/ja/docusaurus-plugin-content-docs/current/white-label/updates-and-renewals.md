# 更新と期間延長

どのライセンスにも、どの買い取りにも、購入日から**6か月間**の製品更新が含まれます。

## 更新に含まれるもの

LifeWell本体に加わる修正、改善、新機能を、私たちが組織のコピーにも適用します。その組織のためだけの変更は更新ではなく、[個別の作業](https://lifewell.aoneahsan.com/white-label/custom-work)です。

## 6か月が過ぎたあと

コピーは最後に適用されたバージョンで動き続けます。3か月、6か月、12か月のいずれかで更新期間を延長すると、新しい更新が再び届きます。延長期間は現在の期間が終わった日から始まり、既に終了している場合はその日から始まります。

[更新ページ](https://lifewell.aoneahsan.com/white-label/updates)でライセンスキーと発行先のメールアドレスを入力してください。延長料金もそのページに表示されます。
