# ライセンス版を設定する

1. **支払いを行います。** [料金ページ](https://lifewell.aoneahsan.com/white-label/pricing)から進みます。支払いページが開いていない場合は見積もりをお送りします。Wise口座へ銀行振込し、振込の参照番号を知らせてください。入金確認後にライセンスを発行します。戻り先のページでは注文内容を1度だけ確認できます。
2. **メールが届きます。** ライセンスキーと証明書が含まれます。更新時にもキーが必要なので保管してください。
3. **組織名を表示するための情報を伺います。** ドメイン、表示したい名前、ロゴ、色です。AndroidではGoogle Play開発者アカウントへのアクセスも必要です。
4. **組織のドメインで公開します。** アドレスをお知らせし、ライセンスファイルも一緒に公開します。ライセンスの状態が設定中から有効に変わります。

ライセンスが成立するのは入金の確認後だけです。戻り先のページやメールだけで利用権が付与されることはありません。
