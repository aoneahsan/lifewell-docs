# プライバシーとセキュリティ

宣伝文なら省きたくなることも含めて、現状を説明します。

## ログイン

方法はGoogleだけです。パスワード入力欄がないので、**私たちがパスワードを見たり保存したりすることはありません**。保存するパスワード自体がありません。

セッションはウェブではブラウザーの保存領域、Androidではプラットフォームのキーストアに置かれます。すべての端末からログアウトすると、目の前の端末だけでなく全セッションが終了します。

## 別のアカウントからの読み取りを防ぐもの

すべてのテーブルで行単位のアクセス制御を有効にし、読み取りはすべて**本人として**行われます。ブラウザーに管理用キーはなく、アプリがあなたに代わって管理用の経路を使うこともありません。

この仕組みで特に間違いやすい3点を明記します。

- **一覧は拒否ではなく絞り込みです。** Postgresの行単位の制御は、エラーの代わりに少ない行を返します。所有者の条件を忘れたクエリでも動いているように見えるため、すべての一覧読み取りで規則が見る列を条件に使います。
- **規則は実際の行で検証します。** 0行を返すクエリだけでは、どんな規則でも通ったように見えます。テストアカウントには90日分と14日分の測定値を別々に入れ、どちらも管理者にはしていません。
- **すべての一覧に上限があります。** 通常は20行、最大でも50行です。上限はデータベースで守り、テーブル全体を読み進めるクエリはありません。

## 利用状況について集めるもの

4つのサービスを使います。それぞれのキーがない場合は、そのサービスはオフになります。

| サービス | 用途 |
|---|---|
| Google Analytics 4 | 使われたページ |
| Amplitude | 行われた操作 |
| Microsoft Clarity | 画面の使いにくさを調べるセッションの再生 |
| Sentry | エラー |

**どのサービスにも記録の本文は送りません。** 慣習だけでなく許可一覧で守ります。分析情報の項目は、その出来事について登録されたものだけが残り、値も型の検査を通る必要があります。文字列は長さの限られた識別語だけなので、文章、メールアドレス、メモ本文は通りません。数字も小さな0以上の整数に限るため、測定値を件数として送れません。

除去処理の検査では実際の識別子を通し、1つでも残れば失敗させます。コードを読むだけの検証では、後からの退行を見逃します。

セッション再生は出来事ではなく画面を記録するため、特に知っておきたいものです。アプリは機密性の高い要素に印を付け、録画内で隠します。

:::note[Firebase Analyticsは禁止されていません。以前のこのページの説明は誤りでした]
以前のドキュメントにはFirebase Analyticsを禁止し、別のものへ置き換えたと書かれていましたが、誤りです。Google Analytics 4は**Firebaseの分析プロパティそのもの**で、同じプロパティへの2つの接続方法があります。Amplitude、Clarity、Sentryと併用しています。4つを合わせた分析の構成について、逆の説明で読者を誤解させていました。
:::

## 権限 \{#permissions}

[権限ページ](https://lifewell.aoneahsan.com/permissions)には、アプリが宣言するすべての権限と用途を載せています。意図だけでなく、統合後のAndroidマニフェストと照合します。プラグインから権限が加わることがあるため、確認せずにいると誰も選んでいない権限を求めかねません。

SMSや通話履歴の権限は求めません。

### 連絡先

電話番号の横の**連絡先**を押したときだけ求めます。Androidは読み取りと変更を1つの権限で確認するため両方を宣言しますが、LifeWellが読むのはあなたが選んだ1件の名前と番号だけです。保存するのも選んだ番号だけで、連絡先の追加・変更・削除はしません。アドレス帳全体をアップロード、検索、保存することもありません。拒否した場合は番号を手で入力できます。

## ほかの人の身分証の写真

自分の記録にいる人の身分証の表面と裏面を追加すると、LifeWellが暗号化して保持します。自分のGoogle Driveには置かれません。管理者が照合時に開ける必要があるため、写真の中でこれだけがこの方法で保存されます。開けるのはLifeWellの管理者だけで、開いた操作はすべて記録されます。あなたには保存の有無、サイズ、日付が表示されますが、写真自体は見えません。本人、つながりのある人、共有リンクからも見えません。写真を外す、その人を削除する、アカウントを削除する場合は、稼働中の保存先から消えます。暗号化された手動バックアップには入れ替え時まで以前のコピーが残ります。詳しくは[人](../domains/people.md#identity-card-pictures)と[削除](../your-data/delete.md)をご覧ください。

## Familyの席で記録は共有されません

誰かのFamilyプランの席を受け取っても、変わるのは自分のプランだけです。支払う人はあなたの記録、入力、人、ファイルを読めず、あなたも相手のものを読めません。支払う人に見えるのは、あなたが席を持つことと受け取った日付だけです。[Familyの席](../plans.md#family-seats)をご覧ください。

## LifeWellがしない主張

- **エンドツーエンド暗号化ではありません。** 記録は通信中と保存時にデータベース提供元によって暗号化されますが、そのデータベースは内容を読めます。別の説明は事実ではありません。
- **医療機器ではありません。** ここにあるものは診断ではありません。
- **外部広告ネットワークはありません。** あなたについての情報は販売されず、製品に第三者の広告コードはありません。
- **特定時点への復元機能はありません。** バックアップは手動で取り、読み戻して検証します。自分で持てるコピーは[エクスポート](../your-data/export.md)で、だからこそすべてのプランで使えます。
