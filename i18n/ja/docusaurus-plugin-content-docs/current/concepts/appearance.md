# 表示設定

上部バーのアイコンは1つ、パネルも1つです。ログイン前後を問わず、どの画面でもすべての表示設定をそこから開けます。

## 8つの設定

| 設定 | 変わるもの |
|---|---|
| テーマ | ライト、ダーク、システムに合わせる |
| 色 | 強調色と周囲の無彩色 |
| 角の丸み | 各要素の角の形 |
| 密度 | 各行の占める広さ |
| 文字サイズ | 本文だけでなく、文字全体の大きさ |
| 書体 | アプリで使うフォント |
| パネルの見た目 | ページに対するパネルの表現 |
| 動き | 通常または控えめ |

## 最初の描画より前に適用

設定を読み取り、**画面を描く前に**ページへ適用します。アプリが立ち上がる途中で間違ったテーマが一瞬見えることはありません。アプリの実行前に決めるためです。

だから設定を1か所に保存し、1つの表から適用します。部品の中に色や角の丸みを固定すると、このパネルから変更できません。単一の操作で防ぎたいのはその状態です。

## 動き \{#motion}

**動きだけで情報を伝えることはありません。** 動きを控えめにしても、情報は失われません。

設定には*システム*という語ではなく、決定済みの値を保存します。単に`prefers-reduced-motion`だけを使うと、OSが動きを控えめにする人はアプリ内で通常の動きを選べなくなります。一度値を決めることで、*通常*の選択がそのまま反映されます。

## 保存先

選択内容はこの端末に保存されます。同じパネルで**表示設定を端末間で引き継ぐ**をオンにすると、アカウントにも保存され、別のログイン済み端末へ引き継げます。パソコンとスマートフォンで違う表示にしたい場合はオフにしてください。それぞれの端末が独自の選択を保ちます。

## コントラストと操作対象

すべての画面はAAのコントラスト、44ピクセル以上のタッチ対象、見えるフォーカス、キーボードからの全操作を基準に作られています。画面幅320～1920ピクセルでもレイアウトが保たれます。
