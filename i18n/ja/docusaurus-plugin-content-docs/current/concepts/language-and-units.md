# 言語と単位

## 言語を選ぶ

LifeWellは英語、簡体字中国語、ヒンディー語、スペイン語、アラビア語、フランス語、ブラジルポルトガル語、ロシア語、日本語、ウルドゥー語に対応します。上部バーから選んでください。アラビア語とウルドゥー語では、右から左へ自然に読めるようページの向きも変わります。

選んだ言語は、別の端末でLifeWellにログインしたりブラウザー拡張機能を接続したりすると引き継がれます。測定値の単位の選択は変わりません。ドキュメントと公開ページには言語別のアドレスがあるため、相手が読む言語のページへ直接リンクできます。

翻訳ファイルを読む場合は、次の2点を知っておくと便利です。

- **キーは英語の文章ではなく意味を表します。** 文を言い換えても参照先は変わりません。
- **訳した断片をつないで文を作りません。** 語順は言語ごとに違うため、値を差し込める1つのキーに1つの文を入れます。

## 単位は言語ではなく好みで選ぶ

メートル法かヤード・ポンド法かは、プロフィールで選ぶ**自分の設定**です。言語とは意図して分けています。英国にいてストーンを使いたい人も、キログラムを使いたい人もいます。画面の言語からは決められません。

内部では**記録を基準となる単位で保存し、読むときに変換**します。このため次のように動きます。

- 好みを変えると、履歴が新しい単位で表示されます。履歴そのものは書き換えません。
- 各入力には記録時の単位が残ります。好みの変更で12年分の測定値を黙って違う意味にしません。

## 日付、数値、週の始まり

日付と数値は選んだ言語に合わせ、端末の国際化機能で表示します。英語では*8 September 2026*と表示される日付も、ほかの言語では順序が変わります。週の始まりは別の端末設定なので、言語を変えても勝手には移動しません。

入力がどの日に属するかはサーバーではなく**自分の端末**から決まります。[データモデル](./data-model.md#the-date-comes-from-your-device)をご覧ください。

## アクセシビリティ

操作できる部品にはReact Aria Componentsを使い、キーボードの動作とスクリーンリーダー向けの情報を各画面が個別に作り忘れないようにしています。

すべての画面はAAのコントラスト、見えるフォーカス、キーボードからの全操作、44ピクセル以上のタッチ対象、幅320～1920ピクセルのレイアウトを基準にします。[動きを控えめにする設定](./appearance.md#motion)は情報を消さずにアニメーションだけを取り除きます。

グラフと同じ数字を読める表も用意するため、値を知る方法がグラフだけになることはありません。
