# オフラインと同期

LifeWellは実際のリクエストが届くか確認します。通信が切れると、全画面の案内が現在のページをその場に保ちます。通信が戻り、新しいリクエストが成功すると案内が消え、ページを再読み込みせずに続けられます。

## 電波がないときにできること

端末設定で**オフラインでも記録を続ける**をオンにすると、通信についての案内に**オフラインで記録を続ける**が表示されます。選ぶと細いオフライン表示とともに現在のページを開けます。対応する測定値、月経周期の日付変更、症状の記録はこの端末に待機させ、通信が戻ってから再送できます。待機できる件数には上限があり、保持できなかった書き込みはそのように表示します。サーバーへの失敗した書き込みを成功したとは伝えません。

端末に既に設定されたAndroidのリマインダーは、通信がなくても届く場合があります。

## できないこと

- **新しいページと、保存されていない画像など。** サービスワーカーはページを保存せず、リクエストを横取りしません。まだ読み込んでいないページを開くには通信が必要です。
- **サーバーからの読み取りと、ほかの書き込み。** メッセージ、コミュニティ、共有、写真、予定、ログインにはサービスへの接続が必要です。端末内の待機は上記の対応する入力種別だけです。
- **オフライン状態での最初の起動。** 閉じたタブから通信なしで立ち上げるためのアプリの保存版はありません。

## 変更が重なった場合

実際の通信が戻ると待機中の変更を再送します。各操作には、再試行しても重複しないよう識別情報が付きます。送信先の記録は、それぞれの規則に従います。

- **合計する**記録では、2件目は別の測定値として加えます。
- **最新を使う**記録では、2件目を訂正として扱います。

水を飲んだ2件は2件のままです。最新値を使う記録では、そのデータ規則に沿って訂正します。待機中の変更は、サーバーに受け入れられるまで別の端末には表示されません。

## 通信についての案内

初期状態では案内がアプリの操作を止め、再試行を選べます。その端末で設定をオンにした場合にだけ、**オフラインで記録を続ける**から先に進めます。その後は細いバーでオフライン状態を示し続けます。再接続時には待機中の書き込みを再送し、表示中の読み取りを更新します。ページの再読み込みはしません。

## 意図して作っていないもの

アプリ全体のオフライン用コピーも、タブを閉じた間のバックグラウンド同期もありません。対応する簡単な入力の待ち行列は、一時的な通信断でも小さな記録を残すための限られた方法です。
