# 記録を削除する

`/settings`の**あなたの記録**を開いてください。この画面では、意図してエクスポートを削除より上に置いています。

## アカウントを削除する

記録全体と、その記録を持つアカウントを削除します。

操作の順序は、**あなたの記録** → **コピーをエクスポート** → **アカウントを削除** → 確認のため`DELETE`を入力 → 直ちにログアウト、記録を削除、です。

稼働中のアカウントには、削除後の一時保存領域はありません。暗号化された手動バックアップには、入れ替え時まで以前の情報が残る場合があります。プライバシーのページで説明しています。アプリはログイン中のセッションを使って削除サービスへ依頼するため、アカウントIDを入力する必要はありません。ログインできない場合は、公開されている[アカウント削除ページ](https://lifewell.aoneahsan.com/delete-account)で支援の依頼方法を確認できます。

## 1つの領域を削除する \{#delete-one-area}

健康や思い出など、選んだ領域の内容を削除して残りを保てます。`/settings` → **あなたの記録** → *1つの領域を削除*から操作します。

- **1つのトランザクション**で処理します。すべてのテーブルの変更が一緒に確定するか、すべて取り消されます。どこまで消えたか分からない状態を残しません。
- 消えた内容を**テーブルごとに件数付きで示します**。
- アカウントの操作記録に1行を残し、後日ただ記録がないと気付くのではなく、削除が実行されたことを確認できるようにします。
- **確認用の文字列**`DELETE HEALTH`や`DELETE MEMORIES`を入力する必要があります。確認はダイアログだけでなくサーバー側でも行います。画面上だけの確認とは異なり、サーバーで守る境界です。

### 知っておきたい連動削除

**人**を削除すると、写真に写る人を示すタグも削除されます。タグが指す人物が存在しなくなるためです。選ばなかった領域で黙って消すのではなく、これらの行も件数に含めて報告します。

### 人と共有は別々に削除されます \{#people-and-sharing-are-deleted-separately}

**人**の削除は、登録した人、家系図、場所を消しますが、共有中の内容には触れません。**共有**の削除は、すべてのリンクを無効にし、つながりを終了し、届くのを待つ返信を削除しますが、登録した人は残ります。連絡先を整理しただけで、医師が読める内容まで黙って終了させないためです。[共有](../domains/sharing.md)をご覧ください。

### 領域の削除後も意図して残るもの

| 残るもの | 理由 |
|---|---|
| 通知 | 配信記録は複数の領域にまたがります。健康を削除しても、共有についての通知を黙って消しません |
| あなたのAIプロバイダーのキー | 個々の領域の内容ではなく、アカウント単位の認証情報です |
| Google Driveとの接続 | 有効な認証情報と外部サービスへの接続です。切断は設定画面の別の操作です |
| Google Playの購入記録 | アカウント単位です。削除すると支払い済みの権利を確認できなくなります |
| AIの利用量記録 | アカウント単位で、上限を数える基になります |

## 非表示と削除は違います

[領域をオフにする](../domains/overview.md#switching-an-area-off)と、すべての行が残ります。領域を削除すると、その領域の行は残りません。だからこそ、この2つは別の場所にある別の操作です。

## 削除が届かないもの

- **自分のGoogle Drive内のファイル。** LifeWellが持つのは参照情報です。記録を削除すると参照情報は消えますが、ファイルはあなたのDriveに残ります。Driveでの削除は自分で行ってください。[記録の保存先](./where-it-lives.md)をご覧ください。
- **ほかの人に送った内容。** 送信したメッセージは、相手の会話にも残ります。
- **アカウントに関する管理操作の監査記録。** 操作者が消せる記録では監査になりません。これらの行はアカウントの削除後も残り、記録の内容ではなく実行された操作を示します。
