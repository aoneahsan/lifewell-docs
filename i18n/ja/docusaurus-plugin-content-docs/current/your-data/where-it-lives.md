# 記録の保存先

保存先は3つあり、それぞれが違うものを持ちます。

| 内容 | 保存先 | 読める人 |
|---|---|---|
| 入力した記録 | Supabaseが運用するPostgresデータベース | あなたと、あなたが[共有した相手](../domains/sharing.md) |
| 写真とファイル | **自分のGoogle Drive** | Googleを通じて、あなた |
| 設定、セッション、下書き | 端末 | その端末を使うあなた |

## 通信が途切れたとき

通常、LifeWellは記録をデータベースに書き込みます。通信が途切れると、実際のリクエストが成功するまで現在のページの操作を止めます。端末の設定で**オフラインでも記録を続ける**を有効にした場合は、対応する測定値、月経周期の日付変更、症状の記録を続けることができます。その変更は端末内で待機し、再接続後に送信されます。

実際の利用では次の点に注意してください。

- 待機中の簡単な記録は、サーバーが受け付けるまで別の端末には表示されません。
- ほかの記録の変更とサーバーからの読み取りには通信が必要です。
- サービスワーカーはページを保存しません。閉じたタブからオフラインでLifeWellを開き直すことはできません。

## 写真は私たちの保存先ではなく、あなたのDriveにあります

LifeWellがGoogleに求める権限は、**LifeWell自身が作成したファイルだけ**に届きます。Drive内のほかのファイルを一覧表示したり、読んだり、変更したりできません。これは私たちの約束だけでなく、権限そのものの制限です。

私たちが持つのはファイルへの参照情報で、ファイル自体ではありません。

| あなたの操作 | 起こること |
|---|---|
| Driveの接続を切る | 説明文、日付、アルバム、タグは残りますが、画像を開けなくなります |
| Drive内のファイルを削除する | 画像はなくなります。LifeWellには、そこに画像があったという情報が残ります |
| 記録をエクスポートする | 参照情報と説明文が含まれます。画像のデータ自体は含まれません |
| LifeWellアカウントを削除する | 参照情報は消えます。ファイルは自分のDriveに残るため、必要ならそこで削除してください |

写真を開くには、あなたが管理するGoogleアカウントが必要です。私たちが管理する保存先に依存させないための選択です。

## データベースで別のアカウントからの読み取りを防ぐ方法

すべてのテーブルで行単位のアクセス制御が有効です。読み取りはすべて**あなたとして**実行されます。ブラウザーに管理用キーはなく、アプリがあなたに代わって管理経路を使うこともありません。

クエリは、自身の条件でデータの持ち主を証明するよう作られています。Postgresの行単位のアクセス制御は、一覧へのアクセスを拒否する代わりに行を*絞り込む*ためです。所有者の条件が抜けてもエラーではなく少ない行が返り、一見問題がないように見えてしまいます。

実際の行を使って確かめられるよう、2つのアカウントにテスト用の記録を用意しました。0行を返すクエリだけでは、どんなルールも検証できないためです。

## バックアップ

このデータベースには特定時点への復元機能はありません。あるかのようには説明しません。バックアップは手動で取得し、一時的なデータベースへ読み戻して件数を比べることで検証し、稼働中のコピーとは別の提供元に保管します。

**自分で持てるバックアップは[エクスポート](./export.md)です。** 無料プランを含むすべてのプランで使えます。人生の記録を預かりながら、コピーを取り出すために料金を求めるべきではありません。

## 端末の外へ出るほかの情報

写真はあなたのGoogleアカウントの保存先へ送られます。分析とエラー報告は[外部サービス](../reference/integrations.md)に記載した先へ送られますが、記録の本文は含みません。エラー報告が示すのは画面と失敗の内容で、入力した文章ではありません。

記録の内容は販売されず、製品に外部広告ネットワークはありません。
