# Android

ウェブ版と同じアプリをCapacitorで包んでいます。アカウントも記録も共通です。

| | |
|---|---|
| アプリID | `com.aoneahsan.lifewell`。変更されません |
| 最低バージョン | **Android 9（API 28）** |
| 現在のソースのバージョン | **3.30.0**。端末で入手できるバージョンはGoogle Playで確認してください |
| 配布先 | [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.lifewell) |

:::note[最低要件はAndroid 7ではなくAndroid 9です]
以前のドキュメントにはAndroid 7.0と書かれていましたが、誤りでした。ビルドの最低SDKは28、つまりAndroid 9です。それ以前の端末にはインストールできません。Google Playは理由を説明せずに一覧を隠すため、ここで明記します。
:::

## 権限

アプリが宣言する権限は[権限ページ](https://lifewell.aoneahsan.com/permissions)で説明しています。最初の5つは機能を使うときに求められ、拒否できます。連絡先に関する2行は1つの確認画面で表示されます。残りはインストール時にAndroidが付与します。

| 権限 | 理由 |
|---|---|
| カメラ | 写真を直接、思い出や記録に加えるため。初めて*写真を撮る*を押したときに求めます。拒否しても端末内の写真を選べます |
| マイク | Speak itで録音するため。録音を押したときに求めます。拒否しても文字入力できます。LifeWellが裏で聞き取ることはありません |
| おおまかな位置 | 専門職のページを開いている間、距離順に並べるため。*現在地を使う*を押したときだけ求め、保存しません |
| 連絡先の読み取り | 電話番号の横の**連絡先**を押して選んだ1件の名前と番号を読み、選んだ番号を入力欄に入れるため。起動時には求めません |
| 連絡先の変更 | 使いません。Androidは読み取りと変更を1つの権限で許可しますが、LifeWellは読み取るだけで、追加・変更・削除しません |
| 通知 | 希望したリマインダーを届けるため |
| インターネット | 記録を同期するため |
| ネットワーク状態 | 同期できるかを把握し、黙って失敗させずに知らせるため |
| 起動時の実行 | 端末の再起動後もリマインダーを保つため |
| スリープ解除 | 予定したリマインダーを届けるため |
| 広告ID | 宣言されています。以下で説明します |

連絡先の利用を断っても、番号を手で入力できます。すべての電話番号欄がどちらでも使えます。アドレス帳全体をアップロード、検索、保存することはありません。

SMS、通話履歴、バックグラウンドでの位置、写真やファイル全体への幅広いアクセスは求めません。

### ビルドから明示的に取り除く2つの権限

通知ライブラリ自身のマニフェストには`SCHEDULE_EXACT_ALARM`と`USE_EXACT_ALARM`が宣言されています。LifeWellはビルド時に**両方を取り除きます**。

Androidでは、時刻を正確に指定するアラームは目覚まし時計やカレンダー向けです。残した場合、この種類のアプリにはGoogleが認めない権限を求めることになり、Android 12以降では権限なしで予定を設定しようとすると、何も設定されずシステムの*アラームとリマインダー*設定が開きます。そのため、リマインダーは正確な時刻を指定せず、予定時刻から数分前後して届く場合があります。

### 広告ID

マニフェストに宣言されています。**アプリに外部広告ネットワークや第三者の広告コードはありません。** ストアへの申告をビルドが可能な動作と一致させるための宣言で、広告を配信していることを示すものではありません。

## Android版に加わる機能

- **端末内のリマインダー**はAndroid自身が届けるため、アプリを閉じていても届きます。[リマインダー](../features/reminders.md)をご覧ください。
- **ネイティブのログイン**では、セッションをウェブの保存領域ではなくプラットフォームのキーストアに置きます。

## プッシュ通知とGoogle Play Billing

### プッシュ通知

プッシュを有効にし、端末の購読が有効になると、LifeWellはOneSignalを通じたチームからの一斉通知を受け取れます。アカウントで起こった出来事について自動でプッシュを送ることはありません。プッシュは、Androidが端末で予定するローカルのリマインダーとは別です。[リマインダー](../features/reminders.md#push-notifications)をご覧ください。

### Google Play Billing

購入処理、サーバーでの検証、Googleの更新通知は実装・コンパイル済みで、Googleの応答から利用権への対応付けは記録済みの応答でテストされています。**実際の購入はまだ行われていません。** サービスアカウントは未設定で、Play経路を有効にする設定も初期状態ではオフです。購入機能はPlayの配布経路からインストールした署名済みビルドでしか試せないため、内部テスト以外では証明できません。[プラン](../plans.md#on-android)をご覧ください。

## 無線での更新 \{#over-the-air-updates}

LifeWellは、対応するAndroidのインストールに署名済みのNative Updateバンドルを適用できます。アプリは適用前にバンドルを検証し、完全に終了してから再起動しても適用済みの更新を保てます。公開検証キーはネイティブビルドに組み込まれるため、そのキーを持たない古いインストールに後から無線更新の機能を加えることはできません。ネイティブコードと権限の更新は引き続きGoogle Playから届きます。新しいバージョンへの更新が必要な場合は、アプリ内のリリース情報でも伝えます。
