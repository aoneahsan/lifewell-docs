# ウェブ

[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)からブラウザーでLifeWellを開けます。Android版とアカウントと記録は共通ですが、端末通知や共有の動作は環境によって異なります。

## ブラウザー

現在のChrome、Edge、Firefox、Safariに対応しています。古すぎて動かないブラウザーでは、壊れた画面を表示する代わりに、起動画面でそのことを伝えます。

## ウェブ版にないもの

一部の操作はブラウザーとOSに左右されます。

- **アプリを閉じていても届く端末内のリマインダー。** 対応する予定や健康に関する通知は、許可されていればAndroidが設定します。ブラウザーのタブを閉じると、その端末通知は届きません。服薬時刻の案内は、薬の一覧を開いたときにLifeWellの受信箱に表示されます。
- **端末標準の共有画面。** ウェブで[買い物リスト](../features/shopping-list.md)を共有すると、システムの共有画面ではなく、明示的にコピーできるアプリ内画面が開きます。

両方の環境で同じアカウントと保存済みの記録を使えます。通知や権限の詳細は各機能のガイドをご覧ください。

## ホーム画面に追加する

多くのブラウザーではインストールを案内し、アイコンとアドレスバーのないウィンドウで開けるようにします。追加のファイルがダウンロードされたり、アプリの動作が変わったりするわけではありません。これはブラウザーの機能です。

## オフライン

通信が途切れると、ウェブアプリは現在のページの操作を止めます。**オフラインでも記録を続ける**を有効にすると、対応する簡単な入力をこの端末に待機させられます。ほかの記録には引き続きサーバーが必要です。オフラインで開くためのページ保存は行いません。[オフラインと同期](../concepts/offline-and-sync.md)をご覧ください。

## 公開ページ

[ツール](../features/tools.md)、赤ちゃんの名前の検索、献血者一覧、ブログ、機能ページ、4つの法的なページにはアカウントなしで開けるアドレスがあります。通常のページとして実際のHTMLで表示され、JavaScriptの読み込み後に文章を組み立てる方式ではないため、検索エンジンやAIの巡回プログラムも同じ言葉を読めます。
