# iOS

**iOS版は2026年7月16日に削除されました。Apple Developerアカウントが用意された場合に再び加えられます。**

## 現在の状態

iPhoneやiPad向けのアプリはなく、TestFlightビルドも、順番待ちの一覧もありません。iOSのプラットフォーム全体をプロジェクトから削除しました。フォルダー、依存パッケージ、ビルド用コマンドは休止中ではなく、存在しません。

理由は技術的なものではありません。App Storeで公開するには有料のApple Developerアカウントが必要で、現在はありません。配布できないiOSアプリを作っても、使える人がいないためです。

## 代わりに使えるもの

**ウェブアプリ**を使えます。[lifewell.aoneahsan.com](https://lifewell.aoneahsan.com)はiPhoneとiPadのSafariで動き、同じ記録を開ける同じアプリです。

ホーム画面に追加すると、アイコンと全画面のウィンドウで開けます。ネイティブ版と比べて使えないのはローカルのリマインダーです。Android版ではOSが予定を設定しますが、Safariに同じ機能はありません。

## 再開する場合

iOSを再び加えるかどうかは、所有者が決めます。Apple Developerアカウントが用意された場合は、このページにそのことと公開バージョンを記します。

それまでは、古い記事や画像、以前のドキュメントにあるiOS対応の説明は、現状と異なるものとして読んでください。
