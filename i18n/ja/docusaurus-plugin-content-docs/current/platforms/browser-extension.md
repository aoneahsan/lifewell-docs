# ブラウザー拡張機能

**ChromeとFirefox向けに完成しています。どちらのストアでもまだ公開されていません。**

## 現在の状態

3.0.0への再構築時には古い拡張機能のフォルダーが残っていました。現在の補助機能は別のWXT拡張機能で、Chrome版とFirefox版があります。どちらのストアにもまだ提出していないため、現時点でインストールできるストアページはありません。

## ブラウザー内で使えるもの

ポップアップでは、閲覧中に水分と休憩のリマインダー、出典付きの一般的な食品の調理情報、予定を確認できます。健康に関するローカル入力と予定の詳細はブラウザーの保存領域に残ります。LifeWellアカウントを接続しても、それらがLifeWellの記録へアップロードされることはありません。

## アカウントを接続する

拡張機能から接続を始めると、LifeWellのウェブサイトが開きます。このブラウザーを承認する前に、両方に表示された短いコードを比べてください。その後、拡張機能は独自のアカウントセッションを受け取り、プロフィールの言語設定を読み取ります。接続は拡張機能から解除できます。

ポップアップにはZaionsのほかの製品が表示される場合があります。これらの自社製品の紹介は、ストアの説明では広告として扱います。
