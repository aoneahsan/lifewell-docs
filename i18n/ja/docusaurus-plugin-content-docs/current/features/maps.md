# つながりと場所

アプリでは`/maps`を**つながり**と呼びます。既に記録した内容の関係を示し、思い出や予定に付けた場所の名前も重ねて見られます。別のコピーを作ったり、地理座標を推測したりせず、元の記録を読みます。

## つながりの表示

| アドレス | 開く内容 |
|---|---|
| `/maps` | すべて、人、場所、位置履歴の層がある「つながり」画面 |
| `/maps/memories` | 思い出を起点に、範囲を限ってつながりをたどる画面 |
| `/maps/notes` | メモを起点に、範囲を限ってつながりをたどる画面 |
| `/maps/people` | 人とその関係を示す図 |

`/maps/full`では周囲のページを取り除き、人の関係図を広く表示します。カレンダーやチャットの内容からもつながりをたどれます。日付と場所の名前は元の記録に結び付いたままです。

## 保存した場所

ここでの場所は、自分で入力した名前です。LifeWellが収集した位置情報ではありません。「場所」の層には、場所の名前が付いた思い出とカレンダーの項目が並びます。保存した場所の情報は[エクスポート](../reference/export-format.md)に含まれます。

## 位置履歴

`/people/location-tracking`と`/people/location-history`は、初期状態では**オフ**の独立した機能です。Android 3.31.0以降に向けて、バックグラウンドの位置記録機能が実装されました。記録を有効にすると、位置情報の権限が別途求められます。既存の履歴は引き続き表示・削除できます。3.31.0のGoogle Playへの公開と実機での検証はまだ終わっていません。現在ストアで配布されている版に、この記録機能があるものとして頼らないでください。

:::note[位置情報は別のアカウントに共有されません]
リンクで共有できるのは記録項目、薬、家系図のいずれかで、それ以外ではありません。位置情報を共有する範囲はありません。これは画面で選択肢を隠しているだけでなく、データベース上の制限です。[共有](../domains/sharing.md)をご覧ください。
:::

## エクスポートに含まれるもの

保存した場所の行と位置の設定はJSONとCSVに含まれます。PDFは座標の一覧を印刷せず、保存した場所の件数を示します。
