# 専門職の一覧

`/professionals`は、自分で掲載を申し込んだ専門職の一覧です。専門職本人は`/profile`から掲載情報を作れます。

## LifeWellは資格を確認していません

この文は一覧の最初の画面にも表示されます。このページで最も大切な説明です。

掲載情報はすべて、その人が自分で入力しています。登録番号を省略せずに表示し、発行元の公開登録簿へリンクします。あなた自身が短時間で確認できるようにすることが、LifeWellが正直に提供できる範囲です。評価点も推薦もありません。

## 本人の申告と確認されたこと

掲載情報には「本人が申告したこと」「LifeWellが確認したこと」「自分で確認する方法」の3列があります。**中央の列はたいてい空欄です。それこそが大事な点です。**

*確認済み*という1つの印では、資格、登録、保険、本人確認、対応可能かという5つの異なる主張を、何を示すか分からない記号に縮めてしまいます。3列なら、どの文章を信じるか、誰に確かめる必要があるかが分かります。一覧に確認済みバッジはなく、管理者が書く列を専門職本人が設定することもできません。

LifeWellが確認できるのは、送ったリンクを本人が押したため**メールアドレスに届くこと**だけです。書き込めるのはサーバーだけで、資格の証明にはなりません。

:::note[登録簿のない申告は承認できません]
管理者は名前を示した専門職の登録簿に照らして確認を記録できます。登録簿を示さない申告は却下のみ可能です。担当者の記憶に頼らず、データベースで守ります。裏付けのない確認を書こうとすると、関数はエラーにします。登録簿なしで認められる確認には意味がありません。
:::

承認も却下も監査記録に残り、却下には理由が付きます。

## 空き時間を提示する

専門職は予約できる時間を公開できます。予約すると**相談**が開きます。これは[会話](./community-and-chats.md#chats)と同じ仕組みで、会話の種類だけが違います。

相談から参照されている予約枠は削除できません。掲載を取り下げるときは、会話を先に終了し、行き先のない予約を残さないようにします。

## 相談とプラン

相談は有料プランの機能です。無料アカウントでは開けず、ボタンを隠すだけでなくサーバーが拒否します。[プラン](../plans.md)をご覧ください。

## エクスポートに含まれるもの

自分の掲載情報、自分が申告した内容、提示した時間、自分について行われた登録簿の確認です。ほかの人の掲載情報は、その人の記録です。
