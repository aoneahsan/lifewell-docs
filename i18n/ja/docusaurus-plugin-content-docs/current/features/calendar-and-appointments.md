# カレンダーと予定

## カレンダー

`/calendar`は、記録にある日付付きの内容を月ごとに見せます。医療用と個人用でカレンダーを分けていません。1週間は、そのように2つに分かれて訪れないためです。

## 予定

`/appointments`には同じ出来事が一覧で表示され、そのうち予定だけに絞られます。

予定には次の内容を残せます。

- 日時と場所
- 会う相手
- **確認リスト** — 聞きたい質問や、持ち帰りたい結果

確認リストは封筒の裏に書いて、駐車場から診察室までの間になくしがちな部分です。予定が終わったあとも一緒に残るため、質問の横に答えを置けます。

## リマインダー

時刻のある予定では、1時間前のリマインダーを設定できます。Androidでは通知が利用可能で許可されていれば、端末から知らせます。ウェブでは予定は保存されますが、タブを閉じた後にブラウザーから知らせることはできません。[リマインダー](./reminders.md)をご覧ください。

## エクスポートに含まれるもの

カレンダー上の出来事は**Calendar**、確認リストは**Appointment notes**としてエクスポートされます。どちらもJSONとCSVに含まれますが、予定のメモはPDFの概要には含まれません。出来事には日付があるため、エクスポート期間を狭めると対象も絞られます。[エクスポート形式](../reference/export-format.md)をご覧ください。

## この機能がしないこと

Google Calendar、Outlookなど外部のカレンダーには接続しません。そこから読み取ることも、書き込むこともありません。LifeWellに登録した予定はLifeWellの中にあります。
