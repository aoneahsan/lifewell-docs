# コミュニティとチャット

## コミュニティ

`/community`にはグループがあり、それぞれで投稿と返信ができます。グループは利用者が新しく作るものではなく、すべてのアカウントに共通の一覧です。

投稿はあなたが書き、グループの人が読みます。個人の記録が自動で添付されることはありません。睡眠についてグループに投稿しても、自分の睡眠記録は公開されません。

## チャット \{#chats}

`/chats`は、つながりのあるアカウント間のメッセージです。1対1か少人数の会話で、[つながり](../domains/people.md#connections-and-groups)から`/chats/new`で始められます。

[専門職との相談](./professionals.md)も同じ仕組みです。会話の種類が違うだけなので、通常の会話と同じように動きます。

### チャットで予定を共有する \{#sharing-an-appointment-in-a-chat}

どの会話にも**記録から何かを共有する**という操作があります。開くと今後の予定が並ぶシートが表示され、それぞれに**共有**ボタンがあります。

- **コピーではなくリンクを送ります。** 相手に見えるのは予定のタイトルと時刻だけで、ほかの記録は含まれません。
- **入力したメッセージも一緒に送ります。** メッセージ欄の内容がリンクの横に届きます。
- **予定を削除するとリンクは開けなくなります。** カードにも予定が表示されなくなります。

あなたの画面には「予定へのリンクで、記録のコピーではありません」、受け取った人の画面には「相手の予定へのリンクで、記録のコピーではありません」と表示されます。今後の予定がない場合はそのことを示し、*カレンダーに追加*する操作を案内します。

チャットにはファイルを添付できないため、クリップのアイコンはありません。会話の先頭には相手の名前と互いに見られる内容を示し、代名詞を推測しません。

## ブロック

相手をブロックできます。これは画面から隠すだけでなく、サーバーで守られます。

誰を表示しないと決めたかも、自分自身の記録です。[エクスポート](../reference/export-format.md)には**ブロックした人**として含まれます。LifeWellを離れる場合にも、コピーを持っておきたい内容の1つです。

## 通報

どの投稿や返信も通報できます。

:::note[通報は送信専用で、送った本人にも読み戻せません]
通報テーブルは投稿者にも通報者にも読み取りを許可しません。通報された投稿を書いた人には、誰が通報したか伝えられません。同じ理由で通報はエクスポートにも含まれません。ダウンロードで管理用の一覧が漏れたら、手順が1つ増えただけで同じ情報漏えいです。
:::

モデレーターは待ち一覧を扱えますが、決定できるのは管理者だけです。役割の追加と同時に投稿を隠す権限まで与えると、十分に確認されていない役割がほかの人の発言を決めてしまうため、2つの権限を分けています。

決定には必ず説明が付きます。投稿者と通報者には、それぞれに向けた文面が表示されます。理由の分からない決定は、後で見直すことも難しくなります。

## エクスポートに含まれるもの

コミュニティへの投稿と返信、参加したグループ、会話とその参加者、**自分が**送ったメッセージ、非表示にしたメッセージです。

相手が書いた言葉は相手の記録なので、あなたのファイルには含まれません。
