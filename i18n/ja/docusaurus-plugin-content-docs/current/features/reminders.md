# リマインダー

`/profile/reminders`、または`/settings`内の同じパネルから設定できます。

## 3つの主な切り替え

| 切り替え | 初期状態 | 対象 |
|---|---|---|
| 服薬リマインダー | **オン** | この端末で薬の一覧を開いた際に、時刻が来ても未記録の服用について受信箱に表示する案内 |
| 予定のリマインダー | **オン** | 通知時刻を設定した予定。Androidでは通知を許可していれば1時間前に知らせられます |
| 健康に関するリマインダー | **オフ** | 目の休憩、体を動かすこと、姿勢について、各ページで自分で選ぶ予定 |

最初の2つは、自分で記録した薬や予定に付随するため、初期状態でオンです。健康のための休憩通知は任意の割り込みなので、オフから始まります。種類をオンにしても、予定や毎日の通知が自動で作られることはありません。

これらは全体を制御する切り替えです。個々の薬のリマインダーは別途オフにできます。服薬の切り替えは、この端末で薬の一覧を開いたとき、LifeWellに受信箱への案内を作らせるかを決めます。既に受信箱にある案内は消しません。

## 通知しない時間

通知しない時間はアカウントではなく**端末に保存**され、設定画面にもそのことが書かれています。同じ人でも、持ち歩くスマートフォンには通知が欲しく、台所のタブレットには不要かもしれません。服薬時刻の案内はLifeWellの受信箱に入るもので、この端末通知の経路ではありません。

## Androidでの動作

対応する予定と健康のリマインダーは、端末通知を許可すると、LifeWellを閉じていてもAndroid自身が届けます。服薬時刻が来て未記録の場合の案内はLifeWellの受信箱に表示され、端末通知やメールは送られません。水分の記録機能は、飲水リマインダーを予定しません。

:::note[LifeWellは正確なアラーム権限を求めません]
Androidは正確なアラームを目覚まし時計やカレンダー向けに制限しています。通知プラグインは初期状態でその権限を宣言しますが、LifeWellはビルドから取り除き、すべてのリマインダーを正確な時刻指定なしで予定します。そのため数分前後して届く場合があります。この種類のアプリにはGoogleが認めない権限を求めても、動作する前に審査で拒否されます。
:::

## プッシュ通知 \{#push-notifications}

プッシュ通知はリマインダーと別です。

- **端末内のリマインダー**は、対応する予定や健康に関する案内から予定され、アプリを閉じていても届きます。
- **プッシュ通知**は、LifeWellチームがOneSignalを通じて送る一斉通知です。アカウントで起こった出来事について、LifeWellが自動でプッシュを送ることはありません。

プッシュは**受信専用**です。LifeWellは端末を購読状態にし、通知を押したときの画面へ案内します。端末ごとに自分でオンにし、ウェブのプッシュは公開サイトでだけ動きます。

権限の許可だけでは購読済みになりません。設定画面に購読状態が表示されます。ウェブでは公開済みのLifeWellアドレスでだけ購読できます。いつ一斉通知を送るかはチームが決めるため、プッシュを有効にしても定期的に通知が届く約束にはなりません。

## リマインダーに表示されるもの

服薬時刻の案内はLifeWellの受信箱に残ります。Androidの対応する予定のリマインダーは、ロック画面にタイトルが表示され、近くの人に読まれる場合があります。ロックを解除するまで内容を隠す設定はAndroid側の通知設定で行い、LifeWell側の設定ではありません。
