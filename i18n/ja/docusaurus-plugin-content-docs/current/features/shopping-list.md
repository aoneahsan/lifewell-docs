# 買い物リスト

食事と献立の領域にある`/diet-plan`から開けます。

## リストの作り方

- **献立から。** 1週間の食事を決めると、材料がリストになります。
- **保存した食事やレシピから。**
- **手入力で。** 献立では分からないものも加えられます。

買い物中に項目にチェックを付けられます。リストは自分の記録に残り、自分で消すまで保持されます。

## アプリの外へ渡す

共有ボタンを押した時点の環境に合わせて方法を選びます。ページを開いた時点では決めません。

| 環境 | 起こること |
|---|---|
| ウェブ | アプリ内の共有画面が開き、明示的にクリップボードへコピーできます |
| Android | 端末標準の共有画面が開きます |

リストは**通常のテキスト**として渡されます。買い物をする人にLifeWell、アカウント、期限付きのリンクは必要ありません。

共有をやめて画面を閉じても、何も起こりません。失敗ではないため、エラーも表示しません。

## エクスポートに含まれるもの

買い物リストと各項目は、JSONとCSVの[エクスポート](../reference/export-format.md)に含まれます。PDFには含まれません。PDFは診察時に渡す概要であり、買い物リストはその読み手に向けたものではないためです。
