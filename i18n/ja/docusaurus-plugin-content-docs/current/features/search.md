# 検索

`/search`は、上部バーの1つの入力欄から、自分のメモ、思い出、人、予定、薬などの記録を探すためのものです。

:::warning[画面はまだ完成していません]
記録を横断するクエリ自体は実装され、公開されています。ただし、検索を開く画面は未完成です。アプリは空の結果一覧を見せる代わりにそのことを伝えます。空の一覧では「自分の記録に一致するものがない」と誤解されるためです。
:::

## 検索対象と対象外

- **自分の記録だけ。** ほかの読み取りと同じ行単位の規則の下で、本人として検索します。不具合があっても別アカウントの行には届きません。
- **公開ページではなく記録。** ブログ、機能紹介、ツールは通常の公開ページです。この入力欄ではなく検索エンジンから探せます。
- **検索エンジンには登録しません。** `/search`には`noindex`を付け、サイトマップからも外しています。検索画面を検索結果に載せると、外部から試される入口になるためです。
