# 献血

## 公開一覧

[献血者一覧](https://lifewell.aoneahsan.com/blood-donors)は公開されており、読むためにアカウントは必要ありません。

一覧には血液型とおおまかな地域が表示されます。**電話番号は表示されません。** 後で追加する予定の機能ではなく、意図した設計です。

## 自分を登録する

`/profile/blood-donor`で一覧への登録を作れます。健康に関する記録は添付されません。献血者の掲載情報は、血液型、地域、現在対応できるかどうかだけです。

## 依頼

自分が送った依頼は`/dashboard/blood-requests`にあります。条件の合う献血者に届き、全員には配信されません。

## 連絡先の開示

献血者が返答を選ぶと、連絡先を**1人に1度だけ**開示します。

これには次の2つの結果があります。

- **開示は取り消せます。** 献血者が取り消すと、依頼した人の画面からも消えます。
- **エクスポートには意図して含めません。** ダウンロードしたファイルの行は一度限りでも、取り消せるものでもありません。依頼した人はアプリで既に見ています。恒久的に残すことを献血者は選んでいません。

自分の掲載情報と送った依頼は[エクスポート](../reference/export-format.md)に含まれます。ほかの人の電話番号は含まれません。

## この機能がしないこと

LifeWellは献血を手配せず、献血の適格性を確認せず、血液センターに連絡しません。これは一覧と依頼の手段です。その後は当事者2人と病院の間で進めてください。
