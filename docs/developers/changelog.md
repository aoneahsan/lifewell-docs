# Developer changelog

Every change to the LifeWell API, the MCP server, webhooks and calendar feeds is listed here, newest first.
The API's version is part of its address — `/v1` — and the [OpenAPI file](./api.md#where-is-the-full-reference)
always describes the version it sits under.

Changes to the app itself are in the [main changelog](../about/changelog.md).

## 19 November 2026

- Switched on in LifeWell: access tokens (Settings → Other apps), the `/v1` API with its OpenAPI file, the MCP
  server for AI assistants, webhooks, calendar feeds, and two-step sign-in (Settings → Security).
