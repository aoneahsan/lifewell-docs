# Moving from Remento to LifeWell

**Weekly spoken prompts turned into written chapters and a hardcover book with a QR code that plays the voice.** Choose Remento if the point is a parent's voice, recorded with no app or login, and a book you can hear. Choose LifeWell if you want one free place for the people, the memories, the tree and the appointments, not a one-year book project.

Last checked 2026-11-07. The full comparison is on [LifeWell and Remento](https://lifewell.aoneahsan.com/compare/remento).

## How to move across

1. [Open LifeWell and sign in](/getting-started/first-run). Start with yourself.
2. Add the people you already have in Remento, one record at a time ([people](/domains/people)). LifeWell does not import from other services, so start with those closest to you.
3. Link them to each other, and the [family tree](/domains/people) draws itself.
4. Add the memories that matter, with a photo, a date and a place ([memories](/domains/memories)).
5. Keep Remento for anything LifeWell does not do, such as historical records or DNA.

LifeWell keeps each Speak it recording privately for you, and you can delete it at any time. It cannot print your tree for a wall, it has no to-do list for today, and it has no iPhone app. It is not medical advice.
