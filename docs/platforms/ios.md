# iOS

**iOS: removed 2026-07-16 — re-added when an Apple Developer account exists.**

## What that means

There is no iPhone or iPad app, there is no TestFlight build, and there is no waiting list. The iOS platform
was removed from the project entirely: the platform folder, the dependency and the build scripts are all gone
rather than dormant.

The reason is simple and it is not technical. Shipping to the App Store requires a paid Apple Developer
account, and there is not one. Building an iOS app that cannot be distributed would be work with no user at
the end of it.

## What to use instead

**The web app.** [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) runs in Safari on an iPhone and an
iPad, and it is the same application with the same record.

Add it to your home screen and it gets an icon and a full-screen window. What you lose against a native build
is the local reminder — those are scheduled by the operating system in the Android build, and Safari does not
offer the equivalent.

## If it comes back

Re-adding iOS is a decision for the owner rather than something that happens quietly. If an Apple Developer
account is ever set up, this page will say so and will name the version it landed in.

Until then, treat any other mention of iOS support — in an old article, an old screenshot, or an earlier
version of this documentation — as out of date.
