# Use LifeWell on the web

There is nothing to install. Open [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com) and sign in.

## Signing in

**Google is the only way in.** There is no email-and-password form, and that is deliberate rather than
unfinished: we never see or store a password, because there is no password to store.

1. Open [lifewell.aoneahsan.com](https://lifewell.aoneahsan.com).
2. Choose **Continue with Google**.
3. Pick the Google account you want the record kept under.

The account you pick is the account the record belongs to. Changing it later means a different record, not a
renamed one.

## What happens next

The first sign-in opens a short setup — five steps, and you can leave most of them blank. It is described in
[The first run](./first-run.md).

## Browser support

LifeWell targets current versions of Chrome, Edge, Firefox and Safari. There is no support matrix beyond
that, and no polyfill layer for older engines: a browser that cannot run the app says so at the boot screen
rather than rendering something broken.

## Adding it to your home screen

The web build is a normal site. Most browsers will offer to add it to a home screen or dock, which gives you
an icon and a window without the address bar. That is a browser feature rather than a LifeWell one — nothing
extra is downloaded and nothing changes about how the app works.

If you want the Android build instead, with local reminders and the platform's own notification handling, see
[Install on Android](./install-android.md).
